## 회의 내용

### GDI 100점 학습 데이터 보완 방안

GDI 100점에 해당하는 보행 데이터를 학습에 활용하기 위해 두 가지 방안을 논의함.

- **기존 보행 데이터 활용** — 건강한 사람의 보행 데이터에 GDI 100점을 부여해 학습에 포함하는 방안을 검토함. 이 방식을 적용하려면 개인마다 보행 특성이 다른 점을 고려해 모든 샘플에 동일한 점수를 부여하는 것이 적절한지 확인할 필요가 있음.
- **생성형 AI 활용** — GDI 100점에 해당하는 보행 데이터를 생성형 AI로 만들어 학습에 추가하는 방안을 검토함. 생성한 데이터를 사용하려면 해당 보행에서 실제로 목표한 GDI 점수가 산출되는지 확인하는 방법이 필요함.

### 가상 카메라를 활용한 촬영 각도별 보행 점수 비교

동일한 3D 보행 데이터를 여러 각도의 가상 카메라에서 바라본 2D 보행 데이터로 변환하는 실험 방안을 논의함. 예를 들어 한 사람의 같은 걸음 동작을 정면, 측면, 대각선에서 본 2D 관절 좌표로 각각 만들고, 이를 모델에 입력해 예측 점수를 비교하는 방식임.

보행 동작은 동일하게 유지하고 관찰 각도만 바꿨을 때 점수가 얼마나 달라지는지 확인하고자 함. 이를 통해 실제 앱에서 보행 영상을 서로 다른 방향에서 촬영하더라도 모델이 일관된 점수를 제공할 수 있는지 평가하고자 함.
