## 회의 내용

### 정상 보행 데이터 추가 효과를 비교하는 실험 설계

뇌성마비 환자 데이터만 학습한 기존 모델과, 같은 환자 데이터에 정상 성인 64명의 보행 영상 881개를 추가해 학습한 모델을 비교함. 정상 성인 영상에는 실측 GDI가 없어 **학습용 가정값으로 100점**을 부여함. 두 모델 모두 2차원 관절 좌표를 입력받아 왼쪽과 오른쪽 다리의 GDI를 각각 예측하며, 정상 성인 데이터 추가의 효과를 확인할 수 있도록 CNN·STT 모델의 구조와 학습 조건을 동일하게 유지함.

### 주요 실험 결과

| 비교 항목 | 기존 모델 | 정상 보행 데이터를 추가한 모델 |
|---|---:|---:|
| 정상 아동의 평균 예측 점수 | 81.8점 | 98.8점 |
| 뇌성마비 아동의 평균 예측 점수 | 72.4점 | 79.3점 |
| 뇌졸중 환자의 마비된 쪽 다리를 더 낮게 평가한 비율 | 65.9% | 80.5% |
| 평가용 뇌성마비 환자 222명의 평균절대오차(MAE) | 6.249점 | 6.375점 |

정상 보행 데이터를 추가한 뒤, 같은 촬영 환경에서 정상 아동과 뇌성마비 아동의 평균 점수 차이가 **9.4점에서 19.5점으로** 커짐. 학습에 사용하지 않은 정상 성인과 건강한 고령자의 평균 예측값도 각각 94.2점과 92.6점으로 나타남. 건강한 성인과 뇌졸중 환자의 3차원 관절각으로 GDI를 직접 계산해 비교했을 때도 정상 보행 데이터를 추가한 모델의 예측값이 계산값에 더 가까웠음.

기존 모델을 다시 학습하지 않고 출력 점수만 조정해 정상 아동 평균을 동일한 98.8점에 맞춘 경우, 환자 평가 오차가 13.714점까지 증가함. 반면 정상 보행 데이터를 추가해 학습한 경우에는 환자 평가 오차가 **0.126점(약 2%)** 증가하는 데 그침.

### 연구 결론 및 한계

정상 성인 보행 영상을 추가로 학습하면 기존 환자 집단에서의 오차 증가는 작게 유지하면서, 새로운 대상자의 정상 보행을 지나치게 낮게 평가하는 문제를 줄일 수 있음을 확인함. 다만 고령자 평가에는 3차원 표지점 좌표를 측면의 2차원 좌표로 변환한 데이터를 사용했고, 정상 성인 학습 영상의 100점은 가정값이었음. 이에 따라 **실제 촬영한 고령자 보행 영상과 실측 GDI가 있는 정상 보행 데이터**를 활용한 추가 검증이 필요하다고 정리함.
