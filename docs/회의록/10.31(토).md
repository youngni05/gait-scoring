## 회의 내용

### GDI 100점에 해당하는 학습 데이터 확보

건강한 사람의 보행 데이터에 GDI 100점을 부여해 학습에 활용하는 방안을 검토함. 이 방식으로 데이터를 추가하려면, 개인마다 보행 특성이 다른 점을 고려할 때 모든 샘플에 일괄적으로 100점을 부여해도 되는지 확인할 필요가 있음.

또 다른 방안으로, 생성형 AI를 이용해 GDI 100점에 해당하는 보행 데이터를 만들어 학습에 추가하는 아이디어를 검토함. 생성된 보행 데이터에서 GDI를 계산했을 때 실제로 목표 점수가 나오는지 확인하는 방법이 필요함.

### 가상 카메라를 활용한 촬영 각도별 점수 비교

하나의 3D 보행 동작을 가상 카메라로 여러 각도에서 바라본 뒤, 각 시점의 2D 관절 좌표로 변환하는 실험을 구상함. 예를 들어 같은 동작을 정면·측면·대각선에서 본 좌표를 각각 모델에 입력하고, 가장 높게 예측된 점수와 가장 낮게 예측된 점수의 차이를 비교하는 방식임.

이를 통해 같은 사람이 같은 동작을 수행했을 때 촬영 방향에 따라 예측 점수가 얼마나 달라지는지 확인하고, 앱에서 촬영 각도가 달라져도 일관된 보행 평가 결과를 제공할 수 있는지 살펴보고자 함.
