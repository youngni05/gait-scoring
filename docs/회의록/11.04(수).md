## 회의 내용

### 논문 주제 및 선행연구와의 차별점

정설영 교수님의 의견을 바탕으로, 지금까지 진행한 작업 중 실험 결과로 설명할 수 있는 내용을 중심으로 논문을 작성하는 방향을 논의함. 연구의 출발점은 **좁은 공간에서 촬영한 보행 영상으로 보행 상태를 점수화할 수 있는가**로 정리함. TUG, SPPB, GDI를 함께 다루는 방안도 제안되었으나, 여러 평가 지표를 한 논문에서 다루기에는 범위가 넓어 우선 GDI 예측에 초점을 맞추는 방향을 검토함.

선행연구인 *Deep neural networks enable quantitative movement analysis using single-camera videos*를 바탕으로, 다음 두 가지 변화가 GDI 예측 성능에 미치는 영향을 살펴보기로 함.

| 비교 항목 | 실험에서 확인할 내용 |
|---|---|
| 모델 구조 | 같은 데이터에서 선행연구의 다구간 CNN과 다구간 CNN에 STT를 결합한 모델의 예측 성능을 비교함. |
| 학습 데이터 | 같은 모델 구조에서 뇌성마비 환자 데이터만으로 학습한 경우와 건강한 사람의 보행 데이터를 추가해 학습한 경우를 비교함. |

### 건강한 사람의 보행 데이터 확보 및 점수 부여

뇌성마비 환자 데이터로 학습한 모델이 건강한 사람의 보행에 대해서도 GDI를 잘 예측하는지는 별도로 확인할 필요가 있다는 의견이 나옴. 이를 검토하기 위해 건강한 사람의 **보행 영상 또는 2D 관절 좌표 데이터**를 찾아보기로 함. 먼저 선행연구의 입력 형식을 확인한 뒤, 후보 데이터의 보행 구간 길이, 촬영 방향, 관절 좌표 형식을 살펴보고 전처리를 통해 같은 조건으로 입력할 수 있는지 검토하기로 함.

건강한 사람의 보행에 일괄적으로 GDI 100점을 부여하는 방안에 대해서도 논의함. **기준 집단의 평균을 나타내는 100점과 개인별 GDI 측정값은 구분할 필요가 있음.** 이에 따라 후보 데이터에 개인별 GDI 정답값이 있는지 먼저 확인하고, 정답값이 없다면 일정한 점수 범위를 가정하는 방식에 근거가 있는지 검토하기로 함. 구체적인 점수 부여 방법은 확정하지 않음.

### 논문 구성 및 작성 순서

논문은 **국문 또는 영문 2~4쪽**으로 작성하며, 개요와 연구 방법을 먼저 작성한 뒤 모델 학습 및 성능 평가 결과를 반영하기로 함.

| 구성 | 작성 내용 |
|---|---|
| 초록(Abstract) | 개요의 핵심 내용을 한 문단으로 요약함. |
| 1. 개요 | 좁은 공간에서 보행 상태를 평가하려는 배경과 기존 검사 방식의 제약을 제시하고, 영상 기반 GDI 예측으로 어떤 문제를 해결하고자 하는지 설명함. |
| 2. 관련연구 | 관련 이론과 유사 시스템을 다룬 논문을 조사하고, 본문에서 인용한 논문은 참고문헌 목록에 포함함. 문헌 조사는 [Google Scholar](https://scholar.google.co.kr/)를 활용함. |
| 3. 시스템 상세 설계 | 입력 데이터의 형식과 전처리 방법, 다구간 CNN과 STT의 구성, 모델 간 비교 조건을 설명함. |
| 4. 시스템 구현 결과 | 모델 학습 및 성능 평가 결과를 제시하고, 모델 구조 변경과 데이터 추가에 따라 예측 성능이 어떻게 달라졌는지 정리함. |
| 5. 결론 | 구현 결과를 요약하고, 개요에서 제시한 문제를 어느 정도 해결했는지와 실험의 한계를 기술함. 성능 향상이 미미한 경우에도 관찰된 결과를 그대로 보고함. |

추가 아이디어로는 **나이를 입력 특성에 포함해 GDI를 예측하는 방법**과 **하나의 모델에서 GDI와 나이를 함께 예측하는 방법**이 제안됨. 두 방안은 후속 검토 사항으로 남김.
