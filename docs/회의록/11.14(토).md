## 회의 내용

### 앱의 목적과 활용 방향

모델의 예측 점수를 한 번 확인하는 기능만으로는 고령자의 어떤 문제를 해결하는지 드러나기 어렵다는 의견이 나옴. 이에 따라 앱의 방향을 **‘영상 기반 보행능력평가 모델을 활용한 고령자 보행능력점수 관리 앱’**으로 정리함. 실제 카메라로 촬영한 보행 영상을 평가에 활용하고, 고령자가 자신의 보행 상태와 점수 변화를 확인하는 것이 운동에 대한 동기부여로 이어질 수 있는지도 논의함.

### 보행 점수와 함께 제공할 지표

현재 모델은 보행능력점수 하나를 출력하므로, 점수와 함께 보여줄 지표의 후보로 **보행주기, 케이던스(분당 걸음 수), 좌우 보행 불균형, 보폭**을 검토함. 모든 지표를 한꺼번에 구현하기에 앞서, 어떤 보행 영상을 촬영하고 어떤 값을 우선 분석할지 정할 필요가 있음.

영상에서 추출한 관절 좌표는 두 가지 용도로 활용하는 구조를 논의함. 보행능력평가 모델에는 좌표를 입력해 **보행 점수**를 예측하고, 별도의 **규칙 기반 분석**에서는 좌표의 시간에 따른 변화를 이용해 세부 보행 지표를 계산하는 방식임. 같은 좌표를 사용하더라도 모델 입력과 지표 계산에 필요한 전처리는 다를 수 있으므로 각 처리 과정에 맞는 입력 형식을 확인하기로 함.

### 개발 일정 및 확인 사항

- **11월 16일(월)까지** — 개발 환경을 설정하고 핵심 API의 동작을 우선 확인하기로 함. 첫 목표는 휴대폰에서 보행 영상을 업로드한 뒤 기기에서 관절 좌표를 추출하고, 정해진 JSON 형식으로 변환하는 흐름을 구현하는 것임. 이 과정에서 좌표 추출의 정확도와 대상자의 키 정보를 분석에 어떻게 활용할지도 검토하기로 함.
- **11월 19일(목)까지** — 프론트엔드를 구현하고, 팀원들이 GitHub에 올린 코드를 확인해 기능을 통합하기로 함. 목요일까지의 통합 범위는 보행능력평가 모델 연결을 제외한 앱 기능 전반으로 정함.
- **모델 개발 및 테스트** — 앱 개발과 병행해 보행능력평가 모델을 개선하고, 직접 촬영한 보행 영상으로 예측 결과를 확인하기로 함.
