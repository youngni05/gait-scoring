## 회의 내용

### 보행 평가 대상 및 지표 검토

보행 평가 지표로 DGI(Dynamic Gait Index)가 언급되었으며, 기존에 연구하던 GDI(Gait Deviation Index)를 고령자 보행 데이터에 적용하는 방안을 논의함. 경로당에서 고령자의 보행 영상을 수집해 향후 모델 개발에 활용하자는 의견이 나옴. 이때 영상을 확보하는 것과 별개로, 각 영상에 대응하는 GDI 점수를 어떻게 확보하고 검증할지가 과제로 제시됨.

뇌졸중 환자의 보행 평가에 대한 현장 수요를 고려해, 뇌졸중 환자와 비뇌졸중 집단의 보행을 비교하는 모델도 제안됨. 보행 상태를 0~100점으로 표현하는 아이디어가 나왔으며, 이 점수 척도의 정의와 GDI에서 100점이 뜻하는 기준은 각각 검토할 사항으로 남김.

### 영상에서 GDI 점수를 산출하는 방안

GDI 레이블이 없는 영상에 대해 연구팀이 직접 점수를 산출할 수 있는지 논의함. 이를 위해 다음 두 가지 기술 과제를 검토함.

1. **GDI 기준 집단과 점수 산출 방법 설정** — 비장애 성인의 보행 데이터로 기준 집단을 구성하고, 어떤 보행 특성과 분포를 바탕으로 GDI 100점의 기준을 설정할지 검토함. 영상에서 추정한 3D 보행 정보로 관절 움직임을 구한 뒤, 특이값 분해(SVD)를 활용해 GDI를 산출하는 방안이 제안됨.
2. **영상 기반 3D 보행 추정의 정확도 확인** — 영상에서 관절 움직임을 얼마나 정확하게 복원하는지가 산출 점수의 신뢰도와 연결된다는 점을 논의함. OpenCap을 검토 대상으로 언급했으며, 기존 3D 추정 모델을 가져와 대상 데이터에 맞게 파인튜닝하는 방안도 제안됨.

영상에서 계산한 GDI를 학습용 정답 레이블로 활용할 수 있을지는 3D 추정의 정확도와 점수 산출 방법을 검증한 뒤 판단하기로 함.

### 앱 구현 및 기업 데이터 활용

뇌성마비·뇌졸중 환자를 대상으로 보행 평가 모델을 개발한 뒤 앱에 연동하고, 실제 기업 데이터로 예측 결과를 확인하는 흐름을 논의함. 이후 기업의 촬영 환경과 대상자 특성에 맞춰 모델을 개선할 수 있도록 기업 데이터로 파인튜닝하는 방안도 검토함.
