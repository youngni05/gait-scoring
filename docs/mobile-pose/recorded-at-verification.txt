촬영일 우선순위 변경 검증
- 년-월-일(YYYY-MM-DD) 수동 입력 우선. 날짜만 받으므로 한국00:00으로 저장, UI에 명시.
- 미입력: mediabunny getMetadataTags().creationTime을 한국시간으로 변환. 파일명/수정일을 대체값으로 사용하지 않음.
- 메타데이터 누락/유효하지 않은 값/1970년 이전 센티넬은 직접 입력 안내. 잘못 입력한 날짜는 메타데이터로 조용히 대체하지 않음.
- 출처 자동 결정. 영상 변경 시 날짜/메타데이터 초기화, 기존 epoch 검사 뒤 새 메타데이터 반영.
- capture.recorded_at 기존 시간대 포함 계약 유지. 수동 YYYY-MM-DDT00:00:00+09:00, 메타데이터 실제 시간 보존.
- 실제 B-758: 독립 PyAV creation_time과 UI 한국 변환 일치.
- UI: 수동 날짜 우선 -> 입력 형식 통과 -> 삭제 -> 메타데이터 복귀 확인.
- 자동115개 통과, mobile 타입 검사/production 빌드 통과. 날짜 경계/윤년/무효일/누락 메타데이터 테스트 추가.
- 프레임 추출 알고리즘은 수정하지 않음. Galaxy 실기기 검증은 보류.
