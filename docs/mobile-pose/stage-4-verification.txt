4단계 구현 및 PC 검증 기록 — 2026-11-16
판정: 추출 기능/전체 프레임·시각/취소/탐색 동작 통과. 관절 정확도와 다인 판정 정확도는 미통과/미검증 항목을 아래에 구분. Galaxy 실기기는 사용자 요청으로 보류.

구현 경계
- PoseExtractor의 MediaPipePoseExtractor 구현을 추가한다. UI/서버/인증과 분리한다.
- @mediapipe/tasks-vision 1.2.3, full float16/1 모델, CPU, runningMode VIDEO, numPoses=1.
- 모델/WASM은 기존 동봉 로컬 경로를 유지한다. 모델 SHA256은 mobile/model-assets.json에 고정되어 있다.
- 입력 t는 파일의 PTS(초). detectForVideo에는 t*1000(밀리초)을 넘기고 출력 t는 그대로 보존한다.
- MediaPipe의 normalized landmarks만 [x,y,z,visibility]로 복사한다. worldLandmarks를 섞지 않는다.
- z는 상대 깊이이며 미터가 아니다. 앱에서 반전/평활화/보간/반올림/클램핑하지 않는다.
- MediaPipe VIDEO 내부 추적/필터 동작 자체를 제거한 것은 아니다. '원본값'은 엔진이 반환한 값이다.
- 미검출은 lm:null. 엔진 오류/비정상 숫자/33관절이 아닌 출력은 오류로 중단한다.
- 순차 처리 중 매 프레임 입력 이벤트에 제어를 넘겨 취소 가능하게 한다. 동기 추론 한 번 도중에는 취소가 즉시 실행되지 않는다.
- 좌표 배열만 메모리에 유지하고 전체 영상 프레임 이미지는 축적하지 않는다. 취소 결과는 폐기한다.
- 모델은 실행별로 생성/close하여 재시작 시 이전 VIDEO 타임스탬프 상태를 이어받지 않는다.

개발 화면
- 같은 선택 영상에 대해 '관절 추출 시작', '관절 처리 취소', 추출/검출/미검출 개수와 처리 시간을 제공한다.
- 완료 후 프레임 번호, 이전/다음 프레임, 오버레이 숨기기/보기를 제공한다.
- 원본 프레임을 demux/디코딩하여 해당 PTS 일치를 검사한 뒤 오버레이를 그린다. HTML video seek 근삿값을 사용하지 않는다.
- 표시만 visibility>=0.5 관절을 연결한다. 숨겨진 관절도 원본 배열에는 그대로 남는다.
- 선택 프레임의 원본값 펼치기로 33개 튜플과 실제 시각을 확인할 수 있다.
- 재선택/해제/취소/언마운트 때 abort와 session.dispose를 수행한다. 이전 요청이 새 화면을 덮어쓰지 않도록 세대와 신호를 검사한다.

다인 점검
- numPoses=1 결과는 단일 인물 확인이 아니다.
- 별도 numPoses=2 엔진으로 전체 프레임의 후보 수를 검사한다. 단일 좌표 출력은 이 검사로 바꾸지 않는다.
- 2명 후보가 나오면 단일 대상 확정을 경고한다. 나오지 않아도 다른 사람이 없다고 보증하지 않는다.
- 추가 검증 자료로 원본 중간 프레임을 메모리상 두 칸에 복제한 기술 시험을 사용한다. 파일로 저장/업로드하지 않는다.
- 실제 두 사람이 함께 있는 다양한 장면의 검출 정확도는 별도 영상/수동 라벨이 필요하다.

범위 밖과 미검증
- 서 있기 자동 검출, coords-1 직렬화/전송, GDI 계산은 구현하지 않는다.
- full/CPU는 비교용 후보이며 최종 모델 선정이 아니다. GPU 경로를 제공하거나 자동 대체하지 않는다.
- Galaxy Wide5/Android13 실기기, lite 비교, GPU, 발열/메모리 실측, 장시간 성능은 미검증이다.
- 시각적 정렬/형식 검사는 임상 정확도 또는 GDI 호환성 검증을 대신하지 않는다.

외부 로그 요청 발견과 수정
- 최초 네트워크 감사는 실패했다. 설치된 SDK에서 https://odml.pa.googleapis.com/v1/log 로 POST를 시도함을 확인했다.
- 영상/프레임 본문 전송이라고 판단할 근거는 없고, 전송 본문을 분석한 것은 아니다. 패키지 소스에서 로그 수집 경로를 확인했다.
- 이전 단계의 '로컬 모델만 사용하므로 외부 요청이 없다'는 추론만으로 비전송을 보증하면 안 된다.
- 제품과 모든 개발용 QA HTML에 connect-src 'self' blob: CSP를 추가했다. 외부 fetch/XHR/WebSocket 연결은 브라우저가 차단한다.
- img-src도 self/data/blob, media-src도 self/blob로 제한했다. 서버 연결 단계에서 명시적으로 정책 재검토가 필요하다.
- SDK 로그 수집 코드를 패치하거나 없앴다는 뜻은 아니다. 요청 시도는 남으며 콘솔에 CSP 차단 메시지가 나타날 수 있다.
- 최종 검증은 CSP 정책 하에서 재수행한다. SDK 자산 다운로드(로컬 GET), 외부 요청 시도, 실제 차단을 구분해 기록한다.
- 참고: https://github.com/google-ai-edge/mediapipe/issues/6306 (공식 저장소의 관련 설명). 실제 근거는 설치된 패키지와 이 PC의 실행 관측이다.
