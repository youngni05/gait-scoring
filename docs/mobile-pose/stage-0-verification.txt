- git remote -v, status --short --branch, branch -a -vv: 원격/깨끗한 작업 트리 확인.
- git ls-remote --symref origin HEAD 'refs/heads/*': 원격 기본 브랜치/전체 branch refs 확인.
- git fetch origin: origin/main 최신화 성공.
- 다른 두 브랜치 명시적 fetch: 성공.
- git ls-tree -r --name-only 및 git ls-files: 구성·지침 파일 검사.
- git log -6 origin/main: 최근 이력 확인.
- git switch --no-track -c feature/mobile-pose-json origin/main: 성공.
- git rev-parse HEAD origin/main: 브랜치 생성 직후 두 SHA 일치.
- node --version, npm --version, pnpm --version, JDK별 java/javac: 위 버전 확인.
- 폴더가 Administrators 소유라 Git safe.directory 오류가 있었음.
  Git 명령마다 아래 옵션을 사용했으며 전역 safe.directory는 변경하지 않음:
  -c 'safe.directory=C:/Users/Your/Documents/ChatGPT/보행능력점수평가모델 만들기/tmp/gait-scoring-review'
