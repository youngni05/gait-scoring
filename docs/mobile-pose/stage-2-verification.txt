2단계 검증 기록 — 2026-11-16 (Asia/Seoul)
브랜치: feature/mobile-pose-json
사용자 기기 정보: Samsung Galaxy Wide5 / Android 13.
사용자가 이번 작업 중 USB 연결 불가를 알려주었음. 실기기 검증은 대기.

구현
- React 19.3.1 + Vite 8.3.8 + TypeScript 7.0.2 + Capacitor 8.6.2.
- 기존 루트 npm 잠금 파일 유지, mobile을 npm workspace로 등록.
- 대상자 ID/키/촬영일/촬영일 출처 입력. 개발용/서버 미연결 표시.
- 촬영일은 빈 상태로 시작. 분석일을 촬영일로 자동 대입하지 않음.
- 폼 검증은 pose/processing-input.ts로 분리, 기존 ProcessingInput 타입 재사용.
- 브라우저/Android 환경 표시, 입력 초기화 안내, 실제 서버 호출 없음.
- 파일 선택 기술 점검은 파일 크기/MIME 확인만. 디코딩·미리보기는 3단계.
- MediaPipe는 로컬 full 모델/CPU로 256x256 회색 합성 이미지 1장 실행.
  성공 여부와 검출 수를 표시. 실제 영상 분석 성공으로 표시하지 않음.
- 모델과 WASM은 빌드에 동봉. 모델 URL/해시는 mobile/model-assets.json,
  엔진 버전은 1.2.3. 최종 모델 선택이나 4단계 실제 추출 구현은 아님.
- Android ID com.gaitscoring.dev, 앱 이름 보행 평가 개발용, 버전 0.2.0 (2).

환경 준비
- 기존 JDK 21.0.9 사용. JDK11 전역 JAVA_HOME은 변경하지 않음.
- SDK 위치: %LOCALAPPDATA%/Android/Sdk
- 공식 commandlinetools-win-15859902_latest.zip 다운로드 및 공식 SHA-256 대조.
- platform-tools, platforms;android-36, build-tools;36.0.0 설치.
- 실제 platform-tools 버전 37.0.1. AGP가 요구한 build-tools;35.0.0도 자동 설치됨.
- Android Studio/에뮬레이터/삼성 USB 드라이버는 설치하지 않음.
- SDK 도구가 sdkmanager의 향후 대체 CLI 안내를 출력했으나 패키지 설치 성공.
- Gradle 8.14.3 / Android Gradle Plugin 8.13.0, minSdk24, target/compileSdk36.
- 한글 경로 사전 검사 실패 후 gradle.properties의 overridePathCheck로 재시도.
- 신규 빌드 명령은 scripts/build-android.ps1에 정리. 전역 환경 설정 보존.
- 생성 템플릿의 무관한 덧셈 테스트/잘못된 기본 패키지 ID 테스트 제거.
