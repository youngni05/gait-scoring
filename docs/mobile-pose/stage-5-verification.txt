5단계: 서 있기 구간 초기 규칙 및 PC 검증
버전 0.5.0 / versionCode7 / stand-frontal-0.1.0

구현
- StandDetector 포트의 FrontalStandDetector 순수 모듈. UI/인증/전송에서 분리.
- 파일 PTS로 구간 시작·끝을 반환. 임의의 첫2초를 사용하지 않음.
- 원본 좌표를 수정하거나 보간하지 않음. z는 거리로 사용하지 않음.
- 입력 가로/세로 비율로 x를 보정한 2D 좌표에서 각도와 거리를 계산.
- 어깨·골반·무릎·발목·발꿈치·발끝 모두 visibility>=0.65이고 화면 안에 있어야 함.
- 어깨→골반 몸통길이>=영상높이0.025, 기울기<=20도, 양 무릎각>=160도,
  어깨보다 골반, 골반보다 무릎, 무릎보다 발목이 아래에 있는 자세만 후보.
- 후보 구간 내 각 관절 x/y 전체 범위가 몸통길이의0.12 이하,
  몸통 길이 변화8% 이하, 어깨 폭 변화12% 이하인 연속 구간을 찾음.
- 구간 사이 PTS 간격>0.12초, 미검출, 낮은 가시성, 자세/움직임 위반에서 구간을 분리.
- 필수 관절 원본값이 정확히 동일한 채0.5초 이상 반복되면 검출 정지 가능성으로 거절.
- 1.5초 이상·8샘플 이상 후보 중 가장 긴 구간을 선택하며 동률은 먼저 나온 구간을 유지.
- 이 값들은 임상 기준이 아니라 명시적 초기 후보 설정이다. STAND_CONFIG에 고정해 버전 관리.
- 검출 시 detected와 실제 시간, 미검출 시 not_detected와 양쪽null/사유를 반환.
- 진단 프레임 수·거절 사유는 로컬 보고서이며 coords-1에 필드를 추가하지 않음.

UI
- 관절 추출 완료 후 서 있기 구간을 자동 계산.
- 후보가 있으면 구간 시작/중간/끝 버튼으로 해당 시각에 가장 가까운 원본 프레임 탐색.
- 검출 근거와 설정값 펼치기 제공.
- 사용자 수동 표시: 미표시/구간 있음/구간 없음. 수동값이 없으면 정확도 미검증.
- 자동−수동 시작/끝 오차, 미검출·오검출 후보를 구분. 수동값으로 자동결과를 덮어쓰지 않음.
- 잘못된 수동시간은 범위 오류. 입력은 메모리에서만 유지하며 영상/추출결과 변경 시 초기화.

자동 검사
- npm test: 96개 통과. 신규13개에 정상서기·시각/원본불변·처음부터걷기·짧은정지·null·가시성저하·앉음·검출정지·시각단절·회전·나중서기/VFR·오류·취소·확대·화면밖발을 포함(일부는 한 테스트에 여러 사례).
- npm run typecheck:mobile 및 Android 빌드에서 TypeScript 검사 통과.
- 합성검증은 정답이 알려진 좌표로 동작을 검사한 것이며 실제 정확도 근거가 아니다.
- 합성UI:0~3초 검출, 중간보기=1.5초 탐색 요청 확인.
- 수동0.5~2.5초 입력: 시작오차−0.500/끝오차+0.500초 확인.

검증 자료 구분
- 초기 임계값 설계/동작검사: 공개 가능한 합성 좌표.
- 실제 원본 영상: 기술 확인용, 수동 정답 구간 미제공. 이 영상의 원하는 결과에 맞춰 임계값을 조정하지 않음.
- 별도의 수동 라벨이 있는 정면 서기→걷기, 처음부터걷기, 회전, 앉기, 가림 영상의 최종 정확도 검증은 미실행.
- 4단계의 잘못된 관절 및 다인 후보13프레임 문제는 정면 영상이라는 설명만으로 해결된 것으로 보지 않음.
- 영상 자체가 정면 촬영인지 자동 판별하지 않음. 같은 좌표가 실제정지인지 디코더고정인지 완전히 구분할 수 없음.
- 카메라가 사람을 따라가거나 깊이방향 움직임이 작게 보이면 오검출 가능. 긴 정지 회전 등 구분도 추가 라벨 검증 필요.
- 갤럭시 실기기 및 임상 정확도는 보류. 6단계 JSON 생성/전송은 구현하지 않음.

시험ID / 영상조건 / 규칙버전 / 조정용 또는 최종검증용
수동판정(구간있음/없음) / 수동시작 / 수동끝
자동상태 / 자동시작 / 자동끝 / 시작오차(자동−수동) / 끝오차
성공·미검출·오검출 후보 / 관절품질·가림·다인 여부 / 확인자·확인일
허용시간오차와 정확도 통과기준은 아직 합의하지 않았으므로 수치만으로 통과를 만들지 않음.
