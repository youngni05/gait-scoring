구현 범위

- t = metadata.mediaTime (초). 벽시계/RAF 횟수/가정 FPS로 시간을 생성하지 않음.
- 프레임은 같은 video에서 canvas.drawImage로 읽음. 캔버스 하나를 재사용.

- 취소/재선택/해제/오류 시 대기 콜백과 타이머·이벤트 리스너 정리.

날짜와 좌표 기준
- HTML video 메타정보만으로 실제 촬영일/시간대를 확인하지 못하므로 자동 입력 없음.
- 파일 수정일은 촬영일로 사용하지 않음. 확인 가능한 촬영일을 사용자가 입력.
- 영상 재선택 시 촬영일을 비우고 출처를 user_entered로 초기화.
- 회전은 브라우저의 디코딩/표시 해석에 의존. 표시와 캔버스는 동일 크기,
  좌우 반전/CSS 회전/임의 리사이즈를 추출 데이터에 적용하지 않음.
- 실제 회전 각도를 0으로 꾸미지 않도록 내부 VideoInfo/ProcessingMetadata의
  rotationAppliedDegrees를 number | null로 변경. coords-1 본문 변경 없음.
- 회전 태그가 있는 파일, 비정사각 픽셀, 영상 중 크기 변경은 미검증.
  영상 중 videoWidth/videoHeight 변경이 감지되면 오류로 중단.

중요한 기술 결정

- PC 합성 시험에서도 원본 프레임 누락을 관측함. 프레임 수가 같다고 해도
