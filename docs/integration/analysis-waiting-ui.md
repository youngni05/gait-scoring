# 분석 대기·실패 화면 개선

기준: main 438df99 (PR #18). 브랜치: codex/analysis-waiting-ui.

## 변경 내용

- 최초 조회에만 전체 로딩 화면을 표시하고, 이후 조회에서는 마지막 상태를 유지합니다.
- 결과만 3초 간격으로 조회합니다. 대상자 정보는 화면 진입 시 한 번 조회합니다.
- 조회 실패 시 기존 상태와 안내를 유지하고, 대기 중에는 10초 후 다시 조회합니다.
- 이 화면에서 1분 이상 대기하면 안내를 표시합니다. 서버 처리 시간이나 완료 예상 시간을 추측하지 않습니다.
- 수동 상태 확인과 이전 결과 목록 이동을 제공합니다.
- 재분석 요청부터 후속 조회까지 하나의 작업만 허용하며 버튼을 잠급니다.
- 재분석 접수 후 조회 실패 시 대기 상태를 유지합니다. 요청 실패 시 처리 여부가 불확실하다고 안내합니다.
- 화면 이탈 시 요청과 타이머를 취소하며, 다른 결과로 이동하면 이전 화면의 상태를 재사용하지 않습니다.

백엔드, DB, 모델 계산, 클라우드 설정은 변경하지 않았습니다.

## 검증

- 모바일 TypeScript 검사 및 제품 빌드 통과.
- 실제 Chromium에서 새 시나리오 3개 통과: 느린 조회/조회 실패에도 화면 유지 및 복구, 1분 안내와 목록 이동, 재분석 중복 클릭 차단과 후속 조회 실패 복구. HTTP 응답은 테스트용으로 제어했습니다.
- Python E2E에 동일한 시나리오 3개 추가. Python 문법 검사 통과. 실제 CI 실행은 push 후 확인해야 합니다.
