# 보행 영상으로 개인의 변화를 비교하기 위한 실험

휴대폰으로 촬영한 보행 영상을 같은 사람의 이전 기록과 비교해, 걸음이 어떻게 달라졌는지 설명하는 것이 목표입니다. 이번에는 평소 기록을 어떻게 기준으로 삼을지, 점수와 함께 어떤 움직임을 보여 줄지, 비교할 영상의 처리 조건을 어떻게 맞출지 살펴봤습니다.

| 실험 | 확인한 내용 |
|---|---|
| [개인 정상 기록 비교](personal-baseline.md) | 같은 사람의 정상 영상 두 편을 평균해 기준으로 쓰면 한 편을 쓸 때보다 정상 반복의 점수 차이가 작았습니다. 실제 날짜 간 변화를 구별할 수 있는지는 여러 날의 반복 촬영으로 확인해야 합니다. |
| [Test02 보행 지표 비교](test02-gait-metrics.md) | 짧은 보폭과 모방 동작에서 화면상 무릎 움직임 범위와 GDI 예측 점수가 함께 낮아졌습니다. 무릎 움직임은 점수와 함께 보여 줄 관찰 지표로 살펴볼 수 있습니다. |
| [같은 영상 입력으로 브라우저와 PC 비교](identical-rgb.md) | 같은 환경에서는 같은 조건으로 반복한 22쌍의 관절 좌표가 모두 일치했습니다. 브라우저와 PC에서는 같은 픽셀을 넣어도 차이가 남아, 개인 기록을 비교할 때 영상 처리 환경과 추적 시작 조건을 맞출 필요가 있습니다. |
