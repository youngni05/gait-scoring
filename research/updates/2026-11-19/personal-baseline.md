# 개인 정상 기록 비교

[실험 요약](README.md)

## 무엇을 비교했나요?

같은 사람의 평소 영상 한 편을 기준으로 쓸 때와 두 편의 평균을 기준으로 쓸 때, 다른 정상 영상과의 점수 차이가 얼마나 달라지는지 살펴봤습니다.

Test02 개발자료 3명·36편에서 이미 계산한 GDI 결합 점수를 사용했습니다. 사람마다 일반 정상 영상 3편 중 한 편을 평가 대상으로 두고, 나머지 두 편을 각각 기준으로 삼거나 두 편의 평균을 기준으로 삼았습니다. 추출기와 모델별로 계산한 뒤, 사람마다 같은 비중으로 결과를 평균했습니다.

## 결과

아래 값은 평가 영상의 양쪽 다리 평균 점수가 같은 사람의 정상 기준에서 떨어진 정도입니다. 단위는 GDI 예측 점수입니다.

| 관절 추출기 | 모델 | 1편 기준 평균 절대차 | 2편 기준 평균 절대차 |
|---|---|---:|---:|
| Full | 기존 모델 | 1.61 | 1.49 |
| Full | 정상100 추가 모델 | 1.84 | 1.61 |
| Lite | 기존 모델 | 1.88 | 1.70 |
| Lite | 정상100 추가 모델 | 3.52 | 3.00 |
| OpenPose | 기존 모델 | 1.87 | 1.61 |
| OpenPose | 정상100 추가 모델 | 2.61 | 2.18 |

여섯 조합 모두에서 두 편 기준의 평균 절대차가 작았습니다. 두 기준을 평균하면 서로 반대 방향의 차이가 상쇄될 수 있으므로, 관찰한 감소에는 평균을 내는 효과가 포함됩니다. 일부 보폭 변경 영상은 어떤 정상 영상을 기준으로 삼느냐에 따라 차이의 방향도 바뀌었습니다.

## 다음에 확인할 점

이번 비교는 촬영 날짜와 순서가 확인되지 않은 영상에서 정상 기준을 바꿔 본 결과입니다. 여러 날에 걸쳐 같은 조건으로 촬영하고, 평가일보다 앞선 기록만 기준으로 삼아야 정상적인 날마다의 변동과 실제 움직임 변화를 얼마나 잘 구별하는지 확인할 수 있습니다.

당시 검산에서는 별도 계산으로 594개 요약 그룹을 다시 만들었습니다. 원래 계산과의 최대 차이는 약 1.93×10⁻¹⁴점이었습니다.
