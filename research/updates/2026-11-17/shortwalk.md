# 짧은 보행: 입력 변환과 추가 학습

집 안에서 긴 직선 보행을 촬영하기 어려울 때, 짧은 관측으로 무엇을 계산할 수 있는지 비교했다. 원시 좌표를 먼저 자르고 그 구간 안에서만 결측 처리·평활화·정규화를 수행했다. 없는 주변 움직임을 전처리에 끌어오지 않았다.

Stanford 개발자료는692명·1,061방문이다. 네 길이를 모두 계산할 수 있는 중앙 구간640명·923방문을 주비교로 했다. 각 방문의 양쪽 절대오차를 평균하고, 같은 사람의 방문들을 평균한 뒤 사람마다 같은 비중으로 평균했다. 정답은 방문 GDI이며 짧은 순간만의 별도 정답은 없다. 보호된 최종평가 정답은 사용하지 않았다.

Stanford의 명목25Hz는 실측 영상 타임스탬프로 확인한 값이 아니다.32/64/96/124프레임의 첫·마지막 관측 간격은 이 시간축에서1.24/2.52/3.80/4.92초다. LJMU30Hz와 Test02의 실제 시간축은 따로 유지했으므로 모든64프레임을 같은 초로 부르지 않는다.

## 학습 없이 입력을 변환한 비교

R0는124프레임 원길이, F1은124칸 선형 보간, F2는 양끝값 채움, F3는 같은 짧은 구간 반복이다. 기존 전체 결합 구성의 가중치·보정·결합 비율을 유지했다. F2/F3가 만든 프레임을 실제 추가 관측으로 세지 않는다.

| 길이·방법 | 기존 모델 MAE | 정상 추가 모델 MAE |
|---|---:|---:|
| 124 R0 | 7.051 | 6.991 |
| 64 F1 | 8.812 | 8.573 |
| 64 F2 | 8.700 | 8.383 |
| 64 F3 | 7.483 | 7.454 |
| 32 F1 | 10.599 | 10.171 |
| 32 F2 | 11.885 | 10.875 |
| 32 F3 | 8.358 | 8.231 |

MAE는 작을수록 방문 정답에 가깝고 단위는 GDI점이다.64프레임에서 F3−F1 차이는 기존−1.329점, 정상 추가−1.120점이었다. 사람을10,000회 짝지어 재표집한95%구간은 각각[−1.607, −1.053], [−1.387, −0.852]다. 고정 모델과 개발자료에 조건을 둔 탐색 결과이며 모델 선택의 불확실성이나 여러 비교 보정을 포함하지 않는다. F3는 진단용 대조이며 제품 방식으로 채택하지 않았다.

## 짧은 입력을 학습한 비교

T0는124입력 추가학습, T1은32/64/96/124를 섞어124칸으로 보간한 추가학습이다. T2_64와 T2_124는 같은 가변 길이 구조에서 학습 길이만 달리한다. 모두3epoch다. 두 사전 난수에서 총240개 모델을 학습했다.

이 비교는 분할별 CNN·STT·양측 모델의 **refit 결합**이다. 위 무학습 전체 bag 구성과 직접 같은 모델 구성으로 취급하지 않는다. 대조 frozen도 같은 refit 구성으로 계산했다. T2는64·124가 모두 가능한 학습 방문만 사용하므로 T1과 비교할 때 구조와 학습 방문 차이가 함께 있다. 보정값은 학습 Stanford로만 정했다. LJMU의100은 실측값이 아닌 가정 목표다.

| 계열·방법 | 64프레임 MAE: 난수1 / 난수2 | 원래 여러 창124 MAE: 난수1 / 난수2 |
|---|---:|---:|
| 기존 frozen | 9.01 / 9.01 | 6.61 / 6.61 |
| 기존 T0 | 8.71 / 8.70 | 6.64 / 6.64 |
| 기존 T1 | 7.77 / 7.66 | 6.81 / 6.76 |
| 기존 T2_64 | 7.38 / 7.35 | 7.00 / 6.97 |
| 기존 T2_124 | 7.60 / 7.61 | 6.65 / 6.65 |
| 정상 추가 frozen | 8.86 / 8.86 | 6.73 / 6.73 |
| 정상 추가 T0 | 8.35 / 8.31 | 6.75 / 6.76 |
| 정상 추가 T1 | 7.75 / 7.75 | 7.13 / 7.15 |
| 정상 추가 T2_64 | 7.39 / 7.41 | 7.00 / 6.98 |
| 정상 추가 T2_124 | 7.50 / 7.52 | 6.79 / 6.80 |

난수 1·2는 20261117·20261118이다. 같은 초기 체크포인트에서 추가학습 난수를 바꾼 결과다. 64프레임 열은 640명·923방문, 원래 여러 창 124프레임 열은 692명·1,061방문이다. 두 열 사이에는 표본 수와 구간을 만드는 방식의 차이도 있다. 입력 길이의 영향을 확인하려면 같은 방문에서 자른 중앙 구간끼리 비교해야 한다.

짧은 입력의 평균 오차는 줄었지만 긴 입력의 오차는 늘었다.64프레임에서 실제 한쪽 GDI<50인16명·16방문의 오차도 frozen 약13.5~13.8점에서 T1 약16.1~17.4점, T2_64 약17.7~18.0점으로 증가했다. 전체 평균 개선이 모든 점수대의 개선은 아니다. 저득점 결과는 작은 집합의 사후 기술 통계이며50은 임상 판정 기준이 아니다.

T2_64의 보정은 학습64입력, T2_124의 보정은 학습124입력으로 정했다. 따라서 보정후 차이에는 학습 길이와 보정 효과가 함께 있다. 원점수 MAE도 보존했다.64프레임에서 기존 T2_64는7.42/7.36, T2_124는7.91/7.89이고, 정상 추가는 각각7.45/7.43, 7.57/7.56이다.

## 실제 짧은 영상과 다음 결정

Test02는 3명·36영상이며 실측 GDI가 없다. Full을 주추출기, Lite를 보조로 정했다. 중앙 32·64프레임은 72통과 중 66개, 96프레임은 52개, 124프레임은 34개를 계산할 수 있었다. 일반 정상 9편은 124프레임 직선 구간이 부족했지만, 32·64프레임에서는 각 영상의 두 통과를 모두 계산할 수 있었다. 짧은 입력으로 점수를 낼 수 있는 구간이 늘었고, 그 점수의 정확도는 실측 GDI가 있는 자료에서 확인해야 한다.

두 통과를 평균한다고 반복 변동이 항상 줄지는 않았다. 정상 추가64프레임에서는 T2 두 군의 반복 표준편차가 줄었으나 frozen/T0/T1은 늘었다. 세 사람의 같은 촬영 자료에 한정된 관측이며 여러 날짜의 변화 검증이 아니다.

짧은 입력에서 개선된 방법은 후속 비교 후보로 삼을 수 있다. 제품 모델 교체는 저득점과 긴 입력에서도 성능이 유지되는지 확인한 뒤 판단한다. 촬영 시간과 추출기 선택은 실제 기기에서 입력 길이별 출력 가능성과 반복성을 검증한 뒤 결정할 사안이다.
