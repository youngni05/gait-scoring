## 학습 단위와 결측 처리

T0/T1은 초기 계열의 기존 방문을 모두 유지한다. 기존은 Stanford만, 정상100은 Stanford+LJMU100이며 방문마다 epoch당 한 번 같은 가중치로 학습한다. 원래 다구간 손실의 방문동일비중을 유지하되 이번 비교의 입력 위치는 공통 center다. 원래 multiwindow 학습을 그대로 재실행한다고 부르지 않는다.

T0는 center124, T1은 center32/64/96/124를 F1으로 보간한다. 방문 순서의 위치와 epoch로 네 길이를 순환 배정하여 매 epoch 약1/4씩 유지한다(나머지 방문은 최대1개 차이). 124가 남아 짧은 입력만 학습하지 않는다. T0/T1은 같은 방문 순서·배치·epoch·seed다. 불가 crop을 학습에 넣거나 다른 방문으로 대체하지 않는다. center124가 불가하면 그 방문의 기존 검산된 첫 유효124구간을 공통 long 대조로 쓴다. T1의 요청 길이가 불가하면 같은 방문의 long 대조로 되돌리고 횟수를 기록한다. 따라서 그 방문은 짧은 입력 학습의 근거로 세지 않는다. 평가에서 불가 crop은 출력불가로 유지한다.

T2는 center64와 center124가 모두 가능한 학습 방문에서만 64/124를 서로 대조한다. 두 군의 방문·가중치·순서·epoch·seed를 맞춘다. 불가64를 패딩해 짧은 실제 관측으로 만들지 않는다. 이 T2 쌍의 가용 방문 수/출처 구성은 T0/T1과 별도로 기록한다. 두 군 모두 같은 초기 가중치와 가변 길이 구조를 사용한다. T2-124는 원형과 출력·기울기가 같지만 학습 방문이 T0와 다를 수 있어 별도 학습한다. 모든군의 평가 사람은 해당 초기 모델 및 추가학습에서 제외한다.

## 갱신·초기값·보정

- 고정 seed: 20261117, 두 번째 확인 seed 20261118. 기존 checkpoint 초기값은 그대로이며 추가학습의 배치/Dropout 난수를 바꾸는 확인이다.
- 고정 epoch: 3. 기존 짧은 전체층 추가학습의 3epoch를 소규모 첫 비교 예산으로 사용한다. epoch를 outer/Test02 결과로 고르지 않는다. 파일럿은 자원·연산·저장 확인용이며 성능으로 설정을 탐색하지 않는다.
- CNN: 원래 RMSprop(alpha0.9, eps1e-8), lr1e-4, 원래 conv3–6 L2 0.00031622776601683794, 16쌍/배치. STT/양측: 원래 Adam, lr1e-4, weight_decay0, 64쌍/배치. 3epoch 동안 고정 lr이다. 기존 100/200epoch 학습과 동일 예산이라고 부르지 않는다.
- 초기 checkpoint의 train-only lo/span을 유지한다. 원래 체크포인트에 기록된 학습 사람 집합과 이번 fold·source의 원래 학습 집합을 대조한다.
- T0/T1/T2-124의 보정은 해당 추가학습 사람의 long124 예측으로 공동 기울기·절편을 적합한다. T2-64는 해당 학습 사람의 native64 예측으로 적합한다. 정상100도 보정에는 Stanford 학습 기록만 사용한다. 한 모델의 보정식을 모든 평가 길이에 그대로 적용하며 길이별 평가 정답으로 재보정하지 않는다. raw/보정후 모두 보존한다.
- 본 비교는 각 family의 outer refit 초기값만 사용한다. CNN/STT/양측3개를 fold별 원래 고정 비율로 결합한 **refit 결합**이다. 논문의 전체 bag 결합 개선을 주장하지 않는다. 4방법×2계열×3family×5outer=120회/seed, 두 seed 모두면240회다. 새 구조의 parameter 개수는 그대로다.

## 파일럿과 평가

파일럿은 outer0/inner1 초기값으로 학습가능 Stanford 최대64방문/LJMU최대32방문, 내부검증 fold1 각 출처 최대16방문을 자료 인덱스 순서로 택한다. 길이32/64/96/124가 모두 가능한 방문만 쓰며 outer0는 제외한다. 샘플 수는 실행 점검용이며 전체 오차로 보고하지 않는다. 1epoch 저장 후 별도 프로세스로 나머지2epoch를 재개하고 저장 모델 재추론을 확인한다.

본 평가에서는 길이별 전체 가용 방문과 모든길이 공통 방문을 구분한다. center 주결과와 start/end 보조, 원래 다구간124 raw/보정후 성능을 따로 남긴다. 학습된 family별 예측과 CNN/STT/양측 refit 결합을 모두 보존한다. Stanford는 사람별 MAE·좌우차이 오차·점수구간별 오차·상위오차 및 사람단위 짝차이를 계산한다. LJMU100 오차는 가정목표와의 거리로 별도 표시한다. Test02는 실측GDI가 없어 점수 반응·출력가능률·반복성만 계산한다.

검산은 원본/공통입력/실행코드/모델 지문, 사람 분리, 학습 방문별 가중치, 실제 step수, resume state, 저장 모델 재추론, train-only OLS 별도 재계산, 결합식·지표 독립 재계산이다. 첫 CPU/장치 사전검사와 실제 라벨 학습·본평가 완료를 구분한다. 최초 GPU 점검의 기본 pooling 결정성 오류는 보존하며 동등한 직접 평균 구현의 후속 GPU 점검 재검사를 통과한 뒤 진행한다.
