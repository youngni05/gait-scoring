# Test02와 짧은 보행 연구

2026-11-17 · 촬영 조건에 따른 모델 반응과 짧은 구간의 GDI 추정 가능성을 확인했다.

| 실험 | 확인한 결과 | 상세 기록 |
|---|---|---|
| Test02 촬영 비교 | 3명·36편에서 기존 모델과 정상 자료를 추가한 모델을 비교했다. Full 추출기에서 일반 정상 영상의 평균 출력은 71.15점에서 84.49점으로 올랐다. 실측 GDI가 없는 영상이므로 이 차이는 모델의 점수 반응을 보여 준다. | [촬영 조건·세 추출기 비교](test02.md) |
| 짧은 보행 | Stanford 개발자료의 공통 640명·923방문에서 짧은 입력을 학습하면 64프레임 평균 오차가 줄었다. 기존 모델 계열의 무학습 대조는 9.01점, 64프레임을 직접 학습한 후보는 두 반복에서 7.38·7.35점이었다. 저득점과 긴 입력에서는 오차가 늘어, 두 조건의 성능을 확인한 뒤 모델 교체를 판단한다. | [입력 변환·추가학습 비교](shortwalk.md) |

정상 자료를 추가한 모델은 LJMU 자료의 목표 점수를 100으로 가정해 학습했다. 짧은 입력의 추가학습은 분할별 refit 모델을 결합해 비교했다. Test02의 고정 전체 결합과 구성 방식이 달라 두 결과는 각 실험의 비교 기준 안에서 읽는다.

실험 설정과 근거는 [학습 프로토콜](TRAINING_PROTOCOL.md), [검산 기록](verification-summary.json), [원본 대응·출처](sources.json)에 있다.

팀원은 기존 124프레임 모델을 받아 모듈 연결을 시험할 수 있다. PC에서 전처리된 NumPy 입력으로 실행하는 방법은 [추론 안내](../../selected/frozen-gdi/README.md), 모델 압축은 [GitHub Release](https://github.com/youngni05/gait-scoring/releases/tag/research-snapshot-20261106)에 있다.
