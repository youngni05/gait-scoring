# 보행 앱의 개인 변화 추적을 검증하는 여섯 가지 실험

2026년 11월 21일 실험 설계 기록. 새로 촬영하는 부담을 줄이기 위해 기존 보행 영상, 사람이 표시한 착지 시점, 반복 방문 기록을 활용한다. 여섯 파트가 각각 한 질문을 맡는다.

| 연구 질문 | 실험 방법 | 판단할 내용 |
|---|---|---|
| 1. 지난 방문과 얼마나 달라져야 개인의 보행 변화로 판단할 수 있는가? | Test02에서 같은 사람이 평소처럼 걸은 영상끼리 점수 차이를 구한다. 촬영일과 상태가 확인되는 반복 자료는 별도로 분석한다. | 다시 찍으면 어느 정도 차이가 생기는가? 안정적인 다른 날의 반복 자료가 충분한 지표부터 방문 간 변화 기준을 추정한다. |
| 2. 어느 발이 언제 바닥에 닿았는지 영상에서 정확히 찾을 수 있는가? | Test02 8구간에서 사람이 표시한 착지 63개와 AI 후보를 대조한다. MoVi 14명의 광학 마커로 추정한 착지 시각도 참고한다. | 놓치거나 추가한 착지, 시점 오차, 좌우를 바꿔 짚은 횟수를 센다. 검토자는 후보 전후 영상을 보고 틀린 표시를 고치거나 빠진 착지를 추가한다. 최종 평가용 구간은 예측을 가리고 판독한다. |
| 3. 걸을 때 다른 사람의 도움이 필요한 사람을 얼마나 잘 구별하는가? | 보행 도움 등급(FAC)이 기록된 같은 사람들에게서 보행 속도만 쓴 예측과 보행 지표·보행편차지수(GDI)를 더한 예측을 비교한다. | 도움이 필요한 사람을 덜 놓치는가? 도움이 필요하다고 잘못 표시한 인원도 함께 센다. |
| 4. 하반신만 보여도 관절과 착지를 찾을 수 있으며, 결과는 얼마나 빨리 나오는가? | 같은 영상을 전신, 골반이 보이는 하반신, 골반까지 잘린 하반신으로 나눈다. 같은 기기에서 MediaPipe와 경량 YOLO Pose를 비교한다. | 어느 구도까지 착지와 좌우를 구별할 수 있는가? 첫 관절이 표시될 때까지의 시간과 영상 전체 처리 시간을 각각 잰다. |
| 5. 여러 보행 지표를 함께 쓰면 판단이 나아지는가? 그 근거를 어떻게 설명할 것인가? | 3·6번에서 얻은 기준값으로 지표 하나를 쓸 때와 여러 지표를 함께 쓸 때의 성능을 비교한다. 같은 방문 기록으로 고정 문장과 언어 모델(LLM)의 설명도 대조한다. | 지표를 합치면 기능이나 변화를 더 잘 구별하는가? 설명이 수치·변화 방향·측정 보류 이유를 정확히 전달하는가? |
| 6. 같은 사람의 실측 보행 점수가 달라지면 앱이 변화 방향과 크기를 따라가는가? | Stanford 자료의 반복 방문자 229명에서 순서가 확인된 인접 방문을 연결한다. 학습에서 제외한 사람을 대상으로 같은 다리의 실측 GDI 변화량과 예측 변화량을 비교한다. | 실제 증가·감소 방향을 맞히는가? 변화량 오차가 매번 ‘변화 없음’으로 예측할 때보다 작은가? |

2번과 4번은 같은 착지 표식을 공유한다. 각 파트는 오차와 함께 전체 대상 중 결과를 낼 수 있었던 비율을 기록한다. 영상 자르기로 확인하는 범위는 화면 구도의 영향이며, 실제 좁은 방에서 걷는 거리나 원근이 달라지는 효과는 별도 검증 대상이다.
