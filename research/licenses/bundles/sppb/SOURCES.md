# 출처와 적용 라이선스

## 학습 자료

- 저자: Pablo Eduardo Caicedo Rodríguez, Carlos Felipe Rengifo Rodas, Luís Eduardo Rodríguez Cheu, Wilson Alexander Sierra Arevalo, María Catalina Gomez Guevara.
- 자료명: Dataset for gait analysis and assessment of fall risk for older adults, Version 1 (2020).
- 공식 자료: https://data.mendeley.com/datasets/xgw6bg3g8h/1 ; https://doi.org/10.17632/xgw6bg3g8h.1
- 라이선스: CC BY 4.0. https://creativecommons.org/licenses/by/4.0/
- 44명·220회 Vicon 마커 보행과 제공된 실제 SPPB 총점을 사용했다. 3초 구간의 좌표·속도를 계산하고 학습용 입력으로 변환했다. 원 임상표·개인별 좌표는 포함하지 않았다.
- 이 묶음의 모델은 본 프로젝트가 Ridge·RF·작은 CNN·TCN을 학습한 결과다. 기존 SPPB 예측 모델의 가중치를 가져온 것은 아니다. 라이브러리 실행 환경은 압축에 포함하지 않는다.

프로젝트 연구기록: https://github.com/youngni05/gait-scoring/tree/main/research
