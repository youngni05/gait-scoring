# 수정·학습·공개 변환 내역

- Vicon 마커에서 연속 3초를 선택하고 골반 중심·다리 길이·이동 방향으로 좌표를 정규화했다. 100Hz에서 30Hz·91시점으로 맞춰 39채널을 만들었다.
- 한 사람의 5회 보행을 같은 분할에 둔 사람 5분할로 Ridge·RF·CNN·TCN을 학습했다. 주평가에서는 사람별 5회 예측을 평균했다.
- 공개 파일은 네 방법의 바깥 분할별 모델, 총 20개다. 전체 44명으로 새로 적합한 단일 최종 모델이 아니다.
- CPU 모델·표준화 객체는 저장된 모델 파일 그대로 보존했다. CNN·TCN은 추론용 상태와 정규화를 보존하고 학습 기록 인덱스를 제외했다. 원 정규화 NumPy 배열을 안전한 torch 로딩용 텐서로 표현했으며 수치·가중치는 보존했다.
- 현재 프로젝트가 GDI 중심으로 전환해 SPPB 후속 연구는 중단한 상태다. 완료한 실험의 연구 이력을 보존한다.

## 2026-11-02 안내 보완

이번 변경은 출처·라이선스 원문·수정 내역·대학 과목 제출용 비상업적 연구 목적 안내를 추가한 것이다. 기존 .pt/.joblib와 weights-manifest.json은 바이트 단위로 동일하게 보존했다. 새 학습·가중치 수정·성능 재평가는 수행하지 않았다. 원 모델 재추론 검산은 연구기록의 publication-verification.json을 따른다.
