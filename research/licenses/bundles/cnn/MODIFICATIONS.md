# 수정·학습·공개 변환 내역

- 공개 doublesided CNN 구조를 참고해 PyTorch로 새로 구현했다. 17관절 x/y/관측 신뢰도의 51채널·124프레임 한 구간에서 좌우 GDI를 동시에 예측한다.
- 원 구현의 한쪽 12특징·여러 구간 평균·Keras와 입력·출력·구현이 다르다. 원 연구의 수치 재현을 주장하지 않는다.
- 695명·1,064기록의 사람 단위 5분할에서 새 초기값으로 학습했다. 공개 파일은 각 바깥 분할의 refit 모델이다.
- 추론용 공개 변환에서 모델 상태와 좌우 정답 역변환 값만 보존했다. optimizer·난수 상태·학습 사람 목록은 제외했다. 모델 텐서는 원 완료 체크포인트와 동일하다.
