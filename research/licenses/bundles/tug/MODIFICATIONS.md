# 수정·학습·공개 변환 내역

- 제공된 OpenCap 보행 자료에서 298명의 3초 연속 구간과 실제 TUG 시간을 연결했다. 17개 각도와 골반 속도 2개를 30Hz·91시점으로 구성했다.
- 한 사람당 한 방문·한 보행 기록을 선택하고 사람 5분할로 Ridge·RF·CNN·TCN을 학습했다. 정규화·모델 선택은 각 학습 집단 안에서만 했다.
- 이번 배포는 298명·3초 조건의 바깥 분할별 모델 20개다. 별도 196명의 1·3·6초 비교 모델이나 원 저자의 질환 탐지 모델은 포함하지 않는다.
- CPU 모델·표준화 객체는 저장된 파일 그대로 보존했다. CNN·TCN은 추론 상태와 정규화를 보존하고 학습 기록 인덱스를 제외했다. 원 정규화 NumPy 배열을 안전한 torch 로딩용 텐서로 표현했으며 수치·가중치는 보존했다.
- 현재 프로젝트가 GDI 중심으로 전환해 TUG 후속 연구는 중단한 상태다. 완료한 실험의 연구 이력을 보존한다.

## 2026-11-02 안내 보완

이번 변경은 출처·라이선스 원문·수정 내역·대학 과목 제출용 비상업적 연구 목적 안내를 추가한 것이다. 기존 .pt/.joblib와 weights-manifest.json은 바이트 단위로 동일하게 보존했다. 새 학습·가중치 수정·성능 재평가는 수행하지 않았다. 원 모델 재추론 검산은 연구기록의 publication-verification.json을 따른다.
