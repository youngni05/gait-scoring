# 보행 영상에서 걸음의 차이를 읽기까지

옆에서 찍은 보행 영상으로 **어떻게 걷는지, 지난번과 무엇이 달라졌는지** 알아보는 연구다. 초기에는 신체 기능검사 점수를 예측했지만, 걷는 영상에는 균형 잡기나 의자에서 일어서기가 담기지 않았다. 그래서 영상에 보이는 관절 움직임과 걸음에 집중했다. [초기 연구 배경](archived-sppb-tug/README.md) · [신체 기능검사 실험](archived-sppb-tug/2026-10-30-sppb-older44/README.md) · [일어나 걸어 돌아오는 검사 실험](archived-sppb-tug/2026-10-30-tug-opencap298/README.md)

## 정상적으로 걸어도 점수가 낮게 나왔다

보행 편차 지수(GDI)는 관절 움직임이 정상 참조집단과 얼마나 다른지 나타낸다. **100점은 그 집단의 평균**이다. 기존 모델은 학습에 쓰지 않은 정상 집단에 평균 80점 안팎을 줬다.

| 왜 확인했나? | 어떻게 확인했나? | 무엇을 알게 됐나? |
|---|---|---|
| 정상 보행을 더 보여 주면 달라질까? | 정상 성인 영상에 학습용으로 100점을 가정해 환자 자료와 함께 학습했다. | 다른 정상 집단의 점수도 올랐지만, **환자의 실측 점수와의 오차는 조금 늘었다.** |
| 목표 점수나 학습 비중을 더 높이면 좋을까? | 정상 영상에 붙인 점수를 바꾸고, 그 영상에서 틀린 값에 더 큰 비중을 줬다. | CNN에서는 둘 중 하나를 크게 높이면 실제 점수가 높은 환자의 오차가 커졌다. |
| 정상 영상은 얼마나 필요할까? | 참여자를 조금씩 늘리고, 학습 시작 조건도 바꿔 반복했다. | 처음 몇 명을 추가했을 때 정상 아동의 점수가 가장 많이 올랐다. |
| 보행 특징을 배워서 점수가 올랐을까? | 영상이 어느 자료에서 왔는지만 구별하는 모델과 비교했다. | 이 모델에서도 점수가 오르는 사례가 있어, 상승 원인을 보행 특징만으로 설명하기 어려웠다. |
| 기존 점수의 눈금만 바꿔도 될까? | 재학습 없이 보정식을 적용해 정상 아동의 평균을 재학습 모델과 같게 맞췄다. | 정상 평균은 맞았지만 환자의 점수 오차는 두 배 이상으로 커졌다. |
| 관절을 별도로 측정해도 낮게 나올까? | 3차원 관절각으로 계산한 GDI와 영상 모델의 예측을 비교했다. | 정상 자료를 추가한 뒤 건강 성인의 점수를 낮게 잡던 차이가 줄었다. |

## 집 안에서는 한 방향으로 걷는 시간이 짧았다

| 왜 확인했나? | 어떻게 확인했나? | 무엇을 알게 됐나? |
|---|---|---|
| 짧은 구간도 쓰면 더 많은 영상을 분석할 수 있을까? | 같은 왕복 영상에서 돌아서는 부분을 빼고, 모델에 필요한 구간 길이를 절반으로 줄였다. | 점수를 낼 수 있는 직선 구간이 거의 두 배로 늘었다. |
| 기존 모델에 짧은 구간을 넣을 수 있을까? | 중간 좌표 채우기, 양 끝 자세 유지하기, 관측한 움직임 반복하기를 비교했다. | 세 방법 중 같은 움직임을 반복했을 때 오차가 가장 작았다. |
| 처음부터 짧은 구간으로 학습하면 더 정확할까? | 여러 길이를 섞어 학습한 모델과 짧은 구간에 맞춰 학습한 모델을 비교했다. | **짧은 구간의 평균 오차는 줄었지만**, 실제 점수가 낮은 사례와 긴 구간의 오차는 늘었다. |
| 낮은 점수를 지나치게 높게 주는 문제도 줄일 수 있을까? | 마지막 층만 학습하거나, 낮은 점수의 오차에 더 큰 비중을 주거나, 짧은 구간과 긴 구간을 함께 학습했다. | 두 길이를 함께 쓰면 긴 구간의 오차는 일부 줄었다. 낮은 점수를 높게 주는 경향은 남아 모델 교체를 보류했다. |

## 다리가 보여도 관절이나 착지를 잘못 짚었다

| 왜 확인했나? | 어떻게 확인했나? | 무엇을 알게 됐나? |
|---|---|---|
| 다리만 보여도 관절을 찾을까? | 같은 전신 영상에서 화면 위쪽을 가리고 MediaPipe로 다시 분석했다. | 가리기 전에는 대부분 GDI를 계산했지만, 가린 뒤에는 계산 가능한 영상이 없었다. |
| 다른 추출기를 쓰면 하반신 촬영도 가능할까? | 한 사람의 영상을 골반이 보일 때와 잘릴 때로 나눠 YOLO Pose를 시험했다. | 골반이 보이면 걸음 빈도를 계산했지만 착지를 놓치거나 더 셌다. 골반까지 잘리면 빈도도 얻지 못했다. |
| 가려진 무릎을 돌아오는 길에 볼 수 있을까? | 갈 때와 돌아올 때 각각 잘 보이는 다리를 골랐다. | 양쪽 무릎을 관찰할 수 있는 영상이 늘었다. 다만 서로 다른 걸음을 봤으므로 같은 걸음의 좌우 차이는 알기 어렵다. |
| 착지를 일찍 잡거나 두 번 세는 오류를 줄일 수 있을까? | 사람이 표시한 착지와 비교해 뒤꿈치가 내려갈 때 시점을 늦추고, 같은 발이 연달아 잡히면 간격을 확인했다. | 한 촬영에서는 잘못 추가한 착지가 줄었지만 다른 자료에서는 시점 오차가 커져 공통 규칙으로 쓰기 어려웠다. |

## 점수 차이가 실제 보행 차이를 뜻하는지 확인했다

| 왜 확인했나? | 어떻게 확인했나? | 무엇을 알게 됐나? |
|---|---|---|
| 천천히 걸어서 점수가 낮은 걸까? | 속도가 비슷하고 실측 GDI가 뚜렷이 다른 두 사람 중 누구의 점수가 더 낮은지 맞혀 봤다. | 이 조건에서는 영상 모델이 속도만 쓸 때보다 낮은 쪽을 더 잘 구별했다. |
| 점수로 보행에 도움이 필요한 사람도 찾을 수 있을까? | 비슷한 속도로 걷는 사람의 기능 등급을 비교하고, 별도 자료에서 속도에 GDI를 더해 도움 등급을 예측했다. | 기능 제한이 큰 쪽의 점수가 더 낮은 경향은 있었다. 도움 등급 예측에서는 놓치는 사람이 줄지 않았다. |
| 평소 기록 한 편을 기준으로 삼아도 될까? | 같은 사람이 평소처럼 걸은 영상을 한 편 기준과 두 편 평균 기준으로 각각 비교했다. | 세 사람의 반복 촬영에서는 두 편을 평균했을 때 평소 기록끼리의 점수 차이가 작았다. |
| 같은 영상도 처리 환경에 따라 달라질까? | 똑같은 프레임을 브라우저와 PC에서 처리해 무릎 움직임을 비교했다. | 같은 영상에서도 차이가 남았다. 개인 기록을 비교할 때는 처리 환경과 추적 시작 조건을 맞출 필요가 있다. |
| 작은 점수 변화까지 표시해도 될까? | 반복 방문에서 예측 변화와 실측 변화를 비교하고, 작은 예측 차이는 표시하지 않는 방법도 시험했다. | **표시한 변화의 방향은 더 자주 맞았지만 실제로 큰 변화도 절반 넘게 가려졌다.** 가정 촬영에 쓸 기준은 아직 정하지 않았다. |

### 어떤 모델로 실험을 시작했나?

Stanford 자료에서 695명의 기록 1,064개를 사용했다. 각 기록의 처음 124프레임에서 관절 좌표를 읽고 왼쪽과 오른쪽 다리의 GDI를 따로 예측했다. 같은 사람의 기록을 한데 묶어 전체를 다섯 그룹으로 나눈 뒤, 매번 556명으로 학습하고 나머지 139명으로 평가했다. 아래 오차는 예측값이 실측값에서 얼마나 벗어났는지를 사람별로 먼저 평균하고, 다시 전체 사람에 대해 평균한 값이다.

|---|---:|
| CNN이 관절 움직임을 처음부터 학습했다. [CNN 실험](2026-10-30-cnn-baseline695/README.md) | 8.683496점 |
| 사전 학습된 MotionBERT에서 움직임 특징을 뽑고, 그 특징으로 점수를 예측했다. | 8.526630점 |

#### 초기 CNN과 MotionBERT로 점수를 다시 계산하는 방법

1. 각 실험 폴더의 `requirements.txt`를 참고해 NumPy와 PyTorch를 설치한다.
2. 초기 모델 배포 페이지에서 원하는 모델의 압축 파일을 받아 푼다. 각 파일에는 서로 다른 556명으로 학습한 모델 다섯 개가 들어 있다. MotionBERT는 마지막 단계를 다시 학습한 모델 다섯 개를 배포했다. [초기 모델 다운로드](https://github.com/youngni05/gait-scoring/releases/tag/research-initial-models-20261101)
3. 각 실험 문서의 명령에 따라 `predict.py`에 전처리를 마친 관절 좌표 배열을 넣으면 양쪽 다리의 GDI가 나온다. 입력의 세 번째 값은 해당 관절이 얼마나 확실하게 관측됐는지를 나타낸다. 휴대폰 원본 영상은 먼저 관절을 추출하고 좌표 형식을 맞춰야 한다.

`run.py`와 설정 파일에는 당시의 학습 절차가 남아 있다. 전체 학습을 다시 실행하려면 공개 범위에서 제외한 개인별 좌표와 정답, 데이터 분할 명단, 캐시 등도 필요하다. 원자료에는 제공 기관의 이용 조건이 적용된다. [공개 파일과 원본의 대응 관계](source-files.json) · [Stanford 원자료 안내](https://github.com/stanfordnmbl/mobile-gaitlab)

#### 배포한 모델로 다시 계산해도 원래 점수가 나오는가?

초기 CNN과 MotionBERT를 배포할 때는 학습을 이어가는 데 쓰는 정보를 빼고, 예측에 필요한 값만 파일에 담았다. 먼저 원본 파일의 내용이 맞는지 SHA-256으로 대조하고, 옮긴 모델의 가중치가 원본과 같은지 확인했다. 그런 다음 **배포할 모델로 기존 보행 기록 1,064개의 GDI를 다시 계산해 원래 저장한 예측값과 비교했다.** 두 모델 모두 차이가 0.0001점 이내였다.

원래 학습에는 RTX A6000과 Python 3.8.10, PyTorch 2.4.0+cu121, NumPy 1.24.4를 사용했다. 배포 파일은 필요한 라이브러리가 이미 설치된 CPU 환경에서 확인했다. 새 컴퓨터에 처음부터 설치하는 과정은 당시 확인 범위 밖이었다. [모델별 재계산 결과와 실행 환경](publication-verification.json)
