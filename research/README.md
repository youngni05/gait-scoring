## GDI 초기 CNN·MotionBERT 실험

보행 관절 좌표로 실제 좌우 GDI를 예측할 수 있는지 살펴본 초기 실험 두 개다. 전체 실험 이력이나 최신 최선 모델을 모두 공개한 목록은 아니다. GDI는 정상 참조집단 평균이 100인 보행 편차 지수이며, 0~100점의 일반 보행능력 점수나 낙상 위험 확률과 다르다.

두 실험은 같은 공개자료의 **695명·1,064기록**, 초반 **124프레임**, 사람 단위 **5분할**을 사용했다. 한 사람의 여러 기록은 같은 분할에 두었다. 매회 556명으로 학습하고 139명을 평가했다. MAE는 좌우와 여러 기록의 절대오차를 사람 안에서 평균한 다음 사람마다 같은 비중으로 평균한 값이며, 단위는 GDI점이다.

| 실험 | 바꾼 방법 | 사람별 MAE↓ | 상세 기록 |
|---|---|---:|---|
| 초기 1D-CNN | 관절 좌표에서 시간 흐름을 직접 학습 | 8.683496 | [CNN](2026-10-30-cnn-baseline695/README.md) |
| MotionBERT 부분학습 | 사전학습된 움직임 모델의 마지막 단계와 출력부를 조정 | 8.354702 | [MotionBERT](2026-10-30-motionbert695/README.md) |

같은 조건의 고정 MotionBERT+Ridge 기준은 MAE 8.526630이었다. CNN은 이 기준을 개선하지 못했고, MotionBERT 마지막 단계 부분학습에서는 약 0.172점 감소를 관찰했다. 개발자료에서 반복 비교한 결과이며 독립 최종 성능, 고령자 현장 성능 또는 임상적 유용성을 입증한 결과는 아니다. 보호해 둔 최종 평가 후보 223명과 기존 검증·평가 37/38명은 두 실험에 사용하지 않았다.

## 모델 받기와 실행

코드·설정·집계 결과는 이 저장소에, 학습된 가중치는 [GitHub Release](https://github.com/youngni05/gait-scoring/releases/tag/research-initial-models-20261101)에 둔다. 각 묶음에는 해당 실험의 5개 평가 분할 모델이 있다. 모두 다른 556명으로 학습한 모델이며 전체 695명으로 새로 학습한 단일 최종 모델은 아니다. MotionBERT 실험의 출력부만 학습·마지막 변환부 학습 결과도 기록하되, 가중치 배포는 `last_stage` 5개로 한정했다.

1. 각 실험 폴더의 `requirements.txt`로 NumPy와 PyTorch를 설치한다.
2. Release에서 해당 가중치 압축을 받아 원하는 위치에 푼다. 분할별 `.pt`와 SHA-256 목록이 나온다.
3. 상세 기록의 명령으로 **이미 전처리한 관절 배열**을 입력한다. `predict.py`는 학습된 모델을 불러와 왼쪽·오른쪽 GDI를 계산한다.

원본 영상, 개인별 관절·정답·예측 배열과 사람 분할 명단은 이번 공개 묶음에 넣지 않았다. 학습 재개용 optimizer와 난수 상태도 가중치에서 제외했다. 원 데이터의 이용 조건은 코드 라이선스와 별개이며 [원 제공자](https://github.com/stanfordnmbl/mobile-gaitlab)의 안내를 따른다.

`run.py`·설정·`manifest.json`은 실제 실행한 원본을 보존한다. 원 manifest가 요구하는 데이터·캐시·보조 파일 중 이번 배포에 넣지 않은 파일이 있으므로 이 저장소만으로 원자료 준비부터 전체 재학습까지 자동 실행할 수는 없다. 가중치 추론은 별도 `predict.py`로 실행한다. 공개 파일과 원본의 대응은 [source-files.json](source-files.json)에 기록했다.

원 학습 환경은 Python 3.8.10·PyTorch 2.4.0+cu121·NumPy 1.24.4·RTX A6000이었다. 이번 공개용 CPU 추론 확인에 실제 사용한 환경은 아래 검증 JSON에 별도로 기록한다. 기존 설치된 라이브러리를 사용했으며 새 환경에 의존성을 설치하는 과정까지 검증한 것은 아니다.

현재 입력은 영상에서 관절을 추출하는 단계 이후부터다. 세 번째 채널은 3D 깊이가 아닌 관측 신뢰도다. 스마트폰 영상·MediaPipe 좌표를 그대로 넣는 경로, 실제 GDI와의 외부 검증, 개인의 장기 변화 판정은 이 공개 범위에 포함하지 않는다.

## 공개 묶음 검증

가중치 파일은 원 실험의 체크포인트 SHA-256과 대조한 후 추론에 필요한 값만 추출했다. 모델 텐서가 원본과 같은지 확인했으며, 공개 묶음의 전송·추론 확인 범위는 [publication-verification.json](publication-verification.json)에 기록한다. 기존 실험 당시의 검산 기록과 이번 공개 준비에서 수행한 검사를 구분한다.
