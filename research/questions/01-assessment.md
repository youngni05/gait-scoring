# 무엇을 평가할 것인가?

짧은 걸음은 신체기능검사 결과를 일부 설명했다. 그래서 걷는 동안 관절 움직임이 기준 보행에서 얼마나 벗어나는지를 우선 평가하기로 했다.

| 파생 질문 | 어디서 나온 질문인가? | 어떤 실험으로 어디까지 답했나? |
|---|---|---|
| 1.1 왜 평소 걸음에 주목했나? | 어르신의 상태를 자주 살펴보려면 검사를 준비하는 부담도 줄어야 했다. | 스마트폰으로 신체기능검사(SPPB)를 자동 측정하는 계획을 검토했다. 시간을 대신 재도 균형 잡기·걷기·의자 일어서기를 매번 수행해야 해서, 걸음만 촬영하는 경우를 따로 살폈다. [초기 연구 방향](../../docs/2026-11-01-interim-presentation_v2.md) |
| 1.2 짧은 걸음에 기능 정보가 담겨 있나? | 1.1의 아이디어를 시험하려면 보행과 실제 검사 결과가 짝지어진 사람이 필요했다. | 고령자 44명의 정밀 3D 보행 기록에서 3초 구간 5회의 예측을 평균하자, SPPB 오차가 대표값만 쓸 때의 1.32점에서 1.00점으로 줄었다. [SPPB 실험](../archived-sppb-tug/2026-10-30-sppb-older44/README.md) |
| 1.3 직선 보행이 놓치는 기능은 무엇인가? | SPPB에는 영상에 안 나오는 동작도 있어, 일어나 걷고 돌아와 앉는 시간(TUG)도 살폈다. | OpenCap 자료에서는 보행을 쓰면 평균 예측이 좋아졌지만 실제 TUG가 20초 이상인 9명의 시간은 평균 약 14초 짧게 예측했다. [TUG 실험](../archived-sppb-tug/2026-10-30-tug-opencap298/README.md) · [느린 수행 사례](../../docs/2026-11-01-interim-presentation_v2.md) |
| 1.4 왜 보행편차지수(GDI)를 선택했나? | 1.3에서 촬영한 동작과 평가 대상이 더 잘 맞는 정답이 필요해졌다. | Stanford에는 보행 영상의 관절 좌표와 같은 방문의 검사실 좌우 GDI가 함께 있었다. 뇌성마비 중심 자료에서 먼저 예측을 시험하고, 고령자의 기능과 개인 변화는 별도로 검증한다. [GDI 추정 방법](02-gdi-estimation.md) |
