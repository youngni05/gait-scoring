# GDI와 함께 보면 보행을 더 잘 설명하는 측정값은 무엇인가?

비슷한 속도에서도 GDI가 기능 차이를 일부 구별했고, GDI가 비슷한 사람도 속도·리듬·무릎 움직임은 달랐다.

| 파생 질문 | 어디서 나온 질문인가? | 어떤 실험으로 어디까지 답했나? |
|---|---|---|
| 5.1 비슷한 속도에서도 GDI가 기능 차이를 보여줄까? | GDI와 속도가 같은 정보라면 둘을 함께 볼 이유가 작다. | Stanford 개발자료에서 속도 차이 0.05m/s 이내이고 대근육 기능 등급이 다른 53쌍 중 38쌍에서 기능 제한이 큰 쪽의 예측 GDI가 낮았다. 엇갈린 15쌍 중 7쌍은 검사실 GDI의 순서도 기능 등급과 달랐다. |
| 5.2 반대로 GDI가 비슷하면 속도가 차이를 드러낼까? | 5.1에서 GDI와 기능 등급의 순서가 항상 같지는 않았다. | 예측 GDI 차이 2점 이내이고 기능 등급이 다른 65쌍 중 48쌍에서 제한이 큰 사람이 더 느렸다. 속도는 같은 방문의 실험실 측정값으로 비교했다. |
| 5.3 종합점수가 비슷한 두 사람의 걸음을 어떻게 설명할까? | 속도와 GDI만으로는 걸음 간격이나 무릎을 얼마나 굽혔는지 되짚기 어렵다. | 고령자 영상 두 편의 GDI는 73.4·74.5점이었지만 분당 걸음 수는 94·102회, 왼쪽 무릎 움직임 폭은 약 67·44도였다. 이 지표들은 같은 영상 좌표에서 따로 계산한다. [걸음 지표 계산](https://github.com/youngni05/gait-scoring/blob/971ff652f31bba434631837d298e6d37b4cacf00/research/updates/2026-11-19/test02-gait-metrics.md) |
| 5.4 무릎 움직임을 더하면 기능 점수도 더 정확해질까? | 5.3에서 움직임의 차이를 설명한 지표가 기능검사 예측에도 보탬이 되는지 물었다. | 고령 뇌졸중 25명에서 한 명씩 제외하고 균형·보행검사(POMA)를 예측했다. 오차는 GDI 단독 4.83점, 무릎 반복성을 더하면 4.13점, 속도 단독 4.01점이었다. 같은 사람들에서 고른 무릎 지표여서 새 자료 검증이 필요하다. |
| 5.5 실제로 도움이 필요한 사람도 더 잘 찾을까? | 돌봄 현장에서는 점수 차이가 걸을 때의 도움 수준과 연결되는지가 중요하다. | 공개 보행 도움 등급(FAC)과 대조했을 때 속도에 GDI를 더해도 더 많은 도움이 필요한 등급을 놓친 인원이 줄지 않았다. 촬영 당시 실제 부축 여부는 별도 정답이 필요하다.
