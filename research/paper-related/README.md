# 논문에 사용한 GDI 실험

기존 영상 모델은 학습에 쓰지 않은 정상 보행에 평균 79.4~82.7점을 냈습니다. 실측 GDI가 없는 정상 성인 64명·881편에 100점을 가정해 환자 자료와 함께 학습한 뒤, 외부 보행의 출력과 실측 GDI가 있는 환자 자료의 오차를 비교했습니다. GDI에서 100점은 정상 참조집단의 평균입니다.

| 비교 | 주요 결과 | 상세 기록 |
|---|---|---|
| 외부 정상·이상 보행 | 정상 집단의 평균 출력은 92.6~98.8점으로 올라갔습니다. 비교한 세 자료에서 정상 집단의 상승 폭이 더 컸습니다. | [자료별 결과](gdi-normal-calibration.md#3-외부-정상-집단과-이상-보행-집단의-점수-변화) |
| 3차원 자료에서 계산한 GDI | 건강 성인의 평균 차이는 −14.3점에서 −5.4점으로 줄었습니다. 뇌졸중 자료 41명에서는 마비측을 더 낮게 평가한 비율이 65.9%에서 80.5%로 늘었습니다. 이 비교에는 3차원 표지점을 변환한 입력을 사용했습니다. | [계산 GDI와 마비측 비교](gdi-normal-calibration.md#4-3차원-관절각으로-직접-계산한-gdi와-비교) |
| 환자 자료의 실측 GDI | 미학습 222명의 평균 절대오차는 6.249점에서 6.375점으로 0.126점 늘었습니다. 정상 아동의 평균을 같게 맞춘 점수 재조정 대조의 오차는 13.714점이었습니다. | [고정 평가](../archive/studies/20261106-final222-normal100/README.md) · [점수 재조정 대조](../archive/studies/20261110-rescale-control/README.md) |

외부 정상 집단의 점수 상승은 이 자료에서 모델의 출력이 달라졌음을 보여 줍니다. 실제 영상에서의 GDI 정확도를 평가하려면 대응하는 실측 GDI가 필요합니다. 개발자료의 오차·출처 대조와 정상·이상을 가르는 기준점 비교도 결과를 어디까지 쓸 수 있는지 판단하는 데 참고할 수 있습니다. [전체 비교 조건·결과·한계](gdi-normal-calibration.md)
