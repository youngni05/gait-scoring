| 실험 | 입력·정답 | 주요 관찰 | 기록 |
|---|---|---|---|
| SPPB | 44명의 Vicon 보행 마커와 실제 SPPB 총점 | 3초 보행 5회의 예측을 평균한 RF MAE 1.001점 | [방법·결과·실행](2026-10-30-sppb-older44/README.md) |

두 실험은 자료·대상·정답·평가 단위가 달라 숫자로 서로의 성능을 비교하지 않는다. 같은 사람의 반복 기록은 같은 분할에 두고, 설정 선택과 정규화는 평가 사람을 제외한 학습 집단에서만 수행했다. 독립 자료에서 임상검사를 대체할 수 있음을 입증한 결과는 아니다.

## 저장 모델과 코드

[GitHub Release](https://github.com/youngni05/gait-scoring/releases/tag/research-functional-archive-20261102)에 SPPB·TUG 모델을 따로 첨부했다. 각 묶음은 Ridge·RF·CNN·TCN의 5개 평가 분할 모델, 총 20개를 포함한다. 서로 다른 학습 집단으로 적합한 모델이며 전체 자료를 학습한 단일 최종 모델이나 별도 앙상블이 아니다.

- `cpu.py`는 보행 채널의 평균·변동·시간 변화 요약으로 Ridge·RF를 학습한 원 코드다.
- `gpu.py`는 시간순 입력으로 작은 CNN·TCN을 학습한 원 코드다. `predict.py`는 저장 모델을 불러와 이미 전처리한 입력의 점수·시간을 계산한다.
- `protocol.json`과 `results/`는 당시 설정과 집계 결과를 담는다. 기존 검산 기록과 이번 배포 확인은 구분하며, 이번 결과는 [publication-verification.json](publication-verification.json)에 있다.

원본 영상·임상표·개인별 좌표·정답·예측·분할 명단은 이번 배포에 포함하지 않았다. 학습 코드는 원 실험의 입력 파일과 분할·보조 파일이 있어야 재실행할 수 있다. 전처리·검산 코드도 원 자료 배치와 원 폴더 구조를 전제로 한 기록이므로, 이 공개 묶음만으로 원자료 수집부터 전체 재학습까지 자동 실행되지는 않는다. 추론 명령은 각 실험 문서에 있다.

새 학습이나 새 모델 선택은 하지 않았다. 기존 모델로 SPPB 220기록·TUG 298기록을 각각 네 방법 모두에서 재추론했고, 기존 저장값과 0.0001 이내로 일치함을 확인했다. 공개 파일의 원본 대응·SHA-256과 경로 정리는 [source-files.json](source-files.json)에 남겼다. SPPB 설정의 작업 PC 전용 정답 파일 경로만 원 자료의 파일명으로 바꾸었으며 과학적 설정은 유지했다.

SPPB는 보정된 Vicon 3D 마커, TUG는 여러 RGB 카메라로 복원된 OpenCap 시계열을 사용했다. 단일 RGB 영상이나 스마트폰에서 바로 같은 성능을 얻는다는 근거는 아니다. 현재 GDI 연구와의 입력·정답 차이를 유지해 해석한다.
