# 보행 기반 저기능 직접 분류와 확률 보정 비교

**결론: 저기능을 직접 학습하거나 이진 확률 보정으로 바꾸는 것만으로 기존4구간 RF를 개선하지 못했다.** 이진RF는 초기값5개 전체에서 놓침이 증가했다. SPPB43.63→49.96%,TUG35.31→38.80%였고 오경고도 각각9.95→10.03%,10.03→10.28%로 늘었다. 기존RF 대비 놓침 차이의 사람 재표집95%구간은 SPPB+3.31~+9.78%p,TUG+1.09~+6.16%p였다.

이진HGB의 TUG 놓침은35.11%로 기존RF35.31%와 거의 같았지만 오경고는10.25%로 증가했다. SPPB는 놓침44.04%·오경고10.76%였다. 기존4구간RF에 이진 보정만 바꾼 결과도 거의 같았다. 같은 질환·속도 구분에서 직접 이진 학습의 추가 이득은 확인되지 않았다. 따라서 큰 모델이나 정답 단순화가 자동으로 저기능 구분을 개선한다는 근거를 얻지 못했다. 이 결과는 현재 입력·설정의 비교이며 이진 학습 전체의 한계를 증명하지 않는다.

질문은 네 점수 구간을 함께 맞추는 대신 저기능을 직접 학습하면 놓침을 줄일 수 있는가다. SPPB≤3점/TUG>20초를 그대로 사용하고 측정 정답을 바꾸지 않았다. 같은2,174명/1,939명,30–60초5개,기존4개+회전 빈도25열,사람5분할·초기값5개를 유지했다.

OriginalRF는 이전4구간RF의 온도 보정·경고 기준을 그대로 재현한다. MultiRF/MultiHGB는 기존4구간 모델의 저기능 확률에 공통 이진 Platt 보정만 새로 적용한다. BinaryRF/BinaryHGB는 저기능 여부를 직접 학습하고 같은 보정을 사용한다. 이 비교로 모델 목표 변경과 확률 보정 변경을 구분한다. RF는128나무·최소잎20, HGB는200단계·학습률0.05·최소잎20·L2=1을 고정하고 잎7/15만 내부 검증에서 고른다. 모든 모델은 사람 동일 학습 비중이며 저기능 가중치를 추가하지 않았다.
