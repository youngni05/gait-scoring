# OpenCap 일어서기·앉기 추가 비교 — 2026-10-31

현재 특징 추출·모델 설정에서는 **기립·착석 추가가 긴 TUG의 과소예측을 더 줄인다는 근거를 얻지 못했다.** 같은 입력시간의 회전·주변 보행 모델과 비교하면, 핵심 구간 추가의 긴 사람 평균 과소예측은 10.910→11.715초였다. 준비 동작 후보까지 포함한 탐색적 비교도 10.340→11.474초로 증가했다. 일어서기만 추가하면 0.190초 감소했지만 사람별 차이와 불확실성이 커서 안정적 개선으로 판단하기 어렵다.

## 비교가 답하는 질문

모델은 같은 방문에 기록된 실제 임상 TUG 시간(`tft_tug`, 초)을 예측한다. 입력은 기존 직선 보행 3초와 TUG 회전 구간에 기립·착석 구간의 움직임·시간 요약을 더한 것이다. 인공 점수나 자동 측정한 전체 TUG 시간을 정답으로 쓰지 않았다.

짧은 기존 회전 입력에 단순히 더 많은 영상을 주는 효과를 구분하기 위해, 대조군에도 **똑같은 초수의 회전 주변 보행**을 추가했다. 두 모델 모두 기존 직선 3초와 기존 회전 전체를 유지한다. 추가 모델은 의자 주변의 동작을, 대조군은 의자 동작과 겹치지 않는 회전 전후의 보행을 본다. 대조군에는 기존 회전 특징도 그대로 남겨, 구간 확장 때문에 기존 정보가 사라지지 않도록 했다.

초기 비교는 움직임이 위아래로 바뀌는 핵심 구간의 실제 길이를 썼고, 별도로 기립 2초·착석 2초의 고정 길이 비교도 수행했다. 움직임을 잡는 과정에서 준비 동작 누락 가능성을 발견해 추가 탐색 비교를 선언했다. 이 추가 방법은 초기 네 비교의 모델 성능을 읽기 전에 설계했지만, 기존 자료를 살펴보고 정한 탐색적 방법이며 사전 등록이나 독립 검증으로 취급하지 않는다.

## 실제 점수 연결과 구간 품질

이전 238명의 같은 사람·방문·직선 파일·TUG 파일을 그대로 시작점으로 삼았다. 다른 방문이나 더 유리한 시행으로 바꾸지 않았다. 실제 임상값은 원본 표와 다시 연결하고 파일 해시를 확인했다. 같은 방문 안의 여러 TUG 시행 중 어느 시행을 임상표에서 계시했는지는 여전히 확정되지 않았다.

처음에는 앉은 높이와 회전 중 높이의 차이로 기립·착석을 찾았지만, 보행 중 높이가 서서히 변하는 자료에서는 구간이 과도하게 길어졌다. 이 입력 점검을 바탕으로 의자 근처에서 높이 변화속도가 크게 양수·음수가 되는 부분을 찾는 방식으로 바꿨다. 기준은 0.25초 평활화, 0.12 m/s 이상의 봉우리, 변화량 0.08 m 이상, 앞뒤 0.25초 여유 구간이다. 착석은 기록 끝의 높이가 처음 앉은 높이와 0.12 m 이내인지도 검사한다. 이는 경험적 구간 탐지이며 사람의 수동 정답은 없다.

[원 연구진 코드](https://github.com/stanfordnmbl/opencap-fshd-dm-analysis/blob/main/feature_extraction/featurize_tug.py)도 골반 중심 높이로 TUG 시점을 계산한다. 원 코드는 TRC 마커를 쓰며 이번 MOT 골반 위치·국소 변화 탐지와 동일한 구현은 아니다. 이를 근거로 임상 정확도가 검증됐다고 보지 않는다.

238명 중 기립 후보 230명, 착석 후보 223명, 둘 다 찾은 사람은 220명이었다. 이후 선택 구간의 수직 속도 급변(3 m/s 초과), 대조군 구간 부족·겹침 등을 검사했다. 긴 9명과 일반 대상 6명의 높이 그래프를 직접 검토했다. 주요 제한은 다음과 같다.

- sub-296: 해당 MOT에서 기립·착석 전환을 식별하지 못했다.
- sub-332·sub-397: 기립은 보이지만 기록 종료 전 앉은 상태가 확인되지 않아 일어서기만 비교했다.
- sub-266·sub-406: 선택 구간의 높이 급변 기준에 걸렸다. 품질 경고를 남긴 별도 민감도 비교에만 두 동작을 포함했다.
- 나머지 긴 4명은 두 동작의 주 비교에 포함됐다. 원본 RGB와 전문 평가자의 동작 경계 정답은 확인하지 못했다.

## 같은 사람 분할과 관찰시간

기존 5가지 사람 분할 및 내부 검증 분할을 공통 대상자에게 제한 적용했다. 각 분할은 5묶음 평가이며 모델 초기값은 3개, 총 15회 반복이다. 각 비교 안에서는 모든 모델이 같은 사람·정답·학습·평가 묶음을 쓴다. 대상자가 달라진 만큼 기존 238명 결과를 그대로 대조군 숫자로 가져오지 않고 모든 모델을 다시 학습했다.

모델은 이전과 같은 Random Forest 128개 나무이며 잎의 최소 자료 수 2/5를 학습 사람 내부에서 선택했다. 입력 표준화도 학습 사람만 이용했다. 작은 고정 길이 집단에도 같은 학습 규칙을 유지했다. 전체 정답이 아닌 학습 정답 범위에만 의존하는 모델이다.

기립·착석 핵심 비교의 입력시간 합계는 6.63~12.93초, 고정 길이 비교는 9.27~13.60초이다. 준비 동작 후보를 포함한 비교는 6.73~24.80초였다. 각 사람에서 대조군과 추가 모델의 시간 합계가 같고, 중복 구간을 두 번 관찰한 것으로 세지 않았음을 검산했다.

이 시간은 **모델에 전달한 구간의 합계**다. 구간을 찾는 데에는 전체 기록을 사용했고 직선과 TUG는 별도 기록이다. 실제 촬영시간이나 하나의 연속 25초 영상 검증을 뜻하지 않는다. 전체 TUG 경과시간, 구간의 절대 시각, 아래의 임상시간 차이 분석값은 모델 입력에서 제외했다.

## 준비 동작을 더 봐도 무엇이 남았나

골반이 올라가기 전의 몸통·고관절 변화가 누락될 가능성을 확인했다. 탐색적 추가 방법은 골반 기울기·허리 각도·좌우 고관절 평균각 중 2개 이상이 처음 0.75초 기준에서 8도 이상 벗어난 상태가 0.25초 이어지는 첫 시점을 찾는다. 그 시점부터 기존 기립 구간 끝까지를 사용한다. 임상 정답으로 구간을 고르지 않았으며 명령 시점·실제 준비 동작 정답을 확보한 것은 아니다.

sub-283에서는 기립 입력 시작이 19.07초에서 7.20초로 앞당겨졌고 총 입력은 24.80초가 됐다. sub-310도 11.17초에서 7.30초로 앞당겼다. 두 사람을 포함한 6명의 확장 그래프를 확인했지만, 단순 자세 바꿈과 실제 기립 준비를 완전히 구분했다고 주장하지 않는다.

준비 후보까지 포함한 101명 비교의 개인별 결과는 다음과 같다. 예측은 15회 평균이고 마지막 열의 양수는 과소예측 감소다.

| 사람 | 실제 TUG | 같은 시간 회전·보행 예측 | 준비·기립·착석 추가 예측 | 과소예측 감소 |
|---|---:|---:|---:|---:|
| sub-246 | 22.18 | 16.67 | 13.20 | -3.46 |

42.59초 사례의 예측은 약 19.01초에서 17.58초로 낮아졌다. 이 사람을 평가할 때 학습 정답의 최댓값은 22.18~22.50초였다. 현재 Random Forest는 학습 정답 범위를 넘어 예측하지 못하므로 입력 구간 추가만으로 극단적으로 긴 시간을 맞추기 어렵다. 이는 확인된 모델 한계이며 임상적 원인을 확정한 설명은 아니다.

또한 높이로 찾은 기립 핵심 시작~착석 종료의 경과시간을 모델 밖에서 점검했다. 양쪽 구간이 있는 220명에서 임상값과의 절대차 중앙값은 0.213초였다. 그러나 sub-283은 경과시간 27.60초와 임상 42.59초 사이에 14.99초 차이가 났다. sub-310은 4.13초 차이였다. 준비시간·계시 시작점·시행 대응·추적 및 구간 탐지 오류를 구분해야 한다. **이 차이만으로 임상표가 틀렸다고 결론 내리거나 정답을 바꾸지 않았다.**

현재의 판단은 “기립·착석은 쓸모없다”가 아니라, 골반 높이·속도·국소 시간 요약을 현재 모델에 추가하는 방식으로는 긴 TUG 문제를 해결하지 못했다는 것이다. 준비 후보를 넓혀도 개선되지 않았다. 다음 판단에는 긴 사례의 실제 계시·동작 경계 확인과 학습 자료 확대가 우선 필요하다. 풍부한 관절 시계열 모델, SPPB 예측, 단일 카메라 측정 정확도는 이번 비교의 검증 범위가 아니다.

## 재현과 검증

`segment.py`는 높이가 오르내리는 후보 구간을 찾고, `build.py`는 그 사람에게 같은 길이의 보행 대조 구간이 있는지 검사한다. 실패하면 값을 채우지 않고 제외 이유를 저장한다. `preparation_phase.py`는 준비 후보를 포함하는 탐색적 추가 비교를 만들며, `fit_study.py`·`fit_extension.py`는 기존 학습기를 그대로 재사용한다. `assess.py`는 실행별·사람별 오차를 계산한다. 이 흐름이 구간 추가 효과와 단순 관찰시간 효과를 구분하는 핵심이다.

로컬 Windows CPU에서 실제 공개 MOT 자료로 학습했다. 새 패키지 설치·GPU 업로드·원본 자료 변경은 없었다. 기존 연구 폴더도 수정하지 않았다. 준비된 입력 재현 순서는 `check_inputs.py` → `fit_study.py` 및 `fit_extension.py` → `assess.py` → `check_results.py` → `finalize.py`이다. 학습 스크립트는 완료 파일이 있으면 덮어쓰지 않는다.

독립 입력 검산에서 원본 해시·실제 임상값·기존 사람 분할·시간 합계·구간 비중복을 확인하고, 특징을 다른 수식 구현으로 다시 계산했다. 준비 후보 탐지 시작점도 별도 계산과 일치했다. 저장 모델 **1,350개**를 재실행해 예측을 확인했고, 학습 자료만의 표준화·학습 정답·내부 설정 선택·지표·재표집 범위도 검산했다. 구현 검증을 통과했으며 임상 검증과는 구분한다.

근거 파일은 `input-verification.json`, `results-verification.json`, `summary.json`, `long-person-comparison.csv`, `timing-audit.json`이다. 구간 검토 그림은 `final-phase-review-*.png`, `preparation-review-*.png`이며 결과 그림은 `chair-comparison.png`이다. 환경과 최종 파일 해시는 `environment.json`, `artifact-manifest.json`에 기록했다.
