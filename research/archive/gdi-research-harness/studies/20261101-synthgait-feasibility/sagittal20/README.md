## 이번에 실제로 수행하는 범위

1. 공개 고정 버전에서 처음 발견되는 측면 움직임20개를 확보한다. 학습 split16개·검증 split4개이며 정답이나 모델 점수로 선택하지 않는다. 원래 사람ID는 공개되지 않아20명이라고 세지 않는다.
2. 영상20개를 끝까지 디코딩하고 실제 프레임 수·FPS를 기록한다. NPZ의6개 보행 지표와 좌우 발뒤꿈치 접지 주석을 보존한다. 영상16Hz와 주석30Hz를 구분한다.
3. 기존 공식 OpenPose BODY25 가중치와 -1x368 입력을 재사용한다. CPU 공식출력3개와 GPU 열지도를 기존1e-4 기준으로 대조한다. GPU는 학습 없이 열지도만 계산하고, 공식 OpenPose CPU의 사람·관절 연결(PAF) 디코더로 좌표를 만든다.
4. 유일한 사람이면 선택하고,여러 사람이면 명시적 프레임별 선택표가 있을 때만 선택한다. 선택표가 없는 여러사람·검출없음은결측으로보존한다. 원래 BODY25 번호를 유지하고 좌우를 화면 위치로 다시 붙이지 않는다.
5. 기존 고정 소스의 보간·sigma1평활·엉덩이 중심·허벅지 길이 정규화·12특징 계산을 재사용한다. 짧은 영상을 반복·늘이기·0패딩해124프레임으로 꾸미지 않는다.

공개 개발표본650프레임의12개 특징·5모델 예측을 먼저 재현했다. `sample-replay.json`의 특징차이0·예측차이0이다. 이 재현은 새 합성 영상의 관절 정확도를 입증하지 않는다.

## 사전학습 파일럿 통과 조건

현재는 **기존124프레임 CNN에 그대로 넣는 파일럿의 입력 조건을 통과하지 못했다.** 변환 성공과 학습 준비 완료를 구분한다. 접지번호를영상프레임으로바꾸는원점/잘라낸시간정보도확인되지않았다. 원인을영상잘라내기나FPS오류로확정하지않고,범위밖접지를잘라붙이거나0~마지막프레임으로압축하지않는다.

다음에 시도할 만한 구체적인 후보는 **합성 영상에서는 원래길이로 CNN의 합성곱 부분만 사전학습하고, 그 부분의 가중치만 기존124프레임 GDI CNN으로 옮기는 방식**이다. 사전학습용 시간평균/출력층은버리고 GDI의원래출력부를새로학습한다. 이경우 원래CNN전체를그대로사전학습한실험과다르므로,같은GDI모델·동일사람분할에서무작위초기화대조군을둔다. BatchNorm통계의이전여부도학습사람안에서만정해야한다. 16FPS와기존입력간시간차이의영향은미해결조건으로남긴다. 이새구조는아직구현·실행하지않았다.

다음 선택지는 변환 결과를 보고 정해야 한다.
