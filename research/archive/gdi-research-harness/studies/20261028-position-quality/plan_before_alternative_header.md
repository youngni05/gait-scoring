# 구간별 입력 품질·움직임과 점수 변화의 관계

2026-10-28 사용자 직접 요청: 구간별 관절 추정 품질과 움직임 차이를 실제로 확인하고, 원인 후보·알고리즘 개선 위치·GDI 대안을 분석한다. 이번에는 새로운 임상 척도로 학습하거나 사람 분리·정답·기존 평가 지표를 바꾸지 않는다. 앱·새 촬영은 하지 않는다.

## 입력과 고정 조건

직전 고정 모델 실험의 검증37명·40건 예측을 사용한다. 원래 개발212명·243건의243프레임 좌표 중 허용된 영상만 읽고, 앞[0:124]·중간[59:183]·뒤[119:243]를 비교한다. 학습175명과 검증37명은 따로 집계하고, 상관 분석은 검증37명에서 사람별로 기록을 먼저 평균해 수행한다. 평가38명·최종223명은 사용하지 않는다. 자료·모델·코드의 지문을 확인한다.

입력은 OpenPose에서 변환한17관절의 화면 좌표·신뢰도다. 신뢰도는 실제 위치 오차의 정답이 아니다. 화면상 움직임은 몸·촬영 각도·카메라 이동·추정 오차가 섞인다. 영상·3D동작 정답 없이 실제 가림이나 회전을 확정하지 않는다. 하체가 연속 검출된 자료만 선택돼 있어 하체 누락률은 구조적으로 낮을 수 있다.

## 계산할 진단 항목과 이유

- 하체6관절 신뢰도 평균과0.3미만 비율, 전체17관절의0값 비율: 검출기 출력 품질의 대리 지표. 0.3은 기술 통계용이며 제외·합격·임상 기준이 아니다.
- 허벅지·종아리 화면상 길이의 변동계수: 추정 흔들림 또는 투영·시점 변화의 대리 지표.
- 골반을 뺀 하체 좌표의2차 차분 크기90백분위: 급격한 변화의 대리 지표. 실제 움직임도 포함하므로 잡음으로 단정하지 않는다.
- 골반 대비 발목 좌우방향 움직임 폭,2D무릎각 움직임 폭,몸통 기울기 폭,어깨 폭/몸통 길이,골반 화면 이동량: 구간의 내용·투영 차이를 설명할 후보. 실제 보행 속도·보폭·회전 정답으로 부르지 않는다.
- 움직임 길이는 각 영상 전체의 하체 길이 중앙값으로 나눠 구간별 분모 변경을 피한다. 무릎·몸통각은 화면상의2D각도다. 신뢰도가0인 관절이 필요한 계산에서는 해당 프레임만 계산 불가로 남기고 사용 가능한 수를 기록한다.

시작 전에 분석을 고정한다. 각 항목의 앞/중간/뒤 평균과 뒤-앞 차이를 보고한다. 검증37명에서 지표의 뒤-앞 변화와 예측의 뒤-앞 변화의 Spearman 순위상관을 계산한다. 절대 변화끼리의 상관도 함께 보고하며 모든 항목을 공개한다. 여러 항목의 탐색적 연관성이고 유의성 판정·인과관계·변수 선택에 사용하지 않는다. 동일인 기록은 먼저 평균한다.

## 학습 위치 차이 진단

저장된 앞/중간/뒤 local 구간별 Ridge 모델3개를 각각 세 위치 특징에 적용해3×3 MAE 표를 만든다. 새 학습·설정 선택은 하지 않는다. 각 모델의 표준화도 해당 저장본 그대로 사용한다. 대각선은 이전 구간별 학습 실험의 오차를 재현해야 한다. 맞는 위치로 학습한 모델이 그 위치에서 개선되는지 확인하되, 위치를 모두 섞어 학습했을 때의 결과를 대신하지 않는다.

## 검증과 다음 판단

원본 지문·243건 프레임 연속성·사람 분리·예측 행 연결을 확인한다. 진단 통계·상관을 별도 코드로 다시 계산한다. 이미 관측된5.07점 차이를 예측오차나 임상 변화 기준으로 바꾸지 않는다. 원인이 확정되지 않으면 대안 가설과 판별 실험을 명시한다.

GDI 대안은 원 논문·공개 자료에 근거해 의미와 데이터 조건을 비교한다. GDI라는 정답을 바꾸는 일과 입력 품질·학습 방법을 개선하는 일을 분리한다. 자료 확보·라벨 존재·사람 연결·사용 조건을 구분하고, 새 점수 체계 채택은 사용자 선택으로 남긴다.

환경 점검에서 기본 Python에 scipy가 없음을 확인했다. 새 패키지를 설치하지 않고 NumPy 순위 계산과 표준 라이브러리 독립 검산을 사용한다. 이 문제는 실험 결과 실패가 아니다.

## 입력 점검 이후 추가 실험: 세 위치를 함께 학습

첫 결과에서 뒤 구간의 신뢰도가 앞보다 낮지 않았고, 위치를 맞춰 학습한 기존 별도 모델도 중간·뒤 오차를 개선하지 못했다. 원 논문(Kidzinski et al., Nature Communications 2020)은124프레임 구간의 시작 위치를 바꾸어 학습했다. 이 방법을 현재 동결 특징+Ridge에 적용할 최소 실험을 한 번 수행한다. 원 논문의 CNN과 같은 구현이나 새 기법이라고 주장하지 않는다.

기존 학습175명·203기록 각각의 앞·중간·뒤 local 특징을 모두 사용한다. 609개 구간이지만175명·203기록임을 유지하고, 각 구간 가중치를1/3로 두어 한 원래 기록의 총 가중치는1로 고정한다. 표준화는 학습 구간만으로 계산한다. Ridge alpha=1을 유지하고 고정 MotionBERT 특징을 재사용한다. 검증37명·40기록에서 세 위치 각각의 MAE·세 위치 범위 및 동일 가중 평균 예측의 MAE를 보고한다. 구간·가중치·alpha를 탐색하지 않으며 새 모델1개만 학습한다.

기존 앞 구간 학습 모델과 새 모델의 같은 입력별 오차 차이 및 범위 차이를 모두 보고한다. 각 사람별 오차를 묶어 기존 seed=20261026,10000회 짝 재표집95% 범위를 계산한다. 개선이 보이더라도 이번 결과를 보고 고른 후속 실험이며 재사용한37명에서의 탐색이다. 최종 채택·임상 타당성·새 독립 평가로 부르지 않는다. 수치 안정성은 SVD 해와 직접 선형방정식 해 일치, 저장 모델 재현으로 확인한다.
