# 구간별 점수 차이의 원인 후보와 다음 개발 방향

2026-10-28 사용자 요청으로 수행했다. 앱·새 촬영을 진행하지 않고 보유 개발 자료의 입력 품질·움직임·모델 학습 조건을 점검했다.

## 먼저 볼 결론

**뒤쪽 구간의 관절 추정 품질이 전반적으로 나빠져서 점수가 변한다는 설명은 현재 자료와 맞지 않았다.** 뒤 구간의 하체 신뢰도는 조금 높고, 낮은 신뢰도 비율과 좌표의 급격한 변화 지표는 오히려 낮았다. 다만 신뢰도는 관절 위치가 실제로 맞았다는 정답이 아니므로 추정 오류가 없다고 결론내릴 수는 없다.

**구간을 다양하게 학습하면 점수의 위치 민감도는 줄일 수 있다는 초기 신호를 얻었다.** 앞·중간·뒤를 함께 학습한 모델은 구간별 점수 폭을5.07→4.27점으로 줄였지만 GDI 정확도는 전반적으로 좋아지지 않았다. 따라서 개선 모델로 채택하지 않았다. GDI 자체를 바꾸기 전에 입력의 누락 처리와 움직임 표현을 점검할 가치가 있다.

GDI 대안 중 가장 가까운 방향은 보행 리듬·무릎 움직임 등 설명 가능한 개별 지표를 예측·검증하는 것이다. 범주화라는 목표에는 임상 보행 등급도 더 직접적이지만 현재 확보한 표본과 입력 형식에 제약이 있다. 정답 종류를 바꿔도 입력의 구간 민감도가 자동으로 없어지지는 않는다.

## 어떤 자료에서 무엇을 했는가

입력 품질 집계는 기존 개발212명·243기록에서 했고, 학습175명·203기록과 검증37명·40기록을 따로 집계했다. 점수 변화와의 연관성·모델 비교는 기존 검증37명에서 했다. 같은 사람의 여러 기록을 먼저 평균해 각 사람에게 같은 비중을 줬다. 기존 평가38명과 최종223명의 특징·정답·예측은 사용하지 않았다.

같은243프레임에서 앞[0:124],중간[59:183],뒤[119:243]를 선택했다. 이 구간들은 겹치므로 독립적인 영상이나 추가 사람으로 세지 않았다. 품질 통계는 공통243프레임 좌표에서 계산해 구간마다 좌표 크기가 다시 바뀌는 영향을 줄였다. 움직임 길이는 같은 영상 전체의 하체 길이 중앙값으로 나눴다. 실제 미터·초당미터·3D관절각을 측정한 것은 아니다.

## 2. 누락 좌표를 다루는 방식은 구체적인 점검 후보다

누락은 주로 코·머리·손목 등에서 나타났다. 예를 들어 앞 구간의 코0신뢰도 비율은 사람별 평균18.0%, 머리는21.5%였고, 뒤 구간에서는 각각10.8%,13.4%였다. 머리·골반 등 일부 관절은 원래 검출점을 조합해 만든 점이므로 독립적인 검출점으로 보지 않는다.

검사한243프레임 좌표의 세 겹치는 구간에서0신뢰도였던7,558개 관절 관측 모두가 x 또는 y의 정규화 범위 경계(-1 또는1)에 있었다. 겹친 프레임은 이 관측 수에 반복 포함된다. 원시 좌표를 정규화한 뒤[-1,1]로 자르는 코드와 연결되는 현상이다.

사용 중인 MotionBERT-Lite 코드에서는 x,y,신뢰도를 입력 선형층에 함께 넣고, 신뢰도0인 관절을 명시적으로 제외하는 처리는 확인되지 않았다. 그렇다고 신경망이 신뢰도를 활용하지 않는다는 뜻은 아니다. 현재 특징은 모든 관절·시간을 평균해 만든다. 누락된 상체 좌표가 하체 평가에 불필요한 영향을 주는지는 **실제 관절 이동을 고정하고 누락값 처리만 바꾸는 대조 실험**으로 확인해야 한다. 아직 그 실험을 수행하거나 처리를 바꾸지 않았다.

## 4. 앞 구간만 학습한 것이 유일한 원인인가

저장된 구간별 Ridge 모델을 교차 적용했다. 수치는 기존 사람별 평균 절대오차이며 작을수록 좋다.

| 학습했던 위치 → 입력 위치 | 앞 | 중간 | 뒤 |
|---|---:|---:|---:|
| 앞 구간 학습 모델 | 7.29 | 7.75 | 8.68 |
| 중간 구간 학습 모델 | 7.60 | 7.97 | 8.69 |
| 뒤 구간 학습 모델 | 8.35 | 8.31 | 8.77 |

해당 위치에 맞춰 학습한 모델이 해당 위치에서 더 정확하지 않았다. 따라서 단순히 뒤 구간 전용 모델을 만들면 해결된다는 근거는 없다. 구간별 학습·평가를 이미 했던 모델을 재사용했으며 이 표를 위해 새 학습은 하지 않았다.

## 5. 여러 위치를 함께 학습하는 최소 개선 실험

원 자료 연구는124프레임 구간의 시작점을31프레임씩 옮겨 학습했다. 이 방법의 목적을 현재 고정 특징+Ridge에 적용했다. 원 논문의 CNN을 재현한 것이 아니다. [원 논문 방법](https://www.nature.com/articles/s41467-020-17807-z)

기존175명·203기록에서 앞·중간·뒤609구간을 학습에 넣었다. 각 구간 가중치를1/3로 두어 원래 기록 하나의 총 가중치는1로 유지했다. 학습 사람만으로 표준화하고 Ridge alpha=1을 유지했다. 특징 추출기를 다시 학습하지 않았고 새로운 Ridge 모델은1개만 만들었다.

점수 폭은 약15.8% 줄었고37명 중26명에서 작아졌다. 폭 감소량의 짝 재표집95% 범위는[0.39,1.24]점이었다. 그러나 각 입력 조건의 정확도 개선 범위는 모두0을 포함했다. 안정성 지표만으로 새 모델을 채택하지 않는다. 사람별 세 구간·좌우 평균 예측의 표준편차도5.78→5.46으로 줄어, 일부는 출력 전반의 압축일 수 있다. 같은 점수만 내는 모델로 갈수록 안정적으로 보일 수 있다는 문제를 계속 확인해야 한다.

이는 초기 점검 결과를 본 뒤 수행한 후속 탐색이다. 이미 여러 번 사용한37명의 결과이며 외부 최종 성능이나 실제 재촬영 안정성의 개선을 입증하지 않는다.

## 6. GDI 대신 다른 방식을 쓰면 무엇이 달라지는가

GDI는 예측할 정답의 종류이고, MotionBERT·Ridge는 그 답을 계산하는 방법이다. 입력의 누락·시점·구간 문제는 GDI를 다른 정답으로 바꿔도 남는다. 다만 어떤 능력을 평가하는지와 결과의 설명 가능성은 바뀔 수 있다.

| 후보 | 해결하고 싶은 문제 | 지금 확인한 자료 | 남는 한계와 판단 |
|---|---|---|---|
| GDI 유지 + 입력 처리·표현 개선 | 현재 확인된 구간 민감도와 예측 오차 | 기존 고정 분리·정답·모델을 바로 비교에 사용 가능 | 움직임 정상 패턴과의 차이이며 일반적인0~100보행 능력과 같지 않음. 원인 대조 실험의 기준으로 유지할 가치 |
| 보행 리듬·속도·무릎 움직임을 각각 예측 | 하나의 숫자에 숨은 문제를 구체적으로 설명 | 같은 공개 압축파일의 alldata.csv 머리글에서 cadence,speed,speedNorm,cadenceNorm,KneeFlex_meanStance,KneeFlex_maxExtension 확인 | 개인별 행을 열지 않았으므로 단위·결측·현재 개발 사람 연결은 미확인. 새 목표를 선택한 뒤 개발 자료만 연결 검사 필요 |
| 임상 보행 등급0~3 | 실제 관찰되는 보행 어려움의 정도를 범주화 | CARE-PD 3DGait 보유43명·90구간에0~3정답. 최고 등급은5명 | SMPL자료 변환 필요, 특정 집단의 임상 기준이며 일반 노인10단계와 다름. 표본·평가자·촬영 차이와 입력 민감도는 남음 |
| POMA-G 등 기능 점수 | 보행 동작별 평가 항목과 모델 연결 | 고령자44명 자료 중 유효 POMA-G39명 | 현재8~12점에 몰려 전체 능력 범위 검증이 어려움. 주 방향보다 보조 타당성 후보 |

GDI 대안 머리글은 압축 해제 출력을1바이트씩 제한해 첫 줄까지만 확인했다. 개인별 자료 행의 압축 해제·파싱·정답 연결은0건이다. 전체 CSV의 CRC는 검사하지 않았으며 파일 확보와 모델 학습 가능 인원을 구분한다. 원 연구는 보행 리듬·속도·무릎각을 각각 모션캡처 정답과 비교하는 방법을 사용했다. 우리가 이 대안을 선택하면 동일한 사람 분리를 유지하면서 실제로 어떤 지표를 더 안정적·정확하게 예측하는지 비교할 수 있다. 단, 이번에 그 대안 모델을 학습한 것은 아니다.

CARE-PD 연구는 움직임 표현 모델과 설명 가능한 보행 특징 기반 Random Forest를 비교하고, 임상 보행 등급을 정답으로 사용한다. 기관이 달라지면 성능이 떨어지고 임상 움직임 자료로 사전학습을 보완하는 효과도 보고한다. 우리에게 가져올 부분은 특정 모델 이름보다 ‘임상 등급과 직접 연결된 보행 특징 대조군’과 ‘기관·사람을 나눈 검증’이다. 공개 파일은 비상업적 연구 조건을 별도로 확인해야 하며 일반 제품 활용이 자동 허용되는 것은 아니다. [CARE-PD 연구](https://arxiv.org/html/2510.04312v1), [자료 이용 조건](https://neurips2025.care-pd.ca/terms-of-use.html)

Auto-Gait은 보행 좌표에서 발 간 거리·움직임 변화 등 특징을 계산해 SARA보행 점수를 예측했다. 이는 어떤 특징으로 어떤 임상 항목을 설명하는지 연결하는 예시다. 그 특징을 우리2D좌표에서 그대로 실제 보폭·속도로 해석하거나, 확보하지 않은 원본 영상을 당장 쓸 수 있다고 취급하지 않는다. [Auto-Gait](https://pmc.ncbi.nlm.nih.gov/articles/PMC11571898/)

## 추천하는 순서

1. **GDI를 대조 기준으로 유지하고 누락 처리의 영향을 먼저 분리한다.** 같은 관측된 움직임을 유지한 채0신뢰도 좌표 처리만 바꾸는 작은 대조 검사를 설계한다. 임의 보간을 정답 복원으로 부르지 않고, 누락 처리와 모델 재학습 효과를 따로 비교한다.
2. **설명 가능한 소수 보행 지표로 만든 비교 모델을 둔다.** 지금 계산한 품질 대리 지표를 바로 건강 점수로 쓰지 않는다. 리듬·각도 등의 의미 있는 특징과 학습된 전체 움직임 특징을 같은 사람·정답에서 비교한다. 이전의 단순 하체 특징 풀링 실험을 이름만 바꿔 반복하지 않는다.
3. **주 목표 전환 후보는 개별 보행 지표 예측 또는 임상 보행 등급이다.** 현재 자료 접근성은 같은 공개 자료의 보행 지표가 가장 가깝다. 범주화 의미는 임상 등급이 더 직접적이다. 어느 쪽을 채택할지는 사용자가 점수의 의미·대상을 선택해야 한다. SPPB 총점으로 되돌리거나 임의10등급을 만들지 않는다.

## 검증과 한계

원본243건·저장 특징·모델 지문과 기존 분리를 확인했다. 구간별 모델의 대각선 성능을 이전 결과와 일치시켰다. 품질 CSV729행, 교차 모델360행, 혼합 모델160행의 집계·순위상관·오차·평균식·범위를 NumPy를 사용하지 않는 별도 코드로 재계산했다. 혼합 모델의 SVD 해와 직접 선형방정식 해의 최대 차이는 약6e-12였다. 저장 모델의 예측 재현도 확인했다. 입력과 기존 증거는 수정하지 않았다.

기본 실행환경에 SciPy가 없어 새 패키지를 설치하지 않고 순위상관 계산을 구현했으며 별도 방식으로 검산했다. 새로운 학습 실패나 정답 누락으로 제외한 기록은 없다. 개별 움직임 공식 전체를 별도로 재구현한 검산, 재표집 구간의 별도 구현 검산, 원 영상의 가림·회전 확인은 하지 않았다. 표본37명·겹친 구간·반복 탐색·대상 집단 차이 때문에 원인 하나를 확정하거나 임상 성능을 주장하지 않는다.

이번에 마친 것은 입력 원인 후보 분석, 저장 모델 교차 진단, 혼합 구간 학습1회, 대안 자료 머리글 확인이다. 후속 개선 모델이나 새 점수 체계의 채택은 아직 하지 않았다.
