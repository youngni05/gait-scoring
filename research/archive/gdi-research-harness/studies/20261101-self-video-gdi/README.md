# 직접 촬영한 정상·비정상 영상의 고정 GDI 모델 비교

1차·Test01·관절 추출기 비교와 발표 방향 결정을 모은 [모사 실험 통합 기록](EXPERIMENT_RECORD.md)을 추가했다. 아래 수치는 기존 실행 결과를 유지한다.

2026-11-01. **이번 두 영상에서는 정상 보행에 더 높은 GDI 예측값을 주는 차이를 확인했다.** 기존 최선 CNN·STT 결합의 정상-비정상 차이는 기존 입력 구간에서 +10.82점, 미리 고정한 직선 구간에서 +9.12점이었다. 두 분석 모두 5개 분할 모델의 차이가 같은 방향이었다. 실제 GDI 정답이 없는 같은 사람의 두 촬영이며, 일반적인 정상·비정상 판별 성능이나 점수 정확도를 검증한 결과는 아니다.

## 촬영은 원 연구와 얼마나 비슷한가

원 연구는 측면 보행을 단일 카메라로 찍고, 사람이 왕복할 때 카메라를 회전해 따라갔다. 카메라를 따라 돌리는 방식 자체는 이번 영상과 비슷하다. 다만 영상 화면에서 정확한 촬영 거리와 보행로 길이를 확인할 수는 없다.

| 조건 | 원 연구 | 이번 영상에서 확인한 내용 |
|---|---|---|
| 보행·카메라 | 약 10m 왕복 3~5회, 측면에서 약 3~4m 거리, 카메라 회전 | 전신 왕복 보행과 카메라 회전은 보인다. 지나가는 위치에 따라 비스듬한 측면·정면·후면이 섞인다. 거리·보행로 실측은 없다. |
| 해상도 | 원본 1280×960, 처리 640×480 | 두 영상 모두 1080×1920 세로 화면이다. OpenPose 입력 비율과 사람의 영상 내 크기가 다르다. |
| 시간 | 원본 29.97 FPS | 두 파일의 평균은 30 FPS다. 비정상은 일정한 간격이고, 정상에는 8개의 불규칙한 프레임 간격이 있다. 원본 순서를 유지했다. |
| 복장 | 최소한의 편한 옷 | 긴 상의와 헐렁한 긴바지로 엉덩이·무릎 윤곽이 가려진다. |
| 대상·정답 | 주로 소아 뇌성마비 환자, 같은 방문의 3D 측정 GDI | 같은 사람이 정상·비정상으로 촬영했다는 사용자 확인이 있다. 비정상 동작의 의도·진단·실제 GDI는 제공되지 않았다. |
| 방향 정렬 | 왕복 방향에 따라 영상·라벨 반전 | 이번에는 기존 고정 모델 처리대로 자동 반전·좌우 교환을 추가하지 않았다. 원 연구 전체 처리의 재현으로 해석하지 않는다. |

원 연구 근거: [Kidziński 등, Methods—Dataset 및 Extracting keypoints with OpenPose](https://pmc.ncbi.nlm.nih.gov/articles/PMC7426855/). 이번 메타데이터는 [inventory.json](inventory.json), 실제 프레임 시각은 [timestamp-verification.json](timestamp-verification.json)과 [timestamp-details.json](timestamp-details.json)에 있다. 공개 학습 좌표의 실제 시간축은 기존에도 미확인 상태여서 30 FPS와 학습 입력이 정확히 정렬됐다고 주장하지 않는다.

## 어떤 입력을 어떤 모델에 넣었나

`원본 영상 → BODY25 관절 추출 → 공식 OpenPose 후처리 → 기존 보간·평활화와 좌우 12개 특징 → 124프레임 구간 → 저장된 모델·보정식 → 영상별 평균 비교`

- 원본은 `영상자료/검증용/정상 보행.mp4` 45.1초·1,353프레임, `비정상 보행.mp4` 34.3초·1,029프레임이다. 사용자가 같은 사람임을 확인했다. 영상별 라벨만 비교에 사용했으며 정상에 GDI 100점을 정답으로 붙이지 않았다.
- 모델은 [기존 내부 모델 평균 결합](../20261030-gpu-motionbert-study/inner-bagging692/README.md)이다. 개발자료 692명·1,061기록에서 사람별 MAE 6.515817점으로 기록된 기존 최선이다. 그 개발 성능이 이번 영상의 오차를 뜻하지는 않는다. CNN 24개·STT 25개·좌우 결합 STT 5개, 총 54개 저장 모델과 기존 분할별 비중·보정식을 그대로 사용했다. 새 영상에는 5개 분할의 예측을 평균했다. 이는 기존 사람별 교차검증 성능을 다시 측정한 것과 다르다.
- 기존 입력 구간은 전체 기록을 먼저 처리한 뒤 시작 프레임 0,31,…,372에서 124프레임씩 고른 13구간이다. 각 영상의 앞 496프레임을 덮으며 정지·회전이 섞일 수 있다. 각 창의 전체 길이는 약 4.1초이고 서로 겹친다.
- 별도 직선 분석은 점수 전에 고정한 3구간씩이다. 비정상은 180–303·570–693·810–933프레임, 정상은 30–153·315–438·600–723프레임이다(0 기준, 양끝 포함). 원본 프레임 시각 기준 길이는 비정상 4.1초씩, 정상 4.1·4.1·4.0667초다. 각 구간은 방향·거리까지 완전히 맞춘 짝이 아니므로 구간끼리의 차이를 같은 보행 주기의 대응 비교로 해석하지 않는다.
- 2,382프레임을 모두 추출했다. 비정상에서 20프레임은 여러 사람이 검출되어 대상자를 임의로 고르지 않고 결측으로 남겼다. 정상은 전 프레임에 한 사람이 검출됐다. 필수 좌표 결측 25% 기준을 유지했고, 예정된 26개 기존 구간·6개 직선 구간이 모두 통과했다. 42개 대표 겹침 그림에서 하체 관절이 다리를 대체로 따라갔으나, 가려진 다리의 정확한 해부학적 좌우나 모든 프레임의 정확성을 보증하지 않는다.

사용자가 학교 ABRM02 본인 계정으로 두 원본 영상을 전송·처리하는 것을 승인했다. 추론 전용 작업 33617은 2분 27초 뒤 종료코드 0:0으로 완료됐다. 모델 학습은 하지 않았고 다른 작업·예약은 변경하지 않았다. 서버의 실험 폴더는 `/abr/RESEARCH_USER/self-video-gdi-20261101`이다.

## 실제 결과

좌우 및 5개 분할 예측의 평균이다. 여기서 정상·비정상은 사용자가 붙인 촬영 조건명이다.

| 모델·구간 | 정상 | 비정상 | 정상 - 비정상 |
|---|---:|---:|---:|
| **기존 최선 결합·기존 입력 13구간** | **75.41** | **64.59** | **+10.82** |
| **기존 최선 결합·직선 3구간** | **76.50** | **67.38** | **+9.12** |
| 단독 CNN 최종 모델 평균·기존 입력 | 71.63 | 67.95 | +3.69 |
| 단독 CNN 최종 모델 평균·직선 | 70.51 | 67.91 | +2.60 |
| CNN 내부 모델까지 평균·직선 | 71.24 | 66.49 | +4.74 |
| STT 내부 모델까지 평균·직선 | 82.13 | 68.58 | +13.56 |

최선 결합의 분할별 정상-비정상 차이는 기존 입력에서 **8.16~13.68점**, 직선 구간에서 **7.24~11.07점**이었다. 직선 구간별 평균도 정상 **75.52·76.04·77.94점**, 비정상 **68.60·68.95·64.60점**으로 이번 표본에서는 겹치지 않았다. 반면 단독 CNN은 직선 구간 비교의 5개 분할 중 하나에서 차이가 −1.03점으로 뒤집혔다. 따라서 모든 모델이 같은 정도로 구분했다고 표현하지 않는다.

![같은 사람의 정상·비정상 GDI 예측 비교](score-comparison.png)

**이번 영상 쌍에서는 요청한 점수 차이가 나타났으므로, ‘차이가 없으면’ 수행할 움직임 설명 모델의 추가 결합은 실행하지 않았다.** STT는 관절 시간열을 처리하는 수치 예측 모델이며, 자연어로 움직임을 설명하는 모델을 추가로 실행했다는 뜻은 아니다. 이 영상에 맞춘 재학습·보정·분류 문턱 조정도 하지 않았다.

## 확인한 문제와 검산

처음 실행한 입력 검사는 비정상 23프레임의 신뢰도 1.010989를 거부했다. 같은 프레임의 공식 CPU OpenPose도 1.010990을 출력했다. 사용자가 별도 어댑터를 승인한 뒤 상한 검사만 예외 처리했다. 좌표·신뢰도를 잘라내거나 바꾸지 않았고, 결측 제한·모델·보정식도 유지했다. [최초 실패](strict-input-failure.json), [공식 재현](official-confidence-proof.json), [승인 범위](confidence-exception.json)를 모두 보존했다. 이 결과는 원래 상한 검사 그대로 통과한 실행이 아니다.

[검산 프로그램](verify.py)을 실제 실행했다. 결과는 [verification.json](verification.json)에 있다.

- 원본 영상 2개, 회수 열지도 97청크, BODY25 JSON 2,382개의 SHA256이 일치했다.
- 기존 공개 샘플 650프레임의 특징·기존 CNN 예측은 기준과 차이 0으로 재현됐다.
- 개인 영상 32구간의 프레임 대응·결측률·특징을 다시 계산했으며 특징 차이는 0이었다.
- 54개 체크포인트의 지문을 확인하고 기존 개발 입력의 저장 예측을 다시 재현했다. 최대 차이는 0.00001526점으로 기존 허용치 0.0001점 이내였다. 이는 코드 실행 재현 확인이다.
- 별도 반복문으로 모델 평균·결합식·평균 차이를 재계산했다. 요약 수치 차이는 1.43×10⁻¹⁴점 이하였다. GPU/공식 CPU 기준 열지도 차이는 최대 1.61×10⁻⁶으로 기존 10⁻⁴ 허용치 이내였다.

## 해석 범위와 파일

확인한 것은 **이 촬영 조건의 같은 사람 두 영상에서 기존 모델이 정상 보행에 일관되게 더 높은 값을 주었다**는 것이다. 반복 구간이나 5개 분할 모델을 독립 참가자로 세지 않았다. 정상 영상이 약 75~76점이라는 사실을 실제 기능 저하로 해석하지 않는다. 실제 GDI 정답, 여러 사람의 재현성, 정상·비정상 판정 정확도, 촬영 조건과 관절 오류가 차이에 기여한 정도는 확인하지 못했다.

코드의 핵심은 [predict.py](predict.py)다. 관절에서 계산한 같은 입력을 저장 모델 54개에 넣고 각 모델의 기존 보정식을 적용한 뒤, 원래 정한 비중으로 결합한다. [prepare_features.py](prepare_features.py)는 원본 프레임 순서를 보존해 이 입력을 만든다. Python·NumPy·PyTorch·기존 OpenPose를 재사용했으며 새 패키지는 설치하지 않았다.

코드·작은 결과·그림·검산은 이 C 폴더에 있다. 큰 배열·회수 열지도·관절 JSON은 `D:/gait-research-data/D_P/self-video-gdi-20261101`에 있다. 주요 수치는 [results.json](results.json), 구간 목록은 [windows.json](windows.json), 점수 전 선정·검토는 [protocol.json](protocol.json)과 [prescore-review.json](prescore-review.json)이다. 개인 영상과 모델 원자료를 Git에 커밋하거나 외부 설명 API로 보내지 않았다.
