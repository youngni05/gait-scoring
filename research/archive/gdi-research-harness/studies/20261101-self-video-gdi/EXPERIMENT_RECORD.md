# 직접 촬영한 정상 보행과 이상 보행 모사 실험 기록

기록일: 2026-11-01. 기존 실행 결과와 사용자 라벨 정정을 정리한 기록이다. 이 기록을 작성하면서 새 학습이나 영상 재추론을 수행하지 않았다.

**같은 사람의 정상·이상 보행 모사 2개 영상에서 정상 점수가 더 높았고, 후속 Test01의 13개 영상에서도 정정된 두 집단의 영상 평균 점수 범위가 겹치지 않았다.** 실제 GDI 정답이 없는 모사 실험이므로 점수 정확도나 고령자 판별 성능을 뜻하지 않는다.

## 1. 왜 이 실험을 했는가

공개자료에서 실제 GDI를 예측한 모델이 직접 촬영한 영상에서도 움직임 차이에 반응하는지 확인하려 했다. 먼저 촬영 조건이 선행연구와 얼마나 비슷한지 살피고, 기존 최선 모델을 바꾸지 않은 채 정상 보행과 이상 움직임을 흉내 낸 보행의 예측값을 비교했다.

질문은 다음 세 가지였다.

1. 원 연구의 측면 보행 촬영과 입력 조건이 어느 정도 맞는가?
2. 정상·이상 보행 모사 영상에 서로 다른 GDI 예측값을 주는가?
3. 촬영 묶음이나 관절 추출 방법을 바꾸어도 같은 방향의 차이가 남는가?

임의로 정상=100점, 비정상=특정 점수라는 정답을 만들지 않았다. 정상·비정상은 사용자가 알려 준 촬영 조건명이다.

## 2. 자료와 비교 단위

| 단계 | 자료 | 사람에 대해 확인한 정보 | 비교 단위 |
|---|---|---|---|
| 1차 | `영상자료/검증용/정상 보행.mp4`, `비정상 보행.mp4` | 같은 사람이 두 조건을 촬영했다는 사용자 확인 | 같은 사람의 영상 2개 |
| 2차 | `영상자료/검증용/Test01/보행자 (1).mp4`~`보행자 (13).mp4` | 세 사람이 여러 움직임을 흉내 냈다는 사용자 설명. 사람별 영상 대응표는 없음 | 요청에 따라 영상별로 보고하고 사람끼리 짝맞춤하지 않음 |
| 추출기 비교 | 1차 영상 2개에 MediaPipe Full을 적용 | 1차와 같은 사람·같은 영상 | 같은 영상의 OpenPose·MediaPipe 결과 |

Test01의 13개 영상을 13명의 독립 대상자로 세지 않는다. 1차와 2차 사이의 사람 중복 여부도 확인되지 않았다. 참가자의 연령·진단·실제 GDI는 제공되지 않아 일반 고령자 실험으로 분류하지 않는다.

## 3. 촬영 조건 확인

원 연구는 약 10m 왕복 보행을 측면에서 촬영하고 카메라를 회전해 대상자를 따라갔다. 직접 촬영한 영상에도 전신 왕복 보행과 카메라 회전이 보였다. 그러나 다음 차이가 있었다.

- 원 연구는 가로 영상이고 이번 영상은 1080×1920 세로 영상이다.
- 순수 측면 외에 비스듬한 측면·정면·후면, 회전·정지 구간이 섞인다.
- 헐렁한 옷 때문에 엉덩이와 무릎 윤곽이 가려질 수 있다.
- 평균은 30 FPS지만 일부 파일의 실제 프레임 간격은 불규칙하다. 원본 순서를 유지했다.
- 촬영 거리와 보행로 길이는 실측하지 않았다. 공개 학습 좌표와 실제 시간축의 완전한 일치도 미확인이다.

따라서 원 연구 촬영을 그대로 재현한 실험으로 해석하지 않는다. 상세 비교는 [1차 실험 README](README.md), 영상별 입력 확인은 [Test01 README](../20261101-self-video-test01/README.md)에 있다.

## 4. 무엇을 고정했는가

```text
원본 프레임 순서 유지
    → OpenPose BODY25 관절 추출
    → 기존 결측 보간·흔들림 완화·좌표 크기 조정
    → 한쪽 다리별 12개 움직임 특징
    → 124프레임 구간별 기존 모델 예측
    → 기존 보정식·결합 비중·모델 평균
    → 영상별 좌우 평균 점수
```

- 기존 개발자료 692명·1,061기록에서 MAE 6.515817점을 기록한 모델 구성을 사용했다.
- CNN 24개·STT 25개·좌우 결합 STT 5개, 총 54개 저장 모델을 사용했다. CNN 내부 모델 한 개는 기존 학습자료 기준의 상수 출력 제외 규칙에 따라 이미 제외돼 있었다.
- 새 영상은 다섯 분할 모델의 예측을 평균했다. 각 사람을 제외해 평가한 기존 교차검증과는 사용 방식이 다르며, 새 영상의 MAE를 계산한 것이 아니다.
- 정상·비정상 라벨로 학습하거나, 점수에 맞춰 보정식·결합 비중·문턱값을 바꾸지 않았다. 점수를 0~100으로 자르지도 않았다.
- 기존 자동 입력은 시작 프레임 0, 31, …, 372에서 연속 124프레임을 선택한다. 길이가 충분하면 13구간이며, 앞 최대 496프레임을 덮는다. 긴 영상의 후반 전체까지 평균한 것은 아니다.
- 필수 좌표 결측 25% 제한을 유지했다. 여러 사람이 검출된 프레임은 임의로 한 사람을 고르지 않고 결측으로 남겼다.
- 공식 OpenPose에서도 신뢰도 1 초과가 재현돼, 사용자 승인 아래 별도 어댑터에서 상한 검사만 예외 처리했다. 원래 좌표·신뢰도를 보존하고 다른 입력 제한·모델·보정식은 유지했다. [예외 범위](confidence-exception.json)

사용자가 학교 ABRM02 본인 계정의 영상 전송·처리를 허용했다. 연구 추론에만 사용했으며 영상·관절을 외부 설명 API로 보내지 않았다.

## 5. 1차 결과

같은 사람의 두 영상에 대한 좌우·다섯 분할 모델 예측의 평균이다. 직선 3구간씩은 점수 확인 전에 고정했다.

| 입력 조건 | 정상 | 이상 보행 모사 | 정상−모사 |
|---|---:|---:|---:|
| 기존 자동 13구간 | 75.41 | 64.59 | **+10.82** |
| 별도 직선 3구간 | 76.50 | 67.38 | **+9.12** |

최선 결합은 두 입력 조건 모두 다섯 분할 모델에서 정상 점수가 높았다. 기존 자동 구간의 분할별 차이는 +8.16~+13.68점, 직선 구간은 +7.24~+11.07점이었다. 이 범위는 재촬영 오차나 신뢰구간이 아니다.

단독 CNN의 직선 비교 차이는 +2.60점이었고, 다섯 분할 중 하나에서는 방향이 뒤집혔다. 최선 결합의 차이가 더 컸다는 관찰을 모델 정확도 개선으로 바꾸어 해석하지 않는다.

점수 차이가 확인됐으므로, 당초 조건부로 검토했던 자연어 움직임 설명 모델의 추가 결합은 이 영상 실험에서 실행하지 않았다. STT는 움직임 수치를 처리하는 예측모델이며 자연어 설명 모델이 아니다.

근거: [결과 JSON](results.json), [구간 목록](windows.json), [사전 조건](protocol.json), [검산](verification.json).

## 8. 재현 확인과 해석 범위

1차는 2,382프레임·32구간, Test01은 6,634프레임·135구간을 처리했다. 각 단계의 원영상·관절·모델 파일 지문, 프레임 대응, 특징 재계산과 별도 결합식 계산을 확인했다. Test01은 기존 전체 예측 재현 차이 0, 특징 재계산 차이 0, 영상 요약 재계산 차이 약 1.42×10⁻¹⁴점이었다.

확인된 것은 **고정 모델이 이 모사 촬영 자료의 움직임 차이에 반응했다는 사실**이다. 다음 항목은 별도 검증이 필요하다.

- 실제 GDI와의 점수 일치, 일반 고령자에서의 유효성.
- 사람·촬영 조건이 달라져도 차이가 유지되는지, 경미한 차이도 구분하는지.
- 상태가 같은 사람을 다시 촬영했을 때의 오차와 실제 개인 변화의 구분.
- 촬영 각도·속도·복장·관절 추출 오류가 점수 차이에 기여한 정도.

이번 결과를 정상/비정상 정확도 100%, 노인 상태 판별 완료, 실제 GDI 12.67점 차이, 또는 GDI=100이어야 정상이라는 근거로 쓰지 않는다. 사후 경계값을 만들어 분류 성능을 보고하지도 않았다.

## 9. 발표 방향에 반영한 결정

2026-11-01 사용자 요청으로 **GDI를 중간발표의 중심 연구 대상으로 둔다.** 근거는 실제 GDI 정답이 있는 개발자료의 예측·개선 결과와, 정답이 없는 직접 촬영 모사 영상에서의 점수 차이를 함께 확보했다는 것이다. 두 근거가 답하는 질문을 나누어 설명한다.

SPPB/TUG 연구는 보행에서 실제 평가값을 찾기 위해 먼저 시도한 경로와 그 과정에서 얻은 점으로 제시한다. 이후 GDI의 방법·개선·모사 결과를 중심에 두고, 일반 고령자·반복 측정·실제 GDI 검증으로 이어 간다. 이는 발표와 개인 연구 방향에 관한 결정이며 새로운 모델 학습이나 임상 판정 기준의 승인을 뜻하지 않는다.

최신 발표 초안: [GDI 중심 중간발표 초안](../../../gait-scoring/docs/2026-11-01-gdi-centered-interim-draft.md).
