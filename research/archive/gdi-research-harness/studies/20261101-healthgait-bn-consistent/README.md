# BN 처리를 일관되게 적용한 Health&Gait 전이학습 비교

현재 상태: 본 비교33593·33594의180개 학습·45개 최종 모델을 D에 회수하고 BN·저장 예측 검산과 기준선140개 모델 재추론·분석을 완료했다. [최종 비교](analysis/RESULTS.md)와 [그림](analysis/comparison.png)을 확인한다. 이전 round2도 회수·검산했다.

사용자가 요청한 비교는 **처음부터 학습 / 기존 GDI 가중치 이식 / Health&Gait 사전학습 후 추가 학습**이며, 같은 입력의 선형 회귀·랜덤 포레스트와 평균·중앙값 기준선을 함께 둔다. 이전과 같은44명·220회 보행·사람별5분할·초기값3개를 사용한다. BN 이외의 학습률·드롭아웃·MSE·최대epoch·사람별 가중치는 초기 비교와 같다.

BatchNorm은 학습 중 현재 미니배치로 작동한다. 가중치를 옮길 때 원래의 평균·분산은 초기화한다. 매 epoch의 검증 직전에는 드롭아웃을 끄고 **그 학습 집단만** 한 번 통과시켜 BN 통계를 다시 계산한다. 이 통계로 검증하고 선택한 체크포인트를 저장한다. 내부 검증에서 고른 epoch로 전체 학습 집단을 다시 학습한 뒤에도 같은 절차를 거쳐 평가한다. 검증·평가 사람의 좌표나 정답은 통계 계산에 넣지 않는다.

Health&Gait395명의 사전학습도 같은 절차로 다시 수행한다. 따라서 이번에는 사전학습부터 기능점수 예측까지 수정된 전체 과정을 비교한다. 기존 Health&Gait 가중치에서 통계만 바꾼 사후 진단과 구분한다. GDI 가중치는 기존 고정fold0을 재사용하며, 발끝이 없는 입력에 맞춰 기존처럼 첫6개 좌표 채널과 대응 가중치만 사용한다.

선형 회귀와 RF는 같은2D 좌표에서 평균·표준편차·시간 변화량36개를 사용한다. 속도·3D 좌표·나이 같은 추가 정보는 쓰지 않는다. 설정은 같은 내부3분할에서만 고른다. Ridge는 결정적 모델이며, RF는 CNN과 같은 초기값3개를 모두 보고하고 평균 예측도 비교한다.

작은 코드·검산·요약은 이 C 폴더에, 입력·가중치·회수 원본·기준선 저장 모델은 `D:/gait-research-data/D_P/healthgait-bn-consistent-20261101`에 둔다. 새 서버 폴더는 `/abr/RESEARCH_USER/healthgait-bn-consistent-20261101`이다. 기존 환경을 사용하며 새 패키지는 설치하지 않는다.

담당 채팅은 `01a1929b-43f3-7bc1-b921-b17bc551d7fe`, 예약은 `healthgait`다. 같은 채팅의 기존 등록부 `C:/Users/jun/Desktop/D_P/gdi-research-harness/studies/20261101-healthgait-transfer/watch/registry.json`를 재사용하고 새 항목은 `bn-` 접두사로 구분한다. 다른 채팅·GPU 확보 작업32844는 변경하지 않는다. 기존 round2 결과의 회수도 빠뜨리지 않는다.

1시간마다 기존 `snapshot.py`에 위 등록부와 소유 채팅 ID를 명시해 조회한다. 새 `manage.py`의 모든 호출에도 `--owner-thread 01a1929b-43f3-7bc1-b921-b17bc551d7fe`를 붙인다. `status`로 확인하고, `pilot-review` 통과 후 `submit --stage source`, `verify_source.py` 통과 후 `submit --stage train --round 0` 순으로 진행한다. 본 학습은GPU1개 worker 두 개가 평가fold0·1·2와3·4를 나눈다. 두 작업 완료 후 `retrieve --round 0`으로 D에 회수한다.

검산은 저장 모델마다 학습 사람·창 인덱스와 정답 연결, 학습 집단의 정답 정규화, BN 통계의 독립 재계산, 내부epoch 선택, 모든 모델 재추론과 지표 재계산을 확인한다. 비교표에는 같은 입력의 기준선, 초기값 변동, 낮은 점수 오차, 이전 결과와의 차이를 함께 기록한다. 코드를 만들거나 파일럿이 통과한 것만으로 성능이 개선됐다고 보고하지 않는다. 완료·회수·검산·분석 보고가 끝나기 전에는 이 예약을 중지하지 않는다.

44명의 개발 자료를 반복해서 본 탐색 비교이다. 실제 영상·현장·임상 성능이나 사전학습의 일반적 우월성을 확정하는 시험이 아니다.

기준선은140개 내부·최종 학습의 모델 저장·재추론을 완료했다. 같은 좌표 시간 요약의 사람별 MAE는 Ridge1.1552점, RF 초기값3개 평균1.0357점, 평균1.3799점, 중앙값1.3182점이다. 새 CNN 평균 MAE는 처음부터1.0814점·GDI1.1689점·Health&Gait1.2063점이다. 상세 값과 D 모델 경로·SHA256은 analysis/baselines/verification.json에 있다. 최종 CNN 검산과 기준선 재검산 후 analyze.py를 실행하면 비교표·사람별 차이·점수대별 오차·그림을 생성한다. 그림에는 기존 Matplotlib 의존성을 재사용한다.
