# 44명 보행 시계열 → 실제 SPPB 총점 — 2026-10-30

**전체 확보·CPU/GPU 비교·회수·검산을 완료했다.** 이전에 실패했던 공식 개별 다운로드가 정상 응답해, 44명 220회 CSV를 모두 받았다. 각 파일은 제공처 SHA-256과 대조했다. 브라우저 호환 요청 헤더를 사용했지만 재시도 시점도 달라, 과거 오류의 원인을 헤더 하나로 확정하지 않는다. 전체 ZIP 대신 공식 개별 파일 경로로 확보했다.

원자료는 Caicedo Rodríguez 등의 2020년 자료이다. 실제 SPPB 총점 표와 100Hz Vicon 보행 마커 좌표가 연결되며, 이용 조건은 CC BY 4.0이다. **RGB 영상에서 추정한 관절의 성능을 검증한 실험은 아니다.** 보정된 3D 좌표와 실제 거리 단위를 사용하므로, 영상의 관절 추정 오차·시점 변화·거리 복원 문제는 평가하지 않았다. [공식 자료](https://data.mendeley.com/datasets/xgw6bg3g8h/1), [원논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC7701341/)

## 무엇을 학습했는가

입력은 보행 3초 동안의 12개 마커 위치와 골반 속도이다. 골반 중심을 빼고 다리 길이에 맞춰 좌표 크기를 조정하며, 진행 방향을 맞춘다. 이 계산은 선택한 3초 안에서만 수행한다. 원본 301시점을 30Hz의 91시점으로 바꾸어 움직임을 나타내는 39채널을 만든다. 결측 구간을 건너뛰거나 짧은 기록을 늘리지 않는다. 정답은 평가표에 직접 제공된 SPPB 총점이다. 나이·성별·다른 임상평가는 입력에 넣지 않는다.

4.1초의 연속 입력을 요구하면 37명 140회만 남았다. 학습 전에 원본 길이와 결측만 확인하여, 44명 220회를 모두 쓸 수 있는 3초를 선택했다. 4.1초 준비물은 `structural-4p1s/`에 보존했고 성능 학습은 하지 않았다. 실제 정답 범위는 **5–12점**이다. 0–4점 대상의 성능은 확인할 수 없다.

한 사람의 5회를 같은 분할에 둔 사람 5겹 평가를 사용했다. 각 학습 집단 안에서 사람 3겹으로 모델 설정과 학습 종료 시점을 골랐다. 새 사람의 5개 예측을 평균하여 실제 점수와 비교했다. 따라서 주결과는 **3초 구간 5개, 총 15초를 합친 사람별 결과**이다. 독립 임상 정답은 220개가 아니라 44개이다.

| 모델 | 평균 절대오차(점) | RMSE(점) |
|---|---:|---:|
| 평균 기준선 | 1.380 | 1.706 |
| 중앙값 기준선 | 1.318 | 1.706 |
| Ridge | 1.142 | 1.407 |
| RF | **1.001** | **1.198** |
| 작은 CNN | 1.236 | 1.635 |
| 작은 TCN | 1.194 | 1.602 |

RF의 중앙값 기준선 대비 오차 차이는 -0.318점이었다. 저장된 사람별 예측을 재표집한 부트스트랩 95% 구간은 -0.634~-0.021점이다. 이번 44명에서는 개선 방향이지만, 독립 자료 검증·재학습 변동·여러 모델 비교의 불확실성을 모두 다룬 결과는 아니다. CNN·TCN의 기준선 대비 구간은 0을 포함했다. 더 큰 모델의 이득은 확인되지 않았다.

저장된 예측으로 파일명 순 첫 1개·3개·5개를 평균하는 사후 분석도 했다. RF 오차는 각각 **1.075·1.024·1.001점**이었다. 단일 3초와 5회 평균을 구분하며, 이를 이용한 추가 모델 선택은 하지 않았다. `aggregation-protocol.json`과 `aggregation-sensitivity.csv`에 조건과 결과가 있다.

SPPB 5점과 6점은 각각 1명뿐이다. 5점 대상의 RF 오차는 2.349점으로 전체 평균보다 컸다. 전체 평균만으로 모든 점수 구간을 잘 예측한다고 판단하지 않는다. 실제 점수별 결과는 `errors-by-actual-score.csv`에 있다.

`verify.py`를 실제 실행하여 220개 원본 지문, 실제 SPPB 행 연결, 별도 구현의 원본 입력 재구성, 사람 분리, 평가 누락·중복, 학습 사람만의 정규화, CPU 모델 재추론, GPU 최종 모델 10개의 CPU 재추론, 사람별 지표 재계산을 확인했다. 입력 재구성 허용차는 0.000001, 환경 간 재추론 허용차는 0.0001이다. `verification.json`에 통과 근거가 있다. 기존 Python·scikit-learn·PyTorch 패키지를 재사용했다.

핵심 코드는 `prepare.py`의 `read_walk → window`이다. 실제 시간순 CSV에서 3초 좌표·속도를 만들고, 평가표의 사람 번호와 연결한다. 이 부분을 별도 코드로 재구성하여 입력과 대조했다. `cpu.py`는 움직임 요약값으로 Ridge·RF를 학습하고, `gpu.py`는 시간순 좌표로 CNN·TCN을 학습한다.

## RGB 점수 정의와 더 큰 자료의 확인

SPPBdataset의 세 MAT는 2021년 원커밋과 Git blob 지문이 일치했다. 2025년 변경은 README였다. 2020년 원논문의 공개 전사본 표 1에는 0–4 채점열이 있고, 2023년 후속논문 III·IV-B는 0–3 수행등급을 설명한다. 단순히 데이터 오류라고 결론 내리지 않는다. 채점 버전·MAT 값의 대응·표준 총점과의 동일성은 확인되지 않았다. 전사본의 표가 잘려 있어 정확한 채점 경계의 최종 근거로 쓰지 않았다. 이전 37명 실험은 표준 SPPB 성능 주장에서 계속 제외한다.
