**MotionBERT 출력값으로 Jev와 Ridge를 직접 비교한 결과 — 2026-10-31**

이번 탐색 실험에서는 **Jev가 Ridge보다 더 정확하게 점수를 예측한다는 근거를 얻지 못했다.** Jev를 보조 특징으로 쓰는 실험과 구분하여, 같은 MotionBERT 특징을 받아 Jev 자체가 점수를 고르게 했다. TUG 12명과 GDI 개발 자료에서 고른 50명에 대한 실제 API 요청과 검산을 완료했다.

보행 좌표 → 고정 MotionBERT-Lite의 512개 특징 → **Jev 또는 Ridge** → 실제 TUG·GDI와 비교했다. 512개 숫자는 모델 내부의 움직임 표현이며, 각 숫자가 특정 각도나 보행 속도를 뜻하지 않는다.

TUG는 기존 12명의 59개 짧은 구간에서 얻은 특징을 사람별로 평균했다. GDI는 기존 695명·1,064기록의 특징과 좌우 점수를 사람별로 평균했다. GDI 평가 대상 50명은 기존 다섯 분할마다 ID 해시 순서로 10명씩 골랐으며, 점수를 보고 고르지 않았다. 최종 평가용으로 보호한 37·38·223명 자료는 사용하지 않았다. 이 실험의 사람 평균 GDI 오차는 기존 좌우·기록별 GDI 오차와 같은 지표가 아니다.

각 평가 사람에게 다음 조건을 적용했다.

1. 평가 사람과 같은 분할에 속한 사람을 학습에서 제외했다.
2. 학습 사람으로만 숫자의 기준과 크기를 맞추고 소수 셋째 자리까지 표현했다. Jev와 Ridge에 같은 512개 값을 제공했다.
3. 특징이 가까운 학습 사람 8명을 골라 순서를 고정하여 섞었다. Jev는 이들의 특징과 정답 예시를 읽었다. 평가 사람의 정답·ID·영상은 보내지 않았다.
4. 동일한 8명으로 학습한 Ridge와, 해당 분할의 학습 사람 전체로 학습한 Ridge를 각각 비교했다. Ridge의 강도는 학습 자료 내부의 세 분할에서 1·10·100·1000 중 골랐다.

Jev는 고객 자료로 가중치를 재학습하지 않는다. 이번 방식은 요청 안의 예시를 읽고 판단하게 하는 방식이다. 따라서 Jev와 Ridge의 학습 방식까지 같다는 뜻은 아니다. [Jev 모델 설명](https://docs.typesafe.ai/models)

Jev는 TUG를 0~60초의 1초 간격, GDI를 0~140점의 2점 간격에서 선택했다. `unknown`도 허용했지만 최종 62명 모두 점수를 선택했다. 따라서 위 직접 예측 오차에는 보류를 중앙값으로 대체한 사례가 없다. 선택 확률을 가중 평균한 두 방식도 함께 보고했으며, 결과가 좋은 방식만 골라 제시하지 않았다. 이 값들은 연속 회귀나 임상 점수 보정을 검증한 결과가 아니다. Jev의 일반적인 `Score` 응답도 서술된 단계의 위치를 나타내는 방식이므로, 그 값을 곧바로 TUG 초나 GDI 점수로 간주하지 않았다. [Score의 정의](https://docs.typesafe.ai/primitives/score)

동일 사람의 오차 차이인 **Jev − Ridge**를 비교하면 다음과 같다. 양수는 Jev의 오차가 더 크다는 뜻이다. 구간은 저장된 교차검증 예측을 사람 단위로 10,000회 다시 뽑아 계산한 조건부 95% 구간이다.

| 비교 | 평균 오차 차이 | 95% 구간 |
|---|---:|---:|
| TUG: Jev − 동일 8명 Ridge | +2.202초 | +0.279 ~ +4.628 |
| TUG: Jev − 전체 학습 Ridge | +2.556초 | +0.623 ~ +4.913 |
| GDI: Jev − 동일 8명 Ridge | +1.573점 | −0.486 ~ +3.715 |
| GDI: Jev − 전체 학습 Ridge | +3.484점 | +1.175 ~ +6.012 |

GDI의 동일 8명 비교는 불확실성 구간에 0이 포함된다. 평균 오차가 더 컸다는 관찰을 일반적인 열세의 증명으로 확장할 수는 없다. TUG에서는 단순 중앙값도 Ridge보다 오차가 작았으므로, 작은 표본에서 MotionBERT 자체의 유용성까지 확인된 것은 아니다. 이번 결과는 **512개 잠재 특징을 그대로 전달하고 예시 8개를 주는 설정에서 Jev로 예측기를 교체할 근거가 없다**는 범위로 해석한다. 다른 입력 표현·예시 수·질문 방식이나 새 기관 자료의 결과는 미확인이다.

검산에서는 62건 모두 평가 분할이 예시에서 제외됐는지, 두 모델의 512개 값과 예시 정답이 같은지, API 요청 지문이 저장 기록과 일치하는지 확인했다. 동일 8명 Ridge 예측은 별도의 선형대수 계산으로 62건 전부 재현했다. 오차와 불확실성 구간도 다시 계산했다. 전체 학습 Ridge를 별도 구현으로 재학습하지는 않았다.
