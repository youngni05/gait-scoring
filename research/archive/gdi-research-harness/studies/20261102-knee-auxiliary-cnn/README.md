## 승인한 비교 조건

- 기존 개발자료 692명·1,061기록·11,261구간·좌우 GDI를 사용한다. 사람 5분할, 124프레임·12특징의 다구간 입력, 전처리·결측 기준을 그대로 유지한다.
- 보조 정답은 원본 임상 자료의 `KneeFlex_maxExtension`, 즉 무릎이 가장 펴졌을 때의 굽힘 지표다. 화면의 관절에서 계산한 각도를 정답으로 재사용하지 않는다. 원 논문도 이 임상 지표를 별도의 예측 대상으로 사용했다. [원 논문](https://www.nature.com/articles/s41467-020-17807-z)
- 2,122개 기록·좌우 조합 모두에 유일한 유한 수치가 연결된다. 다른 무릎 열 `KneeFlex_meanStance`도 점검했지만 이번 학습에는 사용하지 않는다. 원본 압축 안 CSV와 추출 CSV의 SHA256이 일치한다.
- 대조군은 GDI 단독, 실험군은 GDI＋무릎 지표 동시학습이다. 기존 CNN의 사용하지 않던 출력 1을 무릎 예측에 사용하므로 모델 크기·초기 가중치·난수 순서가 동일하다. GDI는 기존 출력 0을 유지한다.
- RMSprop·배치32·학습률·감소 일정·dropout·커널 규제·최대100epoch·기록별 구간 수 보정·학습자료 한정 OLS를 그대로 유지한다. 각 지표는 해당 학습 사람의 값만으로 독립적으로 최솟값·범위를 구한다. 보조 손실에도 같은 기록별 구간 비중을 적용한다.
- 보조학습 비중 0.1·0.3·1 중 하나와 학습 길이는 바깥 평가 사람을 제외한 내부4분할의 **GDI 사람 동일 비중 MAE**로 선택한다. 동률은 작은 비중, 이른 epoch 순이다. 무릎 정답은 추론에 필요하지 않다.
- 대조군25학습, 보조학습60내부＋5재학습으로65학습, 합계90학습·10바깥 예측이다. 추가 모델 평균은 하지 않는다. 기존 CNN MAE6.866655는 참고값이며 이번에 다시 학습한 동일 조건 대조군이 주 비교다.

## 평가와 해석

사람 안의 기록·좌우 절대오차를 평균한 뒤 사람을 같은 비중으로 평균한다. 주 비교는 보조학습−GDI 단독의 MAE 차이다. 사람 단위로 짝지어 10,000회 재표집(seed20261102)한 95% 구간 상한이0보다 작으면 개선 근거, 하한이0보다 크면 악화 근거, 나머지는 불확실로 보고한다. 이 판정이 그동안의 반복 탐색을 보정하는 것은 아니다.

전체 MAE·상관·평균 편향, 5분할 MAE와 표준편차, GDI 사람 평균 구간별 오차와 인원을 함께 제시한다. 분할들은 학습 사람을 공유하므로 표준편차는 독립 반복실험의 불확실성이 아니다. 재표집도 고정된 예측에 대한 구간이며 재학습·모든 탐색의 불확실성을 포함하지 않는다.

이미 결과를 확인한 222명·377기록은 이번 학습·선택·평가에 사용하지 않는다. 이번 결과는 반복 탐색한 개발자료의 비교이며 새로운 독립 최종 평가·고령자 임상 검증으로 부르지 않는다. 원래 가설을 지금 수행하는 탐색 실험이라는 시간 순서도 유지한다.

## 실행과 검산

기존 기준 코드의 출처와 지문을 보존하고 새 폴더에서 실행한다. CPU 가상자료에서 보조 비중0의 기존 모델·학습 곡선 완전 일치, 보조 정답 변경 불변, 보조 오차의 공통층 역전파, 중단·재개 일치,90개 중첩 학습 및 바깥 정답 변경 불변을 확인한다. 실제 자료에서는 사람/좌우/기록 연결과20개 내부 분리를 검사한다.

학교 GPU1개짜리 작업2개, 각각 CPU4개·RAM12GiB·24시간 상한을 사용한다. 서로 다른 물리GPU인지 확인하며,각 GPU 가상검사와 두 조건3epoch파일럿을 수행한다. 파일럿 원본을 D로 회수해 SHA256·모든epoch 지표·학습자료 한정 보정·CPU float64 재추론 허용오차0.0001을 검산한 뒤에만 본 학습을 허용한다. 파일럿 점수로 비중이나 설정을 바꾸지 않는다.

완료 후90학습의 모든epoch 예측·지표·사람 분리·정규화·내부 비중/길이 선택을 검산하고10개 최종 모델을 재추론한다. 로컬 보정식 계수의 엄격 일치 대신, 저장된 계수로 지표를 재계산하고 재적합식과 실제 출력 점수 차이0.0001을 검사하는 기존 수치 검산 방식을 명시적으로 사용한다. 실패하면 원래 실패·허용오차를 보존한다.

코드·설정·입력 점검·작은 검산 보고서는 C 작업본, 모델·체크포인트·압축·대량epoch예측은 `D:/gait-research-data/D_P/gdi-research-harness/studies/20261102-knee-auxiliary-cnn`에 저장한다. 입력약40MB는 서버에 있는 기존 파일의 지문을 대조해 복사한다.30분 전용 감시 등록부는 `watch/registry.json`이며 다른 채팅의 작업·예약·GPU는 변경하지 않는다.
