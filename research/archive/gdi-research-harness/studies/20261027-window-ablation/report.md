# 짧은 입력의 원인 비교와 평가 인원 확대 준비

사용자 직접 요청으로 수행한 연구다. 기존 자동 실행의 설정이나 완료 기록은 변경하지 않았다.

## 먼저 볼 결론

**검증 37명이 적다는 우려는 타당하다.** 이번 비교에서도 검증 37명과 학습 175명의 내부 비교에서 개선 크기와 좌표 조정 효과가 달랐다. ‘짧으면 항상 정확해진다’거나 ‘정규화가 개선의 원인이다’라고 확정할 수 없다. 같은 검증 자료에서 가장 좋은 조건을 새 최종 모델로 채택하지 않았다.

사용자가 선택한 ‘개발용·최종 평가용으로 먼저 나누기’에 따라, 입력을 준비한 새 후보 743명을 정답을 보기 전에 분리했다.

| 용도 | 사람 수 | 준비된 입력 |
|---|---:|---:|
| 개발 후보 | 520명 | 861건 |
| 최종 평가용으로 보존 | 223명 | 378건 |

사람 겹침과 기존 250명과의 겹침은 모두 0이다. **223명은 입력 준비와 용도 보존이 끝난 사람 수다. GDI 정답까지 확인된 평가 인원이 아니다.** 정답이 실제 연결되는 최종 인원은 아직 모른다.

## 무엇을 어떻게 비교했는가

질문은 입력 길이·좌표 크기와 중심 조정·구간 위치를 나누면 앞선 124장 결과를 설명할 수 있는가다. 기존 개발 212명·243건만 사용했다. 원래 학습 175명·203건과 검증 37명·40건을 유지했다. 기존 평가 38명의 특징·정답·예측은 사용하지 않았다.

같은 원시 243장 구간에서 앞[0:124]·중간[59:183]·뒤[119:243]를 선택했다. 서로 겹치는 구간이며 새로운 독립 표본 3개가 아니다. 위치마다 다음 두 조건을 비교했다.

- **전체 기준 유지:** 원래 243장 전체로 구한 좌표 중심·크기를 유지하고 124장만 AI에 넣는다.
- **구간별 재조정:** 각 124장의 원시 좌표로 중심·크기를 다시 구한 뒤 AI에 넣는다.

입력 준비 → 동결된 MotionBERT-Lite로 특징 추출 → 학습 자료만으로 표준화 → 기존 GDI 정답으로 Ridge 학습 → 사람별 오차 비교 순서다. CPU 4스레드, 시간·관절 평균 512개 특징, Ridge(alpha=1, solver=svd)를 유지했다. AI 본체의 파인튜닝과 새로운 설정 탐색은 하지 않았다.

기존 243장과 원시 앞 124장 조건은 저장 모델·특징·내부 예측을 재사용했다. 새 5조건의 검증용 모델 5개와 내부 5묶음 모델 25개만 학습했다. 전체 입력 검사가 끝난 뒤에만 개발 정답으로 점수 계산을 시작했다.

## 실제 결과

| 조건 | 기존 검증 37명 오차 | 학습 175명 내부 5묶음 오차 |
|---|---:|---:|
| 원래 243장 | 7.7185 | 8.3896 |
| 앞 124장·전체 기준 유지 | 7.2309 | 8.3538 |
| 앞 124장·구간별 재조정 | 7.2883 | 8.2758 |
| 중간 124장·전체 기준 유지 | 7.6330 | 8.8828 |
| 중간 124장·구간별 재조정 | 7.9653 | 8.8010 |
| 뒤 124장·전체 기준 유지 | 8.2466 | 8.7936 |
| 뒤 124장·구간별 재조정 | 8.7723 | 8.4332 |

작을수록 좋다. 한 사람 안에서 좌우·기록 오차를 먼저 평균하고 사람 간 평균을 냈다. 내부 175명은 기존의 고정 5묶음을 사용해 140명으로 배우고 35명을 예측했다. 각 사람은 자신의 예측을 위한 학습에서 빠졌다. 다만 이미 연구에 사용한 사람들의 내부 비교이므로 새 사람 평가가 아니다. 학습 조건이 다른 두 열을 합쳐 ‘212명 최종 평가’로 만들지 않는다.

앞 124장·전체 기준 유지 조건은 검증에서 약 0.488의 오차 감소를 보였지만 내부에서는 약 0.036에 그쳤다. 감소량의 95% 재표집 범위는 검증 약 [-0.215, 1.162], 내부 약 [-0.310, 0.374]로 모두 0을 포함했다. 따라서 개선이 확정됐다고 말할 수 없다.

앞 124장을 구간별로 다시 조정하면 검증은 7.2309→7.2883으로 조금 나빠졌지만 내부는 8.3538→8.2758로 좋아졌다. 중간·뒤 구간의 좌표 재조정 효과도 두 집단에서 방향이 달랐다. 앞 구간의 평균 오차가 중간·뒤보다 낮은 양상은 관찰했지만, 관절 추정 잡음이나 회전·촬영 종료가 원인이라고 확인하지는 않았다.

모든 짝 비교·좌우 오차·재표집 범위는 comparison.json에 남겼다. 여러 비교에 대한 통계적 보정은 하지 않았으므로 일부 범위가 0을 포함하지 않아도 독립 최종 검증으로 해석하지 않는다.

**전체 243장으로 좌표를 조정한 앞 124장은 진단용 조건이다.** 좌표 크기를 정할 때 뒤쪽 프레임도 필요하므로, 124장만 관측한 새 영상에 그대로 적용할 수 있는 완성 알고리즘은 아니다. 이 조건의 7.2309만 골라 짧은 영상 모델의 최종 성능으로 발표하지 않는다.

## 준비 중 실패와 복구

첫 경로는 정규화된 243장을 잘라 다시 정규화했다. 학습 3건의 검사는 통과했지만 110개 행을 준비한 뒤 다음 행에서 원시 124장 입력과 최대 약 0.1712의 차이가 나 중단했다. 이 경로로 점수 모델을 학습하지 않았고 허용 오차를 넓히지도 않았다. 코드·임시 파일·실패 기록을 보존했다.

실패한 기록 하나를 진단하니 차이 239개는 모두 신뢰도 0인 관절의 x좌표였다. 원래 정규화가 범위 밖 좌표를 [-1,1]로 자르면서 정보가 사라진 영향이었다. 그 자르기만 생략한 진단용 중간 좌표를 재정규화하면 원시 124장과 최대 약 1.19e-7 차이로 허용 오차 안에 들었다. 이는 한 기록의 좌표 처리에 대한 진단이며 GDI 오차 감소의 원인을 증명한 것은 아니다.

복구 경로는 243건의 원시 선택 항목 158,193개에 크기·CRC·추출 내용 SHA를 확인했다. 원래 243장 입력과 기존 원시 124장 캐시를 재현한 뒤 중간·뒤 구간도 원시 좌표에서 직접 만들었다. 전체 3GB 압축파일의 새 암호학적 지문 검사는 아니다. 앞서 정상 처리한 전체 기준 유지 특징은 110개 기록에서 재사용했고, 잘못 가정한 구간별 재정규화 특징은 최종 비교에서 제외했다.

## 검증 인원을 늘리는 경로

가장 가까운 경로는 새 743명 후보다. 사용자 선택에 따라 사람 ID를 정렬하고 seed=20261027로 한 번 섞어 223명을 최종 평가용으로 보존했다. 나머지 520명은 개발 후보이며 아직 학습에 합치지 않았다. 같은 사람의 준비·실패 기록 모두 같은 용도를 갖는다. 378개 평가 입력을 378명으로 세지 않는다.

약 30%를 평가용으로 남긴 것은 평가 인원을 늘리면서 추가 학습 자료도 남기려는 실용적인 선택이다. 223명이 충분하다는 검정력 분석이나 임상 근거는 아니다. 정답 누락·중복이 있으면 유효 인원은 줄어들 수 있고, 결과를 본 뒤 다른 사람으로 채우지 않는다.

새 743명에게서는 기존 243장 입력을 준비하지 못했다. 따라서 새 223명은 **124장 모델의 GDI 오차 평가**를 확대할 잠재 경로다. 현재 조건 그대로 **243장과 124장의 정확도 직접 비교** 인원을 늘리는 경로는 아니다. 그 질문에는 양쪽 입력과 같은 정답이 있는 다른 사람의 자료가 필요하다.

보류됐던 2,504개 기록도 정답 없이 식별 열만 재검토했다. 2,448개는 연결되는 사람 행이 없고 56개는 한쪽 정보만 있었다. 단순한 식별행 중복을 정리해 좌우 연결을 복구할 수 있는 경우는 없었다. 조건을 완화해 사람을 추가하지 않았다. 영상·검사 연결이 보류된 4개 기록도 임의로 선택하지 않았다.

외부 자료도 추가 경로는 될 수 있다. 다만 목적과 자료 형태를 맞춰야 한다.

| 확인한 외부 후보 | 활용 가능성과 현재 한계 |
|---|---|
| [CARE-PD](https://github.com/TaatiTeam/CARE-PD/blob/master/docs/dataset.md) | 제공자는 363명·9집단을 설명한다. 임상 예측 목표는 UPDRS이고 정답이 없는 하위 자료도 있다. GDI 정답 표본으로 바로 더하지 않는다. |
| [고령자 44명 자료](https://pmc.ncbi.nlm.nih.gov/articles/PMC7701341/) | SPPB·POMA-G와 모션캡처를 제공한다. 다른 평가 목표의 외부 연구 후보이며 이 점수를 GDI로 바꾸지 않는다. |
| [파킨슨병 Nordic Walking 24명 자료](https://www.nature.com/articles/s41597-025-06209-9) | 논문 검색의 제공자 설명에서 GDI를 포함한 STP 파일과 3D 표식 좌표를 찾았다. 직접 원문·저장소 접속 오류가 있었고 파일은 확보·검사하지 않았다. 2D 영상 추정 좌표와의 차이·정답 산식·좌우 연결·이용 조건을 확인해야 한다. 사용 가능한 24명을 확보했다고 세지 않는다. |

영상 구간 자르기나 반복 측정은 같은 사람의 학습 자료를 늘릴 수 있지만, 독립 검증 인원을 늘리지 않는다. 공개 자료 확보·사용 조건·기관 심의·다른 집단의 유효성도 각각 확인할 사항이다.

## 확인한 것과 다음 목표

독립 Ridge 수식, 새 5개 저장 모델의 예측 재현, CSV 14개 방법·대상 조합의 독립 사람별 오차 계산, 원시 243건의 지문·연속성·신뢰도 보존을 확인했다. 새 개발·최종 평가 예약 집단의 사람 분리와 준비 입력 지문도 확인했다. 기존 평가 38명과 새 후보의 정답은 사용하지 않았다.

다음 목표는 고정된 개발 520명·최종 평가 예약 223명 목록을 유지하면서, GDI 연결의 누락·중복·좌우 완전성을 확인할 절차를 준비하는 것이다. 개발용 정답 확인과 최종 정답 보존을 나눠 최종 평가 정답으로 모델을 조정하지 않아야 한다. 지금은 37명에서 설정을 더 맞추는 일보다 실제 평가 인원을 확보하는 일이 우선이다.

이번 연구의 계산은 끝났고 자동 감독 상태는 변경하지 않았다. 계산 후 웹 조회 도구의 긴 대기와 연결 실패가 있었으며 전체 대화가 30분 안에 끝났다고 주장하지 않는다. 준비 프로그램의 실제 시간은 pilot.json과 raw_preparation.json에 있다. 시간 간격 전체의 원인은 확인하지 못했다. 결과와 실패·분리 목록을 보존하고 불필요한 재학습은 하지 않는다.
