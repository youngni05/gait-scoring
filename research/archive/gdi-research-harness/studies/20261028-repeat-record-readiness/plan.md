# 반복 기록의 사용 가능성 확인

사용자는 앱이나 새 촬영보다 보유 자료를 통한 알고리즘 개발 방향 검토를 먼저 진행한다고 명시했다.
이번 질문: 개발용 520명·861건 중 같은 사람·같은 검사 번호에 여러 영상이 연결되는가?
입력: 기존 development_linkage.json 하나. 사람·검사·영상 식별자와 배정 역할만 집계한다.
이유: 같은 사람의 다른 방문을 동일 상태의 반복 측정으로 잘못 해석하지 않기 위해서다.
고정 조건: 기존 모델·정답·분할·평가 지표 불변. 기존 평가38명·예약223명 자료를 열지 않는다. 새 학습과 예측 성능 계산을 하지 않는다.
검사: 역할 전부 development_candidate, 520명·861건, 영상 중복 여부, 집계 전후 원본 해시 일치. 같은 검사 번호라도 촬영 조건이 같다고 단정하지 않는다.
