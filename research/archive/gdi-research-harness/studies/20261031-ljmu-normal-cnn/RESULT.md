## 낮은 예측에 대해 추가 확인한 내용

**보정식 때문에만 낮아진 결과는 아니다.** 보정 전 사람별 전체 평균은 75.44점, 기존 보정 후는 77.47점이다. 보정은 평균을 약 2.02점 올렸다.

**사용 구간의 좌표 결측만으로 전체 현상을 설명하기 어렵다.** 모든 사용 구간의 필수 좌표 결측 비율이 0인 기록 254개·48명만 모아 사람별로 집계해도 평균 78.37점이었다. 결측이 없다는 것은 자세 추정 자체가 정확하거나 영상 조건이 같다는 뜻이 아니다. 이 부분집합은 본 분석을 대체하지 않으며 인원·기록 구성이 달라 인과효과 비교로 사용할 수 없다.

**기존 개발자료에도 높은 점수를 낮게 예측하는 경향이 있다.** 저장된 평가 사람 예측 `cnn-multiwindow695/analysis/cnn_oof.npz`를 재집계했다. 실제 90 이상 100 미만인 좌우 점수 211개는 정답 평균 93.63, 예측 평균 86.12였다. 실제 100 이상인 좌우 점수 44개(36명·39기록)는 정답 평균 103.93, 예측 평균 90.14였다. 이 계산은 기존 개발자료의 정답을 사용한 별도 참고이며, LJMU에 정답을 부여한 것이 아니다. 개발자료는 사람마다 하나의 평가 모델을 사용했고 LJMU 요약은 5개 모델 평균이므로 두 값을 동일한 평가 방식의 성능으로 비교하지 않는다.

현재 근거로는 높은 점수를 낮게 내는 모델 경향과 새로운 대상·촬영 자료의 차이가 가능한 설명이다. 어느 요인이 얼마만큼 영향을 줬는지는 이번 실험에서 분리하지 못했다. 77점을 100점으로 단순히 올리는 후처리는 검증된 해결책이 아니다.

## 해석 한계와 자료의 성격

[LJMU 원 논문](https://www.nature.com/articles/s41597-023-02161-8)의 Methods에서는 보행·자세에 영향을 주는 질환이 없다고 신고한 성인을 모집했다고 설명한다. 참가자 표의 나이는 18–65세다. 이 모집 조건은 실제 3차원 GDI를 측정해 각 개인의 정상값을 확정한 것과 다르다.

- 전달 배열에는 실제 GDI 정답이 없다. MAE·정확도·정상 판별률을 계산하지 않았다. 참조선 100을 개인별 정답으로 사용하지 않는다.
- 정상 자료의 원본 영상·원본 JSON은 이 ZIP에 없으므로 이번 실행에서 정상 전체의 전처리를 원본부터 다시 검산하지는 못했다. 전달 배열과 인계 무결성, 기존 코드 재현, 예측·집계를 확인했다.
- 모든 기록의 실제 FPS는 미확인이다. 원본 프레임을 유지했고 학습자료와 실제 시간 간격이 같다는 보장은 없다.
- 원 영상에서 대상자 추적, 해부학적 좌우, 거울 반전, 촬영 방향을 확인하지 못했다. `90`은 파일명 표시다.
- `P52_E3T4_90_json` 1기록은 E3이면서 90도라는 파일명을 갖는다. 원 논문의 E3 촬영 설명은 정면·후면이므로 실제 영상 확인이 필요한 항목이다. 전달 입력 전체를 평가하기 위해 그대로 포함했으며 해당 예측 평균은 77.59점이다.
- 105기록의 제외로 자료 선택의 영향이 남는다. 이 실험은 제외된 기록이나 다른 정상 성인 집단 전체를 대표한다고 보장하지 않는다.

## 실행과 검산

CPU에서 Python 3.12.14, PyTorch 2.15.0+cpu, NumPy 2.5.4, SciPy 1.18.1로 실행했다. CPU PyTorch와 분석 라이브러리는 `D_P/tmp/ljmu-cnn-python-deps`, `D_P/tmp/ljmu-analysis-python-deps`에 설치했다. GPU·원격 서버는 사용하지 않았다.

1. 원 ZIP의 CRC 검사 및 인계 명세 37파일의 크기·SHA-256 대조를 통과했다. 포함된 원 모델 ZIP이 로컬 v2 묶음과 바이트 단위로 일치했다.
2. 공개 샘플 650프레임 → 12구간을 재처리했다. 기존 예상 특징과 최대 차이 0.0, 5개 모델 예측과 최대 차이 0.0이었다.
3. 정상 입력 전체에 기존 5개 모델을 적용했다. 예측은 모두 유한했다.
4. 구간 예측 CSV 16,535행에서 기록 평균을 다시 계산했다. NPZ의 5×882×2 예측과 최대 차이는 2.84e-14였다. 기록 CSV 4,410행과 사람 CSV 320행도 각각 일치했다.

## 후속 원인 분석 — 2026-10-31

**현재 가장 직접적인 근거는 모델의 높은 점수 과소예측과 시간축 입력에 대한 민감도다.** 성인이라는 이유만으로 77점이 됐다고 설명하기 어렵다. 촬영·옷 조건 차이도 관찰되지만, 기존 자료만으로 원인별 기여도를 합이 100%가 되도록 나눌 수는 없다.

### 77점은 원래 어떤 의미인가

정식 3차원 보행검사로 계산한 GDI 77은 정상 참조 평균 100에서 약 2.3표준편차 낮은 값이다. GDI는 10점 감소마다 정상 참조에서 1표준편차 멀어지는 척도다. 이는 상당한 보행 패턴 차이를 뜻하지만 점수 하나로 특정 질환, 중증도, 통증, 낙상 위험이나 일상생활 능력을 정하지 않는다. 이번 CNN의 외부자료 예측 77점에 정식 측정값의 의미를 그대로 적용할 근거는 없다. [Gillette 보행검사 결과 설명](https://www.gillettechildrens.org/assets/uploads/documents/PIC/Gait-Lab-Outcome-Report.pdf)

### 높은 점수를 못 내는가: 상한은 없지만 실제 예측이 가운데로 몰린다

코드의 마지막 층은 선형 출력이다. 추론 시 sigmoid나 점수 자르기가 없고 기존 평가 예측의 최댓값도 101.91점이었다. 따라서 77점·90점·100점의 하드웨어적 또는 코드상 상한은 없다.

692명·1,061기록을 저장된 5개 모델로 다시 추론했다. 각 기록에는 그 사람을 학습한 모델 4개와 학습에서 제외한 평가 모델 1개가 있다. 전자의 평균은 학습자료에 대한 적합도를 보는 값이며 일반화 성능이 아니다. 아래 표는 좌우 점수 단위로 집계했다.

|---|---:|---:|---:|---:|
| 60 미만 | 232 | 55.14 | 59.38 | 62.65 |
| 60–70 미만 | 506 | 65.50 | 68.11 | 69.86 |
| 70–80 미만 | 674 | 75.05 | 75.51 | 75.37 |

낮은 정답은 높게, 높은 정답은 낮게 예측하는 경향이 뚜렷하다. 100 이상인 점수 44개 중 평가 예측도 100 이상인 것은 1개뿐이었다. 학습한 사람에게도 평균 10.73점 낮게 나왔으므로 외부 성인 자료만의 문제가 아니다.

개발자료의 2,122개 좌우 점수 중 100 이상은 44개(2.07%), 90 이상은 255개(12.02%)였다. 학습 손실은 기록별 구간 수를 보정한 평균제곱오차와 규제항이며 높은 GDI 구간을 별도로 균등하게 반영하지 않는다. 고득점 자료가 적은 점, 입력으로 설명되지 않는 정답 차이, 규제·학습 설정은 가능한 원인이다. 각각을 바꿔 재학습하지 않았으므로 어느 하나가 과소예측의 원인이라고 확정하지 않는다.

### 성인이라서 그런가: 기존 개발자료에도 성인이 있었고, 고득점 과소예측은 양쪽에 있다

| 검사 당시 18세 미만 | 151 | 232 | 95.52 | 86.94 | −8.58 |
| 검사 당시 18세 이상 | 15 | 23 | 94.28 | 85.54 | −8.74 |

높은 점수의 과소예측은 두 집단에서 모두 나타났다. 따라서 성인이라는 속성만으로 큰 차이를 설명할 근거는 부족하다. 다만 성인 고득점 표본이 15명으로 적고 기존 임상자료의 성인과 LJMU 정상 성인은 다른 집단이다. 이것이 성인 정상 보행에 대한 일반화 검증은 아니다.

### 시간축 입력이 점수를 크게 바꾼다

LJMU 특징의 겹치는 구간을 원래 프레임 위치대로 연결했다. 겹침 값은 정확히 일치했다. 같은 중심 시점에서 프레임 진행량을 0.8배·1.0배·1.2배로 바꿔 선형 보간하고 모두 124프레임으로 입력했다. 세 조건을 만들 충분한 주변 프레임이 있는 **동일한 57명·749기록**만 비교했다. 정상 전체 64명의 평균과 직접 차감하지 않는다.

| 진단 입력 | 예측 평균 | 같은 부분집합의 원래 입력 대비 |
|---|---:|---:|
| 프레임 진행량 0.8배: 느리게 보이는 입력 | 72.36 | −5.81 |
| 원래 간격 1.0배 | 78.17 | 기준 |
| 프레임 진행량 1.2배: 빠르게 보이는 입력 | 83.98 | +5.81 |

이는 모델이 시간축 입력에 민감하다는 직접적인 검사다. 실제 FPS를 측정하거나 올바른 재표본화 비율을 찾은 검사가 아니다. 원본 영상 대신 이미 계산된 특징을 보간했고, 같은 중심을 유지하면서 124프레임에 담기는 원본 시간 폭도 달라진다. 실제 보행 속도, 보행 주기, 프레임 간격, 구간에 포함된 움직임의 영향을 완전히 분리한 검사는 아니다. 1.2배를 수정안으로 채택하거나 가장 100에 가까운 배율을 고르지 않았다.

입력의 좌우 발목 차이 신호에서 계산한 주된 반복 빈도는 고득점 개발자료에서 평균 0.0371회/프레임, LJMU에서 0.0325회/프레임이었다. LJMU가 약 12.4% 낮다. 이는 124프레임 신호의 주파수 요약이며 실제 분당 걸음 수나 정확한 보행 주기 측정값이 아니다. 시간 특성이 다르다는 보조 근거다.

문헌상 원 임상 영상은 29.97 FPS, LJMU는 30 FPS로 설명되어 두 명목값의 차이는 약 0.1%다. 이것만으로 20% 시간 변환이 필요하다고 결론낼 수 없다. 두 로컬 JSON의 실제 시간 간격과 추출 이력은 여전히 미확인이다. [기존 연구 Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC7426855/), [LJMU 자료 논문](https://www.nature.com/articles/s41597-023-02161-8)

### 촬영·입력 특징도 다르지만 영향은 구분해야 한다

- **수평 반전:** 전체 64명·882기록에서 x 좌표와 x 차이 특징의 부호를 함께 반전했다. 각도·거리는 유지했다. 평균은 77.47→77.49점으로 거의 같았다. 기록별 변화 절댓값은 평균 1.89점이므로 개별 영향은 있지만, 이 수평 방향 차이가 전체 낮은 평균을 해소하지는 않는다. 수평 반전은 실제 다른 카메라 위치·원근·가림을 재현하지 않는다.
- **옷 변경:** 같은 사람·실험·과제의 원래 옷과 ALT 기록 186쌍·55명을 비교했다. ALT 예측이 사람별 평균으로 1.70점 낮았다. 참가자 단위 탐색적 부트스트랩 95% 구간은 −2.29~−1.11점이다. 옷과 재촬영 당시 실제 움직임·검출 품질이 함께 달라질 수 있어 순수한 옷의 인과효과는 아니다.
- **촬영 배치:** 같은 사람·과제·옷 표시를 맞춘 E1/E2 393쌍·61명에서 E2가 평균 1.28점 높았다(탐색적 95% 구간 0.57~2.04점). 카메라 배치·배경·반복 보행이 함께 달라진 비교다.
- **좌표 특징 분포:** 기록 평균 실제 GDI 90 이상인 개발자료 111기록·95명과 비교했을 때, 허벅지 길이로 나눈 발목 수평 움직임의 표준편차는 0.443→0.587, 발끝–발목 거리는 0.399→0.447이었다. 정상화 후에도 입력 차이가 남았다. 특히 발목 수평 움직임은 LJMU 64명 중 48명이 고득점 개발자료 사람별 분포의 중앙 90% 범위 밖이었다. 이 차이를 비정상 보행 판정이나 연령 효과로 해석하지 않는다. 체형·걸음폭·촬영 투영·자세 추정 오차가 섞일 수 있다.

### 이번 분석의 판단 범위와 다음에 구분할 질문

확인된 것은 **고득점 과소예측이 기존 자료에도 존재한다는 점**, **시간축 입력이 예측을 상당히 바꾼다는 점**, **외부자료의 특징·조건 차이가 남아 있다는 점**이다. 성인·촬영·모델 문제의 기여도를 각각 몇 점이라고 분해할 근거는 없다. LJMU를 실제 GDI 100점으로 간주해 차이를 나누는 것도 타당하지 않다.

후속 검토에서는 실제 FPS·추출 간격을 확인하고, 정상 성인의 동시 3차원 GDI가 있는 자료로 모델 편향을 평가할 필요가 있다. 고득점 표본의 비중이나 학습 손실을 바꾸는 실험은 모델 측 원인을 확인할 후보이지만 이번에는 수행하지 않았다. 정상 자료에 맞춰 상수를 더하거나 시간 배율을 사후 선택하지 않았다.

### 후속 실행 및 검증 기록

기존 CPU 환경에서 `diagnose_models.py` → `analyze_diagnostics.py` → `verify_diagnostics.py`를 실행했다. 입력·가중치·보정식은 유지했고 새 학습은 하지 않았다. 기존 개발 사람의 나이 메타데이터만 연결했으며 예약 평가 사람의 정답은 분석에 사용하지 않았다.

- 5개 모델의 학습·평가 사람 집합을 원 `complete.json`의 학습 ID 목록과 대조했다.
- 개발자료 평가 예측 재현 최대 차이는 0.00003044점으로 기존 0.0001점 재현 기준 안이었다.
- 공개 대조 샘플을 원 BODY25에서 수평 반전해 다시 전처리한 값과, 특징에서 수평 반전한 값의 최대 차이는 0이었다.
- 시간 변환 1.0배 입력은 선택된 원 특징과 정확히 같았다. 기존 구간 예측 CSV를 따로 합산한 점수와의 최대 차이는 0.00000913점이었다.
- 입력과 모델 명세의 SHA-256은 유지됐고 여섯 예측 파일의 값은 모두 유한했다.
- 분석 도중 NumPy 정수를 JSON에 직접 저장한 오류와 나이 중복 행의 부동소수점 엄격 일치 검사를 수정한 뒤 재실행했다. 입력 조건이나 결과 선택 기준을 바꾸지 않았다.

상세 수치는 `diagnostics/summary.json`, `development_score_bins.csv`, `development_age_groups.csv`, `feature_comparison.csv`에 있다. 예측 배열·사용 구간·출처 지문·검산은 같은 폴더의 NPZ·`time_probe_metadata.json`·`sources.json`·`verification.json`에 보존했다. `diagnose_models.py`는 입력·모델 지문을 확인한 뒤 저장된 모델별 예측을 재사용한다.
