# 누락을 고려한 학습: 추가 학습 자체의 효과와 분리한 결과

2026-10-28 · 사용자 요청에 따른 수동 연구 · 기존 학습 자료 안의 비교

**이번 누락 학습은 채택하지 않는다. 일반 추가 학습보다 오차가 아주 조금 작았지만, 확실한 개선으로 보기 어렵고 점수의 흔들림도 줄이지 못했다.** 학습 횟수와 초기 상태를 맞춰 비교했으므로, 단순히 더 많이 학습해서 생긴 차이와 누락 입력을 보여 줘서 생긴 차이를 구분할 수 있었다.

## 무엇을 확인하려 했나

기존에는 누락 좌표를 0으로 바꾸거나, 마지막 특징 평균에서 누락 위치를 빼는 방법을 시험했다. 이번에는 학습할 때부터 일부 관절이 보이지 않는 입력을 함께 보여 주었다. 이 차이가 학습하지 않은 사람의 GDI 예측과 점수 안정성에 도움이 되는지가 질문이다.

관절 좌표 → **고정된 MotionBERT 특징 추출기** → 기존 Ridge 예측 + **작은 점수 보정기** → 좌우 GDI 예측의 순서다. 보정기는 특징 512개를 받아 중간 값 16개를 거쳐 좌우 보정값 2개를 만든다. 처음에는 보정값을 0으로 두므로 기존 예측과 정확히 같다. 이번에 학습한 것은 이 보정기뿐이다. 좌표에서 특징을 만드는 큰 AI 전체를 파인튜닝한 실험은 아니다.

| 조건 | 학습에 보여 준 입력 | 보정기 업데이트 | 이 비교가 알려 주는 것 |
|---|---|---:|---|
| A. 기존 모델 | 추가 학습 없음 | 0회 | 기준 성능 |
| B. 일반 추가 학습 | 원래 입력 + 같은 원래 입력 | 100회 | B와 A의 차이: 이 보정기를 더 학습한 효과 |
| C. 누락을 포함한 학습 | 원래 입력 + 일부를 가린 입력 | 100회 | C와 B의 차이: 이 조건에서 누락 증강을 넣은 효과 |

B와 C는 같은 구조, 초기 가중치, 사람, 정답, 입력 행 수, 학습 순서, 손실, 학습률을 사용했다. 두 번째 입력만 다르다. 초기값을 세 가지로 바꾸어 각각 비교했으며, 좋은 결과만 고르지 않았다. 다른 사람 35명을 예측하는 비교를 기존 5묶음에서 반복해 B와 C 각각 15개, 총 30개 보정기를 학습했다. A는 동일 구조의 0업데이트 상태다.

## 어떤 자료를 어떻게 가렸나

기존 학습용 175명, 203기록을 사용했다. 각 묶음에서 140명으로 학습하고, 그 학습에 들어가지 않은 35명을 예측했다. 사람별 묶음과 GDI 정답은 바꾸지 않았다. **기존 검증 37명, 최종 38명, 새 최종 평가용 223명은 사용하지 않았다.** 반복 사용한 개발 자료의 내부 비교이며, 새 독립 최종 평가가 아니다.

각 기록의 앞 124프레임에서 얼굴(코·머리), 왼쪽 손목, 오른쪽 손목 중 하나를 골라 연속 31프레임의 관측된 좌표와 신뢰도를 0으로 만들었다. 원래부터 누락된 위치와 하체는 그대로 두었다. 실제 움직임과 GDI 정답을 바꾼 것이 아니라 입력 정보만 지운 기술적 실험이다. 원래 입력에도 자연 누락이 있을 수 있으므로 ‘원래 입력’은 누락이 전혀 없는 이상적인 자료를 뜻하지 않는다.

평가에서는 별도 난수로 위치를 정하고 더 긴 62프레임을 가렸다. 학습 사람과 평가 사람은 분리된다. 학습용·평가용은 같은 부위군이므로 모든 현실의 가림을 대표하지는 않는다. 학습 증강은 기록당 하나를 고정해 사용했다. 이미 누락된 부위만 선택되어 새로 가려지는 위치가 없는 기록도 제외하지 않았다. 학습 증강은 203기록 중 195기록, 평가 교란은 194기록에서 실제로 입력이 달라졌다.

## 결과를 어떻게 읽나

오차는 예측 GDI와 실제 GDI 차이의 절댓값이다. 좌우와 같은 사람의 여러 기록을 먼저 평균한 뒤 사람마다 같은 비중으로 평균했다. 단위는 GDI 점이며, 작을수록 정답에 가깝다. 안정성 수치는 정답 오차와 구분한다. 모든 값은 세 초기화에서 계산한 지표의 평균이며, 세 모델의 예측을 합친 앙상블 성능이 아니다.

| 확인 항목 — 모두 작을수록 좋음 | A. 기존 | B. 일반 추가 학습 | C. 누락 학습 |
|---|---:|---:|---:|
| 원래 앞 구간의 평균 오차 | 8.276 | 8.287 | 8.262 |
| 일부를 가린 앞 구간의 평균 오차 | 8.409 | 8.429 | 8.389 |
| 가리기 전후 예측값의 절대 변화 | 0.915 | 0.958 | 0.968 |
| 원래 앞·중간·뒤 예측값의 최대−최소 폭 | 4.724 | 5.586 | 5.586 |
| 원래 중간 구간의 평균 오차 | 8.693 | 8.716 | 8.724 |
| 원래 뒤 구간의 평균 오차 | 9.034 | 9.255 | 9.256 |
| 앞·중간·뒤 예측을 평균했을 때의 오차 | 8.445 | 8.423 | 8.404 |

**첫째, 일반 추가 학습 자체는 뚜렷한 이득이 없었다.** B는 A보다 앞 구간 오차가 0.011점 커졌고, 구간 간 점수 폭은 0.861점 커졌다. 세 초기화 모두 구간 폭이 커졌다. 학습에 쓰인 자료를 더 잘 맞추는 것과, 다른 사람·다른 구간에서 잘 작동하는 것은 다르다.

**둘째, 누락 학습만의 추가 이득도 매우 작고 불확실했다.** C는 B보다 앞 구간 오차가 0.026점 작았다. 세 초기화 모두 이 작은 차이는 같은 방향이었고 5묶음 중 4묶음에서 작았다. 그러나 사람을 다시 뽑아 계산한 95% 범위는 −0.022~0.073점으로, 개선이 없는 경우도 포함한다. 일부를 가린 입력의 오차 감소도 0.040점, 범위 −0.007~0.085점으로 불확실하다. 이 범위는 반복 사용한 개발 자료의 탐색적 계산이며 독립 확증 검정은 아니다.

**셋째, 누락에 덜 흔들리게 만드는 데는 성공하지 못했다.** C의 가리기 전후 변화는 B보다 0.010점 더 컸다. 원래 세 구간의 점수 폭도 B와 거의 같았다. A와 비교하면 그 폭이 약 0.862점 커졌고, 175명 중 136명에서 커졌다. 자연 구간에는 움직임 자체의 차이도 들어 있으므로 이 폭을 촬영 장비의 오차나 실제 반복 측정 오차라고 부르지는 않는다.

| 차이를 분리한 판정 | 앞 구간 오차 감소량 | 사람 재표집 95% 범위 | 해석 |
|---|---:|---|---|
| B 대비 A: 추가 학습 자체 | −0.011 | −0.208~0.188 | 확실한 개선 없음 |
| C 대비 B: 누락 증강의 추가 효과 | +0.026 | −0.022~0.073 | 작고 불확실한 차이 |
| C 대비 A: 전체 효과 | +0.014 | −0.183~0.211 | 기존 모델 대체 근거 부족 |

표의 ‘감소량’은 비교 기준 오차에서 새 조건 오차를 뺀 값이다. 양수면 개선, 음수면 악화다. 앞 구간만 골라 결론 내리지 않고 다른 구간·누락 입력·안정성도 함께 확인했다.

## 왜 이런 결과가 나왔을까

확인된 사실은 두 학습 조건의 15개 모델 모두 학습용 손실이 감소했다는 점이다. 표준화된 평균제곱오차는 B에서 평균 0.67575→0.63729, C에서 0.67580→0.63638이었다. 이는 GDI 점 단위의 평가 오차가 아니며 B/C는 입력이 다르므로 손실 숫자끼리 우열을 판단하지 않는다. 학습 실패나 업데이트 미실행으로 결과가 그대로였던 것은 아니다.

보정기 추가 후 사람 간 예측값의 퍼짐도 증가했다. 앞 구간의 사람 간 표준편차는 A 5.88, B 약 6.51, C 약 6.57이다. 모두 같은 점수만 출력해서 안정적으로 보이는 현상도 아니다. 이번 보정기는 학습 자료를 더 맞추면서 다른 구간에서도 점수를 더 크게 바꾸었고, 그 변화가 필요한 방향의 변화라는 근거는 부족했다.

가능한 설명은 두 가지다. 첫째, 누락 상황을 보여 주기만 하고 원래 입력과 같은 점수를 내도록 직접 묶는 학습 조건은 넣지 않았다. 둘째, 이미 고정된 특징 추출기가 누락을 처리한 뒤의 값만 보정했으므로, 특징을 만드는 단계의 정보 손실은 고칠 수 없다. 이는 다음 실험의 가설이며 이번 결과만으로 원인이라고 확정하지 않는다. 한 기록당 하나의 증강, 특정 부위·길이, 작은 보정기만 시험했다는 제한도 있다.

## 기존 연구를 어디에 적용했나

[MotionBERT 원논문](https://arxiv.org/html/2210.06551v5)의 3.3절은 일부가 가려지고 잡음이 섞인 2D 관절 입력으로 표현을 학습하는 방법을 설명하고, 4.6절은 특징 추출기를 고정하고 뒤쪽 예측부를 학습하는 비교를 다룬다. 이번에는 이 두 아이디어를 작은 GDI 적응 실험의 출발점으로 사용했다. 이 논문이 GDI 예측 개선을 입증한 것은 아니다. 이번 잔차 보정기 구조·가림 길이·부위 선택은 우리 프로젝트의 사전 지정 조건이며 논문의 GDI 실험을 재현한 것도 아니다.

## 다음으로 무엇을 할까

**이번 보정기는 채택하지 않고 기존 모델을 기준으로 유지한다. 학습 횟수만 늘리는 실험도 권하지 않는다.** 이미 추가 학습이 안정성을 악화시켰고 누락 증강이 이를 되돌리지 못했기 때문이다.

다음 판별 후보는 ‘원래 입력과 일부가 가려진 입력의 예측값이 불필요하게 달라지면 벌점을 주는 학습’이다. 이번 C처럼 GDI 정답만 맞추는 조건을 대조군으로 두고, 같은 학습량에서 일관성 벌점을 추가한 효과만 비교할 수 있다. 이때 변화량만 줄이고 모든 사람에게 비슷한 점수를 주는 실패를 막기 위해 GDI 오차와 사람 간 구분 정도도 함께 봐야 한다. 벌점 세기·검증 범위를 미리 고정한 뒤 진행할 후보이며, 이번 결과를 보고 아직 추가 학습하지 않았다.

큰 특징 추출기 자체의 파인튜닝은 별도 선택지로 남긴다. 현재 결과는 ‘누락 학습 전체가 불가능하다’는 결론이 아니라 ‘이 작은 보정기에 누락 예시를 더 보여 주는 것만으로는 충분하지 않다’는 결론이다. 새 임상 점수 체계, 실제 촬영 정확도, GDI 외 정답은 이번에 선택하거나 검증하지 않았다.

## 실행·검증·한계 기록

- 고정된 5묶음, 세 초기화, 100회 업데이트, 동일한 B/C 초기 상태·정답·입력 행 수를 확인했다. AdamW 학습률 0.001, weight decay 0.01, 전체 배치, 512→16→2 보정기 8,242개 매개변수다.
- 원래 입력 3개의 특징을 다시 계산했을 때 기존 특징과 정확히 같았다. 각 증강에서 바꿀 위치 외의 좌표, 기존 누락, 하체를 그대로 유지하는 검사를 수행했다.
- 아무것도 바꾸지 않는 합성 증강을 두 학습 조건에 주면 동일한 학습 결과가 나오는 대조 검사도 통과했다.
- 예측 9,135행을 사람별로 독립 재집계했다. 저장된 모든 보정기를 NumPy 식으로 재현한 최대 차이는 약 2.13×10⁻¹⁴점이었다. 재표집 범위도 재계산해 일치했다.
- 입력·코드·기존 모델 등 213개 원천 파일 지문과 203개 기록별 특징 파일 지문을 검사했다. 원본·기존 앱·완료된 과거 증거는 수정하지 않았다.
- 특징 준비 약 234초, 보정기 학습과 결과 집계 약 6초가 걸렸다. CPU에서 수행했으며 앱 전체의 영상 분석 속도를 뜻하지 않는다. 추가 GPU·API 비용은 사용하지 않았다.
- 이번 평가 사람들은 기존 개발 연구에서 이미 여러 번 사용되었다. 인위적 가림은 재촬영이 아니며 같은 영상의 세 구간도 실제 반복 촬영이 아니다. 임상·고령자·가정 촬영 성능을 주장하지 않는다.

종료 이유: 요청한 통제 실험, 별도 검산, 비교 해석을 마쳤다. 사용량 부족으로 멈춘 것이 아니며, 결과에 맞춰 횟수·부위·학습률을 바꾸는 반복은 하지 않았다. 실제 모델 성능 개선에는 실패했고, 이번 비교 단위의 수행은 완료했다.

재현 파일은 같은 폴더의 plan.md, prepare.py, train.py, verify.py다. 결과는 result.json, predictions.csv, models.npz, training_logs.json, verification.json에 저장했다. 기존 증거를 덮어쓰지 않도록 스크립트는 결과가 이미 있으면 중단한다.
