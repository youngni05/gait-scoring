# 남아 있던 자료에 대한 고정 GDI 모델 예측

기존 원자료 5,713기록 중 기존 모델 개발·직전 평가에 쓴 1,438기록을 제외한 **4,275기록**을 확인했다. 같은 94개 체크포인트로 구성한 17개 방식을 적용했다. 재학습·새 보정·결합비율 탐색은 하지 않았다.

## 이번 비교에서 확인한 점

현재 모델 학습·직전 평가와 사람이 겹치지 않으면서 정답을 비교한 집단은 409명·633기록이다. 과거 다른 실험의 검증 표본도 일부 포함하므로 완전히 새롭고 미사용인 최종시험이라고 부르지 않는다.

|주요 구성|이 집단 전체 MAE|고득점 90 이상 MAE|고득점 90 이상 편향|
|---|---:|---:|---:|
|단순 다구간 CNN|6.815|9.803|-8.717|
|CNN 묶음|6.766|9.281|-8.145|
|기존 결합|6.680|9.869|-8.962|
|RankSim 추가|6.698|9.719|-8.789|
|Huber+RankSim 추가|6.677|9.827|-8.910|
|MAE+RankSim 추가|6.669|9.745|-8.794|

단순 다구간 CNN은 STT나 추가 내부모델 묶음 없이 CNN의 여러 124프레임 구간 예측을 평균한 기준선이다. 기존 5개 바깥 분할 모델의 평균은 유지한다. CNN 묶음은 추가 내부 분할 CNN까지 평균한다.

점 추정치에서는 결합 방식들의 전체 MAE가 단순 다구간 CNN보다 낮았지만, 고득점 과소예측은 단순 다구간 CNN보다 줄지 않았다. CNN 묶음은 전체 MAE 6.766점이지만 고득점 MAE 9.281점·편향 -8.145점으로 이 표의 결합 구성들보다 작았다. 전체 오차와 고득점 결과를 따로 판단해야 한다.

편향이 음수이면 실제 점수보다 낮게 예측한다. 고득점 33명에서 과소예측은 약 8.8~9.0점으로 남았다. 표는 기술통계이며 작은 차이에 대한 우수성을 확정하거나 새 모델을 고른 결과가 아니다.

RankSim 추가의 MAE는 관절 누락 기준 통과 집단(326명·487기록)에서 6.634점, 누락이 큰 탐색 집단(111명·146기록)에서 6.953점이다. 두 집단에는 동일인 28명이 모두 포함된다. 사람과 정답 분포가 달라 이 차이를 누락만의 효과로 해석하지 않는다. 탐색 집단에는 사람 평균 90 이상 표본이 없어, 누락이 큰 고득점 사례의 성능은 확인하지 못했다.

사람 연결 미확인 2,420기록에서 기존 결합과 RankSim 추가의 좌우 점수 차이는 기록당 평균 0.571점이었다. 서로 비슷하게 답한다는 뜻이며 정답을 맞혔다는 뜻은 아니다.

행 이름의 MAE·Huber는 학습 손실 종류이고, 표 열의 MAE는 이번 평가 오차다. 전체 17개 구성과 원래 순서상 첫 사례들의 결과는 아래에 모두 포함했다.
