# OpenCap 3초 보행: 속도 비교·반복 안정성·큰 오차 분석

2026-10-31 완료·검산. 기존 298명의 동일한 3초 보행·실제 TUG를 재사용해 사람 분할 5개와 학습 난수 3개를 교차 비교했다. **3초 RF의 기준선 대비 개선은 15회 모두 유지됐지만, 전체 관절 입력이 속도 요약보다 낫다는 근거는 얻지 못했다.** TUG가 20초 이상인 9명에게는 평균 약 14초의 과소예측이 남아 있다. 새로운 사람 자료를 추가하거나 임상 사용 가능성을 검증한 실험은 아니다.

## 결과와 의미

아래는 실제 TUG와 예측 시간의 평균 절대오차이다. 단위는 초이며 작을수록 좋다. 범위는 반복 실험의 최솟값~최댓값이고 신뢰구간이 아니다. RF·CNN은 15회, 난수에 영향받지 않는 기준선·Ridge는 분할별 5회이다.

| 입력과 방법 | 반복 평균 | 반복 범위 |
|---|---:|---:|
| 중앙값 기준선 | 2.465 | 2.452~2.476 |
| 평균 속도 1개·RF | 2.229 | 2.165~2.273 |
| 속도 평균·변동·변화량 3개·RF | 2.058 | 2.026~2.099 |
| 골반 수평·수직 움직임 6개·RF | 2.127 | 2.054~2.202 |
| 전체 입력 57개·RF | 2.110 | 2.049~2.178 |
| 전체 입력·Ridge | 2.479 | 2.421~2.542 |
| 전체 시계열·CNN | 2.565 | 2.416~2.694 |

전체 RF는 중앙값 기준선보다 평균 0.354초 낮았다. 사람별 오차 차이를 짝지어 재추출한 조건부 95% 구간은 -0.603~-0.100초이다. 같은 분할 안에서 RF 학습 난수만 바꿨을 때의 최대 오차 범위는 0.058초였다. CNN은 그 최대 범위가 0.205초로 더 컸고, 15회 평균도 기준선보다 좋지 않았다. 큰 신경망 전체의 가능성을 부정하는 결과가 아니라 이번 작은 CNN과 고정 학습 설정의 결과이다.

전체 RF는 평균 속도 한 값만 쓴 RF보다 15회 모두 나았지만 차이는 평균 0.119초이고 조건부 95% 구간은 -0.256~0.022초로 0을 포함했다. 속도 요약 3개를 쓰면 오히려 전체 입력보다 15회 중 14회 낮은 오차를 보였다. 전체 입력에서 속도 요약을 뺀 오차 차이는 +0.052초, 조건부 95% 구간은 -0.078~0.184초이다. 관절 각도의 추가 효과를 더 직접적으로 보는 전체 입력 대 골반 움직임 비교도 -0.016초, 구간 -0.123~0.091초였다. **평균 속도 이상의 정보는 도움이 될 수 있지만, 그 정보가 반드시 많은 관절 각도에서 와야 한다는 근거는 없다.** 작은 차이의 불확실성이 남으므로 입력들의 동등성을 입증했다고 해석하지 않는다.

## 큰 오차는 누구에게 나타났는가

전체 RF의 15회 사람별 절대오차 평균을 기준으로 분석했다. 아래 구간은 분석용 구분이며 임상 판정 기준이 아니다.

| 실제 TUG 범위 | 인원 | RF 오차 | 기준선 오차 | RF 예측 방향 |
|---|---:|---:|---:|---|
| 10초 미만 | 240 | 1.576 | 1.203 | 평균 0.955초 길게 예측 |
| 10~20초 미만 | 49 | 2.537 | 5.727 | 평균 1.752초 짧게 예측 |
| 20초 이상 | 9 | 14.031 | 18.334 | 평균 14.031초 짧게 예측 |

전체 평균 개선이 모든 사람에게 고르게 나타난 것은 아니다. 10초 미만 집단에서는 RF가 대표값 기준선보다 나쁘다. 20초 이상 9명은 모두 큰 오차 상위 60명에 포함됐고, 전반적으로 너무 짧게 예측됐다. 큰 오차 집단에는 10초 미만인 사람도 36명 포함된다. 이 36명은 평균 4.198초 길게 예측됐다. 따라서 큰 오차를 긴 TUG 사례만의 문제로 볼 수 없다.

큰 오차 60명의 평균 보행 속도 중앙값은 나머지 238명의 약 60%였다. 전체 사람의 속도와 오차 순위 상관은 -0.569로, 느리게 걷는 구간에서 오차가 커지는 경향이 있었다. 나이(-0.109)·몸무게(-0.020)와의 순위 상관은 약했다. 이는 사후 관련성 분석이며 원인을 밝힌 결과가 아니다.

진단 코드별로도 차이가 있었다. 원자료의 GNE 5명은 MAE 10.069초, DMD 6명은 5.118초였지만 표본이 매우 작아 질환별 성능으로 일반화하지 않는다. 실제 TUG 범위를 나눈 진단별 집계도 `summary.json`에 포함했다. 기존 자료와 중복이 확인되지 않은 171명의 RF 오차는 2.749초로, 파일 일치가 확인된 123명의 1.247초보다 컸다. 두 집단의 사람·점수 분포가 다르므로 이 차이의 원인을 중복 여부 자체로 해석하지 않는다.

입력은 모두 유한값이며 원본의 최대 시점 간격은 약 0.0167초였다. 큰 오차 집단과 나머지 집단의 최대 관절 각도 변화량 중앙값은 21.87와 21.00으로 비슷했고, 이 변화량과 오차의 순위 상관은 0.031이었다. 이는 선택한 단순 지표로 큰 차이를 찾지 못했다는 뜻이다. 관절 추정의 정확도나 RGB 영상 품질이 검증됐다는 뜻은 아니다.

## 질문과 고정 조건

평균 보행 속도만 알아도 기존 전체 관절 입력만큼 TUG 시간을 예측할 수 있는지, 사람을 나누거나 학습 난수를 바꿔도 결과가 유지되는지 확인한다. 반복해서 큰 오차가 나는 사람들의 특징도 살펴본다.

- 입력은 이전 실험의 298명·3초·19채널·91시점 그대로이다. 정답은 같은 방문의 실제 TUG 시간이다. 한 사람당 한 기록만 사용한다.
- 기존 사람 분할 1개를 유지하고 새로운 5겹 사람 분할 4개를 추가한다. 분할 난수는 20261030~20261034이다. 첫 분할은 이전 196명 집단을 보존하던 분할 그대로이며, 나머지는 298명 전체를 새로 나눈다.
- RF 학습 난수 20261030·20261031·20261032를 5개 분할 각각과 조합한다. 총 15회 평가이며 가장 좋은 난수만 고르지 않는다. RF의 난수는 나무 학습용 표본 추출 등에 영향을 준다.
- CNN도 같은 5×3 조건으로 초기 가중치와 dropout 난수를 바꾼다. 이전 작은 CNN의 구조·옵티마이저·최대 80epoch·내부 평가 종료 기준을 유지한다. TCN은 이번 반복에 포함하지 않는다.
- 설정은 학습 사람 안의 3겹 평가에서만 선택한다. 정규화도 학습 사람으로만 계산한다. RF 128개 나무·잎 최소 인원 2/5, Ridge alpha 1/100을 유지한다. Ridge와 대표값 기준선은 학습 난수에 영향받지 않으므로 분할별 한 번만 계산한다.

| 입력 | 값 개수 | 비교 목적 |
|---|---:|---|
| 평균 속도 | 1 | 3초 동안의 골반 수평 이동 속도 평균만으로 예측 |
| 속도 요약 | 3 | 평균·표준편차·인접 시점 변화량을 추가한 효과 |
| 골반 움직임 요약 | 6 | 수평 속도와 수직 속도를 같은 방식으로 요약 |
| 전체 입력 | 57 | 골반 움직임에 17개 관절 각도의 요약을 더한 효과 |

위 네 입력은 같은 RF와 Ridge에서 비교한다. CNN은 전체 19채널 시계열을 직접 사용한 모델의 초기값 안정성을 확인하는 보조 비교다. 평균 속도는 OpenCap 골반 좌표에서 계산했으며, 별도의 속도 측정 장비로 검증한 값은 아니다.

## 오차 분석 방식

사람마다 15회 평가의 절대오차를 평균한다. 예측값을 먼저 평균해 성능을 좋게 보이게 하거나 가장 좋은 반복을 선택하지 않는다. 이 오차가 큰 상위 20%인 60명을 큰 오차 집단으로 정의했다. 임상적 위험 기준이 아니다.

실제 TUG 구간(<10초·10~20초 미만·20초 이상), 진단 코드, 나이·성별, 보행 상태, 기존 129명과의 중복 여부를 사후 기술 분석한다. 이 정보는 모델 입력이나 설정 선택에 사용하지 않는다. 시간 간격과 입력의 유한값을 확인하고 속도 변동·각도 변화량도 살펴보되, 움직임이 크다는 이유만으로 관절 추정 오류라고 판정하지 않는다. RGB 영상 품질·관절 신뢰도 정답은 이번 입력에 없다.

입력 조건의 오차 차이는 같은 사람·같은 반복끼리 비교한다. 반복 평가가 서로 독립인 실험 15개는 아니므로 승리 횟수로 유의성을 주장하지 않는다. 사람별 평균 오차 차이를 재추출한 구간도 저장된 학습 결과에 조건부인 요약이며 외부 검증을 대신하지 않는다.

## 실행 방식과 제한

학교 GPU로 묶음을 전송하려던 호출은 자동 승인 검토에서 보행 시계열·TUG 라벨을 해당 서버로 전송하는 명시적 승인 근거가 부족하다는 이유로 실행 전에 거절됐다. 이번 묶음 전송·원격 작업 제출은 이루어지지 않았다. 대신 로컬 CPU에서 기존 PyTorch 2.14.1+cpu를 사용한다. 새 패키지는 설치하지 않았다.

CNN 로컬 파일럿은 평가 사람을 제외한 학습 자료로 3epoch를 실행했다. 8,138개 파라미터·예측 유한값·저장 후 재추론 일치가 통과했다. CPU 전환에서 모델 구조·손실·옵티마이저는 유지하고 실행 장치와 실행 기록만 변경했다. 이전 GPU와 다른 PyTorch/난수 구현 환경이므로 CNN 결과 차이를 초기값 하나의 효과로만 해석하지 않는다. 이번 15회끼리는 모두 같은 로컬 환경이다. 일부 산출물 이름의 `gpu-`는 기존 실행 코드의 파일 이름을 유지한 것이며 GPU 실행을 뜻하지 않는다.

`protocol.json`과 `splits.json`은 학습 전에 고정했다. `prepare.py`가 입력과 분할을 만들고, `cpu.py`가 같은 분할에서 입력 조건만 바꿔 학습한다. `run_cnn_cpu.py`는 CNN 반복을 순서대로 실행한다. `verify.py`는 저장 모델을 재추론하고 사람 분리·학습 집단 정규화·내부 설정 선택을 재계산한다.

첫 CPU 실행의 검산에서는 기존 RF 예측 재현이 실패했다. 동일한 사람 가중치 1을 생략한 새 코드와 이를 명시한 기존 코드에서 라이브러리의 무작위 표본 추출이 달라진 것이 원인이었다. 기존처럼 가중치 1을 명시한 통제 재실행에서 첫 분할의 예측 차이는 약 3.6×10⁻¹⁵초였다. 첫 실행은 `initial-unweighted-run/`에 진단용으로 보존하고 최종 비교에서 제외했다. 정규화·회귀 학습 모두 명시적 가중치를 복원해 전체 CPU 비교를 재실행했다. 검산 허용 오차는 완화하지 않았다.

최종 RF/Ridge 400개와 CNN 75개의 저장 모델을 모두 재추론했다. 저장 예측과의 최대 차이는 각각 약 7.1×10⁻¹⁵초와 3.6×10⁻¹⁵초였다. 기존 RF·Ridge 결과 재현, 사람 분리, 학습 집단 정규화, 내부 설정·epoch 선택, 전체 298명의 평가 누락 여부가 통과했다. `verify_analysis.py`에서 보고 지표·사람별 오차·상위 60명·메타데이터 연결·조건부 구간을 별도로 재계산했고 통과했다. 근거는 `verification.json`, `analysis-verification.json`이다.

최종 CPU 비교는 약 10분 12초, CNN 15회는 약 24분 10초가 걸렸다. 두 학습은 일부 시간을 겹쳐 로컬에서 실행했다. Python 3.12.14·NumPy 2.3.5·scikit-learn 1.9.1·PyTorch 2.14.1+cpu를 사용했다. 실행 장치와 가중치 재현 수정 근거는 `execution.json`에 기록했다. 원자료는 여러 RGB 카메라로 이미 복원한 OpenCap 시계열이며, 단일 카메라의 3초 영상만으로 전 과정을 수행한 검증은 아니다.
