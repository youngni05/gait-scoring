# 보행 관절만으로 실제 TUG 시간 예측 — 2026-10-30

**완료:** 자료 연결 검사 → 사람 분리 → CPU 기준선·Ridge·RF → 실제 GPU 파일럿 → CNN·TCN 본 교차검증 → 전체 모델 회수 → 재추론·검산을 수행했다. 사람은12명이며 대규모 학습이나 임상 검증을 완료한 것은 아니다.

입력은 이미 확보한 Toronto 영상의 Alphapose 관절59구간이다. 한 구간은4.1초·124프레임·17관절의 x/y/신뢰도다. 정답은 같은 사람 번호의 임상표 TUG(초), 범위9–25초이다. TUG 검사의 일어서기·앉기를 영상 입력에 넣지 않았다. 임상 검사와 보행 촬영은 별도로 수행된 자료다. 원자료14명 중 앞선 연속 관절 품질 조건을 충족한12명만 썼다. 한 사람의 구간 예측을 평균한 뒤 실제 TUG와 비교한다.

평균 절대오차는 사람별 예측과 실제 시간의 차이를 절댓값으로 평균한 것이다. 이번에는 Ridge의 수치가 가장 낮았지만, 중앙값 기준선과의 오차 차이 -0.593초에 대한 사람 단위 부트스트랩95% 구간은 -1.604~+0.244초였다. 모든 학습 모델의 기준선 대비 차이 구간이0을 포함한다. 12명의 저장된 교차검증 예측에 조건을 둔 탐색적 구간이며 독립 임상 검증이나 반복 학습의 불확실성을 모두 반영하지 않는다.

사람5겹 분할을 고정하고, 바깥 학습 사람 안의3겹 분할에서만 Ridge·RF 설정과 CNN·TCN 종료 epoch를 선택했다. 기준선도 바깥 학습 사람의 점수만 사용했다. CNN·TCN은 각11,978파라미터이며,1개 초기값으로 시험했다. 추가 모델 크기·학습률 탐색을 바깥 평가 결과에 맞춰 반복하지 않았다. 이전 MotionBERT 실험과 분할이 다르므로 위 표 밖의 수치를 직접 모델 순위로 비교하지 않는다.

## 확인한 범위와 남은 일

`verify.py`를 실제 실행해 원본 입력과 변환본 일치, 실제 임상표 연결, 모든 사람 분리, 평가 누락·중복, 학습 사람만의 정규화, CPU모델 재추론, GPU최종체크포인트10개 CPU재추론, 사람별 지표 재계산을 확인했다. GPU와 다른 로컬 CPU실행의 예측 허용차는0.0001초다. `verification.json`과 `summary.json`에 근거가 있다. 로컬 검산은 번들 Python3.12 및 기존 scikit-learn1.9.1·PyTorch2.14.1+cpu를 재사용했다. 새 패키지를 설치하지 않았다.

확장할 즉시 가용 영상·실제 점수 자료는 이번 조사에서 확보하지 못했다. SPPBdataset은 점수 의미 불일치 때문에 표준SPPB 성능 주장에 사용하지 않는다. 실제SPPB44명 자료는 전체 좌표 다운로드가 막혀 있다. 파일 구조·사용조건·접근 오류와 다음에 필요한 최소 확인은 [자료와 한계](sources-and-limits.md)에 기록했다. 외부 이메일은 보내지 않았다.

현재 확인한 결과는 **짧은 보행 관절→실제 TUG 예측의 실행 경로가 작동하며, 이12명 조건에서는 작은 CNN·TCN이 단순 회귀보다 낫지 않았다**는 것이다. 독립 사람을 더 확보하고 촬영 환경을 달리한 검증이 필요하다. 이 실험만으로 표준 기능평가 대체나 임상적 의미를 주장하지 않는다.
