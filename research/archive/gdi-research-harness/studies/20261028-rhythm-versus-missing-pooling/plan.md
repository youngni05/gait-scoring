# 두 방향 비교：누락 위치 제외 집계와 설명 가능한 시간 특징

2026-10-28 사용자는 두 방향을 비교하고 기존 실험과 겹치지 않는 다음 실험 실행을 요청했다. 이번 실험은 GDI를 기존 비교 정답으로 유지하며 새로운 임상 점수·등급·판정 기준을 정하지 않는다. 앱·새 촬영·외부GPU는 범위 밖이다.

## 현재 판단과 기존 실험과의 차이

무릎 투영각 요약16개 및 MotionBERT와 결합은 이미243프레임에서 실행했고 결과가 일관되지 않았다. 시간3분할·다리만 평균·좌우 분리도 실행했다. 단순 누락 좌표0치환과 같은 처리의 Ridge재학습도 실패했다. 이 조건은 반복하지 않는다.

누락 고려는 관측 신뢰도0을 분명히 구분할 수 있어 실행 가능하나, 인코더 내부 attention에서 관절 정보가 이미 섞인 뒤 최종 평균만 바꾸는 것으로 근본 해결이 될지는 불확실하다. 설명 가능한 시간 특징은 관측된6개 하체 관절로 계산할 수 있고 구체적으로 무엇을 분석하는지 설명할 수 있어 현재 우선 탐색 가치가 높다. 단, 실제 보폭·속도·3D각도나 보행 리듬의 정답을 복원한다고 주장하지 않는다. 우위는 실험 전 가설이다.

## 고정 비교

기존 학습175명203기록만 사용한다. 이전 internal_cv_protocol.json의 고정5묶음(각35명),사람 분리,alpha=1,사람별 MAE를 유지한다. 검증37명과 기존 최종38명/새 보류223명의 입력·정답을 이번 분석에 사용하지 않는다. 공용 압축 npz에서 학습행을 선택하는 기술상 전체 배열이 일시 해제될 수 있지만 계산·특징 생성·예측·오차에는 학습행만 넣는다. 기존 학습용 OOF CSV와 고정 묶음의 연결을 검사한다. 독립 최종 성능이 아닌 기존 학습자료 내부 비교다.

앞[0:124],중간[59:183],뒤[119:243]의 같은 local정규화 입력을 원본에서 만든다. 모델은 각 묶음의 나머지140명 앞 구간으로만 학습하고,그 묶음35명의 세 위치를 모두 예측한다. 단순3구간 평균도 보고한다. 표준화는 각묶음 학습행에서만 계산한다.

사전 고정한 조건은 네 가지다.
1. 기존 전체 평균 MotionBERT512+Ridge: 저장 특징 사용,앞 구간 OOF는 기존 short124 예측을 재현해야 한다.
2. 유효 위치 평균512+Ridge: 원래 인코더 입력·가중치는 그대로 두고,출력 토큰 중 원래 신뢰도>0인 위치만 평균한다. confidence값을 정확도 확률이나 가중치로 쓰지 않는다. 단순 누락0치환·하체 고정 선택과 다르다. 내부 attention의 누락 영향까지 제거했다고 주장하지 않는다.
3. 설명 가능한 시간 특징10개+Ridge: 발목 사이2D거리,오른쪽·왼쪽 무릎 투영각의 시간 변화를 사용한다. 각각 선형 추세를 제거하고 Hann창을 적용한 스펙트럼에서 지배 주파수(cycles/frame),가장 큰 성분의 비중,정규화 엔트로피를 계산한다(3×3). 마지막1개는 추세 제거한 좌우 무릎각의 같은 시점 상관이다. 실제 cadence·보행 주기 정답으로 부르지 않는다.
4. 기존512+시간10개 결합522+Ridge: 새 시간 정보가 기존 모델을 보완하는가를 확인한다. 결합 방식/가중치/alpha를 탐색하지 않는다.

설명 가능한 특징은 정상화 주파수로 보고 fps를 가정하지 않는다. 선형추세 제거+Hann창은 구간 경계의 영향을 줄이려는 고정 계산 절차이며 효과 자체를 입증한 것은 아니다. 평평한 신호는 스펙트럼 관련값0,상관 불가 시0으로 정하고 발생 수를 남긴다. 유효한 하체가 없거나 뼈 길이가0이면 해당 기록을 조용히 버리지 않고 실패 기록 후 중단한다.

## 사전 검사 및 평가

합성 입력에서 알려진주파수,일정신호,이동·균일크기·평면회전 불변,좌우교환,잘못된하체 입력 거부를 확인한다. 유효 위치 평균은 누락 없는 입력에서 전체 평균과 같아야 하며,torch집계와NumPy가중합 수식의 일치를 처음 학습3건에서 확인한다. 원래 전체 평균 특징도 처음3건 세 위치에서 정확히 재현한다. 주파수·비중·엔트로피 범위와 유한값·프레임 연결·원본 지문을 확인한다.

동일175명의 OOF 예측에서 사람별 MAE,묶음별 MAE,앞/중간/뒤 점수 폭,사람 간 출력 표준편차(표본분모N−1)를 계산한다. 기존seed20261026·10000회 사람별 짝 재표집으로 차이의95% 범위를 제시하되 학습세트 중첩과 여러 비교 때문에 독립 최종 검정으로 주장하지 않는다. 동일alpha라도 유효자유도가 다를 수 있어 각묶음 값을 함께 남긴다. 예측·CSV 집계·저장모델 재현을 확인한다. 결과를 본 뒤 다른 주파수대·후보·상수로 변경하지 않는다.

결과 판단은 숫자가 작아졌다는 사실·일관성·한계로 나눠 설명한다. 높은 점수 정확도,작은 구간차이,설명 가능성,계산 비용 중 무엇이 좋아졌는지 구분한다. 연구목표 채택과 실제 앱 성능 입증은 별도다.
