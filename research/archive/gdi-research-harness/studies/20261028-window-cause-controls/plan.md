# 앞뒤 구간 차이의 원인 후보: 화면상 이동·크기·신뢰도 대조

2026-10-28 사용자가 실제 걸음·촬영 위치·관절 추정 문제를 구분해 개선 위치를 찾으라고 요청했다. 기존 품질 상관·구간 재정규화·혼합 학습·누락 학습은 반복하지 않는다. 새 모델 학습은 하지 않고 고정 특징 추출기와 기존 사람별 Ridge에 통제한 입력만 넣는다.

## 질문과 식별 한계

2D 관절 좌표만으로 실제 3D 움직임과 카메라 원근·회전·추정 오류를 완전히 분리할 수는 없다. 이번에는 그중 분리 가능한 ‘화면상 몸 전체의 위치·크기 변화’와 ‘상대 관절 모양 및 검출 신뢰도’를 계산상 나눈다. 남은 상대 모양을 실제 보행이라고 단정하지 않는다. 정답 영상·동기화3D·관절 위치 정답이 있는지 기존 공급자 설명도 확인한다.

## 자료와 고정 조건

기존 학습175명203기록, 기존5묶음, 앞[0:124]·뒤[119:243], 124프레임, 기존MotionBERT-Lite·Ridge·표준화·정답·사람 분리를 유지한다. 검증37명·최종38명·예약223명은 새 계산에 쓰지 않는다. 정답 예측 정확도를 새로 최적화하지 않고 구간 특징·예측 변화만 진단한다. 원시 관절은 기존203기록의 허용 목록만 읽고 크기·CRC·기존 저장 SHA 증거를 확인한다. 보호집단의 자료는 열지 않는다.

## 대조1: 같은 관절 모양에 다른 화면상 이동·크기를 넣는다

원시 H36M17관절에서 매프레임 골반 위치 r(t)를 구한다. 화면상 크기 s(t)는 양쪽 허벅지·종아리 4개 길이의 프레임별 중앙값에31프레임 이동중앙값을 적용한다. 관측된 하체만 쓰고0길이는 오류로 중단한다. 이 크기는 카메라 거리의 정답이 아니며 자세·투영 영향도 받는다.31은 사전고정 기술조건이며 최적화하지 않는다.

앞을 F,뒤를 L이라 한다. source의 상대 관절 모양·시간순서·신뢰도·누락을 유지한 채 donor의 위치/크기 궤적을 같은 프레임 순번에 넣는다.
- 이동만: x'=x_source-r_source+r_donor.
- 크기만: x'=(x_source-r_source)*(s_donor/s_source)+r_source.
- 이동+크기: x'=(x_source-r_source)*(s_donor/s_source)+r_donor.

각각 F모양+L궤적, L모양+F궤적 두 방향을 검사한다. 원시 좌표에서 조작 후 기존 구간 정규화를 적용한다. 신뢰도0 위치의 최종x,y는 source의 원래 정규화값으로 되돌려 누락값 표현 변화가 섞이지 않게 한다. 관측된 관절은 프레임별 같은 평행이동·양의 등방크기변환이므로2D각도와 상대길이비가 유지되어야 한다. 변화는 실제로 촬영된 영상이 아닌 계산상 대조다. 단일 고정 평행이동·크기는 기존 정규화가 이미 없애므로 이번이 겨냥하는 것은 구간 안의 시간에 따른 변화와 그 정규화 영향이다.

각2x2에서 FF,FL,LF,LL 특징을 얻는다(첫 글자는 상대모양의 출처). D=LL−FF, 이동/크기 항 N=((FL−FF)+(LL−LF))/2, 나머지 항 G=((LF−FF)+(LL−FL))/2이며 D=N+G다. 동일한 고정 Ridge로 점수에서도 분해한다. 이것은 순서 두 가지를 평균한 계산상 분해다. 절대크기는 상쇄·상호작용 때문에 합산하거나 원인 비율로 쓰지 않는다. 특징은 기존 해당묶음 학습 표준편차로 나눈RMS를 사용한다. donor가 같을 때 앞뒤 차이가 어떻게 되는지도 기록한다.

## 대조2: 좌표를 그대로 두고 공통 관측 관절의 신뢰도 차이만 줄인다

앞뒤의 같은 프레임 순번·관절에서 둘 다 신뢰도>0인 위치만 두 신뢰도의 기하평균으로 맞춘다. 좌표·원래 누락mask·한쪽만 검출된 위치는 그대로 둔다. 변화량을 계산하되 전체 관절 추정 오류를 고쳤다거나 누락차이까지 제거했다고 말하지 않는다.

## 움직임·품질의 보조 확인

같은175명에서 기존 품질 통계(신뢰도·누락·2차차분·다리뼈 길이 변동)를 재사용하고 원래 앞뒤 점수변화와의 연관성을 집계한다. 원시2D무릎각은 원래 각도열 차이와 각도분포(정렬한 값) 차이를 따로 계산한다. 분포차이는 시간순서를 무시한 자세 구성 차이를 나타내지만3D진짜보행 정답은 아니다. 화면상 어깨폭/몸통길이 등은 시점 후보의 대리값으로만 사용한다. 탐색적 상관을 인과나 임상 판정으로 해석하지 않는다.

## 검사·종료

기존 특징 재현(처음3기록 앞뒤) 최대오차1e-5, 원래 입력 재현, 신뢰도·누락값·시간순서 보존,각도 보존1e-3도,단일 고정크기·이동 정규화 불변,자기자신궤적 이식 항등 검사를 한다. 입력 지문·203기록·175명·기존5묶음을 확인하고 점수·특징의 정확한 덧셈분해와 사람별 집계를 별도 검산한다. 기존 검증기준을 바꾸거나 실패를 숨기지 않는다.

특징별·부위별 결과를 보고 다시 조건을 고르지 않는다. 개선 후보는 결과와 한계를 연결해 제시하되 새 점수체계나 모델을 채택하지 않는다. 수동 사용자 요청 연구로 별도 studies 폴더에 저장하며 자동배정 기록·규칙·기존 증거는 수정하지 않는다.
