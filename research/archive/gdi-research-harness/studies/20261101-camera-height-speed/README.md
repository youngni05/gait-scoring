# 키를 이용한 영상 속도 측정 진단

고정 카메라에서 키와 영상상 신체 높이로 바꾼 이동 속도가 촬영 방향에 따라 달라지는지 확인했다. 기존 MoVi14명,같은2초 직선/회전구간,카메라2대의56클립을 재사용했다. 독립 사람은14명이다. 새 점수 학습이나 영상 추론은 하지 않았다.

PlaneNet은처음·끝 골반 위치,PlaneOLS는시간에 따른 위치 기울기에 키/영상상 신체 높이를 곱한다. PinholeOLS는추가 카메라 내부 보정값을 써서 깊이도 추정하는 진단용 방법이다. 키만 입력받는 조건과 구분한다. 세 방법 모두 검출된33개자세점의 세로 범위를 영상상 키 대신 사용하는 단순 후보다. 머리 꼭대기 누락·자세 변화·가림·검출 흔들림의 영향을 포함한다.

사전에 정한 단순PlaneOLS직선 목표는 평균MAE와카메라간 차이 각각0.10m/s이하다. 실제 평균MAE0.406,카메라차이0.808m/s로 공동 조건을 만족하지 못했다. 이 문턱은 탐색용 공학 목표이며 임상 기준이 아니다.

기준은 제공된3D골반의 수평 순이동/기울기다. 순이동과기울기방법은해당기준끼리비교했다. 원근추정의3D기울기는수직흔들림도포함하며왜곡·바닥·카메라자세보정은하지않았다. 이정의는Mobilise-D의구간평균보행속도와같지않다.2초결과를30–60초5구간입력으로바로대체할근거는없다.

MoVi에는이실험의SPPB/TUG정답이없다. 정상점수를가정하거나점수적중률을계산하지않았다. 자료의구간선정에는기준좌표를이용했으므로실제사용시자동가용구간선정성능도입증하지못한다. 사람키는제공된메타데이터이며새사용자의입력오차분포는미확인이다. ±2cm의비례민감도만추가표에기록했다.

直선 구간에서 추가 카메라 내부 보정값을 쓰면 평균 오차는0.101m/s,카메라 차이는0.037m/s였다. 평균 차이 감소만으로 실제 속도 오차가 없어진 것은 아니다. 두 카메라의 편향은모두+0.09~+0.11m/s로남았다. 영상상 키 대용값·기하 가정·수직 성분 등 여러 원인이 가능하며 이 결과만으로 한 원인으로 확정하지 않는다.

다음 실험은 다른13명의 한 카메라 직선보행에서 학습한 배율 하나가 평가 사람과 다른 카메라에도 적용되는가다. 평가 사람의 모든 영상은 배율 추정에서 제외한다. 키만으로 사용 가능한 최종 시스템이나 새 임상 점수 정확도의 증거로 설명하지 않는다.
