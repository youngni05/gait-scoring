# 좌우 GDI 차이의 원인 확인과 CPU 개선 실험

2026-10-30 · 개발자료 695명 · CPU 학습·검산 완료

**원 관절에서 좌우 다리의 특징을 따로 계산하자 작은 개선이 나타났다. 전체 오차는 7.975→7.904점, 좌우 차이 오차는 7.429→7.017점으로 줄었다. 다만 실제 좌우 차이의 크기 7.21점에 비해 예측은 여전히 1.74점으로 작다. 원인을 확정하거나 문제를 해결한 결과는 아니다.**

이번에는 좌우 차이가 학습한 사람에게서도 작아지는지, 현재 MotionBERT 요약 특징으로 차이만 따로 학습하면 나아지는지 확인하고 싶었다. 실험과 검산은 AI가 실행했으며, 아래 판단은 저장된 결과에 근거한다.

## 무엇을 바꿨는가

두 다리의 **평균 점수는 기존 PLS 그대로 유지**했다. 바뀐 부분은 `왼쪽 GDI − 오른쪽 GDI`를 예측하는 방법이다. 평균을 M, 예측한 차이를 D라고 하면 왼쪽은 `M+D/2`, 오른쪽은 `M−D/2`로 계산했다. 이렇게 하면 평균 점수의 변화와 좌우 차이의 변화를 구분할 수 있다.

| 비교 방법 | 좌우 차이를 만드는 방식 |
| --- | --- |
| 기존 PLS | 기존에 저장된 좌우 예측 그대로 |
| 차이 0 / 학습 평균 | 두 다리를 같게 예측하거나, 학습자료의 평균 차이를 적용하는 대조군 |
| MotionBERT + 차이 전용 Ridge·PLS | 기존 512개 요약 특징으로 차이만 별도 학습 |
| 다리 특징 + Ridge | 원 2D 관절에서 좌우 위치·무릎 각도·다리 길이의 요약값 164개를 계산해 차이 학습 |
| MotionBERT + 다리 특징 + Ridge | 두 종류의 특징을 함께 사용 |
| 내부 검증으로 선택 | 내부 전체 오차가 기존보다 커지지 않는 후보 중 차이 오차가 가장 작은 것을 선택 |

다리 특징은 각 다리의 엉덩이·무릎·발목 위치를 골반 중심 기준으로 표현하고, 영상 평면의 무릎 굽힘 및 허벅지·종아리 길이를 계산했다. 각 신호의 분위수 5개와 표준편차, 좌우 요약값의 차이, 각도 계산 가능 비율을 사용했다. 영상 평면의 값이며 실제 3D 관절각·신체 길이가 아니다. 순서가 있는 움직임 전체를 학습하는 CNN과도 다르다.

## 같은 사람 분할에서 비교했다

- 기존과 같은 695명·1,064기록, 앞 124프레임을 사용했다. 외부 5분할은 학습 556명·평가 139명이며, 각 사람은 자신이 학습에 들어가지 않은 모델로 한 번 평가됐다.
- 설정 선택은 외부 학습 556명 안의 기존 4분할에서만 했다. 내부 학습 417명·검증 139명을 분리하고, 표준화도 해당 학습자료로만 계산했다.
- Ridge 강도는 0.01·0.1·1·10·100·1,000·10,000, 차이 전용 PLS 크기는 2·4·8·16·32·64를 비교했다. 각 계열에 차이 0·학습 평균 대조군도 포함했다.
- 학습은 기록별 동일 가중치, 평가는 사람별로 오차를 평균한 뒤 사람 간 평균을 내는 기존 방식을 유지했다. 기록이 많은 사람 때문에 평가 결과가 크게 달라지지 않도록 했다.
- 평균 점수의 기준은 기존 외부 학습자료에서 선택된 PLS 32개다. 내부 비교에도 이 크기의 저장 예측을 재사용했다. 기존 개발 결과를 보고 정한 후속 실험이며, 새로운 독립 최종 평가가 아니다.
- GPU 학습·접속·MotionBERT 재추론은 하지 않았다. 보호된 37/38/223명의 수치 자료는 사용하지 않았다.

## 평가 사람의 결과

오차는 낮을수록 좋다. ‘예측 차이 크기’는 평균 절댓값이며, 이 값이 커진다는 사실만으로 정확하다고 볼 수는 없다.

| 방법 | 전체 GDI 오차 | 좌우 차이 오차 | 예측 차이 크기 | 어느 쪽이 높은지 일치 |
| --- | ---: | ---: | ---: | ---: |
| 기존 PLS | 7.975 | 7.429 | 1.277 | 47.3% |
| 차이 0 | 7.934 | 7.214 | 0.000 | 해당 없음 |
| 학습 평균 차이 | 7.938 | 7.213 | 0.153 | 48.5% |
| MotionBERT 차이 전용 Ridge·PLS의 내부 선택 결과 | 7.937 | 7.211 | 0.120 | 20.8%¹ |
| **다리 특징 + Ridge** | **7.904** | **7.017** | **1.740** | **56.8%** |
| MotionBERT + 다리 특징 + Ridge | 7.906 | 7.025 | 1.775 | 57.4% |

¹ MotionBERT 계열은 두 방법 모두 다섯 분할에서 특징 기반 모델 대신 상수 대조군을 선택했다. 두 분할은 학습 평균, 세 분할은 차이 0이다. 차이 0 예측은 방향을 맞힌 것으로 세지 않으므로 방향 일치율이 낮다. 실제 차이가 0인 기록은 방향 계산에서 제외했다. 이 행을 Ridge·PLS 자체의 학습 성능으로 읽으면 안 된다.

다리 특징과 결합 특징은 모두 다섯 분할에서 Ridge 강도 1,000을 선택했다. 전체 오차를 확인하며 선택하는 방법도 다섯 분할 모두 다리 특징을 골라 같은 예측을 냈다. 이를 별개의 성공 사례로 세지 않는다.

![전체 오차와 좌우 차이 비교](comparison.png)

**단순 대조군과의 비교가 중요하다.** 기존 PLS는 차이를 아예 0으로 바꿔도 전체 오차가 0.041점, 차이 오차가 0.215점 줄었다. 기존 차이 예측에 도움이 되지 않는 변동이 있다는 신호다. 다리 특징은 이 대조군보다도 차이 오차를 약 0.197점 줄였다.

| 다리 특징의 비교 대상 | 전체 오차 감소와 조건부 95% 구간 | 좌우 차이 오차 감소와 조건부 95% 구간 |
| --- | --- | --- |
| 기존 PLS | 0.071점 [0.025, 0.117] | 0.412점 [0.244, 0.579] |
| 차이 0 | 0.030점 [-0.013, 0.073] | 0.197점 [0.043, 0.348] |
| 학습 평균 차이 | 0.033점 [-0.009, 0.075] | 0.196점 [0.043, 0.347] |

사람 695명을 복원추출해 10,000번 계산한 구간이다. 저장된 예측을 조건으로 한 탐색적 비교이며 모델 선택·반복적인 개발 탐색의 불확실성은 포함하지 않는다. **상수 대조군보다 전체 GDI 오차까지 확실히 줄였다고 보기는 어렵다.**

## 원인에 관해 어디까지 알게 됐는가

| 확인 항목 | 학습 사람 | 평가 사람 |
| --- | ---: | ---: |
| 기존 PLS의 예측 차이 크기 | 1.216 | 1.277 |
| 다리 특징의 예측 차이 크기 | 1.763 | 1.740 |
| 기존 PLS의 좌우 차이 오차 | 7.118 | 7.429 |
| 다리 특징의 좌우 차이 오차 | 6.798 | 7.017 |

이 표는 다섯 분할의 지표 평균이다. 학습 사람은 분할 간 반복되므로 별도의 2,780명으로 해석하지 않는다.

1. **평가 사람에게만 생기는 문제는 아니다.** 기존 PLS는 학습한 사람에게도 좌우 차이를 작게 예측했다. 단순히 새 사람에게 적용할 때만 발생하는 문제로 설명하기 어렵다.
2. **현재 MotionBERT 요약 특징의 예측부만 나누는 방법에서는 이득을 찾지 못했다.** 시험한 Ridge·PLS 후보가 내부 검증에서 상수를 이기지 못했다. MotionBERT 전체에 좌우 정보가 없다는 뜻은 아니다. 시간·관절 정보를 요약하는 방법, 사전학습과 현재 자료의 차이, 선택한 예측부의 제약이 남아 있다.
3. **원 관절의 좌우별 특징에는 더 활용할 여지가 보인다.** 실제·예측 차이의 사람별 상관은 기존 -0.030에서 +0.257로 높아졌다. 그러나 원 관절 추가와 특징 설계를 함께 바꿨으므로 정확히 어느 요소 덕분인지는 분리되지 않았다.
4. **저장 배열의 단순 순서 혼동은 발견하지 못했다.** CPU·원 관절 입력의 사람·영상·분할·정답이 일치했고, 추가 520명의 861기록은 저장된 좌우 GDI 연결표와 일치했다. 기존 입력 생성 코드도 `[L, R]` 순서다. 원 영상에서 해부학적 좌우를 다시 확인하거나 임상 원본 표·라벨 신뢰도를 재검증한 것은 아니다. 촬영 방향·가림·좌표 변환의 영향은 미확정이다.

현재로서는 **“좌우를 명시한 특징을 보충하면 일부 차이를 더 설명할 수 있다”**가 가능한 해석이다. 원인이 단일 카메라나 특정 모델이라고 단정할 근거는 부족하다.

## 점수 분포와 GPU 연구에 주는 의미

평균 점수를 유지했으므로 사람별 평균 예측의 표준편차는 7.561점으로 그대로다. 실제는 11.134점이다. **낮은 점수는 높게, 높은 점수는 낮게 예측하는 전체 압축은 이번 실험으로 해결되지 않았다.**

| 확인 지표 | 기존 PLS | 다리 특징 |
| --- | ---: | ---: |
| 10점 구간 정확 일치 | 38.71% | 38.75% |
| 두 구간 이상 차이 | 15.53% | 14.98% |
| 실제 40점대 편향 | +15.170점 | +15.310점 |
| 실제 90점대 편향 | -12.942점 | -12.883점 |

40점대에 해당하는 사람이 20명, 90점대에 해당하는 사람이 149명이다. 좌우·기록별 실제 점수대로 집계하므로 한 사람이 여러 점수대에 들어갈 수 있다. 차이 0 대조군의 두 구간 이상 오차는 14.75%로, 이 지표에서는 다리 특징보다 작았다. 점수화 가능성이 확립됐다고 보기는 어렵다.

GPU에서는 준비한 CNN 기준 실험을 그대로 진행하고 싶다. 결과가 나오면 같은 사람별 예측으로 전체 오차, 좌우 차이 오차, 방향 일치율, 평균 점수 압축을 함께 비교할 수 있다. 이번 다리 특징은 **보조 입력 또는 차이 예측부의 비교 후보**로 남긴다. CNN에 실제로 결합했거나 GPU 담당이 이 결과를 읽었다고 기록하지 않는다.

## 구현·검증 기록

핵심 코드는 [run.py](run.py)의 `raw_features`와 `combine`이다. 관절 시계열을 좌우 특징으로 요약하고, 학습 사람 안에서 고른 차이 모델의 출력을 기존 평균 점수와 합친다. 학습·평가 중복, 입력 불일치, 비정상 수치는 검사를 실패시키며 결과를 완료로 기록하지 않는다. 새 패키지는 설치하지 않고 기존 NumPy·scikit-learn 환경을 사용했다.

- [verify.py](verify.py)에서 원 특징 174,496값, 선택된 외부 모델 25개·내부 모델 100개의 별도 재학습, 후보 비교 175행, 지표 176행, 부트스트랩 비교 14개를 검산했다. 예측 재현 차이는 0이었다.
- 원 특징을 별도 계산했을 때 최대 차이는 5.69×10⁻¹⁴였다. 평균 예측 유지와 원본 96파일의 해시 불변을 확인했다. 상세 결과는 [verification.json](verification.json)에 있다.
- 첫 실행은 학습과 예측 저장 후 지표를 합치는 단계에서 중복 키 오류로 중단됐다. 집계 코드를 수정하고 같은 설정으로 재실행했다. [첫 실행 보존본](first_attempt_oof.npz)과 재실행의 모든 저장 배열이 동일함을 확인했다. 데이터·후보·선택 기준은 바꾸지 않았다.
- [present.py](present.py)는 저장 예측만으로 상수 대조군 비교와 그림을 만든다. 추가 비교는 [control_comparison.json](control_comparison.json), 세부 성능은 [metrics.csv](metrics.csv), 분할별 선택은 [selections.csv](selections.csv)에 있다.
- 재검산 명령: 프로젝트 Python 환경에서 `python -B verify.py`, 그림·대조군 재생성은 `python -B present.py`. `run.py`는 완료 결과 덮어쓰기를 막으므로 같은 폴더에서 재학습하지 않는다.

기존 실험과 GPU 작업은 유지한다. 이번 결과는 개발자료에서 관찰한 작은 개선 신호이며, 독립 최종 평가·임상 유효성·촬영 조건 변화에 대한 검증은 남아 있다.
