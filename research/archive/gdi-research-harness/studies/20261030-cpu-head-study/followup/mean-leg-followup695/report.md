# 평균 점수 보완·다리 특징 분리·시간 변화 특징 실험

2026-10-30 · CPU 학습 및 독립 재학습 검산 완료

**시간에 따라 움직임이 어떻게 바뀌는지를 직접 계산해 넣는 방법에서 개선 신호가 나타났다. MotionBERT·다리 특징·시간 변화 특징을 함께 사용한 후보의 전체 오차는 7.619점이다. 기존 PLS 7.975점, 이전 좌우 보완 7.904점보다 작았다. 다만 10점 구간 정확 일치율은 낮아졌으며, 좌우 차이와 양끝 점수 압축도 남아 있다.**

이번에는 좌우 차이만 보완했던 실험에서 더 나아가 평균 점수도 개선할 수 있는지 확인하고 싶었다. 평균 점수 보완 → 다리 특징 종류별 비교 → 시간 변화 특징 추가를 순서대로 실행했다. 아래 수치는 AI가 실행하고 별도로 검산한 개발자료 실험 결과다. 최종 모델 채택이나 독립 최종 평가를 뜻하지 않는다.

## 어떤 입력으로 무엇을 학습했는가

좌우 GDI를 **두 다리의 평균 M과 왼쪽−오른쪽 차이 D**로 나눴다. 예측을 합칠 때는 왼쪽 `M+D/2`, 오른쪽 `M−D/2`를 사용했다.

- 평균만 바꾸는 실험에서는 이전 다리 특징 모델의 차이 예측을 유지했다.
- 차이만 바꾸는 실험에서는 기존 PLS의 평균 예측을 유지했다.
- 마지막에는 시간 변화 특징으로 학습한 평균과 차이를 함께 사용했다. 평균용 Ridge와 차이용 Ridge는 별도로 학습하고 설정도 따로 골랐다.

| 입력 | 구성과 의미 |
| --- | --- |
| MotionBERT 512개 | 기존에 저장한 고정 모델의 요약 특징 |
| 다리 특징 164개 | 골반 중심 기준 좌우 관절 위치, 영상 평면의 무릎 각도, 영상상 다리 길이의 분위수·표준편차 등 |
| 시간 변화 특징 80개 | 프레임 간 변화량·변화량의 변동·변화량이 다시 바뀌는 정도, 좌우 신호의 상관 및 시간차를 둔 상관 |
| 최종 결합 756개 | 위 세 입력을 이어 붙인 것 |

시간 변화는 각 다리의 엉덩이·무릎·발목 x/y와 무릎 각도에서 계산했다. 좌우 관계는 같은 시점 및 -15~+15프레임의 시간차를 비교했다. 실제 FPS를 사용하지 않았으므로 m/s 같은 물리적 속도가 아니다. 상관이 가장 높은 시간차도 검증된 보행 주기나 임상 지표가 아니다. 관절 추출의 흔들림·촬영 조건이 섞일 가능성은 남아 있다.

기존과 같은 **695명·1,064기록, 앞 124프레임**을 사용했다. 외부 5분할은 학습 556명·평가 139명, 내부 4분할은 학습 417명·검증 139명이다. 표준화·학습·설정 선택은 학습 사람 안에서만 했다. Ridge 강도는 0.01·0.1·1·10·100·1,000·10,000, 평균용 PLS 크기는 2·4·8·16·32·64를 비교했다. 평균용은 학습 평균 대조군, 차이용은 차이 0·학습 평균 대조군도 포함했다.

학습은 기록별 동일 가중치, 평가·설정 선택은 사람별 오차를 먼저 평균하는 기존 방식을 유지했다. 기존 평균·차이 모델의 내부 예측은 재사용했다. 이 기준 모델의 설정은 외부 학습 사람으로 선택된 것이며, 각 내부 학습 분할에서 다시 선택한 것은 아니다. 외부 평가 사람은 모든 설정 선택에서 제외했다.

## 1. 평균 점수를 단순히 다시 학습하는 것만으로는 부족했다

아래 후보는 이전 좌우 차이 예측을 고정하고 평균만 바꿨다. 오차는 낮을수록 좋다.

| 평균 점수를 예측하는 입력·모델 | 전체 GDI 오차 | 평균 점수 자체의 오차 |
| --- | ---: | ---: |
| 기존 PLS 평균 유지 — 이전 좌우 보완 | 7.904 | 7.088 |
| MotionBERT + 평균용 Ridge | 8.203 | 7.444 |
| MotionBERT + 평균용 PLS | 7.892 | 7.080 |
| 다리 특징 + Ridge | 8.256 | 7.448 |
| 다리 특징 + PLS | 8.440 | 7.645 |
| MotionBERT·다리 특징 + Ridge | 7.976 | 7.065 |
| MotionBERT·다리 특징 + PLS | 8.048 | 7.128 |

평균 점수 오차가 작아져도 전체 좌우 GDI 오차가 반드시 작아지지는 않았다. 예를 들어 결합 Ridge는 평균 점수 오차가 7.088→7.065점이지만 전체 오차는 커졌다. 같은 사람의 평균 오차와 차이 오차가 어떻게 겹치는지도 영향을 주기 때문이다.

위 여섯 평균 학습 경로의 모든 후보와 기존 평균 유지 중에서, 내부 전체 오차로 선택하는 방법도 비교했다. 네 분할은 결합 Ridge, 한 분할은 기존 평균 유지를 골랐지만 평가 오차는 **8.044점**이었다. 내부 선택이 이번 평가자료에서도 반드시 개선을 보장하지는 않았다.

## 2. 좌우 차이에는 무릎 각도만으로도 비슷한 정보가 있었다

아래는 평균 점수를 기존 PLS로 고정한 비교다. 각 특징 종류마다 Ridge 강도를 내부에서 따로 선택했다.

| 차이 예측에 사용한 특징 | 특징 수 | 좌우 차이 오차 | 전체 GDI 오차 |
| --- | ---: | ---: | ---: |
| 위치만 | 108 | 7.227 | 7.934 |
| 무릎 각도만 | 18 | 7.006 | 7.906 |
| 영상상 다리 길이만 | 36 | 7.229 | 7.940 |
| 다리 특징 전체 — 이전 실험 | 164 | 7.017 | 7.904 |
| 다리 길이 제외 | 128 | 6.996 | 7.901 |
| 다리 특징 + 시간 변화 | 244 | 6.951 | 7.890 |

무릎 각도만으로도 전체 다리 특징과 비슷한 수준이었다. 길이를 빼도 성능이 유지돼 **영상상 다리 길이 정보가 이번 좌우 개선에 필수적이라는 근거는 없었다.** 다만 각도만 사용했을 때의 차이 오차 감소 0.011점, 길이를 제외했을 때의 감소 0.021점은 조건부 95% 구간에 0을 포함한다. 작은 수치 차이를 우열로 확정하지 않는다.

평균 점수를 위치·각도·길이·길이 제외 특징으로 각각 예측했을 때 전체 오차는 8.814·8.786·9.687·8.289점이었다. 어느 한 종류로 평균 점수 문제를 해결하지는 못했다. 특징 수·중복·정규화의 영향도 함께 달라지므로 이 실험은 원인을 분리한 인과 검증이 아니다.

## 3. 시간 변화 특징에서 더 큰 개선이 나타났다

| 방법 | 전체 GDI 오차 | 평균 점수 오차 | 좌우 차이 오차 |
| --- | ---: | ---: | ---: |
| 기존 MotionBERT + PLS | 7.975 | 7.088 | 7.429 |
| 이전 좌우 보완 | 7.904 | 7.088 | 7.017 |
| 다리·시간 변화 → 평균과 차이 | 7.746 | 6.907 | 6.951 |
| **MotionBERT·다리·시간 변화 → 평균과 차이** | **7.619** | **6.715** | **6.963** |

마지막 후보는 이전 좌우 보완보다 전체 오차가 **0.285점, 약 3.6%** 작다. 기존 PLS 대비로는 **0.356점, 약 4.5%** 작다. 이는 오차 감소율이며 GDI 자체의 백분율 오차가 아니다. 평균용 Ridge 강도는 분할 순서대로 100·100·10·100·100, 차이용은 모두 1,000을 선택했다.

시간 변화의 효과를 더 직접적으로 보면, 동일한 이전 차이 예측을 유지하고 **평균용 결합 Ridge에 시간 특징만 추가**했을 때 전체 오차가 7.976→7.628점으로 줄었다. 마지막 차이 예측까지 바꾸면서 7.628→7.619점으로 조금 더 줄었다. 이번 개선의 대부분은 평균 점수 예측 쪽에서 나타났다.

| 비교 | 전체 오차 감소 | 사람 재표집 조건부 95% 구간 |
| --- | ---: | --- |
| 결합 Ridge 평균에 시간 특징 추가 | 0.348점 | [0.167, 0.531] |
| 시간 특징 결합 후보 vs 이전 좌우 보완 | 0.285점 | [0.020, 0.546] |
| 시간 특징 결합 후보 vs 기존 PLS | 0.356점 | [0.089, 0.621] |
| 다리·시간 특징에 MotionBERT도 사용 — 평균·차이 모두 | 0.127점 | [0.010, 0.246] |

표는 저장된 평가 예측에서 사람을 10,000번 복원추출한 탐색적 비교다. 여러 후보를 비교하고 가장 좋아 보이는 결과를 해석하는 과정과 반복적인 개발 실험의 불확실성은 포함하지 않는다. **마지막 후보는 관찰된 유망 후보이며, 독립자료에서 선택·검증을 마친 최종 모델은 아니다.**

이전 좌우 보완 대비 전체 오차는 평가 다섯 분할 모두에서 작았다. 감소량은 0.026·0.485·0.666·0.011·0.239점으로 분할별 차이가 컸다. 학습 사람의 전체 오차는 7.410→6.820점, 평가 사람은 7.904→7.619점이다. 학습과 평가의 차이는 오히려 커졌으므로 과적합 우려가 사라졌다고 볼 수는 없다.

## 점수화와 양끝 편향은 어떻게 달라졌는가

| 지표 | 이전 좌우 보완 | 시간 특징 결합 후보 |
| --- | ---: | ---: |
| 실제 40점대 편향 | +15.310점 | +13.626점 |
| 실제 90점대 편향 | -12.883점 | -11.728점 |
| 실제 100점대 편향 | -20.591점 | -18.933점 |
| 사람별 평균 예측의 표준편차 | 7.561점 | 7.986점 |
| 10점 구간 정확 일치 | 38.75% | 37.20% |
| 두 구간 이상 차이 | 14.98% | 13.45% |
| 좌우 어느 쪽이 높은지 일치 | 56.79% | 56.66% |
| 예측한 좌우 차이의 평균 크기 | 1.740점 | 2.053점 |

40점대 20명, 90점대 149명, 100점대 34명이다. 좌우·기록별 실제 점수대로 집계하므로 사람이 여러 점수대에 포함될 수 있다. 실제 사람별 평균 점수의 표준편차는 11.134점, 실제 좌우 차이 크기는 7.214점이다. **양끝 편향은 일부 줄었지만 점수 압축과 좌우 차이 축소는 여전히 크다.**

큰 구간 오류가 줄면서도 정확한 구간 일치는 낮아졌다. 연속 점수의 오차 개선을 점수화 성능 전반의 개선으로 바꾸어 설명하지 않는다. 이번에는 구간 경계나 점수 정의를 바꾸지 않았다.

## 현재 방향과 GPU 결과 연결

이번 결과로는 **현재 MotionBERT 요약 특징에 시간 변화 정보를 직접 보충하는 방향**의 가능성이 높아 보인다. MotionBERT를 없애야 한다는 결론은 아니다. 다리·시간 특징만 사용한 후보보다 MotionBERT까지 함께 쓴 후보의 전체 오차가 작았기 때문이다. 특정 시간 특징이 어떤 보행 현상을 반영하는지는 아직 검증하지 않았다.

준비된 CNN 기준 실험은 유지한다. GPU 결과가 나오면 같은 695명의 예측으로 기존 PLS·이전 좌우 보완·이번 후보·CNN을 비교하고 싶다. 특히 CNN이 시간 변화에서 얻는 정보와 이번 특징의 정보가 겹치는지, 서로 다른 사람의 오차를 줄이는지 확인할 수 있다. 이번에 CNN 입력을 바꾸거나 결합 학습을 실행한 것은 아니다.

## 실행·검증 근거

핵심 구현은 [run.py](run.py)의 `temporal_features`와 `reconstruct`다. 관절의 시간 변화와 좌우 관계를 계산하고, 학습 사람 안에서 고른 두 예측을 다시 좌우 GDI로 합친다. NumPy·scikit-learn의 기존 CPU 환경을 재사용했으며 새 패키지를 설치하지 않았다. 입력 불일치·사람 중복·비정상 수치는 검사 실패로 중단한다.

- 18개 학습 경로와 기준·결합·선택 결과를 포함해 23가지 출력 조건을 저장했다. 설정은 [protocol.json](protocol.json), 분할별 선택은 [selections.csv](selections.csv)에 있다.
- [verify.py](verify.py)에서 시간 특징 85,120값을 별도 방식으로 계산하고, 선택된 외부 모델 94개·내부 모델 376개를 독립 재학습했다. 최대 예측 차이는 3.37×10⁻¹²였다.
- 후보 비교 735행·성능 지표 506행·부트스트랩 비교 42개를 별도 계산으로 대조했다. 데이터·기존 결과·선언 설정 등 원본 131파일이 유지됐음을 확인했다. [검산 결과](verification.json).
- 추가 설명용 비교는 저장 예측만 사용했다. [descriptive_comparisons.json](descriptive_comparisons.json), [metrics.csv](metrics.csv), [score_bands.csv](score_bands.csv), [train_held.csv](train_held.csv)에 세부 근거가 있다.
- 프로젝트 Python 환경에서 `python -B verify.py`로 재검산하고 `python -B present.py`로 그림을 다시 만들 수 있다. `run.py`는 완료된 결과 덮어쓰기를 막는다.
- GPU 접속·GPU 학습·MotionBERT 재추론은 하지 않았다. 보호된 37/38/223명은 사용하지 않았고 기존 GPU 코드·실험은 변경하지 않았다.

현재까지는 개발자료에서의 개선 신호다. 독립 최종 평가, 원 영상의 좌우 확인, 촬영 조건 변화, 임상적 유효성은 이번 검증 범위가 아니다.
