# 학습·평가 사람의 GDI 오차와 점수 분포 진단

기준: 2026-10-30 13:59 KST

**양끝 점수를 중앙으로 당겨 예측하는 현상은 평가 사람뿐 아니라 이미 학습한 사람에게서도 나타났다. 출력부 추가 학습 후에도 이 양상은 거의 같았다.** 따라서 현재 문제를 “학습한 사람은 잘 맞지만 처음 보는 사람에게만 실패한다”는 설명만으로 보기는 어렵다.

현재 특징·선형 예측·표준화·정규화·자료의 조합에서 어떤 제약이 있는지 더 볼 필요가 있다. 이번 분석은 원인을 확정한 실험이 아니며, MotionBERT가 병목이거나 특정 모델이 쓸모없다는 증거로 확대하지 않는다.

## 1. 무엇을 비교했는가

완료한 5개 fold의 모델을 그대로 사용했다. 각 fold에서 학습 140명과 평가 35명을 나누어 앞·뒤 124프레임의 캐시 특징을 예측했다. 기존 Ridge 계수와 200업데이트를 마친 선형 출력부 체크포인트만 읽었고 새 학습은 하지 않았다.

| 비교 대상 | 무엇을 확인하는가? |
|---|---|
| 학습 사람·앞 | 실제 학습에 사용한 사람과 구간을 얼마나 맞추는가? 진단용 수치다. |
| 학습 사람·뒤 | 사람은 학습에 포함됐지만 학습 입력으로 쓰지 않은 뒤 구간도 맞추는가? |
| 평가 사람·앞/뒤 | 그 모델의 학습에서 제외한 사람에게도 작동하는가? |

한 사람은 5개 모델 중 4개의 학습 집단, 1개의 평가 집단에 들어간다. 어느 한 모델 안에서는 학습·평가 사람이 겹치지 않는다. **700개 학습 사람–모델 조합을 700명의 새 사람으로 세지 않았다.**

오차는 사람 안의 좌우·기록을 평균하고, 그 사람의 4개 학습 모델에서 얻은 오차를 평균한 뒤 175명을 같은 비중으로 집계했다. 평가 쪽은 사람당 1개 모델 결과다. 점수대별 값도 해당 구간에 들어온 값만 같은 방식으로 집계했다. 예측값 4개를 먼저 평균해서 오차를 작게 만든 방식은 아니다.

## 2. 전체 오차와 점수의 퍼짐

점수의 퍼짐은 사람 안에서 기록·양쪽 점수를 평균한 값의 가중 표준편차다. 학습 모델 4개에서 나온 반복 예측은 한 사람이 차지하는 전체 비중이 같도록 나누었다. 예측값 자체를 4개 모델 평균으로 바꾸지는 않았다.

실제 점수의 퍼짐은 두 집단 모두 **11.094점**이다. 여기서는 모집단식(ddof=0)을 사용했다. 이전 보고서의 표본식(ddof=1) 11.126점과 수치가 조금 다르며, 기존 오차·구간 일치율 계산을 바꾼 것은 아니다.

| 모델 | 구간 | 학습 MAE | 평가 MAE | 학습 예측 퍼짐 | 평가 예측 퍼짐 |
|---|---|---:|---:|---:|---:|
| 기존 Ridge | 앞 | 7.600 | 8.276 | 5.865 | 5.865 |
| 기존 Ridge | 뒤 | 8.776 | 9.034 | 5.346 | 5.339 |
| 출력부 추가 학습 | 앞 | 7.596 | 8.282 | 5.862 | 5.861 |
| 출력부 추가 학습 | 뒤 | 8.767 | 9.030 | 5.341 | 5.338 |

기존 Ridge의 앞 오차는 학습 7.600점, 평가 8.276점으로 평가가 약 0.676점 더 크다. 그러나 양쪽의 예측 퍼짐은 모두 약 5.865점으로, 실제 11.094점의 약 0.529배다. **학습한 사람의 점수도 실제 사람 간 차이만큼 넓게 구분하지 못했다.** 퍼짐 비율은 정확도 백분율이 아니다.

실제 기록·좌우 GDI 범위는 39.12~106.64점이다. 기존 Ridge의 학습 사람 앞 예측은 51.28~88.63점, 평가 사람 앞 예측은 51.21~89.74점이다. 학습 여부와 관계없이 극단값을 덜 예측했다.

출력부 추가 학습 모델도 앞 학습 MAE 7.596점, 평가 8.282점이며 퍼짐은 약 5.862/5.861점이다. 이번 200업데이트·한 시드 조건에서는 압축을 해소하지 못했다.

뒤 구간에서는 학습 사람도 오차가 8.776점으로 앞 7.600점보다 컸다. 사람만 새로워지는 문제가 아니라, 학습에 쓰지 않은 같은 영상의 다른 구간에서도 오차가 커질 수 있음을 보여준다. 구간 자체의 별도 임상 정답이나 재촬영 자료로 확인한 결과는 아니다.

![기존 Ridge 실제와 예측](02_ridge_actual_predicted.png)

학습 그림의 점이 많은 이유는 같은 사람이 4개 모델에서 예측됐기 때문이다. 점 개수를 독립 사람 수로 해석하지 않는다.

## 3. 양끝 점수에서 이미 나타나는 편향

아래는 기존 Ridge의 앞 구간이다. 편향은 **예측−실제**이며, 양수는 높게, 음수는 낮게 예측한 것이다.

| 실제 GDI | 고유 사람 | 기록·좌우 값 | 학습 MAE | 평가 MAE | 학습 편향 | 평가 편향 |
|---|---:|---:|---:|---:|---:|---:|
| [30,40) | 1 | 1 | 31.573 | 33.300 | +31.573 | +33.300 |
| [40,50) | 7 | 9 | 18.421 | 20.087 | +18.421 | +20.087 |
| [50,60) | 43 | 60 | 10.379 | 11.685 | +10.076 | +11.316 |
| [60,70) | 79 | 116 | 5.998 | 6.582 | +4.756 | +5.151 |
| [70,80) | 88 | 133 | 4.142 | 4.451 | -2.135 | -2.311 |
| [80,90) | 45 | 56 | 9.506 | 10.202 | -9.485 | -10.111 |
| [90,100) | 20 | 25 | 15.403 | 16.454 | -15.403 | -16.454 |
| [100,110) | 5 | 6 | 22.633 | 22.900 | -22.633 | -22.900 |

- [40,50)는 학습 사람에게도 약 18.42점 높게 예측했다. 평가에서는 약 20.09점 높았다.
- [90,100)는 학습 사람에게도 약 15.40점 낮게, 평가에서는 약 16.45점 낮게 예측했다.
- [100,110)의 오차는 학습 22.63점, 평가 22.90점으로 양쪽 모두 컸다.
- 최저 [30,40)는 1명, 최고 [100,110)는 5명이다. 양끝 표본이 적다는 점을 함께 고려해야 한다.

출력부 추가 학습 후에도 [40,50)의 편향은 학습 +18.487/평가 +20.197점, [90,100)는 −15.397/−16.447점이었다. 뒤 구간에서도 학습·평가 양쪽의 양끝 편향이 유지됐다.

전체 앞 편향이 거의 0이라고 해서 양끝에서 잘 맞는 것은 아니다. 낮은 점수의 과대예측과 높은 점수의 과소예측이 평균에서 상쇄될 수 있다.

구간은 A와 같은 고정 10점 구간이다. 자료를 보고 새 임상 경계나 허용오차를 정하지 않았다. 한 사람의 좌우·기록이 여러 구간에 들어갈 수 있어 구간 인원을 합치면 175가 아닐 수 있다.

## 4. fold를 나누어 보아도 같은가?

기존 Ridge·앞 구간 결과다. 퍼짐 비율은 예측 표준편차/실제 표준편차이며, 각 fold의 사람 집단 안에서 계산했다.

| fold | 학습 MAE | 평가 MAE | 학습 퍼짐 비율 | 평가 퍼짐 비율 |
|---|---:|---:|---:|---:|
| 0 | 7.415 | 8.994 | 0.502 | 0.477 |
| 1 | 7.906 | 7.110 | 0.475 | 0.500 |
| 2 | 7.631 | 7.798 | 0.564 | 0.634 |
| 3 | 7.297 | 9.492 | 0.563 | 0.603 |
| 4 | 7.750 | 7.985 | 0.528 | 0.443 |

5개 fold 모두 학습·평가의 퍼짐 비율이 1보다 작았다. 다만 평가 MAE가 학습 MAE보다 작은 fold도 있다. 전체 평균 차이를 모든 모델에서 동일하게 나타난 악화로 설명하지 않는다. 각 fold의 실제 점수 구성도 다르다.

## 5. 현재 판단과 아직 모르는 것

**확인한 것:** 학습 사람에게도 양끝의 큰 편향이 남고, 학습·평가의 예측 퍼짐이 모두 좁다. 이번 출력부 추가 학습은 그 양상을 거의 바꾸지 못했다.

**가능한 설명:** 현재 특징에 GDI와 관련된 정보가 부족하거나, 선형 예측부가 관계를 충분히 표현하지 못하거나, 정규화 강도·점수대별 자료 구성·정답과 짧은 구간의 대응이 영향을 줄 수 있다. 여러 요인이 함께 작용할 수도 있다.

**구분하지 못한 것:** 어떤 요소가 원인인지, alpha나 학습 예산을 바꾸면 해결되는지, MotionBERT 파인튜닝이 도움이 되는지다. 과적합이 전혀 없다고 하거나 특징 모델을 바꾸면 반드시 해결된다고 말할 수 없다.

1차 보고서의 “학습자료 기록동일 MSE가 4/5 fold에서 조금 증가했다”는 사실도 유지한다. 현재 표는 사람가중 MAE이므로 그 학습 손실과 혼동하지 않는다. 이번에는 새 설정 탐색이나 학습을 진행하지 않았다.

## 6. GPU 결과와 연결할 방법

기존 평가 예측 `(203,2,2)`만 받으면 평가 사람의 오차·점수화는 비교할 수 있지만 학습 사람 진단은 할 수 없다. **각 fold 최종 모델이 학습 140명과 평가 35명 모두를 예측한 결과**가 추가로 필요하다. 학습 중 미니배치 손실과 최종 모델의 전체 학습 사람 오차는 구분한다.

| NPZ 키 | 모양과 순서 |
|---|---|
| predictions | `(5,203,2,2)`: fold 모델 0~4 → 원본 기록 → front/back → left_GDI/right_GDI |
| person_id / video_id / fold | 원본 203기록의 식별자와 평가 fold 배정, 원본 순서 |

메타데이터는 `gdi_fold_model_predictions_v1` 형식으로 자료·예측·기준 지문, 축 순서, 앞 구간 학습 여부, 각 fold의 140/35명 명단과 모델 지문을 담는다. [CPU 메타데이터 예시](cpu_head_only.metadata.json)는 실제로 읽어 같은 집계로 연결되는지 검사했다. GPU 담당은 실제 GPU 산출물과 모델 지문으로 작성해야 한다.

검사기는 모델축·앞뒤·좌우·사람 명단이 맞지 않으면 거부한다. 메타데이터는 선언이므로, 생산 코드·학습 로그와 평가 사람 제외 여부도 조율에서 확인해야 한다. GPU에서 추가 예측을 생성할지는 시간과 자원을 고려해 GPU 담당과 조율한다. 이 CPU 채팅에서 본체를 재추론하지 않는다.

```powershell
# 미래 GPU 파일 경로를 실제 산출물로 바꿔 사용한다. 현재 GPU 결과가 있다는 뜻은 아니다.
& 'C:/Users/jun/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -B -X utf8 'C:/Users/jun/Desktop/D_P/gdi-research-harness/studies/20261030-cpu-head-study/followup/train_eval_diagnostic/diagnose.py' --predictions GPU_FULL_FOLD_PREDICTIONS --metadata GPU_METADATA --name gpu_variant --output 'C:/Users/jun/Desktop/D_P/gdi-research-harness/studies/20261030-cpu-head-study/followup/train_eval_diagnostic/gpu_variant'
```

GPU 결과는 다음 질문으로 이어가려 한다.

| 결과 양상 | 해석할 부분 |
|---|---|
| 학습·평가 MAE와 양끝 편향이 함께 줄어듦 | 현재 제약을 줄일 가능성. 새 사람 효과와 계산 비용도 확인 |
| 학습만 좋아지고 평가는 그대로이거나 악화 | 학습 적합이 새 사람으로 이어지는지 확인 |
| 예측 퍼짐만 넓어지고 오차는 증가 | 점수 폭 확대 자체를 개선으로 보지 않음 |
| 중앙 구간만 좋아지고 양끝 편향은 유지 | 전체 MAE 개선과 점수대 구분을 따로 판단 |

자료·출력부 조건·시드·예산이 달라지면 현재 CPU 대조와의 차이를 밝힌다. 조건을 맞추지 않은 결과를 특징 조정만의 효과로 설명하지 않는다. GPU 특징으로 Ridge를 다시 학습하는 작업은 [기존 입력 계약](../artifact_contract.md)에 따라 자료와 조건을 확인한 뒤 진행할 별도 과제다.

## 7. 검증과 파일

- 기존 Ridge와 출력부 모델의 사람 제외 예측을 재생해 이전 OOF 결과와 대조했다.
- 각 fold 학습 앞 구간의 기록동일 MSE를 1차 검증값과 대조했다.
- 표본별 가중치를 직접 만드는 독립 계산으로 전체 8행·구간 64행을 검산했다. 학습 사람의 4개 모델 중복을 처리했다.
- GPU 메타데이터 오류 6종을 실제로 거부했다.
- 원본 입력과 기존 1차 26개 파일의 지문이 유지됐는지 검사했다. 새 학습·본체 추론·GPU 사용은 0회다.
- 그림 2개를 확인했고 사람·영상 식별자를 공유용 그림과 본문에 넣지 않았다.
