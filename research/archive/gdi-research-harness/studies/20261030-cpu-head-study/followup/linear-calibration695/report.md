# 선형 보정 효과와 원 연구 입력 준비 상태

2026-10-30 · CPU 두 모델의 보정·검산 완료 · CNN 보정은 학습 예측 회수 대기

**현재 CPU 모델에서는 선형 보정으로 뚜렷한 개선을 얻지 못했다. 시간 특징 결합 모델의 가장 작은 오차는 7.619→7.610점이었지만 감소량은 0.009점이고 불확실성 범위에 0이 포함됐다. 보정하지 않은 7.619점 모델을 기존 비교 기준으로 유지하고 싶다.**

원 논문의 ‘CNN 예측 평균 뒤 선형 보정’이 우리 점수 압축에도 도움이 되는지 확인하고 싶었다. AI가 기존 모델의 저장 예측을 사용해 CPU에서 보정식을 학습하고 별도로 검산했다. 원 CNN 전체 처리 과정이나 논문의 6.5점 결과를 재현한 실험은 아니다.

## 무엇을 비교했는가

보정은 `보정 점수 = a × 기존 예측 + b`다. 왼쪽·오른쪽 기록을 함께 사용해 하나의 기울기 a와 이동값 b를 구했다. 임의로 범위를 늘리거나 0~100으로 자르지 않았다.

| 방식 | 보정식을 만드는 자료 |
| --- | --- |
| 보정 없음 | 기존 결과 그대로 |
| 학습 예측 보정 | 해당 외부 모델이 학습한 556명에 대한 예측과 정답 |
| 내부 검증 예측 보정 | 같은 556명 안에서, 각 사람이 해당 내부 모델 학습에서 빠졌을 때의 예측과 정답 |

같은 695명·1,064기록의 외부 5분할을 유지했다. 각 평가 139명은 보정식 학습·선택에 사용하지 않았다. 두 방식을 사전에 정해 모두 보고했으며 평가 결과로 보정 방식을 자동 채택하지 않았다. 모델 자체의 학습 설정·epoch는 다시 선택하지 않았다.

보정식은 기록·좌우 값에 동일 비중을 둔 최소제곱법으로 학습하고, 평가는 기존처럼 사람별 오차를 먼저 평균했다. 내부 예측의 모델 설정은 외부 학습 집단 전체의 내부 검증으로 이미 선택돼 있어 완전히 새로운 보정 전용 자료는 아니다. 바깥 평가 사람의 정답이 보정에 들어간 것은 아니다.

## 평가 결과

| 모델 | 보정 없음 | 학습 예측 보정 | 내부 검증 예측 보정 |
| --- | ---: | ---: | ---: |
| MotionBERT + PLS | 7.975 | 7.975 | 8.029 |
| MotionBERT·다리·시간 특징 결합 | 7.619 | 7.651 | 7.610 |
| 기준 CNN | 8.683 | **미실행** | **미실행** |

값은 사람별 평균절대오차(MAE)이며 낮을수록 좋다. PLS의 학습 예측 보정은 모든 분할에서 a≈1, b≈0이어서 수치 정밀도 범위에서 원래 결과와 같았다.

시간 특징 모델의 학습 예측 보정은 a=1.041~1.090으로 범위를 넓혔지만 전체 오차가 커졌다. 내부 검증 예측 보정은 a=0.868~0.948로 오히려 범위를 줄였다. 후자의 오차 감소 0.009점에 대한 조건부 95% 구간은 **[-0.030, 0.049]점**이다. 사람을 10,000번 복원추출한 탐색적 결과이며, 개발 과정의 반복 선택 불확실성은 포함하지 않는다.

## 점수 압축을 단순 확대해서 해결할 수 있었는가

시간 특징 결합 모델을 비교하면 다음과 같다.

| 지표 | 보정 없음 | 학습 예측 보정 | 내부 검증 예측 보정 |
| --- | ---: | ---: | ---: |
| 사람별 평균 예측의 표준편차 | 7.986 | 8.613 | 7.360 |
| 실제 40점대 편향 | +13.626 | +12.488 | +14.722 |
| 실제 90점대 편향 | -11.728 | -11.183 | -12.305 |
| 10점 구간 정확 일치 | 37.20% | 36.82% | 37.02% |
| 두 구간 이상 오류 | 13.45% | 13.87% | 13.28% |

범위를 넓히면 양끝 편향이 줄어드는 대신 전체 오차가 커졌다. 범위를 줄이면 전체 오차가 아주 조금 작아졌지만 양끝 편향은 커졌다. **현재 모델의 정보 부족을 단일 직선 보정만으로 해결하지는 못했다.** 원 논문의 낮은 오차가 선형 보정 하나 때문이라는 근거도 얻지 못했다. CNN에서의 보정 효과는 아직 모른다.

## CNN은 왜 아직 보정하지 않았는가

회수본의 각 분할 `predictions.npz`에는 평가 사람의 예측만 있다. 학습 사람의 예측과 모델 가중치는 로컬 회수본에 없다. 평가 정답으로 보정식을 맞추면 같은 자료에서 결과가 좋아 보일 수 있어 시행하지 않았다. 다른 바깥 분할의 평가 예측도 현재 평가 사람을 학습한 모델에서 나왔을 수 있으므로 보정용으로 대신 쓰지 않았다.

[학습 예측 추출 도구](export_cnn_train_predictions.py)와 [실행 안내](CNN_EXPORT.md)를 준비했다. 원 서버의 완료된 `fold*/refit/latest.pt`에서 추론만 하므로 새 학습이 필요하지 않고 CPU로도 실행할 수 있다. 체크포인트 지문·학습 사람·epoch·정답 변환 및 기존 평가 예측 재현을 검사한 뒤 학습 예측을 저장한다.

로컬에서는 Python 3.8 문법·도움말·가중치 부재 시 출력 생성 전 거부를 확인했다. 첫 문법 검사에서 추출 도구의 닫는 괄호 누락을 발견해 수정 후 다시 통과했다. 실제 가중치 추론은 아직 실행하지 못했다. 내부 모델의 선택 epoch 예측은 별도 회수가 필요하며, 최대 epoch의 가중치로 자동 대체하지 않는다.

## 원 연구 입력과 여러 구간 준비 상태

GPU 담당 폴더에서 준비된 자료를 읽기만 하며 확인했다. 이 채팅에서 입력을 새로 생성하거나 GPU 작업을 변경하지 않았다.

- 원 연구의 한쪽 다리 12개 시계열은 **692명·1,061기록**, 입력 모양 `기록 × 좌우 2 × 시간 124 × 특징 12`로 준비돼 있다.
- 기존 695명 중 3명이 제외됐다. 기록상 원 변환기의 프레임 범위 밖 1기록, 필요한 좌표의 결측 25% 초과 2기록이다. 사람·영상·정답·기존 분할을 원 자료와 대조했다.
- 준비 기록에는 유지된 자료에서 사용 가능한 여러 구간 시작점 **11,257개**가 있다. 해당 시작점이 없는 기록도 4개다. 현재 확인한 주 입력은 기록당 한 구간이며, 시작점 목록을 확인한 것을 여러 구간 학습 완료로 표현하지 않는다.
- 준비된 1,061개 개별 입력의 지문·주 입력 배열과의 일치·124개 연속 프레임을 검사했다. 원 전처리 전체를 이 채팅에서 독립 재구현한 검증은 아니다.
- 다음 원 입력 CNN과 기존 모델을 엄밀하게 비교하려면 공통 사용 인원뿐 아니라 학습에 포함되는 사람도 맞춰야 한다. 기존 695명 결과와 새 692명 결과를 그대로 우열 비교하지 않는다.

이 확인 시점의 상태는 [입력 준비 스냅샷](input_readiness_snapshot.json)에 보존했다. 다른 채팅의 이후 작업 상태는 별도 확인이 필요하다.

## 검증과 다음 단계

[run.py](run.py)는 기존 예측에서 학습 사람만 골라 보정식을 구하고 같은 평가 사람에게 적용한다. [verify.py](verify.py)는 scikit-learn의 별도 회귀 구현으로 보정 20개를 재학습하고 지표 144행·부트스트랩 비교 4개를 검산했다. 최대 예측 차이는 8.53×10⁻¹⁴, 기존 파일 180개의 지문은 그대로다. [검산 결과](verification.json).

세부 결과는 [metrics.csv](metrics.csv), [coefficients.csv](coefficients.csv), [score_bands.csv](score_bands.csv)에 있다. 프로젝트 Python 환경에서 `python -B verify.py`로 재검산할 수 있다. 보호된 37/38/223명 자료와 GPU는 사용하지 않았다.

다음은 CNN 학습 예측을 회수해 동일한 학습 예측 보정을 확인하고, 준비 중인 12개 입력·좌우별 학습과 여러 구간의 효과를 비교하는 단계다. CPU 보정에서는 뚜렷한 이득이 없었으므로 추가 보정식 탐색을 넓히기보다 입력·시간 범위 차이를 확인하는 쪽에 우선순위를 두고 싶다.
