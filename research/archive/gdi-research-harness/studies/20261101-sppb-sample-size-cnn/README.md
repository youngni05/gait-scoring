# 사람 수별 성능 곡선과 작은 CNN 비교

현재 상태: 본 비교33606·33607의1,800개 CNN 학습·450개 최종 모델을 D에 회수·검산했고,RF1,050개 학습·150개 최종 모델의 저장 재추론·지문 검산과 최종 분석까지 완료했다. [결과](analysis/RESULTS.md)·[곡선 그림](analysis/learning-curves.png)을 확인한다. 이전 원본 결과는 유지한다.

질문은 학습 사람을 늘리거나 CNN을 줄이면 실제 SPPB 예측의 오차·불안정성이 줄어드는가이다. RF와 CNN32·16·8을 같은 입력·사람별5분할에서 비교한다. 최종 학습 사람 수는8·16·24명·전체35–36명이다. 각 학습 집단 내부3분할로만 epoch와 RF leaf를 선택한다. 앞서23–24명은 전체 조건의 내부 검증 사람을 제외한 실제 학습 인원이다.

작은 집단은3회 다르게 뽑고,8→16→24명이 포함 관계를 갖도록 한다. 점수대 비율은 해당 바깥 학습 집단에 가깝게 유지한다. 평가 사람의 점수로 표본이나 설정을 고르지 않는다. 초기값3개의 평균 예측을 사람 추출별로 평가하고, 추출별 MAE의 평균·변동을 보고한다. 추출3회를 합쳐 더 큰 앙상블로 만드는 방식은 주 지표에 쓰지 않는다.

CNN은 채널 수만 바꾸며 BN·손실·학습률·입력은 이전 수정본과 같다. RF는 같은 좌표의 시간 요약36개를 사용한다. 입력에 속도·나이·3D 등 추가 정보는 없다. 같은 사람의5회 보행은 묶어서 이동한다. 정규화·BN 통계는 매번 실제 학습 사람만으로 계산한다.

전체 조건CNN32와 RF는 이전 전체 자료 결과와 연결해 재현성을 확인한다. 새 사람을 확보한 실험이 아니며44명의 개발 자료를 반복해서 본 탐색이다. 수백 명에서의 개선이나 실제 RGB·임상 성능을 보장하지 않는다. 낮은 점수대와 높은 점수대의 오차·초기값 변동도 함께 보고한다.

코드·설정·표·검산 요약은 이 C 폴더에, 입력·모델·로그·회수 원본·캐시는 D:/gait-research-data/D_P/sppb-sample-size-cnn-20261101에 둔다. 예상 누적 대용량 자료는 수GB 이내이다. 서버는 /abr/RESEARCH_USER/sppb-sample-size-cnn-20261101의 새 폴더를 사용한다. 기존 환경을 재사용한다. 서버에 sklearn이 없어 RF는 이 PC의 기존 sklearn에서 실행하고 저장 모델을 재추론한다. RF 작업 번호·로그·완료 근거는 control/rf-job.json과 D/rf/progress.json에 기록한다.

GPU1개 worker 두 개가 fold0·1·2와3·4를 나눈다. 실제 CUDA 파일럿과 독립 CPU BN·예측 검산 후 본 학습을 제출한다. 담당 채팅은01a1929b-43f3-7bc1-b921-b17bc551d7fe이다. 기존 공유 전용 등록부 ../20261101-healthgait-transfer/watch/registry.json에 실제 제출만 lc- 접두사로 추가한다. 감시 예약은 control/campaign.json의 실제 automation_id를 따른다. 다른 채팅과 GPU 확보32844는 변경하지 않는다.

1시간마다 등록부·예약 소유권을 대조하고 공통 snapshot.py에 --registry 전용 절대경로 --owner-thread 실제ID를 붙인다. manage.py status와 rf-status로 GPU와 RF를 함께 확인한다. preparing은 중복 준비하지 않는다. 파일럿 완료 시 pilot-review 후 submit --stage train --round 0, RF 미시작이면 rf-start로 진행한다. 본 학습 완료 후 retrieve --round 0으로 D에 회수·검산한다. RF도 모든 저장 모델을 재추론한 뒤 analyze.py로 곡선·비교표·한계를 기록한다. 완료·검산·보고가 끝나기 전에는 예약을 종료하지 않는다. 추가 GPU 최적화는 이번 범위에 없다.

RF의 추출별3seed평균예측 MAE를 추출 간 평균한 선행 결과는 학습8명1.2316점·16명1.1895점·24명1.1365점·전체1.0357점이다. 전체RF는 이전 검산 예측과 최대1.8e-15 차이로 재현됐다. 작은 집단의 추출에 따라 결과가 달라지므로 한 번의 추출을 전체 성능으로 보고하지 않는다. CNN의 크기별 최종 비교도 완료했다. 전체 MAE는CNN32 1.0814점·CNN16 1.2461점·CNN8 1.3045점이었다. 이번 비교는 모두 처음부터 학습하며 별도 사전학습 단계를 포함하지 않는다.
