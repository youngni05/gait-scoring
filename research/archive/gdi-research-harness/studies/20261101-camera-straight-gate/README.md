# 영상만으로 회전 구간을 걸러내는 조건 점검

직선 보행에서는 걸음 빈도 대용값의 차이가 작아져, 실제 영상만으로 직선 조건을 가려낼 수 있는지 확인했다. 같은 14명의 직선·회전 2초 영상과 두 카메라를 유지했다. 영상에서 복원한 어깨·골반 좌우 벡터의 방향 변화가 30도 이내이고 관절 가시성이 0.5 이상이면 통과시킨다. 별도 학습이나 결과에 따른 문턱 조정은 없다.

차이의 단위는 걸음/분이며 광학 발뒤꿈치 사건 대용값과의 차이다. 전문가 발접촉 정답에 대한 정확도가 아니다. 통과한 사람만의 차이가 작아져도 전체 성능 개선으로 해석하지 않는다. 통과하지 못한 영상은 측정 불가이며 낮은 기능 점수가 아니다.

방향 변화는 영상 모델이 복원한 좌표에서 계산한 값이다. 실제 몸의 회전 각도로 검증되지 않았고 깊이 흔들림으로 직선 영상을 거부할 수 있다. 같은 14명의 개발 진단으로 일반 휴대폰·다른 질환·새 사람의 성능을 입증하지 않는다. 기존 SPPB/TUG 모델·사람·구간·초기값 5개는 그대로 유지했다.
