# 기존 GDI 모델의 특수 사례 비교

같은 222명·377기록에서 기존 학습 모델 94개로 구성한 17개 예측 방식을 비교했다. 새 학습이나 보정계수 조정은 하지 않았다. 이미 결과를 본 표본을 다시 분석한 **사후 진단**이다. 새로운 미사용 최종 시험이나 임상 검증이 아니다.

## 확인된 차이

기존 결합 모델(Fusion)·RankSim 추가·HuberRank 추가·MAERank 추가는 전체 MAE가 약 6.22~6.25점으로 가깝다. MAERank 추가의 점 추정치가 가장 낮지만, 기존 RankSim 추가 대비 차이의 설명용 95% 구간이 0을 포함하므로 우수성을 확정하지 않는다. 고득점 과소예측도 남아 있다.

|고정 비교|전체 MAE 차이(앞−뒤)|설명용 95% 구간|
|---|---:|---|
|Fusion + RankSim − Fusion|-0.0215|[-0.0597, 0.0171]|
|Fusion + HuberRank − Fusion + RankSim|0.0025|[-0.0325, 0.0387]|
|Fusion + MAERank − Fusion + RankSim|-0.0045|[-0.0400, 0.0303]|

RankSim 추가의 고득점 26명 편향은 -8.3636점이다. MAERank 추가는 -8.3703점으로, 전체 MAE의 작은 감소가 과소예측 해결로 이어지지는 않았다. 100 이상·50 미만은 각각 4명뿐이므로 세부 차이의 일반화에 특히 주의해야 한다.

RankSim 추가는 같은 영상 내 구간 SD가 2.5376점, 구간 최대−최소 범위가 7.5666점이다. 3구간 이상인 375기록·222명에서 계산했다. 구간이 서로 겹치므로 독립 표본이나 재촬영 오차로 간주하지 않는다.

다른 검사 기록이 있는 97명·243쌍에서 RankSim 추가의 실제 변화 대비 예측 변화 오차는 7.7121점이다. 실제 변화가 5점 이상인 좌우 관측의 변화 방향 일치는 사람 균등 평균 74.12%다. 이는 재촬영 정밀도나 변화 탐지의 임상 기준이 아니다.

좌우 실제 차이가 10점 이상인 87명·105기록에서 좌우 차이 자체의 예측 오차는 Fusion 11.2124, RankSim 추가 11.2491, MAERank 추가 11.1093점이다. 전체 MAE가 낮아도 비대칭의 크기를 정확히 복원했다고 볼 수 없다.

오차(MAE)는 낮을수록 정답에 가깝다. 편향은 예측−정답이며 음수이면 과소예측이다. 사람별로 기록과 좌우를 먼저 평균해, 기록이 많은 사람의 영향이 커지지 않게 했다.

관측 점수 자체가 90·100 이상인 좌우 관측만 따로 집계한 결과는 results.json의 observation_groups에 있다. 사람 평균 기준과 표본 수가 다르다.

영상 안 구간 SD는 같은 영상에서 124프레임씩 위치를 바꿨을 때 점수의 표준편차다. 3구간 이상인 기록으로 계산했다. 값이 작아도 정확도가 좋다는 뜻은 아니다. 항상 비슷한 오답을 내는 모델도 안정적으로 보일 수 있다.

다른 기록 변화 오차는 동일인의 모든 기록 쌍에서 (예측 변화−실제 변화)의 절댓값을 계산한 것이다. 검사 사이에 실제 보행이 달라질 수 있으므로 재촬영 반복정밀도나 ICC로 해석하지 않는다. 날짜 순서를 가정하지 않았다.

## 확인 범위와 파일

- 좌우 실제 차이가 5·10 이상인 기록의 예측 차이 오차, 고득점 100 이상, 저득점 50 미만, 초기·중간·마지막 구간, 다른 기록 변화 방향은 results.json에 고정 기준 그대로 포함했다. 해당 인원이 없으면 빈 집단으로 기록했다.
- 불확실성 구간은 사람 단위 10,000회 재추출(seed 20261105)로 계산했다. 여러 사후 비교 중 우수한 결과만 골라 새 최선 모델로 승격하지 않는다.
- 기존 7개 방식의 모든 최종 예측을 0.0001점 이내로 재현했고, 94개 모델의 기존 예측 대조·학습/평가 사람 분리·입력 연결·원본 파일 지문과 독립 계산을 확인했다. 검산 근거는 verification.json이다.
- 대량 구간 예측과 개별 모델 기록: D:/gait-research-data/D_P/gdi-case-audit-20261105. 원래 결과는 변경하지 않았다.
- 전체·고득점 표: model-comparison.csv, 길이별 표: shorter-input.csv, 기계 판독 전체 결과: results.json.
