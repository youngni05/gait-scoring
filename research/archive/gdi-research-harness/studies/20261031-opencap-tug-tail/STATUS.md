# 긴 TUG 과소예측: 원인 점검과 속도 요약 모델 개선 실험

2026-10-31 완료·검산. 같은 298명·3초 보행·사람 분할을 유지했다. **긴 TUG 사례의 학습 가중치를 높이면 평균 오차는 조금 줄었지만, 다른 사람들의 오차가 커졌다. 이번 방법 중 전체 성능을 유지하면서 긴 TUG의 큰 과소예측을 해결한 방법은 없었다.**

이번 기준인 속도 요약 RF는 전체 평균 절대오차 2.058초, TUG 20초 이상인 9명에서는 13.477초였다. 모두 같은 개발 자료를 반복 사용한 탐색 실험이며, 9명이 반복 평가됐다고 독립 표본이 늘어난 것은 아니다. 20초 구분은 이번 분석용 기준이며 임상 위험 판정 기준이 아니다.

## 확인한 과소예측 과정

**1. 긴 TUG 사례가 적고, 비슷한 속도 입력의 학습 사람들은 대체로 TUG가 짧았다.**

전체 298명 중 TUG 20초 이상은 9명이다. 각 바깥 학습 집단에는 5~9명이 있었고, 내부 학습 집단 75개 중 1개에는 한 명도 없었다. 긴 사례마다 학습 사람 중 속도 특징이 가까운 5명을 찾으면, 그중 긴 TUG 사람은 평균 0.27명이었다. 가까움은 학습 사람으로 표준화한 세 속도 특징의 거리로 계산했으며 임상적 유사성을 뜻하지 않는다.

기존 RF의 예측을 학습 사람들의 TUG에 부여한 가중 평균으로 정확히 다시 계산했다. 긴 TUG를 예측할 때 긴 학습 사례의 가중치 합은 평균 8.9%, 중앙값 5.7%였다. 즉 대부분은 짧은 TUG 값들의 영향을 받았다. 재구성한 값과 저장 예측의 최대 차이는 약 1.2×10⁻¹⁴초이다. 이는 모델의 계산 구조를 확인한 것이며, 사람의 임상 상태가 왜 다른지 밝혔다는 뜻은 아니다.

**2. RF가 낼 수 있는 값의 범위도 제한된다.**

RF는 학습 정답의 가중 평균을 내므로 학습에서 본 최대 TUG를 넘지 못한다. 가장 긴 실제 42.59초 사례를 평가할 때 학습 집단의 최대값은 분할에 따라 25.14~28.03초였다. 다만 범위 제한만으로 불가피한 과소예측의 하한을 모든 긴 사례에서 평균하면 1.746초이다. 실제 13.477초 오차 전체를 이 제한 하나로 설명할 수는 없다.

**3. 가장 큰 오차 사례에는 속도 추정의 급격한 변화도 있었다.**

실제 TUG 42.59초 사례에서 기준 예측은 평균 6.30초였다. 선택한 3초 구간의 골반 수평 속도는 평균 1.90m/s, 중앙값 0.72m/s, 최댓값 12.97m/s였다. 저장 좌표가 약 1/30초 사이에 0.87m 변하는 부분이 있었다. 원본 시점의 최대 간격은 약 0.0167초라, 큰 시간 공백을 단순히 미분한 결과로 설명되지는 않았다.

이는 좌표의 급격한 변화가 속도 평균을 부풀렸을 가능성을 보여준다. 원본 RGB 영상이나 수작업 관절 정답으로 추적 오류를 확정한 것은 아니다. 원본 파일 지문과 사람·방문·TUG 연결은 다시 확인했지만 원래 임상 검사 측정 자체의 정확도까지 검증하지는 않았다.

이 사례의 평균 대신 중앙값 등을 사용해도 예측은 7.59초에 그쳤고, 극단값에 덜 민감한 요약과 가중치 10을 함께 사용해도 8.57초였다. 따라서 속도의 급변만 없애면 긴 TUG 문제가 해결된다고 볼 수 없다.

**4. 입력이 담지 않는 검사 동작도 있다.**

TUG는 의자에서 일어나 걷고, 돌아서 다시 와 앉기까지의 시간을 잰다. 이번 입력은 별도의 보행 검사에서 선택한 짧은 구간이라 이 모든 동작을 직접 측정하지 않는다. 따라서 보행 속도가 비슷해도 실제 TUG가 달라질 수 있다는 설명은 가능하다. 다만 각 사람의 과소예측이 일어서기·회전 중 어느 단계 때문인지는 이번 자료 분석으로 확인하지 못했다. [CDC TUG 검사 절차](https://www.cdc.gov/steadi/media/pdfs/STEADI-Assessment-TUG-508.pdf)

## 같은 사람 분리에서 무엇을 바꿨는가

기존 사람 분할 5가지, 각 분할의 바깥 평가 5묶음·내부 평가 3묶음, RF 학습 난수 3개를 그대로 사용했다. RF 조건은 각각 15회, 난수에 영향받지 않는 역속도 Ridge는 분할별 5회이다. 모든 방법이 같은 298명 전체를 예측한다. 큰 오차 사람을 빼거나 실제 TUG를 알고 평가 때 다른 모델로 바꾸지 않았다.

| 변경 | 실제 처리 | 확인하려는 것 |
|---|---|---|
| 균형 선택 | 학습 집단 내부의 `<10`, `10~20 미만`, `20 이상` 각 구간 MAE를 동일 비중으로 평균해 설정 선택 | 많은 짧은 사례 때문에 설정 선택이 긴 사례를 덜 반영하는가 |
| 극단값에 덜 민감한 요약 | 같은 속도 시계열의 중앙값·사분위 범위·인접 변화량 중앙값 사용 | 급격한 좌표 변화의 영향을 줄이면 나아지는가 |
| 긴 사례 가중치 증가 | 학습 사람 중 TUG≥20인 사람의 `sample_weight`를 10, 나머지는 1로 설정 | 긴 학습 사례를 더 반영하면 과소예측이 줄어드는가 |
| 역속도 회귀 | `1/max(평균속도,0.1)`, 속도 표준편차/속도, 속도 변화량/속도로 Ridge 학습 | 학습 TUG 범위 밖으로도 값을 낼 수 있는 형태가 도움이 되는가 |
| 가중치 3 추가 | 첫 결과 확인 뒤 가중치 10의 부작용을 줄이려고 3을 시험 | 개선과 악화 사이의 중간 조건이 있는가 |

가중치는 학습 정답에만 적용한다. 평가할 사람의 TUG·진단·나이·다른 임상 검사 결과를 예측 입력에 넣지 않는다. RF의 나무 수 128, 잎 최소 인원 후보 2/5를 유지했다. 정규화는 학습 사람만 사용하고, 설정은 내부 평가에서만 선택했다. 역속도 Ridge의 alpha 후보는 0.1/1/10/100이며 예측 하한만 0으로 두고 상한을 두지 않았다.

첫 8개 조건은 `protocol.json`을 고정한 뒤 실행했다. 가중치 3의 두 조건은 첫 결과 이후 정한 추가 탐색이며 `followup-protocol.json`으로 구분했다. 처음 결과는 `primary-summary.json`에 보존했다. 결과를 보고 좋은 난수나 좋은 사람만 고르지 않았다.

## 결과

평균 절대오차이며 단위는 초이다. 전체 298명, 짧은 TUG 240명, 긴 TUG 9명이다. 나머지 49명의 TUG는 10~20초 미만이다.

| 방법 | 전체 | 10초 미만 | 20초 이상 |
|---|---:|---:|---:|
| 속도 요약 RF 기준 | 2.058 | 1.549 | 13.477 |
| 설정 선택만 균형화 | 2.070 | 1.557 | 13.482 |
| 중앙값·사분위 범위 RF | 2.055 | 1.515 | 13.571 |
| 중앙값 요약 + 균형 선택 | 2.086 | 1.520 | 13.608 |
| 가중치 10 RF | 2.645 | 2.058 | 12.412 |
| 중앙값 요약 + 가중치 10 | 2.502 | 1.851 | 12.590 |
| 역속도 Ridge | 2.714 | 1.839 | 16.934 |
| 역속도 Ridge + 균형 선택 | 2.717 | 1.841 | 16.952 |
| 추가 탐색: 가중치 3 RF | 2.285 | 1.759 | 13.084 |
| 추가 탐색: 중앙값 요약 + 가중치 3 | 2.341 | 1.760 | 13.082 |

가중치 10 RF는 긴 집단의 평균 오차를 1.064초 줄였고 15회 모두 그 방향이었다. 하지만 사람별로 보면 9명 중 5명만 개선되고 4명은 악화됐다. 전체 오차는 0.586초, 10초 미만 집단은 0.509초 증가했다. 긴 사례가 여전히 대부분 과소예측되고 있어, 길게 예측하기만 하면 문제가 해결되는 상황은 아니다.

가중치 3 RF는 긴 집단 오차가 평균 0.393초 줄고 전체 오차는 0.227초 증가했다. 15회 중 14회 긴 집단 평균이 나아졌고, 9명 중 7명이 개선됐다. 다만 사람별 오차 차이의 조건부 95% 구간은 -1.020~0.050초로 0을 포함했다. 가중치 10의 같은 구간은 -2.256~-0.114초였다. 이 구간은 9명의 반복 평균 오차를 짝지어 재추출한 것이며 재학습·설정 선택·새 사람 모집에 따른 불확실성을 모두 포함하지 않는다.

단순한 선택 기준 변경, 중앙값 요약, 역속도 회귀에서는 긴 집단의 평균 오차가 줄지 않았다. 특히 역속도 회귀는 학습 범위 밖으로 예측할 수 있다는 성질만으로 성능이 개선되지 않음을 보여준다. 이번 결과는 이 구체적인 입력 변환·회귀 설정에 대한 결과이며 모든 외삽 모델을 부정하지 않는다.

## 검산·산출물·한계

새 모델 575개와 기존 기준 모델 75개, 총 650개를 재추론했다. 예측 재현 최대 차이는 약 7.1×10⁻¹⁵초였다. 사람 분리·기존 입력과 분할의 지문·학습 집단 정규화·실제 학습 가중치·내부 설정 선택·모든 사람의 평가 포함을 확인했다. 중앙값·사분위 범위 입력도 정렬된 값에서 별도로 재구성했다. `verify_analysis.py`에서 지표·편향·사람별 오차·조건부 구간·원인 분석 집계를 다시 계산해 통과했다.

핵심 코드 경로는 `train.py`의 `fit`이다. 같은 사람 분할에서 속도 표현과 학습 사람의 가중치만 바꾸고, 평가 사람의 정답은 학습에 사용하지 않는다. `causes.py`는 기준 RF가 어느 학습 사람의 TUG를 얼마나 섞어 예측했는지 재구성한다. 이 계산과 임상적 원인 추정은 구분한다.

- 조건·실행: `protocol.json`, `followup-protocol.json`, `completion.json`, `followup-completion.json`
- 원인 근거: `cause-summary.json`, `baseline-tail-mechanisms.csv`, `long-people-audit.json`, `forest-training-label-weights.json`
- 결과: `summary.json`, `run-metrics.csv`, `person-results.csv`, `long-person-comparison.csv`
- 검산: `verification.json`, `analysis-verification.json`

기존 Python·NumPy·scikit-learn 환경을 재사용했고 새 패키지 설치나 외부 자료 전송 없이 로컬 CPU에서 실행했다. 본 비교 학습은 약 3분 47초, 추가 가중치 비교는 약 2분 33초였다. 원자료와 중복·방문 연결의 배경은 [이전 속도 안정성 실험](../20261030-opencap415-speed-stability/STATUS.md)에 있다.

현재 결과는 이미 검토한 개발 자료의 오류 원인과 개선 가능성을 살펴본 것이다. 새 독립 집단의 검증, 원본 영상의 좌표 오류 확인, TUG 동작 단계별 실제 시간 분석은 하지 않았다. 여러 RGB 카메라로 이미 복원된 시계열을 사용했으며 단일 카메라의 3초 영상만으로 전 과정을 검증한 결과가 아니다.
