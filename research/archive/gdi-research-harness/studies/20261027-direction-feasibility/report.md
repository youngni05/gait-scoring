# 공개 자료로 가능한 실험과 최소 제출물

**추천은 A를 제출 기반으로 확보하고, C의 작은 기능 점수 탐색을 후속 후보로 두는 것이다. B도 실험 가능한 정답이 있지만 입력 변환과 적은 중증 표본을 먼저 해결해야 한다.** 이번에는 보유 파일을 직접 읽어 사람·입력·정답·누락·점수 분포를 확인했다. 새 학습·새 분할·임상 경계 선택은 하지 않았다. 추천은 주 방향 확정이나 팀 합의가 아니다.

## 실제 보유 자료 확인

| 방향 | 파일 내부에서 확인한 것 | 현재 가능한 것 | 추가로 필요한 것 |
|---|---|---|---|
| A GDI | 기존175명 학습 모델·검증37명, 새 개발520명·861건 고정 모델 결과. 새 개발 사람별 오차9.27, 평균 기준10.62 | 기존 입력에서 비교 모델·특징 실험, 실제 추론을 연결한 연구용 화면 | 평균보다 강한 기준 모델과 비교, 앱 좌표 입력 차이 검증 |
| B 임상 등급 | CARE-PD 3DGait 43명·90구간. 전 구간에0~3 정답·SMPL 움직임이 있고 점수 누락0 | 소규모 순서 등급 예측 가능성 검사 | SMPL 입력 처리 또는 제공 관절 형식 확보, 사람별 평가 계획 |
| C 고령자 기능 | 44명·220회 보행변수와44명 SPPB 연결. POMA-G 유효39명,5명 평가 누락 | 측정된 보행변수로 기능 점수 예측 신호 탐색 | 영상 추정값으로의 전환 검증. 현재 로컬 동작 좌표는1회 샘플,RGB0개 |

B의0/1/2/3점 구간 수는24/42/14/10이다. 해당 점수가 등장하는 사람 수는16/26/12/5명이다. 16명은 기록마다 다른 점수가 있어 이 인원들을 더하면 전체 인원을 초과한다. 모든 기록은 사람 단위로 묶어 평가해야 한다. SMPL은 관절의 회전 등을 나타내는 자료이며 현재 앱의 영상 관절 좌표와 같은 입력이 아니다. 배열 값의 유한성은 확인했지만 관절 복원·모델 입력 변환은 실행하지 않았다.

C의 SPPB는5~12점이며44명 중28명이10~12점이다. POMA-G 전문가 첫 평가39명은8~12점이고20명이10점이다. 현재 자료로 전체 능력 범위의10단계를 구분한다고 주장하기 어렵다. 보행변수220개 기록은44명의5회 반복이며220명의 정답이 아니다.

POMA-G의 같은 전문가1·2주차 총점은39명 중16명이 정확히 같고 평균 절대 차이는0.744점이다. 같은1주차 전문가·초보 평가자는12명이 정확히 같고 평균 차이는0.923점이다. 이는 이 표의 총점에 대한 기술 통계다. 모델의 최소 오차, 임상적으로 의미 있는 변화량, 공식 신뢰도 계수로 해석하지 않는다. 두 평가자의4회 평가는 사람 수를156명으로 늘려주지 않는다.

Toronto 평가표14명은 POMA-G10점1명·11점2명·12점11명이다. 심한 보행 어려움까지 나누는 주 학습 자료로는 적합성이 낮다. 영상·입력 연결 실험의 보조 후보로는 남길 수 있다. 이번에는 Toronto 좌표와 개인별 점수의 연결을 완결하지 않았다.

## 가능성을 가를 실험

### 우선 실험 A 단순한 움직임 특징보다 현재 모델이 나은가

목적은 평균을 넘는 실제 비교 기준을 만드는 것이다. 같은 좌표에서 계산한 리듬·좌우 차이·관절 움직임 범위 등 소수의 설명 가능한 특징으로 예측하는 모델과 현재 고정 MotionBERT 특징+Ridge를 비교한다. 현재 입력에서 계산할 수 없는 실제 거리·속도는 만들어내지 않는다. 필요하면 두 종류 특징 결합은 별도의 세 번째 후보로 사전에 고정한다.

제안 조건: 기존175명 학습·37명 설정 선택을 유지하고, 새520명에서는 설정을 다시 고르지 않은 개발 비교를 한다. 이미 본520명은 독립 최종 시험이 아니다. 최종223명과 기존38명은 열지 않는다. 기존 사람별 평균절대오차를 유지하고, 같은 사람의 오차 차이·어떤 범위에서 실패하는지·처리시간을 함께 검토한다. 새로운 진단 구간/성공 기준은 실행 전 합의한다.

판단: 단순 특징보다 개선되면 AI 특징의 추가 가치를 지지한다. 차이가 불분명하면 복잡한 모델이 필요하다고 주장하지 않는다. 단순 모델이 비슷하거나 더 좋으면 정확도와 계산 비용을 측정해 단순 모델을 채택할 근거로 삼을 수 있다. 어떤 결과라도 작동하는 예측 모델과 비교 결과를 제출할 수 있지만 새 기여가 입증됐다고 자동으로 부르지 않는다.

### 후속 후보 C 측정된 보행정보가 기능 점수와 연결되는가

보행 속도 같은 단순 기준과, 소수의 보행변수를 함께 쓴 모델을 비교한다. 44명의 SPPB 또는39명의 POMA-G 중 목표 하나를 먼저 선택한다. SPPB는 걷기 외 기능을 포함하고, POMA-G는 현재 점수 범위가 좁다는 차이가 있다. 평가자·평가 시점 선택 또는 합치는 규칙은 먼저 정하며 결과를 보고 유리한 평가를 고르지 않는다.

제안 방법: 한 사람의5회 측정을 전부 같은 묶음에 두고, 사람을 번갈아 제외하는 검증을 사용한다. 특징 선택·표준화·설정 선택은 매번 학습 사람 안에서만 한다. 정답을 사람마다 반복 복사한 뒤220명을 평가한 것처럼 계산하지 않는다. 다수 변수를44명에 무제한 맞추지 않는다.

판단: 새 사람에서 단순 속도 기준보다 추가 정보를 주는지와 결과의 불확실성을 본다. 가능성이 있으면 관련 특징을 영상으로 얼마나 정확히 얻을 수 있는지 다음 실험으로 간다. 첫 단계 성공은 영상만으로 기능 평가에 성공했다는 뜻이 아니다.

### 대안 B 정상/비정상을 넘어 등급 순서를 구별하는가

주 입력 형식을 먼저 정하고, 같은 표현에서 일반 분류와 순서형 예측을 비교한다. 움직임 표현 모델까지 동시에 바꾸지 않는다. 사전학습 특징은 고정하고 작은 예측 부분부터 학습하며, 이후 필요할 때 일부 파인튜닝을 검토한다. CARE-PD 원 연구의 사람 단위 분리와 단순 보행특징 비교를 참고한다.

제안 평가: 등급별 맞힘, 평균 몇 단계 틀리는지,3점을0점으로 보는 큰 오류, 사람별 결과와 불확실성. 중증5명을 여러 구간으로 잘라도 새로운 중증 사람이 늘지 않는다. 점수3이 학습이나 평가에서 빠지는 분할을 전체4단계 성능으로 과장하지 않는다. 먼저 공식 분할과 적용 가능성을 검사한다.

판단: 다수 등급만 맞히는 기준을 넘는지, 순서형 학습이 큰 단계 오류를 줄이는지 본다. 최적화 전에 작은 중증 표본이 결론을 지탱하는지 검토한다. 4단계가 가능해도10단계가 된 것은 아니다. 현재3DGait는 고령 신경퇴행성 질환·건강 대조 자료로, CARE-PD라는 이름만으로 전부 파킨슨병이라고 부르지 않는다.

참고: [CARE-PD 원 연구](https://arxiv.org/html/2510.04312v1), [CORAL 순서형 학습](https://arxiv.org/abs/1901.07884), [고령자44명 원 자료 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC7701341/). 이 방법들은 우리 실험에서 아직 실행하지 않았다.

## 최소 제출물에 맞는 앱

권장 첫 사용자는 기존 계획의 현장 담당자 또는 평가를 검토하는 연구자다. 가족이 독립적으로 건강을 판단하는 서비스는 새 사용자·촬영 조건 검증이 더 필요하다. 기존 앱의 대상자·측정·이력·보고서 흐름을 유지하고 보행 기록 검토 기능을 넣는다.

최소 흐름: 대상자 또는 공개 예제 선택 → 허용된 입력 불러오기 → 실제 모델 분석 → 점수의 의미·적용 범위와 함께 결과 표시 → 분석 조건·모델 버전·결과 저장 → 이전 기록과 나란히 비교 → 검토 메모·보고서.

최소 구현의 모델 입력은 현재 검증한 형식의 공개 좌표여도 된다. 영상이 준비돼 있으면 같은 기록의 영상을 함께 표시하되 영상에서 실시간으로 그 좌표를 얻었다고 속이지 않는다. 사용자가 올린 영상의 MediaPipe 입력까지 연결하는 것은 별도 확장 단계다. 이 단계가 없으면 '영상 자동 평가 완성'이라고 부르지 않는다.

앱의 가치는 기록을 한곳에서 비교하고, 영상·측정값·모델의 보조 추정·담당자 의견을 함께 남기는 데 있다. 점수가 조금 바뀌었다고 호전/악화를 단정하거나 낙상 위험 경보로 바꾸지 않는다. 오류·입력 불일치는 재확인 상태로 표시하고0점으로 저장하지 않는다. 평균 검증 오차9.27을 모든 개인의 ±9.27 신뢰구간으로 표시하지 않는다.

기존 SPPB 결과와 AI 추정 GDI/임상 등급은 서로 다른 항목으로 구분한다. 그래프와 보고서도 척도·모델 버전·촬영 조건이 다른 값은 섞지 않는다. 웹 앱의 저장·조회·보고서 흐름이 작동하는지와 평가의 임상 정확도는 별도로 검증한다.

제출 우선순위 제안: 1) 기존 모델의 재현 가능한 실행과 강한 비교 기준 2) 예제 입력부터 결과 저장·조회까지의 최소 웹 흐름 3) 여력이 있으면 영상 연결 또는 C/B 중 하나의 탐색. 세 방향을 모두 완성하려 하지 않는다. 기존 원본 앱·DB·점수 정의는 이번 작업에서 수정하지 않았다.

## 사용 범위와 검사

CARE-PD 공식 약관은 비상업 연구 이용이다. 기존 HF 표기에는 다른 라이선스 표기가 있어 변경 자료 재배포나 기업 서비스 이용을 자동 허용된 것으로 보지 않는다. 원본·모델·가중치·제품 배포 조건은 단계별로 확인한다. [공식 약관](https://neurips2025.care-pd.ca/terms-of-use.html). 고령자44명 자료는 기존 확보 당시 CC BY4.0으로 기록돼 있으며 실제 제출 때 출처와 해당 파일 조건을 유지한다.

확인 파일의 해시는 분석 전후 동일했다. B 정답 분포 합계90, C 보행44×5=220·SPPB44명, POMA 평가별39명·항목 합계와 총점 일치를 확인했다. POMA는 전체44명 중5명에게 유효 총점이 없었다. 원본의 빈칸을0점으로 채우지 않았다. 보행변수 표의 합쳐진 사람 칸은 다음 사람 전까지 해당 사람의 반복 측정으로 연결했다.

첫 실행은 NumPy 정수를 JSON으로 저장하는 과정에서 실패했다. 기본 정수형으로 변환하도록 고친 뒤 재실행했고 집계·저장이 완료됐다. 분석 코드와 원본 지문·집계·검산은 이 폴더에 남겼다. 새 모델 학습·성능 향상·GPU 실행은 이번에 하지 않았다.
