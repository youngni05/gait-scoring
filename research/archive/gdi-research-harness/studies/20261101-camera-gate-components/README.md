# 영상 품질 판정의 시점 차이: 가시성과 방향 변화 분리

**이번 14명의 시점 차이는 방향 변화 조건에서 발생했다.** 관절 가시성 조건은 모든 직선·회전 영상을 통과시켰다. 방향 조건만 남기면 원래 규칙과 동일하게 PG1 직선 1/14명, PG2 직선 14/14명을 통과시켰다. 이 결과는 어떤 방향 판정법을 배포할 수 있다는 검증이 아니라, 실패한 규칙의 원인을 좁히는 진단이다.

같은 14명의 직선·회전 2초 구간과 두 카메라를 유지했다. 관절 가시성 0.5와 어깨·골반 방향 변화 30도라는 원래 문턱은 바꾸지 않았다. 원래 두 조건을 함께 쓰는 규칙, 각각만 쓰는 규칙, 아무 조건도 쓰지 않는 대조를 비교했다.

PG1의 거부된 직선 13명 중 가시성 조건 제거로 되살아난 사람은 0명, 방향 조건 제거로 되살아난 사람은 13명이다. 사전에 정한 10명 이상이라는 원인 분리 기준에서는 방향 조건이 주된 원인이다. 다만 방향 조건을 빼면 회전도 모두 통과하므로 해결책으로 채택할 수 없다.

이 판정은 영상 모델이 복원한 어깨·골반 좌우 벡터의 x/z 방향 변화를 사용한다. 실제 해부학적 회전의 정답이 아니므로, 원인이 깊이 흔들림·카메라 투영·몸의 움직임 중 무엇인지까지 확정하지 않는다. 같은 개발 표본에서 판정 조건을 분리한 결과이며 새 사람이나 임의 휴대폰에 대한 검증이 아니다.

56클립의 독립 각도·분위수·가시성 재계산, 224상세/8지표/8시점짝의 전체 열, 원본·선택 배열·사람·프레임·조건·파일 지문을 검산했다. 각도 허용오차 1e-10과 판정 완전 일치를 유지했다. 기존 본 계산 코드와 출력은 수정하지 않았고, 처음 일부 검사만 수행한 main-verification.json과 별도로 main-full-verification.json을 남겼다.

이번에는 모델을 학습하지 않았다. 기존 SPPB/TUG 모델·사람·구간·초기값 5개는 그대로이며, 임상 점수 정확도나 낮은 기능 구분이 개선됐다는 결과가 아니다. 관측에 실패한 영상은 측정 불가로 처리하며 낮은 점수를 부여하지 않는다.
