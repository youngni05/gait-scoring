**실제 영상 설명 → Jev의 추가 정보 효과 — 2026-10-31**

12명의 실제 영상으로 설명 생성·Jev 해석·TUG 예측 비교를 실행했다. **이번 경량 영상 모델과 입력 조건에서는 숫자 특징에 더할 만한, 믿을 수 있는 움직임 정보와 일관된 예측 개선을 확인하지 못했다.** Ridge에서 조금 줄어든 오차는 불확실성 범위가 컸고, 랜덤포레스트에서는 오차가 늘었다. 정지 화면으로 만든 설명도 비슷하거나 더 작은 오차를 보여, 숫자가 좋아지는 것만으로 실제 움직임을 읽었다고 판단할 수 없었다.

이 실험은 Jev를 Ridge 대신 쓰는 직접 비교와 다르다. 여기서는 **영상 설명을 Jev가 읽어 만든 보조 특징이 기존 숫자 특징에 도움이 되는지** 확인했다. 별도로 완료한 [MotionBERT → Jev 대 Ridge 직접 비교](C:/Users/jun/Desktop/D_P/gdi-research-harness/studies/20261031-motionbert-jev-vs-ridge/STATUS.md)에서는 Jev가 최종 점수를 고르게 했다.

Toronto 공개 자료 중 기존 실험에 포함된 12명의 하단 카메라 원본 영상을 사용했다. 각 영상의 처음 30초에서 사람의 몸이 잘 보이고 위치 변화가 있는 구간을 정해진 규칙으로 골랐다. 점수와 생성 설명으로 구간을 고르지 않았다. 처음에 고정 10초 지점을 시험했으나 사람이 충분히 보이지 않아, 설명 생성과 점수 평가 전에 가시성 규칙으로 변경했다.

같은 4.1초 구간을 두 경로로 처리했다.

| 경로 | 실제 처리 |
|---|---|
| 숫자 특징 | 124개 시점의 영상 → MediaPipe 관절 17개 → 좌표·신뢰도의 평균, 표준편차, 인접 변화량 153개 |
| 영상 설명 | 같은 구간에서 고른 실제 RGB 프레임 9장 → 시간 순서와 시각을 붙여 SmolVLM2-500M-Video-Instruct에 입력 → 생성된 설명을 Jev에 전달 |
| 비교 | Jev의 비대칭·불규칙성·회전 등 9개 항목의 선택 확률 36개를 추출 → 숫자와 합치거나 단독으로 Ridge·랜덤포레스트에 입력 → TUG 초 예측 |

영상 모델과 Jev의 가중치는 추가 학습하지 않았다. 영상 모델은 로컬 CPU에서 실행했고 Jev에는 숫자·설명 텍스트만 보냈다. 영상·참가자 ID·TUG 정답은 보내지 않았다. 영상 모델 입력은 **4.1초의 프레임 9장**이며 전체 프레임률의 동영상을 그대로 입력한 것은 아니다. 사용 모델의 고정 버전과 실제 파일 지문은 [acquisition.json](C:/Users/jun/Desktop/D_P/gdi-research-harness/studies/20261031-video-caption-jev/acquisition.json)에 있다. [모델 원문](https://huggingface.co/HuggingFaceTB/SmolVLM2-500M-Video-Instruct)

숫자와 영상의 시간 범위를 맞추기 위해 MediaPipe 특징을 새로 추출했다. 따라서 과거 Alphapose 기반 실험의 입력·성능을 그대로 재사용한 비교가 아니다. 12명 중 1명은 선택 구간에서도 멀리 서 있어 관절을 전혀 검출하지 못했다. 이 사람을 사후에 제외하거나 잘 나오는 영상으로 바꾸지 않았다.

비교에는 움직임 항목을 구체적으로 요청한 **집중 설명**, 일반적인 행동을 요청한 **일반 설명**, 첫 프레임을 9번 반복한 **정지 화면 설명**을 사용했다. 프레임은 같고 질문만 다른 조건과, 질문은 같고 실제 시간 변화가 없는 조건을 나누었다. 숫자와 집중 설명을 Jev에 동시에 주는 조건은 생성 설명 오류를 확인한 뒤, TUG 결과를 보기 전에 추가한 탐색 조건이다. 원래 조건은 보존했다.

설명 36개를 모두 고정한 뒤 TUG 정답을 불러왔다. 같은 다섯 사람 분할로 모든 방법을 비교했다. Ridge는 강도 100, 랜덤포레스트는 나무 128개·최소 잎 표본 2개로 고정했다. 아래 값은 TUG 평균 절대오차(MAE, 초)이며 작을수록 좋다.

| 예측에 넣은 특징 | Ridge | 랜덤포레스트 |
|---|---:|---:|
| **숫자만** | **3.665** | **3.025** |
| 숫자 + 숫자를 읽은 Jev | 3.744 | 3.075 |
| **숫자 + 집중 영상 설명을 읽은 Jev** | **3.497** | **3.118** |

집중 설명을 추가한 Ridge는 평균 오차가 0.168초 줄었지만, **추가 후 − 추가 전** 차이의 조건부 95% 구간은 −0.537~+0.152초로 0을 포함한다. 랜덤포레스트는 0.093초 늘었고 구간은 −0.176~+0.279초다. 사람 12명의 저장된 예측을 10,000번 다시 뽑아 계산한 구간이며 독립 기관 검증이나 학습 변동 전체를 나타내지 않는다.

또한 Ridge에서 설명 특징을 학습·평가 묶음 안에서 각각 무작위로 섞은 대조 실험을 50회 했다. 중앙 오차는 3.665초, 범위는 3.359~3.949초였으며, 10회는 올바른 사람에게 설명을 연결한 3.497초보다 같거나 작았다. 이는 작은 표본의 우연한 개선을 살펴보는 진단용 비교이며 정식 유의확률로 해석하지 않는다. 이 섞기 실험은 Ridge에만 수행했다.

실제 프레임과 설명을 대조한 관찰도 예측 성능만큼 중요했다. 아래는 Codex가 9장짜리 접촉 시트를 본 정성 점검이며, 독립된 임상 평가자의 정답은 아니다.

- 2·5·10·13번 영상에서는 몸과 발의 방향을 돌리는 장면이 보이지만 집중 설명은 실제 보행 방향 전환을 명확히 설명하지 않았다. Jev도 집중 설명 조건에서 12명 모두 회전이 있다고 답하지 않았다. 이 가운데 8명은 없음, 4명은 판단 불가였다.
- 카메라 쪽으로 다가가는 장면을 “왼쪽에서 오른쪽으로 이동한다”고 설명하는 오류가 반복됐다. 요청에서 제외한 옷·배경 묘사도 생성됐다.
- 정지 화면 9장에도 걷는다고 서술했다. 한 장의 보행 자세에서 행동을 추정할 수 있다는 점과, 실제 시간 변화를 관찰했다는 것은 구분해야 한다. 특히 6번 정지 조건은 움직임이 점점 더 유연해지고 발의 움직임이 역동적으로 바뀐다는 시간 변화를 덧붙였다. 이 변화는 입력에 존재하지 않는다.
- 멀리 서 있는 7번 영상에는 “서둘러 카메라 쪽으로 걷는다”는 잘못된 설명이 나왔다. 이 설명만 받은 Jev는 불규칙성·몸통 움직임·멈춤·회전 등 일부 항목을 없음으로 분류했다. 관절 신뢰도가 전부 0인 숫자를 함께 주자 **9개 항목 모두 판단 불가**로 바뀌었다. 입력의 불확실성을 반영한 사례이지만, 이런 변화가 전체 TUG 예측 오차 개선으로 이어지지는 않았다.
- 집중 설명 조건에서 좌우 비대칭과 발 끌림은 각각 12명 모두 판단 불가였다. 대답이 길어졌다고 세밀한 보행 정보가 확보된 것은 아니었다.

따라서 현재 확인된 것은 **연결 구조가 실제로 실행된다는 점과, 숫자가 잘못된 설명에 대한 판단을 보수적으로 바꾼 사례**다. 예측에 유용한 새 움직임 정보가 확보됐다는 결론은 아직 내릴 수 없다. 12명, 경량 모델 하나, 9장 입력이라는 제한이 있으므로 모든 영상 설명 모델의 가능성을 부정하는 결과로 확장하지 않는다. 이 영상 비교에는 GDI 정답이 없어서 GDI 예측을 수행하지 않았다.

입력 검산에서는 원본 영상에서 프레임 108장을 다시 추출해 모델에 준 이미지와 정확히 같은지 확인했고, 숫자 특징 12개 벡터를 다시 계산했다. 결과 검산에서는 36개 설명과 60개 요청의 파일 지문, 사람·정답·분할 대응, 23가지 예측의 오차와 50개 섞기 결과를 확인했다. 주요 Ridge 두 조건은 별도 선형대수 계산으로 재현했다. 랜덤포레스트를 별도 구현으로 재학습하지는 않았다.
