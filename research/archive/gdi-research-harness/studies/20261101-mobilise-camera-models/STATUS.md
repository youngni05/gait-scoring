# 속도 중심 동일 입력에서 RF·Deep Sets와 내부 적중률 선택 비교

고정 휴대폰·바닥 거리 표시 없음·키1회 입력 가능이라는 사용자 조건을 유지한다. 이전 실험은 속도5개를 유지한 효과를 확인했으나 걸음 빈도 추가가 전체 적중률을 높이지는 못했다. 이번 질문은 같은 속도/속도+빈도 입력에서 모델과 학습 내부 선택 기준을 바꾸면4구간 적중률이 높아지는가다.

속도만1개특징×5구간과 속도+걸음빈도2개특징×5구간을 각각 비교한다. 입력에 구간 지속 시간·회전 빈도·진단명·검사점수는 넣지 않는다. 같은 SPPB2,174명·TUG1,939명,방문·30–60초5구간·기존사람5분할/내부3분할·초기값5개·4구간 경계를 유지한다. 사람의 모든 방문은 같은 분할에 둔다.

비교군은 기존 고정RF(128나무·최소잎20),내부 적중률로 잎5/20을 선택한RF,같은 입력의Deep Sets다. Deep Sets는특징1/2→32→구간평균→16→4,CE·AdamW학습률0.01·가중치감쇠0.001이다.10–600epoch를10간격으로 비교한다. 모든 모델은 사람 동일 비중을 사용한다.

선택은 학습 내부 예측의 사람 평균 적중률 최대,동률은 로그손실 최소,그다음 큰 잎/이른epoch다. 수학적 동률의 수치 순서가 흔들리지 않게 선택 점수만 소수12자리로 비교한다. 모델 재현 허용오차는1e-12로 유지한다. 평가 사람의 정답으로 설정·보정·문턱을 선택하지 않는다. 내부 선택 예측을 보정에도 사용하므로 내부 값은 독립 성능 추정이 아니다.

CPU4개 독립 프로세스로 실행한다. 프로세스마다Torch난수와단일연산스레드를 분리하며 GPU는 필요하지 않다. 예상 학습·검산은20–45분,모델·전체 후보 내부예측 약1–3GB다. 파일럿은0번분할·첫초기값의두목표이며 본실험은50작업이다. 기대검산은1500모델/부분집합재현·32지정재학습·전체130행·속도짝60행이다. RF후보/DS선택과 모든 보정·구간/사람/정답 연결을 검산한다.

주지표는4구간적중률이며 구간별/평균재현율·양끝오판·저기능놓침/오경고·같은질환/비슷한속도구분과5개초기값도 보고한다. RF조정효과와동일입력RF/DeepSets차이,걸음빈도추가효과를나누어보고한다. 기존평가자료반복사용의탐색한계와영상측정오차미검증을명시한다.
