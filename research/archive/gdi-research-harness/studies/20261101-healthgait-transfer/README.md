# Health&Gait 사전학습과 실제 SPPB 추가 학습

현재 상태: 승인된 초기 비교와 개선 두 차례를 모두 회수·검산했다. 마지막33587·33588의1,125개 학습에서 초기값3개 평균 MAE는 처음부터1.4214점·GDI3.5995점·Health&Gait1.2099점이었다. 이후 BN 처리 일관성을 고친 별도 비교도 완료했으며, 최신 비교는 ../20261101-healthgait-bn-consistent/analysis/RESULTS.md에 있다. 이 폴더의 원본 실행은 보존한다.

비교하는 질문은 **일반 성인의 보행 특징을 먼저 익히거나 기존 GDI 가중치를 가져오면, 새로운 고령자의 실제 SPPB 점수 예측이 좋아지는가**이다.

| 조건 | 시작 가중치 → 추가 학습 |
| --- | --- |
| scratch | 무작위 초기화 → OlderAdults44 SPPB |
| gdi | 기존 다구간 GDI CNN의 대응 가중치 → 같은 SPPB |
| health | Health&Gait의 실제 측정 보행값 사전학습 → 같은 SPPB |

Health&Gait는 기능점수가 없어 측정 보행속도·보폭·활보장·분당 걸음 수를 사전학습 정답으로 사용한다. 영상과 측정은 동시 촬영이 아니므로 그 한계를 기록한다. 나이·활동수준을 기능점수로 바꾸지 않는다. 공식 배포의 관절 JSON과 측정 CSV만 받아 불필요한 영상 파생 이미지의 다운로드를 줄인다. [공식 자료](https://zenodo.org/records/14039922), [이용 조건](https://github.com/AVAuco/healthgait/blob/main/DUA.txt).

공개 측정표를 먼저 확인하니 일부 큰 값과 빠른 보행 조건의 누락이 있었다. 값을 임의 수정하지 않고, 정답이 있는 조건만 사용하며 사전학습에는 큰 오차의 영향을 줄이는 SmoothL1 손실을 적용한다. 추가 학습 세 조건의 초기 비교에는 동일한 MSE를 유지한다. 실제 사용 인원·기록·제외 이유는 `source-audit.json`, 측정표 분포는 `source-label-audit.json`에 남긴다.

Health&Gait에는 발끝이 없어 입력을 세 조건 모두 엉덩이·무릎·발목의 2D 좌표 6개로 맞춘다. 기존 GDI 첫 합성곱에서는 이 6개 좌표에 해당하는 가중치만 가져오고 나머지 특징 추출층을 재사용하며 점수 출력층은 새로 학습한다. 원래 12개 특징 모델의 전체 재현과 구분한다.

추가 학습은 [OlderAdults44](https://data.mendeley.com/datasets/xgw6bg3g8h/1)의 **실제 SPPB 정답 44명**으로 한다. 220회 보행을 220명으로 세지 않는다. Vicon 표면 마커를 옆면 좌표로 투영하며 엉덩이 마커는 영상의 관절 중심과 다르다. 이 결과만으로 실제 영상 성능을 주장하지 않는다.

사람 단위 기존 5분할을 유지한다. 각 학습 집단 안의 3분할로 학습 길이·설정을 고른 뒤, 바깥 평가 사람을 한 번 예측한다. 세 초기값을 모두 보고하며 같은 사람의 모든 보행·구간·좌우는 함께 이동한다. 기준선은 각 학습 집단의 평균·중앙값 점수이다. 상세 조건은 `protocol.json`이다.

코드·작은 검산표는 C 작업본, 다운로드·입력 배열·가중치·회수 원본은 `D:/gait-research-data/D_P/healthgait-transfer-20261101` 및 `D:/gait-research-data/D_P/datasets/HealthGait`에 둔다. GPU 실행은 별도 `/abr/RESEARCH_USER/healthgait-transfer-20261101`에서 한다. 기존 학습과 GPU 확보 작업32844는 변경하지 않는다.

사용자가 2026-11-01 승인한 범위는 초기 비교 → 매1시간 확인 → 완료 결과 회수·검산 → 분석 → 후속 GPU 개선 학습이다. 첫 비교 뒤 최대 두 차례의 개선 묶음을 진행하고 결과를 정리한다. 그 뒤 계속할 근거가 필요하면 남은 문제와 다음 후보를 보고한다. 반복 결과를 본 뒤 개선했으므로 최종 결과도 탐색 결과로 구분한다. 이번 요청은 감시 스킬의 기본30분·재학습 금지 대신 1시간 간격과 이 실험의 후속 학습을 명시적으로 허용한다. 다른 실험의 예약·제출 권한은 확대하지 않는다.

파일럿은 성능 검사가 아니다. GPU 계산·실제 몇 epoch 학습·저장 모델 재추론을 먼저 확인한 후 본 학습을 제출한다. 완료 후에는 서버/로컬 SHA256, 분할, 학습 수, 원점수 지표와 저장 모델 재추론을 확인하고 분석한다. PC와 Codex 앱이 켜져 있어야 예약 조회·회수가 동작한다.

세 초기값의 예측을 평균한 사람별 오차다. Health&Gait와 처음부터 학습의 MAE 차이는−0.112점, 고정 예측에 대한 사람별 부트스트랩95% 범위는−0.392~+0.161점이다. 첫 개선이 사전학습 효과를 확인한 결과는 아니며, 초기값 변동과 낮은 점수의 큰 오차가 남는다.

바깥 평가 사람을 제외한 내부 검증 사람들의 저장 모델도 별도로 재추론했다. Health&Gait의 내부 검증 MAE는5–8점에서2.168점,9–12점에서0.925점이었다. 같은 사람이 여러 분할·초기값에서 반복 등장한 진단치이며 추가 참가자나 독립 성능 검증으로 세지 않는다. Health&Gait의 최종15회 중13회는 학습률0.001·전체 학습을 선택했다. 상세 선택 빈도와 오차는 `analysis/round1/training-diagnostics.json`에 있다.

마지막 개선은 미리 정한 학습률0.001/0.0001, 드롭아웃0.2/0.5, MSE/SmoothL1의8개 조합을 세 방식에 동일하게 적용한다. 같은44명·분할·초기값·입력을 유지하고 내부 검증으로만 고른다. 전체 층을 학습하는 비교이므로 첫 개선의 층 고정 후보보다 항상 좋아지는 과정은 아니다. 드롭아웃을 줄이면 정보를 더 유지할 가능성이 있고 SmoothL1은 큰 오차의 영향을 줄이지만, 드문 낮은 점수의 실제 오차도 덜 반영할 수 있다. 개선을 전제하지 않고 MSE도 함께 비교한다. 근거·한계는 `improvement-r2.json`에 남겼다.

## 중앙값보다 낮은 성능의 원인 진단

사용자 요청으로 원자료·학습 방식의 영향을 추가 진단했다. 기존 GPU 실행·가중치·입력·정식 비교 결과는 변경하지 않았다. 진단 코드와 수치는 `diagnose_failure.py`, `diagnostics/`에 있다.

- 점수는9–12점34명/44명이고 모든 학습 묶음의 중앙값이10점이었다. 10점 상수 예측의 MAE는1.318점이다. 초기 CNN은 MSE로 학습하면서 평균 점수 근처에 모였으며, 평균 기준선의 MAE는1.380점이다. 내부 학습 집단은23–24명, CNN 가중치는46293개다.
- 같은2D 좌표를 평균·표준편차·시간 변화량으로 요약하고 같은 사람별 분할·내부 설정 선택을 적용하자 Ridge MAE1.104점, RF1.050점이었다. 기존3D 좌표와 속도를 사용한 RF1.001점도 재현했다. 현재 입력에도 예측에 사용할 정보가 남아 있다. 다만 같은44명의 탐색 진단이며 새 모델의 독립 일반화 검증은 아니다. 동일2D RF와 중앙값의 MAE 차이 부트스트랩95% 범위도−0.561~+0.009점으로 넓다.
- GDI에서는 입력12채널을6개로 줄이면서 기존 BatchNorm의 평균·분산도 그대로 이식했다. 통계 업데이트율은1%이며 초기 GDI 재학습의 중앙 학습 길이에서는 원 통계 기여가 약58% 남는다. 입력·통계의 부조화가 의심되어 학습 사람들만으로 BN 통계를 다시 계산했다. 학습 가중치는 그대로 두었고 정답·옵티마이저를 사용하지 않았다.
- 초기 내부 GDI 모델45개의 검증 MAE는1.885→1.238점,35개에서 낮아졌다. 첫 개선의 최종 모델45개를 진단용 재추론한 MAE는 GDI3.664→1.244점, Health&Gait1.337→1.201점, scratch1.449→1.575점이었다. 각 바깥 평가 사람을 제외한 학습 사람들만 통계 재계산에 사용했다. GDI의 큰 오차에 BN 통계 부조화가 기여한 근거이며, scratch에서는 악화되어 일괄 해결책으로 보지 않는다. 기존 통계 잔존·입력 변경·드롭아웃/BN 조합 각각의 기여는 분리하지 않았다.
- 위 재계산은 이미 열람한 개발 자료의 사후 원인 진단이다. 이전 정식 결과를 대체하지 않고, BN 처리를 내부 검증 단계부터 일관되게 적용한 재학습 성능이나 임상·실제 영상 성능으로 주장하지 않는다. 정답·분할 연결과 입력 유한성 검사는 통과했고 진단 뒤에도 원본 최종45개 체크포인트와 입력의 SHA256이 그대로임을 확인했다.

또한 매 프레임 골반 중심 이동·크기 정규화는 절대 이동과 신체 크기를 제거하고3D를 옆면으로 투영한다. 표면 골반 마커는 영상의 엉덩이 관절 중심과 다르다. 이런 설계 한계가 있으나 같은 입력의 작은 모델 결과를 보면 이를 전부 성능 부진의 원인으로 돌릴 수 없다. SPPB 정답도 균형·보행·의자 일어나기의 총점이며 공개표에 구성요소별 점수는 없다. 3초 보행만으로 관찰하지 않은 기능까지 추정하는 한계는 별도로 남는다.
