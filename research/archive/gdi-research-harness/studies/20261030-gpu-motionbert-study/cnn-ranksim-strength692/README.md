## 파일럿 검산·본 학습 확인 — 2026-11-01T22:18

작업 **33677·33678·33679가 DIS01의 서로 다른 물리 GPU 3개에서 본 학습 중**이다. 세 GPU의 가상 검사, 두 조건의 실제 3epoch 파일럿(학습416명·내부검증138명), 서버GPU/CPU64와 회수 후 로컬CPU64·SHA 검사를 통과했다. 로컬 재예측 최대 차이는 1.17264663e-05점으로 기존0.0001 기준 이내다. 동일한 지문과 파일럿 증거로만 승인 파일을 보냈고, 실제 세 worker의 main 단계와 중복 없는10개 분담(4/3/3)을 확인했다. 파일럿은 epoch당 최대 26.23초, GPU 최대 할당 182.2MiB였다. 초기 예상보다 느렸다. 모든 refit도100epoch라고 놓은 단계 수 환산은 총 GPU 38.8시간, 가장 긴 작업 약15.4시간이다. 이는 대기·입출력·마지막 요약 시간을 제외한 거친 추정이며, 내부 선택이 refit을 줄이거나 부하가 바뀌면 달라진다. 작업별24시간 상한은 유지하고 1시간 감시에서 진행·남은 시간을 확인한다. 초기 계획의 예상치는 원본에 보존하고 [실측 기반 추정](checks/runtime-estimate.json)을 별도로 기록했다.

기존 최선에 RankSim을 추가한 조합은 MAE 6.515817 → 6.476735점으로 다섯 분할 모두 낮아졌지만, 95% 차이 범위 −0.085931~+0.005065점에 0을 포함했다. 단독 RankSim보다 결합에 추가 가치가 있을 가능성을 보고, 순위 손실을 약하게 주면 점수 예측의 손해를 줄일 수 있는지 확인한다.

입력은 같은 692명·1,061기록·11,261구간의 측면 OpenPose 12특징, 구간 길이 124프레임이며 정답은 좌우 GDI다. 모델·자료·사람 분할·초기값·사람별 추출·최적화·보정은 유지하고 **RankSim 추가 비중만 1에서 0.1 또는 0.3으로 낮춘다.** 새 두 조건은 각 25개, 총 50개 학습이다. 기존 동일 조건 MSE(비중 0)와 RankSim(비중 1)은 지문과 학습 함수·입력·초기값을 대조해 재사용한다. 같은 대조군을 다시 학습하지 않는다.

네 강도 0·0.1·0.3·1 중 어느 것을 사용할지와 학습 길이는 각 바깥 학습 자료의 내부 4분할에서만 선택한다. 각 강도의 내부 평균 MAE가 최소인 epoch를 구한 뒤 가장 작은 점수를 고르고, 1e-12 동률은 약한 강도를 우선한다. 바깥 사람은 모델·정규화·보정·강도와 epoch 선택에서 모두 제외한다. 후보별 고정 결과와 내부 선택 결과를 구분해 보고한다.

CPU 가상 학습·20개 실제 사람 분리 검사와 기존 대조군 연결 검사를 먼저 한다. 그다음 GPU 1개짜리 최대 3개 작업으로 10개 조건/바깥 분할을 4/3/3개로 나눈다. 각 GPU의 가상 검사, 두 실제 3epoch 파일럿, 서버 GPU/CPU64와 로컬 CPU64 재추론·SHA 검산이 전부 통과해야 본 학습을 시작한다. 점수 재추론 허용오차는 0.0001이다. 파일럿 점수를 최종 성능으로 비교하지 않는다.
