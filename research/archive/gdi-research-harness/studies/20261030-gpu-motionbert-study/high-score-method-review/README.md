# 고득점 과소예측: 반복 검사와 새 학습 방식 검토

2026-10-31. 기존 개발자료의 연결과 CNN 코드, 두 방법의 공식 구현을 확인했다. 새 GPU 학습은 실행하지 않았다. 아래 실험 순서는 검토 후보이며 채택·성능 개선이 확인된 상태는 아니다.

## 먼저 확인된 것

**현재 반복 기록으로 측정 잡음이나 피할 수 없는 오차를 계산할 수 없다.** 같은 사람의 기록이지만 다른 검사에 속하며, 나이로 확인한 검사 간격도 길다. 따라서 고득점 오차가 측정의 한계 때문이라는 결론은 아직 근거가 없다.

| 개발자료 확인 항목 | 결과 |
|---|---:|
| 독립 사람 / 기록 / 입력 구간 | 692명 / 1,061개 / 11,261개 |
| 기록이 여러 개인 사람 | 229명 |
| 서로 다른 검사 ID가 있는 사람 | 229명 |
| 같은 검사 ID에 연결된 복수 영상 | 0개 |
| 반복 기록 사람의 첫·마지막 나이 차이 중앙값 | 4.063년 |
| 첫·마지막 나이 차이가 0.5년 이상인 사람 | 228명 / 229명 |
| 검사 간 GDI 절대 차이, 사람별 같은 비중 | 8.941점 |

마지막 수치는 사람마다 가능한 모든 검사 쌍을 만들고, 좌우 GDI 절대 차이를 평균한 뒤, 사람별 평균을 같은 비중으로 평균한 값이다. 581쌍을 그대로 평균하면 9.432점으로 달라진다. **둘 다 모델의 MAE 하한이나 과소예측의 몫이 아니다.** 성장·치료·실제 보행 변화·측정 변동이 섞여 있다. 검사 날짜와 실제 중간 치료 이력은 확인되지 않았다. `upcoming_` 수술 표시는 수술이 실제 시행됐다는 증거로 쓰지 않았다.

자료 연결은 개발자료의 영상 ID→검사 ID와 사람 ID로 확인했다. 추가 개발자료에 해당하는 859기록은 별도 기존 연결 기록과 사람·검사·좌우 정답의 정확한 일치를 확인했다. 692명 전원이 한 사람 분할에만 속한다. 보호된 평가자료의 수치 정답은 선택하지 않았다.

## 기존 가중치 실험에서 배운 점

다른 담당 채팅의 [완료·검산 기록](../../20261031-cnn-high-gdi/README.md)을 확인했다. 이번 검토에서 모델 재추론을 다시 수행한 결과는 아니다.

| 조건 | 전체 사람 평균 MAE | 실제 90 이상 관측의 MAE |
|---|---:|---:|
| 여러 구간 CNN | 6.8667 | 9.3455 |
| 고득점 오차 3배 가중 | 6.8741 | 9.4878 |
| 희소 점수대 가중 | 6.8436 | 9.7007 |

고득점에 가중치를 주는 것만으로 해결되지는 않았다. 여기의 고득점은 **개별 기록·다리의 정답이 90 이상인 관측**을 골라 사람 비중을 맞춘 기준이다. 앞서 사용한 ‘사람 평균 GDI 90 이상 68명’과 대상이 달라 8.78점 같은 다른 기준의 수치와 직접 비교하지 않는다.

## 적용할 수 있는 두 방법

**Balanced MSE를 먼저 작게 비교하고, RankSim은 다음 후보로 두는 방향이 가능성이 있어 보인다.** 둘 다 GDI에서 개선이 확인된 기술은 아니다.

| 방법 | 실제로 바꾸는 것 | 우리 CNN에 적용할 위치·한계 |
|---|---|---|
| Balanced MSE의 BMC 구현 | 예측 하나를 자신의 정답뿐 아니라 같은 학습 묶음의 다른 정답들과 비교해, 정답 분포의 불균형을 고려하는 손실을 계산한다. | CNN 구조·입력·출력은 유지하고 `run.py`의 MSE 계산을 교체할 수 있다. 배치의 정답 구성이 중요하며 단순 고득점 가중치와 다르다. |
| RankSim | 한 표본에서 정답이 가까운 이웃의 순서와 CNN 특징이 비슷한 이웃의 순서를 맞추는 추가 학습 목표다. 단순히 높은 점수를 주는 기능이 아니다. | `model.py`의 마지막 출력 직전 10차원 특징을 반환해 MSE에 순서 손실을 더할 수 있다. 순위 계산용 역전파와 중복 정답 처리가 필요하다. |

Balanced MSE는 CVPR 2022 연구이며 공식 저장소에는 회귀용 최소 구현과 연령·깊이 추정 등의 실험 코드가 공개되어 있다. BMC는 배치의 예측–정답 거리 행렬을 만들어 자기 정답의 위치를 맞히는 계산을 사용한다. [공식 코드](https://github.com/jiawei-ren/BalancedMSE)

RankSim은 ICML 2022 연구로, 얼굴의 연령 예측과 문장 유사도 회귀 등 세 불균형 회귀 벤치마크에서 평가했다. 우리에게 참고할 부분은 모델 이름이 아니라 ‘정답 사이의 거리 관계를 내부 특징에도 학습시키는 방식’이다. 고득점끼리 구분할 입력 정보가 있다면 활용을 도울 가능성이 있으나, 옆 영상에 없는 정보를 새로 만들어 주지는 않는다. [논문](https://proceedings.mlr.press/v162/gong22a.html) · [공식 구현](https://github.com/BorealisAI/ranksim-imbalanced-regression)

## 바로 붙이기 전에 해결할 조건

현재 CNN은 한쪽 다리의 124프레임·12특징 구간을 학습한다. 구간 수가 많은 기록의 비중을 줄여 **기록끼리는 같은 비중**이 되지만, 여러 기록을 가진 사람의 총 학습 비중은 더 크다. 예측은 기록별 여러 구간을 평균하고 학습자료만으로 선형 보정한 뒤 사람별 같은 비중으로 평가한다. 학습과 평가의 사람 비중이 완전히 같지는 않다는 뜻이며, 이것이 고득점 문제의 원인이라고 확정한 것은 아니다.

20개 내부 학습 분할에서 실제 학습처럼 구간·좌우 표본을 펼쳐 무작위 32개 배치를 구성해 확인했다. 새 학습이 아닌 배치 구성 진단이며 실제 실행 seed 재현은 아니다. 분할별 결과를 같은 비중으로 평균하면:

- 배치당 독립 사람은 평균 30.48명이다. 약 79.7%의 배치에 동일인이 한 번 이상 중복된다. 중복 비율은 높지만 평균 중복 수가 많다는 뜻은 아니다.
- 약 31.0%의 배치에 정확히 같은 GDI 정답이 반복된다. RankSim 공식 구현은 같은 정답마다 한 표본을 선택한다. 임의로 GDI를 정수로 반올림해 중복을 늘리지 않는다.
- 고득점 관측이 전혀 없는 배치는 약 1.23%다. 고득점이 매번 빠지는 것만으로 현재 문제를 설명할 근거는 약하다.

BMC에 기존 표본 가중치를 마지막에 곱하는 것만으로는, 배치 안에서 다른 정답과 비교하는 부분의 분포까지 사람 비중으로 바뀌지 않는다. 사람별 균등 추출을 도입한다면 **같은 추출 방식을 쓰는 MSE 대조군**이 필요하다. 이 변경은 BatchNorm이 보는 자료 구성에도 영향을 준다.

점수는 현재 각 학습 분할의 최솟값·범위로 정규화한다. BMC의 거리 척도도 같은 단위로 맞춰야 한다. 코드의 `noise_sigma`라는 이름을 실제 검사 잡음의 추정치로 해석하지 않는다. RankSim은 일반 `argsort`만 붙여서는 학습되지 않으므로 공식 `TrueRanker` 역전파를 확인해야 한다. 중복 표본 선택 난수와 체크포인트 재개도 검산 대상이다.

## 후속 비교 후보와 판단 방식

아래는 이번 검토에서 정리한 후보이며 새 실행을 시작한 상태는 아니다.

1. **기존 CNN 조건을 기준으로 보존한다.** 같은 692명·구간·사람 분할·평가 방식으로 비교한다.
2. **사람 비중을 맞춘 MSE 대조군과 같은 추출 방식을 쓰는 BMC를 비교한다.** 사람→기록→구간·다리의 추출 방식과 epoch당 업데이트 수를 두 조건에서 맞춘다. 기존 기록 가중치를 그대로 중복 적용하지 않는다. 기존 CNN과의 차이는 추출 방식 효과, 새 대조군과 BMC의 차이는 손실함수 효과로 나눠 본다.
3. **그다음 같은 대조군에 RankSim만 추가한다.** BMC와 RankSim을 처음부터 함께 넣으면 어떤 변경이 유효한지 구분하기 어렵다.

각 후보는 CPU 수식·중복 정답·유한 gradient 검사 → GPU 짧은 파일럿·저장 모델 재추론 → 본 비교 순서가 필요하다. BMC와 RankSim 모두 CNN 재학습에는 GPU를 사용하는 편이 적합하다. 추가 계산은 배치 내 비교가 중심이지만 실제 시간·메모리는 아직 측정하지 않았다. 검토만으로 ‘하루 이상 필요’하다고 단정하지 않는다.

거리 척도, 추가 손실 비중, 학습 길이는 바깥 평가 사람을 제외한 내부 검증에서만 고른다. 현재처럼 전체 MAE만으로 선택한 결과와 고득점 목표를 반영한 선택은 서로 다른 실험이다. 고득점 선택 목표를 도입한다면 허용할 전체 MAE 변화와 점수대별 기준을 실행 전에 정해야 한다.

비교에는 전체 MAE, 동일한 정의의 90·100 이상 MAE와 평균 편향, 낮은 점수대 오차, 보정 전후 결과를 함께 남긴다. 고득점 편향만 줄고 전체 오차가 늘어나는지 확인하고 사람 단위 재표집으로 불확실성을 본다. LJMU의 평균을 100에 가까워지게 만드는 것을 선택 기준으로 쓰지 않는다. 기존 개발자료에서 여러 방법을 탐색하고 있으므로 바깥 예측 개선도 최종 독립 검증과 구분한다.

- 원자료·코드 SHA256은 결과 JSON에 기록했다. 신규 보고서와 JSON은 C 작업본에 저장했다.
- 첫 실행에서 같은 검사의 좌우 나이 값 `5.9945205479452`와 `5.99452054794521`을 서로 다른 나이로 판정했다. 약 `9.77e-15`년의 표기 차이임을 확인하고, 나이 설명 통계에만 유한값·차이 `1e-10`년 미만 조건을 적용했다. GDI 정답 연결은 정확한 일치 검사를 유지했다.
