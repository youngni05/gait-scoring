# 구간 예측의 극단값을 줄이는 CPU 집계 비교

2026-10-31. 기존 GPU 학습·모델 가중치·할당·예약을 유지하고, 저장된 모델의 구간 예측을 CPU에서 다시 계산했다. **대조군의 159점 폭주는 중앙값으로 크게 줄었지만, 기존 최선 결합의 전체 성능 개선은 0.0033점에 그쳤다.** 집계 변경만으로 큰 돌파구를 얻었다고 보기는 어렵다.

## 같은 조건에서 무엇을 바꿨나

자료는 기존 692명·1,061기록·11,261구간과 같은 사람 분할이다. 사람마다 같은 비중으로 MAE를 계산한다. 기록 안의 각 다리 예측을 다음 여섯 방법으로 합쳤다.

| 집계 | 계산 방법 |
|---|---|
| 평균 | 모든 구간을 같은 비중으로 평균 |
| 중앙값 | 구간 예측을 정렬한 가운데 값; 짝수이면 가운데 두 값의 평균 |
| 양끝 10%·20% 제외 평균 | 작은 쪽과 큰 쪽에서 각각 해당 수만큼 제외하고 평균 |
| 양끝 10%·20% 눌러 평균 | 제외하는 대신 양끝 값을 남는 경계값으로 바꾼 뒤 평균 |

끝에서 처리할 개수는 `floor(구간 수×비율)`이다. 구간이 적어 0개가 되면 평균과 같고, 구간 하나인 기록도 그대로 남는다. 특정 기록을 제외하거나 좌표를 바꾸지 않았다.

CNN·STT의 집계 후 예측에 대해 **각 기본 모델의 학습 기록만으로** 기울기·절편 보정식을 다시 계산했다. 보정 자체는 원래와 같은 기록·좌우 관측별 OLS이며, 선택·평가 MAE는 사람 동일 비중이다. 기존 CNN 결합 비중과 좌우 차이 결합 비중은 유지했다.

각 바깥 평가 집단을 제외한 내부 검증에서 CNN 6방법×STT 6방법, 총 36조합 중 기존 평균·좌우 차이 결합의 MAE가 가장 작은 조합을 골랐다. 동률은 사전에 적은 순서를 따른다. 내부 선택 파일을 저장한 다음 별도 실행에서 바깥 평가 예측을 계산했다. [사전 조건](protocol.json).

## 전체 결과

아래 표는 좌우 차이 결합까지 유지한 조건이다. 각 고정 방식은 CNN과 STT 양쪽에 같은 집계를 적용했다.

| 집계 | 사람 동일 비중 MAE |
|---|---:|
| 기존 평균·좌우 차이 결합 | **6.605589** |
| 중앙값으로 고정 | 6.634626 |
| 양끝 10% 제외 | 6.611470 |
| 양끝 20% 제외 | 6.619620 |
| 양끝 10% 눌러 평균 | 6.608905 |
| 양끝 20% 눌러 평균 | 6.615359 |
| 내부 검증에서 CNN·STT 집계를 각각 선택 | **6.602250** |

선택된 CNN/STT 방식은 바깥 분할 순서대로 `20% 눌러 평균/10% 눌러 평균`, `평균/중앙값`, `평균/20% 눌러 평균`, `평균/평균`, `평균/평균`이다. 후반 두 분할은 집계를 바꾸지 않았다.

선택 조건의 개선 폭은 **0.003338점**이다. 사람 단위 10,000회 재표집의 탐색적 95% 범위는 새 조건−기존 최선 기준 **−0.013829~+0.007484점**으로 0을 포함한다. 뚜렷한 개선으로 해석하지 않는다. 고득점 68명 MAE도 8.780505→8.753083으로 변화가 작다.

좌우 차이 결합을 붙이기 전의 기존 CNN·STT 결합은 6.686592점이었다. 이번 선택 조합을 그 단계에 적용하면 6.685124점이다. 이 조합은 평균·좌우 차이 결합을 목표로 선택했으며, 단순 CNN·STT 결합에 별도 최적화한 결과는 아니다. 기존 6.686592와 새 6.602250의 차이 대부분은 앞서 수행한 좌우 차이 결합 효과다.

## 159점 폭주는 줄어드는가

완료된 기록 배치 대조군 `window_control`의 5개 바깥 모델도 같은 방법으로 확인했다. 진행 중인 기록 평균 모델의 결과가 아니다. 이 부분은 여섯 고정 방법의 진단 비교이며 평가 결과를 보고 집계법을 선택하지 않았다.

| 집계 | 정답 55.60인 사례의 예측 | 대조군 전체 MAE |
|---|---:|---:|
| 평균 | 159.01 | 7.250783 |
| 중앙값 | **68.85** | 7.220899 |
| 양끝 10% 제외 | 121.42 | 7.224735 |
| 양끝 20% 제외 | 89.12 | 7.209307 |
| 양끝 10% 눌러 평균 | 143.29 | 7.244792 |
| 양끝 20% 눌러 평균 | 108.96 | 7.218013 |

중앙값은 일부 구간의 폭주에 강했지만 정답까지 맞추지는 못했고, 전체 MAE 개선은 작았다. 이 기록의 기존 좋은 CNN·STT 결합은 이미 약 57.86점이었다. 따라서 대조군 한 사례를 안정시킨 성과와 최선 결합을 개선한 성과를 구분한다.

## 검산과 한계

- CNN 내부 20개·최종 5개, STT 내부 20개·최종 5개, 대조군 최종 5개 등 **55개 저장 모델**을 CPU로 재추론했다. 각 모델의 평균 집계가 기존 결과를 0.0001점 이내로 재현하는지 확인했다. 최종 결합의 평균 재현 최대 차이는 0.000016801점이다.
- 원본 모델·자료·캐시 지문, 사람 분리, 330개 집계·보정 조건을 확인했다. 별도 정렬·합계 계산의 최대 차이는 4.27e-14점 이내다. 평가 정답 변경 시 보정·선택 불변성, 순서 변경 불변성, 일부러 섞은 사람 거부, 단일 구간·극단값·빈 기록 처리도 확인했다.
- 검산 첫 실행은 분산으로 나누는 독립 보정식에서 중단됐다. CNN 내부 `outer0/inner4`의 학습 예측이 모두 74.990036으로 같아 분모가 0이었기 때문이다. 원래 OLS 계산이나 예측은 바꾸지 않고, 상수 입력의 최소노름 해를 독립적으로 계산하도록 **검산 코드만** 수정했다. 같은 허용오차로 통과했으며 첫 실패 로그는 보존했다. 실제로 내부 모델 하나가 학습 사람을 구분하지 못한다는 신호이므로 단순한 검산 문제로만 감추지 않는다.
- 내부에서는 남은 마지막 모델인 CNN 100epoch·STT 200epoch를 사용하고, 바깥 모델은 기존 내부 선택 epoch를 사용한다. 길이가 다른 한계가 남는다. 기존 결합 비중과 새 집계 선택에 같은 내부 검증 자료를 사용했다. 바깥 사람은 제외했지만 반복 탐색한 개발자료이므로 독립 최종 검증은 아니다.
- 신경망 추가 학습은 없고 보호된 최종 평가자료·LJMU를 사용하지 않았다. 기존 GPU 작업은 조회·변경하지 않았다.

## 점수 대신 점수 구간의 확률을 예측할 수 있는가

가능성은 있다. 다만 **현재 연속 점수를 구간으로 잘라 표시하는 것**과 **구간별 확률을 학습하는 것**은 다르다. 이번에는 전자만 계산했으며 확률 모델을 새로 학습하지 않았다.

기존처럼 `[70,80)`, `[80,90)`의 고정 10점 구간을 사용하고 0~100으로 강제 제한하지 않았다. 사람 동일 비중으로 계산한 결과는 다음과 같다.

| 조건 | 정확히 같은 구간 | 정확한 구간 또는 바로 옆 구간 | 두 구간 이상 차이 |
|---|---:|---:|---:|
| 기존 평균·좌우 차이 결합 | 43.04% | 91.77% | 8.23% |
| 이번 내부 선택 집계 | 43.09% | 91.63% | 8.37% |

‘바로 옆 구간’까지 맞힌 비율은 ‘점수 오차 10점 이내’와 다르다. 예를 들어 70.1과 89.9는 옆 구간이지만 19.8점 차이다. 이 표는 개인별 확률의 정확도나 보장된 예측 구간도 아니다. 구간을 넓히면 정확도가 올라가는 효과를 모델 개선으로 설명하지 않는다.

후속 후보는 기존 CNN·STT 점수, 모델 사이의 불일치, 구간 예측의 퍼짐을 입력으로 받아 **점수 순서를 고려하는 작은 확률 예측부**를 CPU에서 학습하는 방식이다. 정답은 실제 GDI의 고정 구간이며, 학습 사람 내부에서 만들어진 검증 예측으로만 학습·선택·확률 보정을 한다. 바깥 사람으로는 평가만 한다.

순서형 회귀는 ‘60 이상인가, 70 이상인가, 80 이상인가’를 연결해 학습하여 구간의 순서를 반영하는 접근이다. CORAL·CORN은 이런 순서 일관성을 갖춘 신경망 출력부를 제공한다. 원래 얼굴 사진의 나이 예측 등에서 검토된 방법이며, 우리 GDI에서 더 정확해진다는 근거는 아직 없다. 우선 작은 CPU 예측부를 비교하고, 필요하면 CNN·STT의 마지막 출력부에 같은 원리를 적용하는 갈래를 검토할 수 있다. [연구자 공식 구현·설명](https://raschka-research-group.github.io/coral-pytorch/).

‘70% 확률’이라고 출력한 사례가 실제로 약 70% 맞는지 따로 확인해야 한다. 이미지·문서 분류 실험에서 신경망 확률이 실제 정답률과 어긋나고 보정이 필요할 수 있다는 결과가 있으며, 이는 현재의 GDI 점수 선형 보정과 다른 문제다. 정확 구간 일치율뿐 아니라 Brier 점수·로그 손실처럼 확률 자체를 평가하는 지표와 실제 정답률을 함께 볼 필요가 있다. [Guo 등, 2017](https://proceedings.mlr.press/v70/guo17a.html). 확률을 붙이는 것만으로 외부 자료의 입력 분포 차이나 고득점 과소예측이 해결되지는 않는다.
