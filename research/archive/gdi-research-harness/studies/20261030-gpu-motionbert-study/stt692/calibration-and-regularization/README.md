# 보정 비교와 사람 비중·과적합 억제 실험

기존 STT 학습을 유지하면서, 점수 보정만 바꿨을 때의 효과와 학습 방식 변경의 효과를 따로 확인하고자 한다. **CPU 보정 비교와 GPU 실행 묶음의 로컬 검증을 완료했다.** 서버 전송·GPU 제출·새 실제 GDI 학습은 하지 않았다. 네 조건 각각의 가상 25개 학습, 저장·재개, 검증자료 격리, 실제 자료의 비중 검사, 독립 압축해제 실행·손상 거부가 통과했다. [GPU 준비 검증](gpu/verification.json).

## CPU에서 확인한 보정 효과

두 모델 모두 첫 바깥 분할(fold0)을 제외한554명·846기록의 내부 검증 예측을 사용했다. 각 내부 분할에서 그 사람들을 제외하고 학습한 모델의 예측이다. 기존 내부 검증으로 이미 선택된 epoch를 고정했다. 여러 구간 STT는115epoch, 좌우 결합 STT는94epoch이며, 보정법마다 epoch를 다시 고르지 않았다. 전체692명의 최종OOF가 아니고, epoch 선택에 사용한 내부 자료를 다시 보는 탐색 진단이다. 모델 간 최종 순위나 독립 검증 결과로 해석하지 않는다.

| 보정 방식 | 여러 구간 STT MAE | 좌우 결합 STT MAE |
|---|---:|---:|
| 보정 없음 | 7.072660 | 7.059693 |
| 절편만 보정 | 7.053719 | 7.086518 |
| 기울기를1 쪽으로 수축, λ=1 | 7.003566 | 7.016017 |
| 더 강한 수축, λ=4: 민감도 확인 | 7.023027 | 7.048290 |
| 자유로운 직선 보정: 사람 비중 대조군 | 7.040783 | 7.028263 |

위 표는 보정계수 계산과 평가 모두 사람에게 같은 비중을 준 결과다. 사람의 여러 기록은 그 사람의 비중을 나누고, 두 다리도 같은 비중으로 처리한다. 원래 기록별OLS 보정 재현값은 여러 구간7.024704, 좌우 결합7.023007이다. λ=1의 사람 비중 보정과 비교하면 각각0.021137점·0.006990점 차이다. 현재 결과는 작은 개선 가능성이며 보정만으로 큰 돌파구가 생겼다고 판단하지 않는다.

비중 효과를 분리하기 위해 같은5개 방법을 기록 동일 비중으로도 계산했다. 기록 비중 λ=1은7.001458·7.013132로, 사람 비중보다 오히려 약0.002~0.003점 작다. **사람 비중이 검증 기준과 일치한다는 것과 성능이 좋아졌다는 것은 다르다.** 이 결과만으로 학습 손실의 사람 비중 효과도 판단할 수 없다.

절편은 학습자료의 가중 평균 잔차로 구한다. 기울기 수축은 `학습 가중 MSE + λ × 학습 예측 분산 × (기울기−1)²`를 최소화한다. λ=1이면 같은 비중의 자유로운OLS 기울기와1의 중간값이 되고, λ=4이면OLS 기울기의1로부터 벗어난 정도가1/5로 줄어든다. 임의 상·하한으로 잘라내는 방식이 아니다. λ=1을 기본 진단,4를 민감도로 미리 지정했고, 내부 검증에서 최적λ를 찾았다고 주장하지 않는다. 절편과 수축 보정은MSE 목적을 통일해 형태 차이를 확인하며MAE 목적 보정은 이번 범위에 포함하지 않았다.

실제 λ=1 기울기는 여러 구간1.0992–1.1309, 좌우 결합1.0865–1.1709다. 보정계수에는 해당 내부 학습 사람의 예측과 정답만 사용했다. 검증 사람의 정답을 보정계수에 넣지 않았고 바깥 평가 예측·보호된 최종 평가자료는 열지 않았다.

검산: 서버 원시 예측8개의SHA256, 같은 개발자료 지문, 학습/검증 사람·정답 배열 지문과 순서, 사람 겹침 없음, 사람별 총비중 동일, 검증 기록별 한 번씩 예측을 확인했다. 다른 계산법인 확장 가중 최소제곱으로 보정계수를 검산했으며 최대차이7.82e-14다. 기존 보정 MAE 재현 차이는1.25e-14 미만이다. 사람의 동일 기록 복제에 대한 비중 불변성과 상수 예측 예외도 검사했다. 새 모델 최적화는0회다.

근거: [비교 결과](cpu/comparison.json), [계산 코드](cpu/compare.py), [서버 읽기 전용 회수](cpu/export_readonly.py). 결과 파일에는 각 내부 분할의 기울기·절편·MAE·RMSE·편향도 남겼다.

## GPU 후속 준비

과적합 징후가 큰 좌우 결합STT를 고정하고 네 조건을 분리한다. 같은692명·1,061기록·11,261구간,124프레임, 사람5분할, 내부4분할 선택,33,183개 파라미터, 학습률·배치·난수 초기값을 유지한다.

| 실행 이름 | 학습 손실의 비중 | 최적화 |
|---|---|---|
| baseline | 기록 동일 비중 | 기존Adam, 감쇠0 |
| person | 사람 동일 비중 | 기존Adam, 감쇠0 |
| decay | 기록 동일 비중 | AdamW, 감쇠0.01 |
| person_decay | 사람 동일 비중 | AdamW, 감쇠0.01 |

사람 비중은 **사람→그 사람의 기록→그 기록의 구간→좌우** 순으로 나눈다. 전체 가중치 평균을1로 유지해 학습률의 전체 크기 변화와 섞이지 않게 한다. 같은 모든 구간과 순서를 유지하며, 사람 균형 배치 샘플러로 바꾸지는 않는다. AdamW 감쇠0.01은 효과 확인용 고정 후보로 모든 학습 파라미터에 적용한다. 드롭아웃·모델 크기·정답·보정법을 함께 변경하지 않는다.

**GPU 네 조건의 출력 보정은 기존 학습 기록OLS로 통일한다.** 이번에는 학습 손실의 사람 비중과 가중치 감쇠 효과만 분리하기 위해서다. CPU의 사람 비중 수축 보정을 동시에 채택하지 않는다. 원시/보정 지표는 모두 저장하고, 최종 적용할 보정법은 이후 별도로 검증한다.

예상 GPU는 1개다. 최대 메모리는 기존 좌우 결합 파일럿의 188MiB를 참고해 1GiB 이내를 예상하지만, 새 묶음의 GPU 실측 전 추정이다. 네 조건의 3epoch 파일럿을 순차 실행하도록 준비했다. 시간은 수분~수십분 예상, Slurm 상한은 1시간이며 실측으로 갱신한다. 파일럿 후 본 학습 자동 실행은 없다. 새 초기값·새 폴더를 사용하고 기존 32844 확보·다른 실험·자동 감시 등록부는 변경하지 않는다. 제출 시에만 여유 GPU 1개 이상을 확인하고 이 채팅 등록부에 실제 작업 번호를 등록한다.

```bash
# 아래는 이후 GPU 실행을 승인받아 전송·할당한 뒤 사용할 준비 명령이다.
mkdir -p logs
sbatch submit.slurm
# pilot_all.py가 baseline -> person -> decay -> person_decay 순서로 실행한다.
```

묶음: [GPU ZIP](gpu/gdi-stt692-person-regularization.zip). `run.py`는 필수 `--variant`와 변형별 출력 하위 폴더로 결과 혼합을 막고, 체크포인트에 학습 조건을 저장한다. 원본 묶음은 지문으로 보존한다. 로컬 검사에는 실제 25개 학습 부분집합의 사람 비중 합, 불균등 구간·반복 사람의 가상 손실, 네 조건의 동일 초기값, 가상 학습 저장·재개, 검증자료 변경 시 학습 불변, 각 조건의 가상 25개 내부/바깥 학습과 최종 평가 격리, 독립 ZIP 실행·손상 거부가 포함된다. 실제 GDI를 CPU로 학습하지 않는다.

## 최신 연구에서 참고할 방향 — 조사일2026-10-31

**우선 검토 후보는 보행을 복원·예측하는 사전학습이다.** 아래는 조사 결과와 적용 제안이며 구현·실행·채택 완료를 뜻하지 않는다.

- **PathoFM, 2026-05 프리프린트:** 척수손상 230명의 생체역학 시계열에서 구간 가림 복원·미래 예측·같은 사람의 다른 구간을 이용한 복원을 결합했다. 사람별 균형 배치, 학습자료 정규화, 고정 특징 추출기와 작은 예측부를 사용하고 검증 10명·평가 10명을 분리했다. 우리에게는 2D 보행 좌표의 일부 시간을 가리고 복원하거나 다음 구간을 예측한 뒤 GDI를 학습하는 방식이 참고된다. 원 논문의 각도·모멘트 등 입력과 우리 2D 좌표는 다르며 GDI 개선 결과가 아니다. 평가 사람이 적고 프리프린트이므로 결과를 확정 근거로 쓰지 않는다. 공개 실행 코드·가중치의 확보는 이번에 확인하지 않았다. [원문 §4–6](https://arxiv.org/html/2605.26194v1).
- **Utility of synthetic musculoskeletal gaits, Nature Communications, 2025-07:** 근골격 시뮬레이션으로 만든 보행을 2D로 투영해 촬영 방향과 잡음을 바꾸고, 보행지표 예측 및 사전학습 후 임상 과제로 전이했다. 치매·뇌성마비 자료의 서로 다른 촬영 조건에서 평가했다. 우리에게는 촬영 조건에 둔감한 특징을 미리 배우는 방향이 참고된다. 임의 좌표 변형에 GDI를 붙이는 방법이 아니며 합성 GDI 정답이 저절로 생기지는 않는다. [원 논문](https://www.nature.com/articles/s41467-025-61292-1), [연구진 설명](https://research.ibm.com/publications/utility-of-synthetic-musculoskeletal-gaits-for-generalizable-healthcare-applications), [사용된 시뮬레이션 코드](https://github.com/namjohn10/GenerativeGaitNet). 저장소 존재는 확인했으나 설치·생성·우리 자료 전이는 미실행이다.
- **Gait foundation model, 2026-03 프리프린트:** 성인 3,414명의 깊이카메라 3D 골격·다섯 운동 과제를 이용해 여러 건강 특성을 예측했다. 소아 GDI 하나에서 성인의 여러 과제로 옮기는 방향에 참고가 되지만, 단일 RGB 입력이나 TUG/SPPB 전이 성능의 입증은 아니다. 공개 가중치·자료의 실제 확보는 미확인이다. [원문](https://arxiv.org/abs/2603.25283).

우리 자료로 먼저 시도한다면, 학습 사람만으로 가림 복원/미래 예측 사전학습 → GDI 예측부 학습 순서가 가장 작은 실험이다. 이때도 내부 검증 사람·바깥 평가 사람의 좌표를 사전학습에 넣지 않고, 중첩 구간이 분할을 넘지 않게 해야 한다. 현재 준비한 비중·감쇠 실험에 사전학습까지 합치지 않고 별도 갈래로 둔다.
