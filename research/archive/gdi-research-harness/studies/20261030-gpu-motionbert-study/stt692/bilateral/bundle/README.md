# 좌우를 함께 보는 STT

사용자 승인: 기존 두 STT 작업은 유지하고, 여유 GPU를1개 이상 남긴 상태에서 추가1개로 파일럿·본 학습을 진행한다. 기존 모델의 다리별 독립 처리에서 벗어나, 같은 구간의 두 다리를 함께 보고 공통 GDI와 좌우 차이를 학습해 보고자 한다. 아직 성능 개선은 확인하지 않았다.

입력·정답은 여러 구간 STT와 완전히 같은692명·1,061기록·11,261구간이다. 2D xy 좌표이며3D 좌표가 아니다. 두 다리는 공식 STT의 같은 특징 추출기를 통과한다. 두 특징의 평균과 차이로 공통 점수와 좌우 차이를 만들고, 왼쪽=공통+차이·오른쪽=공통−차이로 출력한다. 좌우 입력을 바꾸면 출력도 바뀌도록 구조적으로 제한한다. 다리쌍64개를 한 배치로 처리해 기존 다리128개의 규모를 유지한다. 모델 구조와 배치의 좌우 결합을 함께 바꾸는 실험이며, 공식 STT 그대로의 재현은 아니다.

기존 사람5분할, 내부4분할 epoch 선택, 최대200epoch, 학습자료만의 정답 정규화·OLS 보정, 구간 수 역수 손실 가중치, 기록별 구간 평균과 사람 동일 비중 MAE를 유지한다. 본 학습은 새 초기값에서25개 학습을 진행하며 파일럿 가중치를 재사용하지 않는다. 바깥 평가자료로 설정을 고르지 않고 보호된 최종 평가자료를 열지 않는다. 기존 OOF의 오류 분석은 탐색 근거이며 독립 최종 검증이 아니다.

CPU에서 구조적 좌우 교환·저장/재개·내부선택·평가자료 격리 검사를 하고 GPU에서 같은 검사와3epoch 파일럿을 실행한다. 결과·모델·입력 지문 및 저장 모델 재추론을 검산한 뒤에만 본 학습 승인 파일을 전달한다. 기존 파일럿의 CPU float32 차이0.0001점 기준을 유지하고, 실패는 그대로 남긴다. GPU 메모리는1GiB 미만, 시간은수시간 수준을 예상하지만 파일럿으로 다시 측정한다. 새 작업은 최대12시간이며 종료 후 반환한다. 기존24시간 확보 작업32844는 변경하지 않는다.

다른 탐색 갈래인 `mil_pool.py`는 기록 안의 구간별 비중을 학습하는 구조의 CPU 시제품이다. 가상 자료로 구간 순서 불변·빈 구간 제외만 검사한다. 실제 GDI 학습이나 성능 비교를 마친 모델이 아니다. 이번 GPU 학습에는 연결하지 않아 좌우 결합 효과와 섞지 않는다.
