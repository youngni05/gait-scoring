# 구간별 비중 학습과 단순 평균 비교

같은 기록의 여러 보행 구간을 무조건 같은 비중으로 평균하는 대신, GDI 예측에 도움이 되는 구간의 비중을 학습해 보고자 한다. 현재 학습은 유지하고 별도 GPU 파일럿을 실행할 수 있는 묶음을 준비하는 범위다. 아직 서버 전송·GPU 배정·실제 파일럿·본 학습을 진행하지 않았다.

두 모델 모두 같은 STT로 각 구간의 움직임 특징과 좌우 GDI를 예측한다. `mean`은 구간 점수의 단순 평균, `attention`은 움직임 특징에서 계산한 비중을 곱한 평균이다. 비중은 각 기록·다리 안에서 합이1이며, 비중 계산기를0으로 초기화해 두 모델이 같은 단순 평균 예측에서 출발한다. 특징 추출기·점수 예측부 초기값도 같다. 좌우 결합 모델은 사용하지 않아 두 변화가 섞이지 않게 한다.

두 모델은 모두 **기록의 최종 점수 오차**로 학습한다. 이전 여러 구간 STT는 구간별 점수 오차를 학습했으므로 기존 STT와의 차이에는 학습 방식 변화도 포함된다. 비중 학습의 직접 효과는 이번 `mean` 대조군과 `attention` 사이에서 확인한다. 기존 여러 구간CNN6.8667점·단일STT8.5691점은 같은 사람 평가의 참고 기준이며 이 비교만으로 비중의 효과를 확정하지 않는다.

## 동일하게 유지하는 조건

- 기존692명·1,061기록·11,261구간 파일을 SHA256까지 그대로 사용한다. 프레임124개·다리별4관절xy·31프레임 간격 및4개 대체 구간도 같다. 구간 추가·제외·랜덤 추출을 하지 않는다.
- 사람별5분할과 기록·구간 대응을 유지한다. 기록8개를 한 배치로 처리하고 각 기록의 모든 구간을 함께 사용한다. 구간 수가 많은 기록에도 학습 손실에서 같은 비중을 준다. 평가에서는 각 사람에게 같은 비중을 준다.
- Adam·학습률0.0003·최소0.00008·40epoch cosine 주기·최대200epoch·seed20261028을 두 모델에 동일하게 적용한다. 내부4분할 검증으로 종료epoch를 각각 선택하고 바깥분할5개로 평가한다. 본 학습 시 모델별25개, 합계50개 학습이다.
- 정답 min/max와 출력 보정 기울기·절편은 해당 학습자료에서만 계산한다. 같은 사람·기록의 구간이 학습과 평가에 나뉘지 않는다. 보호된 최종 평가자료를 사용하지 않는다.

구간 수가 다른 기록은 빈 칸을 채워 한 배치에 넣지만 빈 칸은 특징 추출과 가중치 계산에서 제외한다. 한 구간만 있는 기록은 가중치1로 처리하며, 구간이 없는 기록은 오류로 거부한다. 구간 순서는 최종 점수에 영향을 주지 않아야 한다. 기록 간 구간을 섞거나 한 기록의 가중치를 다른 기록에 적용하지 않는다.

## 확인과 GPU 실행

CPU에서는 가상 자료로 평균과 초기 비중 모델의 일치, 실제 비중 변화, 구간 순서·빈 칸·좌우 연결·기록 간 독립성, 저장/재개, 검증자료 변경 시 학습 불변, 두 모델 각각25개 가상 학습의 평가 격리를 검사한다. 실제 데이터에서는 모든 구간의 소속·사람 분할·입력 전달만 검사하며 실제 GDI로 CPU 최적화하지 않는다. 독립 압축해제 실행과 파일 손상 거부도 확인한다.

GPU 파일럿은1개 GPU에서 `mean`→`attention` 순으로3epoch씩 진행한다. 학습416명, 내부검증138명, 바깥평가138명이며 바깥평가 예측은 파일럿에서 만들지 않는다. 같은 초기값·학습 순서·업데이트 횟수로 비교하고, 시간·최대GPU메모리·가중치 분포·저장 모델 재추론을 기록한다. 메모리는 수백MiB~약1GiB 수준으로 예상하나 실제 GPU 확인 전 추정이다. Slurm 상한1시간, 실행 제한50분이며 완료 후 반환한다. 파일럿이 끝나도 본 학습을 자동으로 시작하지 않는다.

향후 실행할 때 먼저 기존 작업과 정상 가용GPU를 확인해 최소1개를 남기고, 이 폴더만 별도 경로로 전송한다. 현재 작업32844·32846·32850을 취소·수정하거나24시간 확보를 해제하지 않는다. 제출하는 채팅은 실제 작업ID를 감시 등록부에 추가해야 하며 파일럿 전용 `pilot_complete`·`pilot_failed` 상태와 산출물에 맞는 감시 절차를 등록한다. 현재 미제출 묶음을 진행 중인 학습으로 등록하지 않는다.

실행 후 `runs/pilot/mean`·`runs/pilot/attention`에 점수와 가중치, `checks/replay-*`에 재추론 검산, `runs/pilot/pair_summary.json`에 두 모델의 운영 검증이 저장된다. `runs/pilot-review.tar.gz`를 회수·SHA256 대조 후 같은 묶음의 `review_pilot.py`로 CPU 재추론도 확인한다. 점수 허용차0.0001점, 가중치 허용차0.000001이며 실패는 기록하고 허용차를 임의로 바꾸지 않는다.

매epoch 원시 예측·학습자료 보정계수·사람별MAE를 저장한다. 최종 평가와 파일럿에는 구간별 가중치·점수·시작프레임을 기록해 특정 구간에 비중이 몰리는지 확인한다. 높은 비중은 예측 모델이 활용한 정도이며, 실제 가림 정도나 임상적으로 중요한 순간을 검증한 표시가 아니다. 파일럿3epoch의 오차를 최종 성능이나 모델 선정 근거로 사용하지 않는다.
