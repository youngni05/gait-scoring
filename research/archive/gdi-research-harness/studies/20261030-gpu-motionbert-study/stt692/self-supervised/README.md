## 무엇을 학습하는가

입력은 기존 692명·1,061기록·11,261구간의 2D 좌표다. 한 구간은 124프레임이며, 좌우를 별도 예제로 처리하고 발목·무릎·엉덩이·엄지발가락의 xy를 본다. 기존 좌표·사람 분할·기록별 구간 평균·학습자료 OLS 보정·사람별 동일 비중 MAE를 그대로 유지한다. 입력 SHA256은 `7aa3d05af0533d63e612f4adae95c33cae123add74b83aed44bd6cae47d9ef26`이다.

| 단계 | 입력과 정답 | 미리 고정한 조건 |
|---|---|---|
| 가림 복원 | 연속 31프레임의 모든 관절 xy를 0으로 가린 입력 → 원래 좌표 | 위치는 예제·epoch마다 재현 가능한 난수로 선택, 가린 부분만 MSE |
| 미래 예측 | 앞 93프레임, 마지막 31프레임은 0 → 마지막 31프레임의 원래 좌표 | 숨긴 미래 좌표는 특징 추출부에 전달하지 않음 |
| 사전학습 | 위 두 손실의 0.5:0.5 평균 | Adam 0.0003, 배치128, 25epoch, 내부 검증으로 길이 선택 안 함 |
| GDI 미세조정 | 기존 전체 124프레임 → 좌우 GDI | 기존 STT와 같은 Adam·배치128·최대200epoch·내부 종료epoch 선택 |

공간·시간 특징 추출부의 초기값은 기존 STT와 같은 seed로 만든다. 사전학습 동안 기존 GDI 출력부와 시간 평균층은 학습하지 않고, 작은 복원 출력부 두 개를 붙인다. 사전학습 후 복원 출력부는 버리고 공간·시간 특징 추출부만 이전한다. GDI 출력부와 시간 평균층은 기존 seed의 초기값을 유지하며 미세조정에서는 전체 STT를 학습한다. 최종 GDI 모델 파라미터는 기존과 같은 27,022개다.

사전학습도 기존 STT의 기록별 총비중을 유지한다. 사람 비중 변경·AdamW·새 보정은 이번 갈래에 섞지 않는다. 기존 좌표의 기록별 전처리는 유지하며 전체 자료에서 새 평균·표준편차를 구하지 않는다. 이미 전처리된 창 안에서의 미래 복원 과제이므로 실시간 인과적 보행 예측이나 실제 가림 측정 성능을 검증한 것은 아니다. 사전학습으로 계산량이 늘어나므로 계산량까지 동일한 비교도 아니다.

## 검증 사람이 섞이지 않게 하는 방법

바깥 분할5개 각각에 대해 내부 학습4회와 최종 재학습1회를 수행한다. **25개 학습마다 자기 학습 사람으로만 사전학습을 처음부터 수행한다.** 바깥 학습 사람 전체로 사전학습한 모델을 내부 검증에 재사용하지 않는다. 내부 검증 사람과 바깥 평가 사람의 좌표는 비지도 사전학습에도 들어가지 않는다. 사전학습 함수에는 GDI 정답 인자 자체가 없다.

내부 검증은 기존처럼 GDI 미세조정 종료epoch만 선택한다. 바깥 평가자료는 최종 예측에서만 사용하며, 보호된 최종 평가자료는 열지 않는다. 사람 ID·구간 소유 기록·좌표 지문·사전학습 설정을 매 학습에 저장하고, 다른 사람 자료로 캐시를 재사용하면 거부한다. 사전학습 체크포인트25개와 GDI 체크포인트25개는 별도 단계다. 감시의 `expected_fits=25`는 GDI 학습 수다.

## 검사와 실행

CPU 가상 자료로 가림·미래 입력 불변성, 특징 추출부만 이전, 새 GDI 출력부 유지, 저장·재개, 검증 입력·정답을 바꿔도 학습 모델이 같음, 바깥 평가를 바꿔도 학습·epoch 선택이 같음을 검사한다. 가상25개 학습과 실제 좌표의 분할·구간 대응 검사, 독립 ZIP 실행·손상 거부도 실행한다. 실제 GDI 학습은 GPU에서만 한다.

파일럿은 같은 학습416명·내부검증138명·제외한 바깥138명으로 **사전학습3epoch + GDI3epoch**를 수행한다. GPU와 CPU에서 저장 모델을 다시 실행하고 원시·보정 점수와 사전학습 복원 출력의 최대차이 `0.0001` 이내, 단계·사람·지문·학습자료 한정 보정을 확인한다. 고정 검사를 모두 통과한 경우에만 `control/approve-main.json`에 근거를 기록하고 본 학습25개를 시작한다. 실패하면 그 상태와 로그를 남기고 멈춘다. 파일럿 성능으로 새 조건을 선택하지 않는다. 본 학습은 파일럿 체크포인트를 재사용하지 않는다.

GPU1개·CPU4개·RAM12GiB, 새 할당은12시간 상한이다. GPU 메모리는 약1GiB 이하, 전체는 수시간으로 예상하되 실제 시간은 파일럿 이후 기록한다. 사용자 후속 결정으로 빈 GPU1개 유지 조건은 해제했다. 기존 작업과 확보한32844는 취소하거나 반환하지 않는다. 기존 할당을 재사용하면 원래 종료시각이 그대로 적용된다.

완료 검산에서는 `run.py audit_fit`과 `pretrain.audit`로25쌍의 학습과 매epoch GDI 예측·보정을 확인한다. 사전학습25개 체크포인트·probe와 바깥 GDI5개 모델을 회수해 CPU 재추론한다. 전체 OOF를 같은 사람 비중의 여러 구간 STT·여러 구간 CNN·단일 구간 STT와 비교한다. 보정 전 결과와 기울기 변화도 함께 본다. 감소한 사전학습 손실만으로 GDI 개선을 주장하지 않는다.
