# 695명 자료 확대: Ridge와 GPU 부분학습 결과

2026-10-30. 사용자가 확대 Ridge 다음 같은 조건의 MotionBERT 부분학습을 시작하도록 요청했다. **CPU Ridge 비교와 GPU 15작업·3,000회 갱신을 완료했고, 내려받은 예측·집계의 독립 검산을 마쳤다. 마지막 Transformer 단계까지 학습한 모델은 같은695명 조건의 Ridge보다 평균 절대 오차를 약2.02% 줄였다.**

## 실제 GPU 결과와 Ridge 대비 변화

세 방법 모두 확대 Ridge 초기값에서 시작했다. 같은695명·1,064기록의 앞124프레임을 평가했고, 각fold에서는 학습556명·평가139명을 분리했다. 아래 감소량은 확대 Ridge 오차에서 해당 방법의 오차를 뺀 값이므로 양수가 개선이다.

| 방법 | 사람별 평균 절대 오차 | Ridge 대비 감소량 | 상대 오차 감소 |
|---|---:|---:|---:|
| 확대 자료의 고정 MotionBERT+Ridge | 8.526630 | 기준 | 기준 |
| 출력부만 학습 | 8.528939 | -0.002309 | -0.03% |
| 마지막 특징 변환부도 학습 | 8.614338 | -0.087707 | -1.03% |
| 마지막 Transformer 단계까지 학습 | 8.354702 | 0.171928 | 2.02% |

last_stage의 개선량은 사람 재표집10,000회의 탐색적95% 범위0.0358~0.3070점으로0을 포함하지 않았다. 5fold 중4개에서 평균 오차가 줄었고, 사람별로는356명 개선·339명 악화였다. 출력부만 학습한 대조보다도0.1742점 낮았다(탐색적95% 범위0.0411~0.3074). 이번 고정 설정에서 작은 개선 신호를 확인했지만 모든 사람에게 개선된 것은 아니다.

| 평가 집단 | 확대 Ridge | last_stage | 오차 감소 |
|---|---:|---:|---:|
| 기존175명 | 8.294691 | 8.068087 | 0.226604 |
| 추가520명 | 8.604687 | 8.451160 | 0.153527 |
| 전체695명 | 8.526630 | 8.354702 | 0.171928 |

사람별 좌우·기록 평균 예측의 표준편차는5.86→6.87점, 전체 개별 예측 범위는51.36~88.76→48.03~91.39점으로 넓어졌다. 예측의 중앙 집중이 일부 풀린 모습이지만 이것만으로 양끝 정확도가 충분하다고 해석하지 않는다.

10점 고정 구간의 정확 일치율은35.81%→35.22%로 낮아졌다. 한 구간 이내 비율은82.26%→83.92%로 높아졌고, 두 구간 이상 오류는17.74%→16.08%로 줄었다. 연속 GDI 오차의 개선과 정확한 구간 표시의 개선을 구분한다. 구간은 floor(GDI/10)이며 임상 등급이나0~100 능력 점수가 아니다.

자료 확대 전의 작은 Ridge를 **동일695명 평가 대상**에게 적용한 오차는9.092874점이었다. 그 기준과 비교하면8.354702점까지 총0.738172점, 약8.12% 감소했다. 이는 자료 확대와 부분학습의 합산 변화이며, 부분학습만의 효과는2.02%다. 이전175명만 평가한8.275834점과 직접 빼지 않는다.

## GPU 회수 검산과 해석 범위

- 서버 로그: DIS01/Slurm29918, 실제 학습·집계15:11:19~15:31:00 KST,19분41초. 앞선26초의 사전 검사는 별도다.
- 세 방법×5fold×200회 갱신을 완료했다. 원격 설정·실행 코드·manifest가 준비본과 일치했고,15개 예측파일 지문·작업 식별자·기록 범위·정상 종료 기록을 확인했다.
- 각 방법에서1,064기록을 평가fold로 정확히 한 번씩 예측했다. 학습556명·평가139명의 중복은 없고 기존/추가 집단도 분리된 원본 연결을 유지했다.
- 사람별 평균과 별도 사람 가중 합으로 지표를 재계산했다. 서버 집계·재표집 범위를 재현했고 확대 Ridge 예측은 로컬 CPU 저장본과 정확히 일치했다.
- 서버가 보고한 체크포인트15개의 SHA-256을 회수했다. 체크포인트 본체를 내려받아 재추론하거나 가중치 변경 범위를 독립 검산한 것은 아니다. frozen_unchanged는 서버 실행기의 검사 기록이다.
- 개발자료 반복 탐색·시드1개·고정200회 갱신의 결과다. 이 재표집 범위는 다른 시드/새 학습자료에서 생기는 모든 변동을 포함하지 않는다. 최종예약223명을 사용한 독립 평가, 임상 타당성, 고령자 촬영, 앞뒤 안정성 결과는 아니다.
- 최신 사용자 요청에 따라 이번에는 기존 Ridge와의 결과 확인에 집중했다. 수정 중인 공용 방향성 문서는 변경하지 않았고, 새 CNN 결합이나 학습을 실행하지 않았다.

검산 코드는 `verify_gpu_results.py`, 근거는 `analysis/gpu/verification.json`이다. 같은 폴더의 `summary.json`, `metrics.csv`, `fold_metrics.csv`, `score_bands.csv`에 전체·기존/추가 집단·분할·점수대 결과를 남겼다. 세 `*_oof.npz`와 `*_provenance.json`은 원본 행 순서와 사람·영상·fold·좌우 대응, 서버 모델 지문을 함께 제공한다.

## 목적과 분할

자료를 늘리는 것 자체가 도움이 되는지 먼저 확인한다. 기존 학습175명·203기록과 추가 개발520명·861기록, 합계695명·1,064기록을 사용한다. 기존37/38명·최종예약223명은 포함하지 않았다. 원본·이전 실험은 보존한다.

기존175명의5fold를 유지하고 추가520명을 seed20261030으로104명씩 배정했다. 각fold 평가139명(기존35+새104명)은 두 모델에서 동일하다. 작은 모델은 기존 집단의140명만, 확대 모델은 기존140+새416=556명으로 학습한다. 같은 사람의 다른 기록은 같은fold에 둔다.

입력은 기존과 같은 고정 MotionBERT-Lite의512특징이다. 추가 자료는 앞124프레임 입력·특징이 준비돼 있으므로 이번 비교는 앞 구간만 대상으로 한다. 뒤 구간을 복제하거나 앞뒤 안정성 결과를 만들어내지 않았다. Ridge alpha1을 고정했고 StandardScaler와 Ridge는 각 모델의 학습분에만 적합했다. 새 학습률·규제 탐색은 하지 않았다.

## 실제 CPU 결과

평가 사람의 좌우·기록 오차를 먼저 평균한 뒤 사람별 동일 가중 평균을 냈다. 단위는 GDI점이며 작을수록 좋다.

| 같은 평가 사람 | 기존140명 학습 Ridge | 확대556명 학습 Ridge | 오차 감소 |
|---|---:|---:|---:|
| 기존175명의 교차검증 예측 | 8.2758 | 8.2947 | -0.0189 |
| 추가520명의 교차검증 예측 | 9.3678 | 8.6047 | 0.7632 |
| 전체695명의 교차검증 예측 | 9.0929 | 8.5266 | 0.5662 |

추가520명에서는322명 개선·198명 악화했고, 감소량의 사람 재표집95% 범위는0.5350~0.9959점이다. 전체695명에서는409명 개선·286명 악화, 범위0.3657~0.7645점이다. 기존175명에서는87명 개선·88명 악화, 범위-0.4221~0.3903점으로 뚜렷한 변화가 없다.

자료를 늘린 효과가 추가 개발 집단에서 관측됐다. 모든 사람에게 좋아진 결과는 아니며, 같은 배포처의 반복 탐색 개발자료에서 얻은 결과다. 최종 독립 성능·고령자 실사용 성능으로 표현하지 않는다. 과거의175명 전체 학습 모델이 새520명에 보인9.269점과는 학습 인원·모델이 다르므로 직접 감소량을 계산하지 않는다.

## 검증

- 기존묶음·추가특징·정답 연결 지문, 추가861개 원시 입력의 지문·형태·연속 프레임을 확인했다. 기존/새 집단 사람·영상 중복은0이다.
- 기존fold를 그대로 유지했고 확대fold별 학습556명·평가139명의 분리와 기존/새 집단 인원을 확인했다. label이나 성능을 기준으로 분할을 다시 선택하지 않았다.
- CPU에서 총10개 Ridge를 적합했다. sklearn SVD 해와 별도 정규방정식 예측을 비교했다. 기존175명의 기준 예측은 최대1.42e-13점 차이로 재현됐다.
- 저장된 확대 Ridge 계수·표준화로 예측을 다시 계산했고, 사람별 가중 합으로 전체·하위집단 MAE를 독립 재계산했다. 지표 차이는0이다.
- GPU 실행 코드의 로컬 CPU 재현 검사에서 기존/새 집단 각fold1건씩 총10건 모두 캐시 특징 기반 초기 점수와 차이0이었다. 가상4프레임 입력의 세 학습 범위·중단재개 검사도 통과했다. 실제 GPU 검사·부분학습 완료를 뜻하지 않는다.
- 최종ZIP 내부 지문·무결성과 Python3.8 문법을 검사했다. Windows에서 Git Bash 문법검사 시도는 호스트 접근 제한(NtCreateDirectoryObject)으로 실행되지 않았다. 서버에서는 `bash -n launch.sh`를 먼저 수행하도록 안내한다.

## GPU 실행 조건과 준비 당시 기록

이번에는 각fold의 **확대 Ridge 초기값**에서 head_only, tail, last_stage를 비교한다. 세 방법의 학습·평가 대상과 초기값을 동일하게 맞춘다. seed20261028, 배치32, 200회 갱신, 출력부lr0.0001·본체lr0.00001, AdamW·weight_decay0·dropout비활성화를 유지한다. 자료가 늘었으므로 같은200회 갱신에서 전체 자료를 반복해 보는 횟수는 이전보다 적다. 최적 학습시간을 확인한 실험은 아니다.

`gdi-expanded695.zip`을 서버의 별도 `gdi-motionbert-expanded695-20261030` 폴더에 풀었다. `launch.sh`가 Slurm할당 안에서 초기재현(기술기준1e-4점) → 배치32 가상점검 → 실제15작업 → 집계를 실행했다. 확대 자료 CUDA 초기재현 최대 오차는2.8485e-5점으로 기준을 통과했고, 배치32 가상 재개 가중치 차이는 세 방법 모두0이었다.

이전 작업29918과 tmux gdi-gpu는 사용자의 재접속 출력에서 DIS01 실행 상태로 확인해 재사용했다. 위 학습 완료 시각 이후의 원격 할당 유지 여부는 별도로 확인하지 않았다.
