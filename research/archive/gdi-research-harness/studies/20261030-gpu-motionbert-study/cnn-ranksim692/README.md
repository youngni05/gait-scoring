보정 전 MSE의 전체/고득점 MAE는 7.276794/12.790320점, RankSim은 7.114621/11.732814점이다. 보정 후 결과를 주비교로 두고 원시 결과는 출력 분포와 보정 영향의 진단으로 구분했다.

MSE와 RankSim의 직접 비교는 같은 초기값·사람별 추출·기록 평균·학습자료 한정 OLS 조건에서 추가 순서 손실의 영향을 본다. 기존 최선은 CNN·STT·좌우 STT 결합과 내부 모델 평균을 사용하므로, 단독 RankSim과의 비교는 현재 시스템을 대체할 만한 성능인가에 대한 비교다. 전체 오차와 고득점 오차를 구분해 판단하며 한 지표의 변화만으로 둘 다 개선됐다고 표현하지 않는다.

로컬 원본 감사의 보정계수 일치 검사(허용오차 1e-10)는 실패했고 원래 실패 기록을 보존했다. 원본 코드나 기준을 바꿔 통과 처리하지 않았다. 원래 서버 환경에서 기존 worker의 summarize가 모든 학습 감사를 마친 뒤 요약을 생성했음을 코드 지문과 완료 표식으로 확인했다. 별도 보완 검사에서는 저장된 계수로 모든 epoch 지표를 재계산하고, 로컬 재적합식과 저장식의 실제 점수 차이를 원래 점수 허용오차 0.0001로 확인했다. 계수 최대 차이는 3.21651969e-05, 학습 점수 차이는 1.11176632e-08, 내부 검증 점수 차이는 3.56521923e-10다. 따라서 엄격한 로컬 계수 일치는 미통과이고, 나머지 근거를 합친 조건부 검증 결과로 구분한다.

최종 모델 10개 CPU float64 재추론의 최대 차이는 3.7688796e-05로 기존 0.0001 허용오차 이내다. 모든 학습의 사람 분리·학습자료 정규화·균등 추출·저장 계수 지표·내부 epoch 선택·전체 OOF의 행 연결을 검산했다. 보호된 최종 평가자료와 LJMU는 사용하지 않았으며, 반복 개발자료 결과로서 임상 또는 외부 일반화 검증은 아니다.

## 목적과 가설

이전 사람비중 MSE/BMC는 전체 MAE6.9218/6.9454로 최선 결합6.5158을 개선하지 못했다. BMC는 보정 전 고득점 오차를 줄였으나 기존 학습자료 한정 OLS 후에는 이득이 유지되지 않았다. 출력 점수의 빈도 보정에 이어, **점수 차이가 내부 특징의 이웃 순서에도 반영되도록 학습하는 방법**을 확인한다. 이는 검토 가설이며 고득점 개선을 보장하지 않는다. 기존 MSE를 같은 조건으로 새로 학습해 직접 대조한다.

공식 RankSim은 정답이 가까운 표본의 순서와 특징의 코사인 유사도 순서를 맞춘다. [공식 코드](https://github.com/BorealisAI/ranksim-imbalanced-regression)와 원본 `ranking.py`·`ranksim.py`, `RANKSIM_LICENSE`를 함께 보존했다. 라이선스는 CC BY-NC-SA4.0이며 이번에는 연구 실험에 사용한다. 모델 출력 직전 ReLU 특징10개에 적용한다. 입력과 정답은 같은692명·1061기록·11261구간의 한쪽 다리124프레임·12특징과 해당 다리GDI다.

## 비교 조건

- MSE: 기존 사람별 균등추출 제곱오차.
- RankSim: 같은 MSE에 평균 순서 손실을 더한다. 공식 구현의 표본별 합을 고유정답 수로 나눈 평균을 사용하고 비중1.0·순위 역전파 interpolation2.0으로 고정한다. 최적값으로 확인된 설정이 아니며 평가결과로 바꾸지 않는다.

정확히 같은 GDI가 있는 배치는 공식 구현처럼 각 정답에서 하나를 고른다. 선택 난수는 배치의 학습 정답 지문으로 정해 저장·재개 시 동일하게 복원한다. 점수 반올림은 하지 않는다. 고유정답이1개면 추가 손실0으로 처리한다. 이 어댑터의 평균화·난수처리는 원본과 구분해 `rank_aux.py`에 기록했다.

기존692명 사람5분할, 동일초기값·표본순서·사람별동일횟수, 구간별입력, RMSprop·dropout·L2·최대100epoch, 기록내 모든구간 예측평균·학습기록만의 OLS를 유지한다. 같은 초기 모델의 특징을 추가 반환할 뿐 가중치 구조는 바꾸지 않는다. 보정 전후 원시예측·계수·지표·표본지문을 모든epoch에 저장한다. 내부4분할의 사람MAE로 학습길이를 고르고 바깥사람을 제외한 새학습으로 최종평가한다. 조건별25,총50학습·10바깥평가다. 보호된 최종자료와 LJMU는 사용하지 않는다.
