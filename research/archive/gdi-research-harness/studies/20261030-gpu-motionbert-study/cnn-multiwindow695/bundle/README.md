# 여러 보행 구간을 사용하는 CNN

같은 692명·1,061기록에서, 한 구간 CNN과 여러 구간 CNN을 비교한다. 원 연구식 12개 특징·좌우 별도 처리·47,840개 학습 파라미터·사람별 분할은 유지한다. 다른 실험 폴더와 실행을 공유하지 않는다.

## 입력과 학습

원 공개 처리 코드로 전체 영상 좌표를 보간·평활화한 뒤, 앞부분에서 124프레임 구간을 31프레임 간격으로 추출한다. 시작 위치는 0 기준 `range(0,500-124,31)`다. 필수 좌표의 결측률이 25%를 넘거나 특징이 유한하지 않은 구간은 제외한다. 기존 1,061기록에서 11,257개 구간을 얻었고, 앞부분 유효 구간이 없는 4기록은 기존 단일 구간을 사용한다. 최종 11,261구간이며 사람·기록·정답·fold는 기존 단일 구간과 동일하다. 따라서 앞부분 구간만 사용하는 원 논문의 완전 재현은 아니다.

각 기록은 좌우 GDI 정답을 갖고, 해당 기록의 모든 구간은 같은 정답을 사용한다. 한 사람의 모든 기록과 구간은 같은 fold에 머문다. 학습에서 각 구간·다리의 오차에 `전체 학습 구간 수 / (학습 기록 수 × 그 기록의 구간 수)`를 곱한다. 전체 예제의 평균 가중치는 1이다. 가중치를 배치마다 다시 정규화하지 않으며, 예측·정답·가중치의 1차원 형태를 검사해 원 코드의 차원 확장 문제를 피한다.

이 처리는 기록별 구간 수에 따른 손실 비중 차이를 보정한다. 한 사람이 여러 기록을 가진 효과와 BatchNorm의 구간 분포까지 보정하는 것은 아니다. 학습률·최대 100epoch·배치 32개 좌우 예제는 단일 구간과 같지만, epoch당 모든 구간을 사용하므로 갱신 횟수와 계산량은 증가한다. 시간 범위·평균 효과·학습량이 함께 달라지며, 성능 차이를 구간 평균 하나의 효과로 단정하지 않는다.

## 예측과 평가

구간별 좌우 예측을 기록 안에서 평균해 기록당 좌우 점수 하나씩 만든다. 그다음 현재 학습 기록의 평균 예측과 정답으로만 하나의 기울기·절편을 계산한다. 검증·평가에는 이 보정값을 그대로 적용한다. 보정 후 결과가 미리 정한 주 결과이며 보정 전 결과도 저장한다.

내부 검증 20회와 바깥 재학습 5회로 진행한다. 학습 종료 epoch는 내부 검증의 사람 평균 절대오차로 선택하고, 바깥 평가 정답은 이 선택에 쓰지 않는다. 기존 최종 평가 예약 자료도 사용하지 않는다. 실제 GPU 실행 상태는 상위 STATUS.md와 회수한 결과에서 확인한다.

## 실행

`sbatch --time=00:30:00 submit.slurm pilot`으로 먼저 입력·GPU·가중치·재개 검사를 하고 실제 학습 3epoch의 시간과 메모리를 확인한다. 기존 한 구간 학습은 유지한다. 별도 GPU 배정과 파일럿 성공을 확인한 뒤 `sbatch submit.slurm train`을 실행한다. 기본 상한은 8시간, 내부 실행 예산은 7.5시간이며 epoch마다 저장한다. 중단 뒤 같은 묶음·명령으로 재개할 수 있다.

로그는 `logs/pilot.log`, `logs/train.log`, 결과는 `runs/main/summary.json`, `runs/main/oof_predictions.npz`, 회수 압축은 `runs/main-review.tar.gz`다. 완료 표시는 `MULTIWINDOW_CNN_PILOT_FINISHED`와 `MULTIWINDOW_CNN_TRAINING_AND_EXPORT_FINISHED`다.

## 원 공개 코드

Stanford mobile-gaitlab commit `4167ee6213ac81fb9168f4e20c6538d42a41a5a6`의 처리·CNN·기록별 역수 가중치·구간 평균·학습 내 선형 보정 방식을 참고했다. 고정 출처와 라이선스는 sources/에 있다. PyTorch 변환, 현재 사람 분할, 사람 MAE에 의한 epoch 선택, 4기록 대체 구간, 학습 집단에서만 가중치 정규화 등은 현재 실험 조건이다.
