# 고정 CNN + MotionBERT 보정 실험

같은 692명·1,061기록·124프레임·좌우 GDI에서 기존 단일 CNN 예측에 작은 보정값만 더한다. 기존 여러 구간 CNN과 별도 폴더·별도 Slurm GPU 1개를 사용한다.

## 입력과 학습 대상

다리별 12개 특징 → 고정 CNN과 기존 학습 내 선형 보정 → 기본 예측.

고정 MotionBERT의 시간별 512개 특징 → 512→16 채널 변환 → 작은 시간 합성곱 → 시간 평균 → 좌우 보정값 2개.

최종 예측은 기본 예측+보정값이다. CNN과 MotionBERT는 학습하지 않는다. 보정기만 AdamW, 학습률 0.001, weight decay 0.0001, batch 32, 최대 100epoch로 학습한다. 보정기는 9,026개 파라미터이며 마지막 층을 0으로 초기화해 시작 예측은 기준 CNN과 같다. 추가 출력 보정·점수 제한은 적용하지 않는다.

## 검증 사람이 섞이지 않도록 하는 방식

- 기존 사람별 바깥 평가 5분할을 유지한다. 각 바깥 학습 사람 안에서 나머지 4분할로 내부 검증한다.
- 내부 검증에는 해당 바깥·내부 검증 사람을 모두 제외하고 학습한 CNN만 사용한다. 기존 내부 CNN의 고정 100epoch 체크포인트를 사용하며 검증 오차를 보고 이 가중치를 새로 고르지 않는다.
- 최종 평가에는 해당 바깥 평가 사람을 제외한 기존 CNN 재학습 가중치를 사용한다. 그 CNN의 종료 epoch는 당시 바깥 학습 사람 내부에서 선택했다. 내부 보정기 학습에 이 최종 CNN을 재사용하지 않는다.
- 25개 CNN 체크포인트의 지문·학습 사람·검증 사람·평가 사람·정답 변환 범위를 검사한다. 추론 전후 CNN 가중치와 BatchNorm 상태가 변하지 않는지 검사한다.
- MotionBERT 특징은 GDI 정답으로 학습하지 않은 원 모델의 고정 캐시다. 특징의 평균·표준편차는 각 보정기 학습 사람의 입력에서만 계산한다.
- 보정 정답은 해당 학습 사람의 실제 GDI−고정 CNN 예측이다. 이는 학습 사람에 대한 CNN 예측의 잔차이며, 교차 예측 잔차로 다시 만든 것은 아니다. 이 때문에 검증 사람의 잔차와 분포가 다를 수 있다. 검증 정답을 학습에 사용하는 것과는 구분한다.
- 내부 검증 인원으로 가중한 MAE가 최소인 0~100epoch를 선택한다. 0epoch도 후보이므로 보정하지 않는 선택이 가능하다. 바깥 평가 정답으로 학습·정규화·종료 시점을 선택하지 않는다.
- 기준 CNN은 내부 단계에서 100epoch, 바깥 재학습에서 기존 선택 epoch를 사용한다. 단계별 기준 CNN의 학습량 차이는 결과 해석의 한계로 남긴다.

## 실행

GPU 1개·CPU 4개·RAM 12GB를 요청한다. GPU 메모리는 파일럿 전 미실측이며 2GiB 이내를 예상한다. 본 학습은 20개 내부 학습+5개 재학습, 최대 2,500epoch다. 특징 추출과 CNN 재학습은 없으며 파일럿 시간으로 전체 실행 시간을 추산한다. Slurm 최대 4시간, 학습 프로세스 최대 3시간으로 제한한다.

```bash
mkdir -p logs
sbatch --nodelist=DIS02 --time=00:30:00 submit.slurm pilot
```

입력/25개 기준 가중치 확인 → 가상 자료 GPU 갱신·정확 재개·검증 변경 불변 검사 → 실제 학습 416명·검증 138명의 3epoch 파일럿 순서다. 바깥 평가 138명은 파일럿 학습·선택에 사용하지 않는다. `checks/`와 `runs/pilot/pilot_summary.json`의 통과·유한 수치·실행 시간·메모리를 확인한 후 실행한다. 3epoch에서 정확도가 좋아졌는지를 본 학습 진입 조건으로 사용하지 않는다.

```bash
sbatch --nodelist=DIS02 submit.slurm train
```

`logs/train.log`, `runs/main/fold*/`, `runs/main/summary.json`, `runs/main-review.tar.gz`에 저장한다. epoch마다 체크포인트와 난수 상태를 저장한다. 동일 입력·설정·폴더로 재개할 수 있지만 기존 작업이 종료됐는지 먼저 확인한다. 코드·설정이 달라지면 재개를 거부한다.

## 검증 범위

`run.py check`는 실제 자료·기준 CNN의 추론 검사이며 새 정답 학습은 없다. `verify.py`는 직접 만든 가상 자료로 보정 학습, 중단 재개, 검증 입력·정답 변경 시 가중치와 정규화 불변, 사람 중복·다른 체크포인트 거부, 0보정 재현을 검사한다. 실제 GPU 파일럿·본 학습 완료는 상위 연구 STATUS의 실행 기록과 구분한다. 보호한 최종 평가자료는 사용하지 않는다. 결과는 반복 개발 평가이며 임상 또는 독립 최종 평가가 아니다.

기준 CNN의 원 구현 출처·라이선스는 `sources/provenance.json`, `sources/LICENSE`에 보존했다. `base_model.py`는 기존 검산된 실행본과 같다.
