# 양쪽 평균 점수와 좌우 차이를 나눠 결합한 CPU 비교

2026-10-31. 기존 GPU 학습을 유지하면서, CNN·STT 결합의 양쪽 평균은 보존하고 좌우 결합 STT의 차이 정보를 더했다. 같은 692명·1,061기록·사람 분할에서 MAE가 **6.686592 → 6.605589점**으로 줄었다. 신경망 추가 학습은 없으며 보호된 최종 평가자료는 사용하지 않았다.

## 어떤 질문을 확인했나

좌우 결합 STT는 전체 예측 MAE가 더 컸지만 좌우 차이 예측에는 장점이 있었다. 그래서 두 장점을 분리해 사용할 수 있는지 확인했다. 여기서 전체 점수란 **좌우 GDI 예측의 산술평균**이며 새로운 임상 점수가 아니다.

기존 결합의 평균을 `m`, 기존 결합의 왼쪽−오른쪽 차이를 `d₀`, 좌우 결합 STT의 차이를 `d₁`이라고 하면 다음과 같다.

`차이 d = (1−t)×d₀ + t×d₁ → 왼쪽 = m+d/2, 오른쪽 = m−d/2`

먼저 차이를 전부 교체하는 `t=1`을 비교했다. 두 번째 조건은 `t=0, 0.25, 0.5, 0.75, 1` 중 내부 검증 MAE가 가장 작은 값을 선택했다. 동률이면 작은 값을 사용한다. 조건과 후보는 바깥 평가 계산 전에 [protocol.json](protocol.json)에 기록했다.

## 결과

사람마다 같은 비중을 주며, 한 사람 안에서는 기록과 좌우를 평균한다. 작은 값이 좋다.

| 방법 | 좌우 GDI MAE | 양쪽 평균 오차 | 왼쪽−오른쪽 차이 오차 |
|---|---:|---:|---:|
| 기존 여러 구간 CNN | 6.866655 | 5.902996 | 6.863330 |
| 기존 여러 구간 STT | 6.944988 | 5.821890 | 6.990092 |
| 기존 CNN·STT 예측 결합 | 6.686592 | 5.681287 | 6.646023 |
| 좌우 결합 STT 단독 | 7.003698 | 6.097776 | 6.592555 |
| 평균 보존 + 좌우 차이 전부 교체 | 6.657108 | 5.681287 | 6.592555 |
| 평균 보존 + 내부 검증으로 차이 비율 선택 | **6.605589** | **5.681287** | **6.350560** |

내부에서 선택한 좌우 결합 STT 차이 비중은 분할별 **50%, 50%, 50%, 50%, 25%**다. 기존 CNN·STT 평균을 만드는 CNN 비중 35%, 60%, 50%, 50%, 65%는 그대로 사용했다. 새 조건은 다섯 바깥 분할 모두 기존 예측 결합보다 MAE가 낮았다. 사람별로 276명 개선·224명 악화·192명 동일하다. 평균을 보존하기 때문에 좌우 변화가 서로 상쇄되는 동일 사례도 있다.

개선 폭은 기존 결합 대비 **0.081004점(약 1.21%)**, 기존 CNN 대비 0.261067점이다. 사람 단위 10,000회 재표집의 탐색적 95% 범위는 새 조건−기존 결합 기준 −0.121620~−0.042191점이다. 차이를 전부 바꾼 조건은 −0.105543~+0.045230점으로 0을 포함한다. 반복 탐색한 개발자료의 범위이며 새 독립 검증에서 개선이 확정됐다는 뜻은 아니다.

**고득점 문제는 거의 그대로다.** 실제 사람 평균 GDI가 90 이상인 68명의 MAE는 기존 결합 8.808609 → 새 조건 8.780505점이다. 양쪽 평균 자체는 바뀌지 않았으므로 공통적인 과소예측을 고치는 방식이 아니다. 원 논문 6.5보다 낮아진 것도 아니며 평가 조건도 다르다.

## 검증 자료를 어떻게 분리했나

각 바깥 평가 사람을 먼저 제외한다. 나머지 사람 안에서 학습·내부 검증을 나눈 20개 모델의 예측으로 비율을 선택한다. 좌우 결합 STT의 각 보정식도 그 모델의 학습 기록만으로 다시 계산했다. 평가 사람의 정답이나 예측은 비율 선택에 들어가지 않는다. 결합 뒤 추가 보정도 하지 않았다.

기존 CNN·STT 내부 예측 캐시는 원본 160개 파일의 지문과 기존 검산 기록을 재확인한 뒤 재사용했다. 좌우 결합 STT의 20개 내부 모델은 사람 경계·마지막 epoch 원시 예측·학습자료 보정·내부 MAE를 재검산했다. 세 기본 모델의 저장 모델 재추론은 각 기존 완료 검산에 근거하며, 이번 결합에서 전체 모델을 다시 학습하거나 재추론한 것은 아니다.

[verify.py](verify.py)는 별도 수식으로 사람 비중과 결합 예측을 계산하고, 행 순서를 바꿔도 선택이 같은지, 바깥 정답을 임의의 큰 값으로 바꿔도 선택이 같은지, 평가 사람을 일부러 섞으면 거부하는지 확인했다. 모든 지문·분할·수식 검사를 통과했다. 양쪽 평균 보존과 독립 결합 계산 차이는 1e-12점 이내다. [검산 JSON](analysis/verification.json) · [결과 JSON](analysis/comparison.json).

현재 내부 선택에는 남아 있는 마지막 모델인 CNN 100epoch·STT와 좌우 STT 200epoch를 사용한다. 바깥 모델은 원래 내부 선택 epoch로 재학습됐으므로 학습 길이가 일치하지 않는다. 기존 CNN 비중과 새 차이 비중이 같은 내부 검증 자료를 사용한다는 한계도 있다. 바깥 사람을 섞지는 않았지만, 반복 탐색한 개발자료의 결과라는 경계는 유지한다.

## 실행 경로

`compare.py select`는 내부 예측만 읽어 비율을 저장한다. 그 뒤 `compare.py evaluate`가 바깥 예측을 열어 성능을 계산하고, `verify.py`가 별도 검산한다. 지문이나 사람 분리가 맞지 않으면 중단한다. 작은 코드·요약·결합 캐시는 C의 이 폴더에 저장했고, 원본 대용량 자료·모델·GPU 작업은 변경하지 않았다.
