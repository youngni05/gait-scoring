# CNN·STT 점수와 구간별 흔들림을 이용한 10점 구간 확률 비교

2026-10-31 CPU 완료. **확률을 출력하는 모델은 만들었지만, 정확한 구간을 맞히는 비율은 기존 최선 43.09%를 넘지 못했다.** 사전에 정한 내부 선택 모델은 41.15%다. 간단한 확률 대조군보다 로그 손실은 조금 작았지만, 정확도와 신뢰성이 모두 뚜렷하게 좋아졌다는 결론은 아니다. 기존 GPU 학습·할당·예약은 변경하지 않았다.

## 무엇을 예측했나

각 기록의 왼쪽·오른쪽 GDI가 `[60,70)`, `[70,80)`, `[80,90)` 등 어느 10점 구간에 들어갈 확률인지 예측했다. 경계는 평가 전에 0~150의 10점 간격으로 고정하고, 0 미만·150 이상은 별도 열린 꼬리 구간으로 뒀다. GDI를 100으로 잘라내지 않는다. 실제 평가 정답은 30~120 사이 구간에 있고, 110~120은 두 사람뿐이어서 극단 구간의 신뢰성을 강하게 평가하기 어렵다.

같은 692명·1,061기록·2,122개 좌우 정답을 사용했다. 같은 사람의 반복 기록·좌우가 많아져도 전체 비중이 커지지 않도록 사람→기록→좌우 순서로 동일 비중을 줬다. 겹친 영상 구간을 새로운 사람이나 독립 평가 표본으로 세지 않는다.

기본 입력은 CNN 점수, STT 점수, 두 모델의 차이와 반대쪽 다리의 평균 점수 차이다. 추가 입력은 각 모델의 구간 예측 표준편차·가운데 50% 범위(IQR)다. 흔들림 값에는 `log(1+값)`을 적용했다. 원래 좌표나 모델 가중치는 변경하지 않았다.

확률 계산부는 고정된 점수 경계에 대해 누적 확률을 계산하는 작은 순서형 모델이다. 점수만 쓰는 조건은 입력에 따라 예측 중심을 조정하고 공통적인 퍼짐을 학습한다. 흔들림을 추가한 조건은 중심과 퍼짐을 모두 입력에 따라 조정한다. 출력 확률은 음수가 없고 합계가 1이다. 모델 크기와 과도한 계수 변화를 억제하는 강도 후보 1·0.1·0.01은 내부 검증의 로그 손실로 선택했다. [실행 전 조건](protocol.json).

## 평가 사람이 간접적으로 섞이는 것도 막은 구조

이미 모인 내부 예측을 무작정 다시 나누면, 보정용 사람의 정답으로 학습된 기본 모델이 다른 입력을 만드는 데 쓰일 수 있다. 이를 피하려고 기존 내부 모델을 각각 독립된 경로로 사용했다.

한 바깥 평가 집단을 먼저 제외하고, 나머지 네 집단 중 하나를 더 제외한 CNN·STT 쌍을 사용한다. 이 쌍은 제외한 내부 집단을 학습하지 않았다. 그 내부 사람을 다시 다음처럼 나눈다.

`확률 모델 학습 약 82~83명 → 설정 선택 27명 → 선택 후 앞의 두 집단으로 재학습 → 남겨 둔 29명으로 확률 보정`

한 경로 안에서 기본 CNN·STT 학습 사람, 확률 모델 학습 사람, 설정 선택 사람, 확률 보정 사람, 바깥 평가 사람은 모두 분리된다. 확률 보정 사람은 마지막 재학습에서도 제외한다. 같은 바깥 평가 집단에 대해 이런 경로 네 개의 **확률을 고정 1:1:1:1로 평균**한다. 평균 뒤 평가 정답으로 다시 보정하지 않는다.

총 20개 경로에서 설정 후보 120개 적합, 최종 점수/흔들림 모델 40개 적합, 간단한 확률 대조군 20개 적합과 보정 60회를 수행했다. 모두 CPU이며 CNN·STT 신경망을 추가 학습하지 않았다. 모델 학습·선택·보정 파일을 확정한 다음 별도 실행에서 바깥 평가 결과를 계산했다.

**비교상 한계:** 이 구조는 원래 최선의 바깥 재학습 모델 하나를 쓰는 경로와 다르다. 세 집단으로 학습한 기존 내부 모델 네 쌍을 사용하며, CNN은 고정 마지막 100epoch·STT는 200epoch다. 원래 최선은 더 많은 학습 사람과 내부 선택 epoch를 사용한다. 따라서 기존 최선과의 전체 비교와, 같은 네 쌍을 쓰는 대조군 대비 효과를 함께 본다.

## 결과

구간 정확도는 높을수록, 로그 손실(NLL)·Brier 점수는 낮을수록 좋다. 두 확률 지표는 정답 구간에 적절한 확률을 주는지 평가한다. 확률을 내지 않는 원래 점수 방식에는 임의의 확률 보정 점수를 붙여 비교하지 않았다.

| 방법 | 정확한 10점 구간 | 로그 손실 | Brier 점수 |
|---|---:|---:|---:|
| 기존 CNN·STT 결합 점수를 구간으로 변환 | 42.20% | — | — |
| 기존 평균·좌우 차이 결합 | 43.04% | — | — |
| 기존 집계 선택까지 적용한 최선 | **43.09%** | — | — |
| 같은 네 쌍의 점수를 평균한 대조군 | 40.69% | — | — |
| 같은 네 쌍＋공통 오차 분포＋확률 보정 | 41.23% | 1.300005 | 0.684056 |
| 점수만 사용하는 확률 모델＋보정 | 41.15% | 1.295959 | 0.682841 |
| 점수＋구간 흔들림 확률 모델＋보정 | 41.72% | 1.295181 | 0.682401 |
| **내부에서 모델 종류까지 선택＋보정** | **41.15%** | **1.295084** | **0.682343** |

주 결과는 마지막 줄이다. 내부 선택에서는 20경로 중 17개가 점수만 쓰는 모델, 3개가 흔들림도 쓰는 모델을 골랐다. 바깥 평가에서 정확도가 조금 높게 나온 다른 줄로 사후 교체하지 않았다. 선택 기준은 확률 품질을 보는 로그 손실이며, 정확도 최대화와 같은 목표는 아니다.

사람 단위 10,000회 재표집으로 본 탐색적 차이는 다음과 같다.

- 기존 최선 대비 정확도 **−1.94%p**, 95% 범위 −3.47~−0.43%p. 이 실행 경로로 기존 방식을 교체할 근거는 없다.
- 같은 네 쌍의 단순 구간 예측 대비 **+0.46%p**, 범위 −0.61~+1.49%p. 확실한 정확도 개선으로 보기 어렵다.
- 간단한 확률 대조군 대비 로그 손실 **−0.004921**, 범위 −0.009358~−0.000425. 확률 품질에서 작은 개선 신호가 있다.
- 같은 대조군 대비 Brier **−0.001712**, 범위 −0.003829~+0.000368로 0을 포함한다.

같은 개발자료에서 여러 실험을 수행한 뒤의 비교이며, 이 범위는 새 독립 평가의 확증이 아니다. 확률 지표 하나가 좋아진 것을 정확도와 신뢰성 전체의 개선으로 확대하지 않는다.

## 확률은 얼마나 믿을 만했나

선택 모델의 보정 후 가장 높은 구간 확률은 평균 44.21%, 실제 구간 일치율은 41.15%다. 고정된 10% 확률 구간으로 계산한 신뢰도 차이(ECE)는 3.06%p이며, 간단한 확률 대조군의 3.88%p보다 작았다. 여전히 약간 과신하는 경향이 있다.

| 가장 높은 확률의 범위 | 평가 비중 | 평균 표시 확률 | 실제 정답률 |
|---|---:|---:|---:|
| 30~40% | 10.55% | 38.78% | 38.04% |
| 40~50% | 88.29% | 44.78% | 41.42% |
| 50~60% | 1.16% | 50.42% | 48.96% |

50~60% 구간은 20명·22개 좌우 관측뿐이다. **60% 이상 확신한 사례는 없으므로, 높은 확률의 신뢰성을 이번 자료로 검증했다고 할 수 없다.** 40~50%에 대부분 몰려 있다는 것은 여러 인접 구간 사이의 불확실성이 크다는 뜻이다.

확률 보정은 각 경로의 별도 29명만으로 온도 매개변수를 학습했다. 선택 모델의 보정 전후 ECE는 3.66→3.06%p로 줄었지만 로그 손실은 1.293909→1.295084로 조금 나빠졌다. 보정 자료에서 맞춘 효과가 바깥 평가의 모든 지표에서 개선으로 이어진 것은 아니다. 경로별 보정 후 평균한다고 최종 평균 확률까지 자동으로 보정되는 것도 아니다.

온도 보정은 출력 확률의 날카로움을 조절하며, 한 모델에서 가장 높은 구간의 순서를 바꾸지 않는다. 관련 연구는 이미지·문서 분류에서 보정 방법을 비교한 것으로, 이 GDI 실험의 효과를 보장하지 않는다. [Guo 등, 2017](https://proceedings.mlr.press/v70/guo17a.html). 로그 손실·Brier에는 구분 능력도 함께 반영되므로 신뢰도 표를 별도로 확인했다. [확률 보정·평가 공식 설명](https://scikit-learn.org/stable/modules/calibration.html).

저장된 전체 지표에서 단순 구간 예측을 원핫으로 표현한 Brier·ECE도 계산했지만, 이는 형식적인 대조 수치다. 원래 점수 모델이 ‘100% 확신’을 주장한 것으로 해석하거나, 그 값보다 좋아졌다는 이유만으로 새 확률 모델이 검증됐다고 설명하지 않는다. 원핫의 틀린 예측은 로그 손실이 무한대가 되므로 임의의 작은 확률로 바꿔 좋은 비교처럼 만들지 않고 null로 기록했다.

## 검산

원본 모델·구간 예측·학습 산출물의 SHA256, 각 경로에서 전체 692명이 중복 없이 역할별로 나뉘는지 확인했다. 입력 평균·표준편차는 해당 확률 모델의 재학습 사람으로만 계산했다. 후보 120개·최종 모델 40개와 온도 60개를 다시 적합하고 선택을 재현했다. 별도 누적확률·온도 계산으로 저장 모델의 확률을 재현하고 네 경로의 평균, 사람 동일 비중의 정확도·로그 손실·Brier·신뢰도 표를 검산했다.

평가 정답을 큰 값으로 바꿔도 모델 입력 정답이 바뀌지 않는지, 보정 정답을 바꿔도 확률 모델의 학습 계수가 바뀌지 않는지 확인했다. 경계값 0·10·100·150, 열린 꼬리 구간, 확률 합계·양수성, 온도 보정의 구간 순서 보존, 의도적인 사람 혼입 거부와 손실 미분의 수치 검산도 통과했다. 보호된 최종 평가자료와 LJMU는 사용하지 않았다.

검산은 계산·자료 분리의 확인이다. 일반 성인이나 다른 촬영 환경에서 확률이 유효하다는 검증은 아니다. 이번에는 기존 최선 점수 예측을 바꾸지 않고, 확률 표현의 가능성과 현재 한계를 확인한 결과로 남긴다.

## 코드 흐름과 저장 위치

`core.py`가 점수·구간 흔들림에서 확률을 계산한다. `train.py`는 사람 분리→후보 선택→재학습→확률 보정을 수행하고, 완료 뒤 `export_outer.py`가 바깥 사람의 입력 점수를 꺼낸다. `evaluate.py`가 네 경로의 확률을 평균해 평가하며 `verify.py`가 별도 계산으로 확인한다. 지문·분할·확률 조건이 맞지 않으면 중단한다.

코드·보고서·검산 JSON은 C의 이 폴더에 있다. 학습된 확률 모델 계수·보정 예측·평가 확률·기본 모델 재추론 캐시는 `D:/gait-research-data/D_P/gdi-research-harness/studies/20261030-gpu-motionbert-study/probability-bands692/cache`에 저장했다. 새 GPU 작업이나 원본 모델 변경은 없다.
