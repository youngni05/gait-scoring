## 학습 차이와 유지 조건

각 epoch에 사람마다 같은 수의 표본을 뽑는다. 각 표본은 해당 사람의 기록 → 그 기록의 구간 → 한쪽 다리를 균등하게 선택한다. 사람별 추출 횟수는 `ceil(기존 전체 구간·다리 수 / 학습 사람 수)`이며, 기존 구간을 모두 한 번씩 방문하는 방식과는 다르다. 기록·구간의 균등성은 무작위 추출의 기대값이고, 사람별 횟수는 실제로 정확히 같다.

두 조건은 초기값·추출 seed·매 epoch 표본 순서·업데이트 수·RMSprop·학습률 감소·dropout·L2를 맞춘다. 배치 32를 사용하고 마지막 1개만 남으면 앞 배치와 합친다. 작은 마지막 배치의 손실은 표본 수/32로 조정한다. 기존 기록 가중치를 중복 적용하지 않는다. 학습에서 뽑지 않은 구간도 예측할 때에는 모두 사용한다.

- **MSE 대조군:** 사람 비중을 맞춘 추출로 제곱오차를 학습한다.
- **BMC:** 같은 배치에서 자기 정답과 다른 정답들의 거리를 비교하는 Balanced MSE를 학습한다. [공식 구현](https://github.com/jiawei-ren/BalancedMSE)을 바탕으로 고정 `sigma=5 GDI`를 사용한다. 각 학습 분할의 점수 범위로 나눠 정규화 단위를 맞춘다. 학습되는 잡음 추정치가 아니며 최적값으로 확인된 값도 아니다. 평가 결과를 보고 sigma를 바꾸지 않는다.

두 조건 모두 기록별 여러 구간의 예측을 평균하고, 현재 학습 기록의 좌우 정답만으로 기존과 같은 OLS 기울기·절편을 구한다. **최적화의 사람 비중은 같지만 OLS는 기존 기록 비중을 유지한다.** 보정 방식 변경까지 섞지 않기 위한 비교 조건이며, 보정 전 예측도 모든 epoch에 남긴다.

학습 길이는 바깥 평가 사람을 제외한 내부 4분할의 사람 평균 MAE로 선택한다. 고득점만 잘 맞히는 epoch를 사후에 고르지 않는다. 조건별 내부 20개＋최종 5개, 합계 50개 학습·10개 바깥 예측이다. 최대 100epoch다. 각 내부 학습은 새 초기값으로 시작하며 다른 분할의 학습 모델을 재사용하지 않는다.

## 결과 회수와 해석

큰 압축·체크포인트·epoch 예측은 D의 대응 실험 폴더에, 코드·요약·검산 보고서는 C에 둔다. `runs/main-review.tar.gz`에는 두 조건의 50개 체크포인트·모든 epoch 예측·로그 이외 검산 자료를 포함하며 실행 로그는 별도로 회수한다. 서버/로컬 SHA256을 대조한 뒤 `audit.py`로 학습자료 한정 정규화·보정·표본 추출·지표·내부 선택을 검산하고 최종 모델 10개의 CPU 재추론을 수행한다.

전체 MAE뿐 아니라 실제 90·100 이상 관측과 사람 평균 기준 고득점 집단을 구분해서 MAE·평균 편향·인원수를 기록한다. 낮은 점수대와 보정 전후 결과도 함께 본다. 같은 사람의 두 조건 오차 차이를 사람 단위로 재표집해 불확실성을 확인한다. 기존 CNN·STT 결합과의 비교는 같은 사람·자료에 한정하고, 개발자료에서 탐색한 결과와 임상 검증을 구분한다. 정상 성인 예측이 100에 가까워지는지를 모델 선택 기준으로 쓰지 않는다.
