# RankSim을 기존 최선 결합에 추가하는 CPU 비교

## 내부 선택 CPU 비교 결과 — 2026-11-01

RankSim을 추가한 조합에서 전체 MAE의 점 추정이 가장 낮았다. 다섯 바깥 분할 모두 줄었으나 차이의 95% 범위가 0을 포함해 확실한 개선으로 승격하지 않는다. 같은 모델 수 효과를 보는 일반 MSE 추가 대조군도 소폭 낮아졌다.

| 조합 | 전체 MAE | 고득점 68명 MAE | 고득점 편향 |
|---|---:|---:|---:|
| 기존 최선 | 6.515817 | 8.782528 | -7.915159 |
| 기존 최선 + RankSim | 6.476735 | 8.680640 | -7.809613 |
| 기존 최선 + SynthGait | 6.502693 | 8.713426 | -7.820313 |
| 기존 최선 + 일반 MSE 대조군 | 6.493969 | 8.717439 | -7.880226 |

RankSim 추가: 전체 차이 -0.039082점, 사람 짝지은 10,000회 재표집 95% 범위 -0.085931~+0.005065, 개선 분할 5/5, fold별 비중 [0.45, 0.05, 0.15, 0.35, 0.3]. 고득점 차이 -0.101887점(95% -0.225024~+0.016586).

SynthGait 추가: 전체 차이 -0.013124점, 사람 짝지은 10,000회 재표집 95% 범위 -0.051872~+0.024828, 개선 분할 3/5, fold별 비중 [0.35, 0.1, 0.1, 0.3, 0.3]. 고득점 차이 -0.069102점(95% -0.166771~+0.024164).

MSE 추가: 전체 차이 -0.021847점, 사람 짝지은 10,000회 재표집 95% 범위 -0.059550~+0.016078, 개선 분할 2/5, fold별 비중 [0.35, 0.2, 0.2, 0.1, 0.2]. 고득점 차이 -0.065089점(95% -0.188670~+0.050027).

모든 바깥 평가 사람을 모델 학습·정규화·보정·비중 선택에서 제외했다. 실제 모델의 학습/검증/평가 ID, 내부 캐시와 결과 지문, 행·영상·좌우·정답 연결을 대조했다. 내부 선택의 행 역순과 바깥 정답 변경으로 비중이 달라지지 않음, 주입한 사람 혼입 거부, 별도 MAE·그리드 최소값 계산을 확인했다. 내부 단일 모델과 바깥 bagged 기준선의 구조 차이 및 기존 결합계수의 메타학습 범위는 위 프로토콜대로 한계로 남는다.

[계획](protocol.json) · [비교와 불확실성](analysis/comparison.json) · [검산](analysis/verification.json). 반복 개발자료의 결과이며 독립 검증이나 원 논문의 6.5를 같은 조건에서 넘어섰다는 주장은 아니다. 다음 GPU 라운드는 RankSim 강도를 0.1·0.3으로 낮추는 두 후보만 추가하고, 기존 동일 조건 0·1 대조군에 연결해 내부 선택한다.

## 재개 상태 — 2026-11-01

사용자가 새 학습과 앙상블 연구를 재개했다. 앞선 취소 상태를 해제하되, 먼저 SynthGait 전체 결과를 회수·검산·분석한 뒤 이 CPU 비교를 진행한다. RankSim의 단독 결과는 이미 검산·보고했으며 같은 검산을 반복하지 않는다. 실제 조합 비교는 아직 미실행이다. SynthGait 기여도 별도 내부 선택 비교로 확인한다. 최신 순서와 운영 범위는 [반복 연구 계획](../../../control/gpu-watch/iterative-research/README.md)을 따른다.

아래 내부 OOF의 정답으로 비중을 고르는 과정은 바깥 학습 자료 안의 메타학습이다. 기존 결합 계수도 같은 내부 자료에서 선택했다면 내부 j에 대해 완전히 독립적인 조합 검증이라고 설명하지 않는다. 최종 바깥 f는 모델·정규화·보정·모든 조합 선택에서 제외한다. 내부 단일 모델과 바깥 bagged 모델의 차이는 한계로 남긴다.

2026-11-01 사용자 승인. 기존 GPU학습은 유지하고, RankSim 전체 결과의 회수·검산 완료 후 기존 최선 결합에 추가하는 앙상블을 CPU에서 비교한다. 현재는 대기·준비 상태이며 새 성능 결과는 없다. 추가 신경망 학습이나 새 GPU를 신청하지 않는다.

## 비교를 먼저 고정한다

같은692명·1061기록·사람5분할을 사용한다. 바깥fold f마다, 그 사람들을 제외한 내부4분할의 예측으로 **RankSim 비중 w 하나**를 선택한다. 후보는0~1의0.05간격이다. 좌우에 같은비중을 사용하고 `(1-w)×기존결합＋w×RankSim`으로 계산한다. 내부 사람 동일비중 MAE가 가장 작은 비중을 선택하며, 1e-12 이내 동률이면 RankSim비중이 작은 쪽을 택한다. 고득점별 별도비중이나 결과를 본뒤 후보 추가는 하지 않는다.

## 내부 검증의 학습 정보 혼입을 막는다

바깥f·내부j의 선택자료에는 f,j사람을 모두 학습에서 제외한 모델만 사용한다. RankSim의 해당inner학습이 끝난 최종epoch 예측·학습자료한정OLS와, 기존CNN/STT/좌우STT의 해당inner 검증예측을 연결한다. 베이스모델별 다른epoch 후보를 추가 탐색하지 않고 기존내부모델예측을 고정한다. 사람·영상·좌우·정답·순서를 검증한다. 기존최선결합의 CNN비중/좌우차이비율은 mean-difference692의 바깥fold별 내부선택값을 재사용한다. 새RankSim비중의 선택에 바깥평가 정답은 사용하지 않는다.

**기존최선의 5모델평균을 내부j검증에 그대로 재사용하지 않는다.** 그 구성원 중 일부는 j사람을 학습했기 때문이다. 비중선택용 기존결합은 f,j를 제외한 단일내부모델의 CNN/STT/좌우예측을 사용하고, 바깥평가에는 실제최선인 내부모델평균결합을 그대로 사용한다. 기존최선 자체도 평균 전 내부예측에서 고른 결합비중을 유지한 방식이다. 이 내부·바깥 평균구조 차이는 한계로 명시하며 정확히같은 bagged stacking이라고 설명하지 않는다. 기존결합비중은 바깥f를 제외한 내부자료에서 정해졌으며, j별 완전히 독립된 하위선택과는 다르다.

각바깥fold에서 기존최선평가예측과RankSim의 refit평가예측을 연결하고, 앞서정한w를 적용한다. **각바깥평가사람은 기준선/RankSim학습·정규화·보정·비중선택 전부에서 제외되어야 한다.** 캐시의모델학습사람ID·checkpoint·지문을 확인하고, 필요하면 기존모델을 CPU로재추론해 내부검증캐시를 만든다. 전체OOF를 한꺼번에 학습/검증으로 나눠 stacking하지 않는다. 보호최종평가자료는 열지 않는다.

## 무엇을 확인할지

현재최선 전체MAE6.5158165692·사람평균GDI90이상68명MAE8.7825277479의 예측을 먼저재현한다. 기준선·RankSim단독·내부선택앙상블을 같은사람비중으로 비교한다. 전체MAE·평균편향, 고득점68명 및 정답90/100이상 개별관측의 MAE·편향·인원수, 낮은점수대, 바깥fold별변화, 선택비중을 기록한다. 사람단위 짝지은 재표집10000회(seed20261101)로전체/고득점MAE차이95%범위를 계산한다. 작은MAE변화와 과소예측개선을 구분하고, 수치가좋은평가결과를근거로후보를다시선택하지 않는다. 반복 탐색한 개발자료 결과이며 독립임상검증은 아니다.

## 진행과 저장

`select_weight.py`는 내부선택함수이며 바깥정답을 인자로 받지 않는다. 완성된비교실행기는 RankSim검산결과·캐시경로를 확인한 뒤 연결한다. 선택함수는 알려진가상정답·사람비중·행순서변경으로 확인했다. 실제앙상블비교는 아직 실행하지 않았다. 코드·선택기록·검산/분석요약은C의이폴더, 대량예측캐시는D의같은경로에저장한다. 1시간 예약 gdi-2는 최신 반복 연구 지시에 따라 이 비교 보고 후 다음 실험 준비를 이어간다.
