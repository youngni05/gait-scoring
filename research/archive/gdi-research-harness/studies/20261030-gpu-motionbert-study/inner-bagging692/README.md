# 이미 학습된 내부 모델을 함께 평균한 CPU 비교

2026-10-31. 신경망을 새로 학습하지 않고, 교차검증 중 만들어진 내부 모델을 평가 사람 예측에 함께 사용했다. 같은 692명·1,061기록·사람 분할에서 현재 최선 결합의 MAE가 **6.605589 → 6.515817점**으로 줄었다. 결과를 보기 전에 정한 성공 기준을 통과했다. 보호된 최종 평가자료는 사용하지 않았다.

## 무엇을 바꿨나

각 바깥 분할에는 평가 사람을 뺀 전체로 다시 학습한 최종 모델 1개와, 설정 선택용으로 학습한 내부 모델 4개가 있다. 내부 모델도 평가 사람을 학습하지 않았다. 기존에는 최종 모델만 사용했다. 이번에는 CNN과 STT 각각 최종 모델과 내부 모델의 예측을 같은 비중으로 평균했다. 그 뒤 기존 결합식(CNN 비중, 좌우 차이 비율, 좌우 결합 STT 차이)은 그대로 적용했다.

- 각 모델의 예측은 기존과 같이 기록 안 구간 평균 후, 그 모델의 학습 기록으로만 맞춘 보정식을 적용했다.
- 학습 기록 예측의 표준편차가 0.01점 미만인 모델은 제외하는 규칙을 미리 정했다. CNN outer0/inner4 1개만 해당했다(모든 기록에 같은 값을 출력).
- 후보는 하나만 정했고 평가 사람으로 선택하거나 조정하지 않았다. 조건은 [protocol.json](protocol.json)에 실행 전에 기록했다.

## 결과

사람마다 같은 비중을 준 좌우 GDI MAE다. 작을수록 좋다.

| 방법 | MAE | 사람 단위 95% 범위 |
|---|---:|---|
| 여러 구간 CNN (최종 모델만) | 6.866655 | |
| CNN 모델 평균 | 6.590389 | |
| 여러 구간 STT (최종 모델만) | 6.944988 | |
| STT 모델 평균 | 6.752031 | |
| 기존 최선 결합 | 6.605589 | 6.33 ~ 6.88 |
| **모델 평균 + 같은 결합** | **6.515817** | **6.25 ~ 6.78** |

- 기존 최선 대비 −0.089772점(약 1.4%), 짝지은 사람 재표집 95% 범위 −0.156 ~ −0.024점으로 0을 포함하지 않는다. 372명 개선·320명 악화.
- 바깥 분할 MAE: 6.983→6.793, 6.185→6.185, 6.408→6.382, 6.306→6.366, 7.144→6.853. 다섯 중 넷이 개선됐다.
- 단독 CNN은 −0.276점(95% 범위 −0.382 ~ −0.175), 단독 STT는 −0.193점(−0.291 ~ −0.095) 개선됐다.
- **고득점 문제는 그대로다.** 실제 평균 GDI 90 이상 68명의 MAE는 8.7805 → 8.7825점이다. 여러 모델을 평균하면 흔들림은 줄지만, 모두 같은 방향으로 낮게 예측하는 경향은 고쳐지지 않는다.

원 논문 CNN 6.5점과 거의 같은 값이며, 평가 집단이 달라 직접 우열을 판단하지 않는다.

## 검산

- 내부 모델 40개를 평가 사람에게 새로 적용하면서, 같은 모델로 각자의 내부 검증 사람도 다시 예측해 저장된 값과 비교했다. 최대 차이는 0.00001점 미만이다.
- 최종 모델만 쓴 결합을 다시 계산해 기존 6.605589점을 최대 0.0000136점 차이로 재현했다.
- [verify.py](verify.py): 체크포인트 학습 기록에서 40개 모델 모두 평가 사람과 겹치지 않음, 제외 규칙 재계산, 별도 반복문으로 결합 재구성(차이 0), 별도 MAE 계산식, 행 순서 변경 불변, 모델 2개의 체크포인트 직접 재추론(최대 0.0000032점 차이)을 확인했다.

## 한계

- 같은 개발자료를 여러 번 분석해 왔으므로 독립 검증으로 확정된 성능이 아니다.
- 내부 모델은 마지막 epoch(CNN 100, STT 200), 최종 모델은 내부에서 고른 epoch로 학습 길이가 다르다.
- 결합 비중은 평균하지 않은 내부 예측으로 고른 값을 그대로 썼다.
