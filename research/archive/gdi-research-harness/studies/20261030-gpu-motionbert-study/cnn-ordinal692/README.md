## 입력과 모델

같은692명·1,061기록·11,261구간,124프레임·12특징·좌우 별도 입력과 원래 사람5분할을 사용한다. 원본 입력 SHA256은 `7c1912cd27c63a82ed0d0324f98c0c0fae9a608174d52bd7a502f05e9a8c7a1e`이다. CNN6개 합성곱층과10개 특징을 유지하고 같은 기록의 구간별 특징을 평균한다. 이 평균 특징에서 점수 또는 구간을 예측한다.

| 조건 | 학습 목표 | 본 학습 수 |
|---|---|---:|
| regression | 점수만 예측하는 같은 구조의 대조군 |25|
| ordinal10·ordinal20 |10점·20점 경계마다 그 이상인지 예측 |각25|
| joint10·joint20 |점수와 경계 초과 여부 함께 예측 |각45|

구간 경계는0~160의10점 또는20점 간격으로 고정하고 양끝은 열린 구간이다. `[a,b)`를 적용하며 GDI를100으로 자르지 않는다. 순서가 보장된 누적확률의 차이로 각 구간 확률을 얻는다. CORAL의 순서형 예측 발상을 적용한 자체 구현이며 공식 코드 재현은 아니다. [연구팀 구현](https://raschka-research-group.github.io/coral-pytorch/).

동시 학습은 학습 정답만으로 최소·범위를 계산한 점수 제곱오차와 누적 이진 손실을 함께 쓴다. 구간 손실 비중0.25·1.0과 종료epoch를 내부 검증에서 선택한다. 구간 모델은 정확한 구간 일치율 우선, 동률이면 확률 로그손실·이른epoch 순서로 선택한다. 점수 대조군은 내부 MAE로 종료epoch를 고른다. 최대100epoch와 원래RMSprop·학습률 감소·dropout0.5·커널L2를 유지한다.

CNN 특징과 점수 출력부의 초기값을 조건 간 일치시키고 매 학습은 새로 시작한다. 이번 실행은 고정 특징 후처리가 아닌 CNN 전체 학습 갈래다. 학습 비중은 같은 사람이 여러 기록을 갖더라도 총비중이 같도록 한다. 기록2개 배치·특징 평균·사람 학습 비중은 과거CNN과 다른 조건이므로 새 점수 전용 대조군이 필요하다. 단순히 모델 이름만으로 차이를 해석하지 않는다.
