# MotionBERT 특징+CNN 결과 검산과 오차 증가 분석

확인일: 2026-10-30. 기존 여러 구간 CNN은 유지하고, 완료된 결합 실험만 회수·분석했다.

**이번 단순 특징 결합은 단일 구간 CNN보다 평균 절대오차가 1.185점, 약 15.1% 커졌다.** 결과 파일과 저장 모델을 검산해 같은 결과를 재현했다. 현재는 이 결합 모델로 기준 CNN을 교체할 근거가 없다. MotionBERT 전체의 가능성을 부정하는 결과가 아니라, 이번 입력 결합·학습 설정에서 개선되지 않은 결과로 본다.

## 무엇을 비교했는가

같은 692명·1,061기록, 같은 124프레임과 좌우 GDI, 같은 사람별 5분할이다. 한 사람의 기록이 해당 모델의 학습과 평가에 동시에 들어가지 않는다. 각 바깥 학습 집단 안에서 4개 내부 검증으로 종료 epoch를 선택하고 재학습했다. 보호한 최종 평가자료는 사용하지 않았다.

- 단일 CNN: 다리별 12개 특징 → CNN → 해당 다리 GDI.
- 결합 CNN: 기존 12개 + 고정 MotionBERT의 시간별 512개 특징 → CNN → 해당 다리 GDI.
- MotionBERT는 원 사전학습 가중치 그대로 사용했다. 관절 축을 평균해 얻은 전신 512개 특징을 좌우 입력에 똑같이 붙였다. GDI로 MotionBERT를 파인튜닝한 실험이 아니다.
- 기존에 학습한 단일 CNN을 이어 학습한 것도 아니다. 입력 채널이 늘어난 새 CNN을 처음부터 학습했다. 학습률·배치·손실·종료 선택 규칙은 유지했지만, 파라미터 수가 47,840→178,912개로 약 3.74배 늘었다. 같은 seed라도 구조가 달라 개별 초기 가중치까지 같은 비교는 아니다.

## 같은 평가 사람에서 나온 결과

MAE는 각 사람 안에서 기록·좌우 오차를 평균하고, 사람마다 같은 비중으로 평균한 값이다. 작을수록 좋다. 10점 구간 일치는 임상 등급 정확도가 아니다.

| 모델 | 사람 MAE↓ | 10점 구간 일치↑ | 두 구간 이상 오류↓ |
| --- | ---: | ---: | ---: |
| 단일 구간 CNN | **7.839** | 36.76% | **14.84%** |
| 고정 MotionBERT+PLS | 7.987 | **38.66%** | 15.59% |
| MotionBERT 마지막 단계 부분학습 | 8.369 | 35.16% | 16.15% |
| 고정 MotionBERT+Ridge | 8.542 | 35.75% | 17.82% |
| 이번 MotionBERT 특징+CNN | **9.024** | **32.46%** | **20.17%** |

단일 CNN 대비 5개 평가 분할 모두 악화했고, 692명 중 400명의 오차가 커졌다. 고정된 사람별 평가 예측을 10,000번 재표집한 탐색적 오차 증가 범위는 0.798~1.572점이다. 재학습 변동이나 반복 실험으로 인한 선택 효과를 포함한 확정적 통계 검정은 아니다.

단일 CNN과 결합 CNN의 학습·평가 사람은 같다. PLS·Ridge·부분학습 등 이전 모델은 695명 학습 결과에서 공통 692명만 재집계한 것이므로 학습 집단은 최대 3명 차이가 난다.

## 왜 나빠졌는가: 관측과 원인 후보

**1. 공통 MotionBERT 특징의 영향이 너무 커졌을 가능성이 높아 보인다.**

12개 다리별 특징에 512개 전신 특징을 첫 합성곱 층부터 붙였다. 저장 모델별 학습 기록 앞 32개를 진단했을 때, 첫 층에서 MotionBERT 입력이 만드는 신호 크기는 기존 특징 신호의 약 11~29배였다. 출력 채널별 평균을 뺀 변동 크기로 비교해도 약 54~152배였다. 이는 첫 층의 활성화 이전 신호 진단이며, 전체 데이터의 특성 중요도나 최종 예측의 인과 기여율은 아니다. 이후 ReLU·BatchNorm도 있으므로 이 비율을 그대로 최종 영향으로 해석하지 않는다.

좌우에 같은 512개 특징을 제공하는 구조와 함께 보면, 좌우를 구별하던 12개 특징이 충분히 활용되지 못했을 가능성이 있다. **실제 좌우 GDI 차이의 평균은 7.23점인데, 단일 CNN의 예측 좌우 차이는 5.40점, 결합 CNN은 0.35점이었다.** 이번 모델은 두 다리에 거의 같은 점수를 출력했다.

다만 좌우 차이를 크게 출력하는 것 자체가 정확도를 뜻하지는 않는다. 좌우 차이의 오차는 단일 CNN 7.48점, 결합 CNN 7.24점으로 단일 CNN도 비대칭을 정확히 맞춘 것은 아니다. 사후 진단으로 단일 CNN의 좌우 예측을 평균해 양쪽에 동일하게 적용해도 MAE는 7.850점으로 원래 7.839점과 비슷했다. 따라서 **좌우 구별 소실만을 전체 악화의 원인으로 단정하지 않는다.** 이 진단 예측을 새 성능 후보로 선택한 것은 아니다.

**2. 낮은 점수와 높은 점수를 구별하는 능력도 줄었다.**

예측 범위는 단일 CNN 51.75~103.79점에서 결합 CNN 57.53~91.66점으로 좁아졌다. 기록·좌우 기준 예측 표준편차도 8.98→6.58점으로 줄었다. 좌우 평균 점수 자체의 사람 MAE 역시 6.805→8.250점으로 악화했다. 양쪽 점수가 같아진 것뿐 아니라 사람 간 차이도 덜 반영한 것이다.

| 사람의 실제 평균 GDI 구간 | 사람 수 | 단일 CNN MAE | 결합 CNN MAE |
| --- | ---: | ---: | ---: |
| 60 미만 | 62 | 10.837 | 13.785 |
| 60~70 미만 | 171 | 6.713 | 8.390 |
| 70~80 미만 | 246 | 6.822 | 6.683 |
| 80~90 미만 | 145 | 7.896 | 9.166 |
| 90 이상 | 68 | 11.493 | 14.444 |

이 표는 사람별 실제 좌우·기록 평균으로 집단을 나누고 그 집단에서 사람 MAE를 계산한 사후 진단이다. 임상 구간을 정한 것이 아니다. 가운데 구간은 약간 좋아졌지만 양끝에서는 예측이 가운데로 치우치며 오차가 늘었다.

**3. 단순히 더 오래 학습하면 해결될 양상은 아니다.**

20개 내부 학습의 평균 곡선에서 결합 모델은 40→100epoch 동안 학습 MAE가 7.67→5.44로 줄었지만 검증 MAE는 8.87→9.14로 커졌다. 같은 100epoch에서 단일 CNN의 학습 MAE는 5.38, 검증 MAE는 7.99였다. 두 모델이 학습 자료를 맞추는 수준은 비슷해져도, 결합 모델은 새로운 사람에게 덜 일반화되는 과적합 양상을 보인다.

실제 최종 모델은 100epoch를 무조건 사용하지 않고 내부 검증으로 더 이른 35~43epoch를 선택했다. 선택 절차의 오류는 아니며, 종료 시점 조절만으로 기준 CNN을 따라잡지 못했다. 특징 수·학습 가능 파라미터·정규화·초기값 등이 함께 달라졌으므로 어느 요인이 얼마나 기여했는지는 추가 통제 실험이 필요하다.

**4. 보정 계산이 악화의 주원인이라는 근거는 없다.**

결합 모델의 학습 내 선형 보정 전 MAE는 9.217점, 보정 후는 9.024점이다. 보정이 오차를 조금 줄였지만 정보 손실·일반화 문제를 해결하지는 못했다. 특징 추출 정합성도 확인했으므로, 우선 조사할 대상은 단순 파일 오류보다 결합 구조와 학습 설정이다.

![학습 곡선과 사람별 평가 예측](analysis/diagnostics.png)

왼쪽: 점선은 학습, 실선은 내부 검증의 20개 학습 평균이다. 주황색 결합 모델은 학습 오차가 계속 낮아져도 검증 오차가 다시 커진다. 오른쪽: 사람별 실제·예측 평균이며 회색 대각선에 가까울수록 정확하다. 결합 예측은 가운데로 더 모인다. 그래프의 내부 곡선 평균은 설명용이고, 실제 종료 시점은 각 바깥 분할 안에서 검증 인원으로 가중해 선택했다.

## 다음에 검토할 순서

현재 결과를 보면 **기존 CNN 경로를 보존하면서 MotionBERT의 추가 정보만 작게 반영하는 결합**이 더 가능성 있어 보인다. 아래는 후속 후보이며 구현·학습을 새로 시작한 것은 아니다.

1. 두 입력을 각각 처리한 뒤 마지막에서 합치는 방식부터 검토한다. 기존 12개 특징의 CNN 경로를 유지하고, MotionBERT의 512개 특징은 작은 층으로 줄여 합친다. 추가 특징의 크기를 제한하고, 가능하면 같은 학습 범위의 기준 CNN 가중치를 활용한다. 내부 검증용 모델에는 해당 내부 학습 사람으로만 학습한 가중치를 사용해야 한다.
2. 단순 결합과 구조 변경의 효과를 나눌 수 있도록, 압축한 특징의 결합과 다리별 특징을 보존한 결합을 동일한 사람 분할에서 비교한다. 차원 축소·정규화·설정 선택은 각 학습 집단 안에서만 한다. 평가 결과를 보고 최적 설정을 선택하지 않는다.
3. 결합 구조가 내부 검증에서 유효하다는 근거를 얻은 뒤 MotionBERT 마지막 부분의 학습을 검토한다. 현재의 524채널 직접 결합 상태에서 학습 범위만 늘리는 것은 우선순위가 낮아 보인다.

이번 바깥 평가 결과를 보고 새 후보를 설계하는 만큼 후속 비교는 개발용 반복 실험이다. 독립 최종 평가 성능으로 부르지 않는다. 여러 구간 CNN 결과와 별도 SPPB/TUG 작업은 이 결합 실험의 결과와 섞지 않는다.
