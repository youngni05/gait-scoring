# 고정 MotionBERT 시간별 특징과 단일 구간 CNN 결합

같은 692명·1,061기록, 같은 124프레임과 사람별 분할에서 MotionBERT 특징 추가의 가능성을 확인한다. 비교 기준은 완료한 원 연구식 입력 단일 구간 CNN의 MAE 7.839점이다. 이번 묶음은 준비용이며 실제 GPU 학습이나 성능 개선을 완료했다는 뜻이 아니다. 여러 구간 CNN과는 폴더·로그·작업을 분리한다.

## 모델이 하는 일

입력은 같은 구간에서 만든 두 자료다. 하나는 기존 CNN의 좌우 다리별 12개 좌표·각도·거리 특징이다. 다른 하나는 기존 MotionBERT용 17관절 x/y/신뢰도 좌표다. 정답은 기록별 좌우 GDI다.

`17관절 좌표 → 고정 MotionBERT → 프레임마다 512개 특징`

`기존 12개 특징 + 시간별 512개 특징 → 524채널 CNN → 해당 다리 GDI → 학습 내 선형 보정`

기존 512개 특징 파일은 시간까지 평균해 움직임의 순서가 사라져 있다. 이번에는 MotionBERT의 `[기록,124프레임,17관절,512특징]` 출력에서 관절 방향만 평균한다. `[기록,124프레임,512특징]`을 저장하며 시간 방향은 유지한다. 전신 특징은 좌우 입력에 같은 값으로 추가하고, 기존 좌우별 12개 특징은 각각 유지한다. 512개는 공간 좌표축이 아닌 학습된 특징이다.

## 무엇을 학습하는가

MotionBERT는 원 사전학습 `MB_lite.bin`을 읽고 전체 가중치를 고정한다. 앞선 GDI 부분학습 모델은 사용하지 않는다. 따라서 특정 평가 사람을 이미 학습한 가중치를 다시 쓰지 않는다. 특징 추출에는 GDI 정답이 필요 없으며, 추출 코드는 정답이 없는 `motion_input.npz`만 읽는다.

CNN은 처음부터 학습한다. 첫 Conv1D의 입력만 12→524채널로 늘리고 나머지 6층 CNN 구조·배치·학습률·정규화·최대 epoch·사람 분할·선형 보정 절차는 기존 기준과 같다. 학습 파라미터는 47,840→178,912개다. 입력 특징과 모델 크기가 함께 바뀌는 비교이므로 개선이 있어도 사전학습 지식만의 효과로 단정하지 않는다. MotionBERT 파인튜닝과 여러 구간 결합은 이번 실행에 포함하지 않는다.

MotionBERT 특징 512개의 평균·표준편차는 각 내부 학습 또는 바깥 재학습의 **학습 기록과 시간에서만** 구한다. 기존 12개 특징은 추가 정규화하지 않는다. 검증·평가 자료에는 저장한 학습 평균·표준편차만 적용한다. 이 값은 CNN 체크포인트에 함께 저장한다.

## 검증과 평가

입력 대응·사람 분리·계수 적용·최종 집계는 기존 검사를 유지한다. 추가로 시간별 특징의 시간 평균이 기존 고정 MotionBERT 특징과 일치하는지, 추출 전후 가중치가 그대로인지, 묶음 크기에 따라 결과가 달라지지 않는지 확인한다. 허용하는 특징 최대 절대차는 0.0001이다. 캐시는 입력·사전학습 모델·코드 지문으로 구분하고, 중단 후 완료된 부분의 지문을 확인한 뒤 이어서 추출한다.

주 결과는 학습 자료만으로 보정한 예측이며, 보정 전 예측도 진단용으로 저장한다. 기존과 같은 내부 20개 학습으로 epoch를 고르고 바깥 5개 재학습으로 평가한다. 바깥 평가 정답으로 설정이나 종료 시점을 선택하지 않는다. 692명으로 평가 대상을 맞춘 Ridge·PLS·부분학습·이전 CNN과도 비교하지만, 이 기존 모델들은 원래 695명으로 학습됐다는 차이가 있다. 새 기준 CNN과 이번 결합은 692명으로 맞춘다.

## GPU에서 실행할 순서

1. `run.py check`: 실제 입력·대응·분할 검사. 학습 없음.
2. `features.py check`: 실제 두 기록으로 고정 특징·시간축·묶음별 일치 검사. 학습 없음.
3. `run.py smoke`: 가상 자료로 CNN 갱신·저장·재개 검사.
4. `features.py extract`: 실제 전체 입력에서 고정 특징을 한 번 추출해 캐시. 정답 학습 없음.
5. `run.py pilot`: 내부 학습 416명·검증 138명으로 실제 3epoch. 바깥 평가 미사용.
6. 파일럿 확인 후 `run.py train`: 전체 25개 학습·평가와 결과 압축.

서버 폴더는 `/abr/RESEARCH_USER/gdi-cnn-motionbert-fusion-20261030`이다. 파일럿은 특징 캐시 생성까지 포함하므로 1시간 한도로 제출한다. GPU 1개·CPU 4개·RAM 12GB이며, 본 학습 기본 한도는 5시간이다. 실제 GPU 시간과 VRAM은 파일럿 전에는 미측정이다. 기존 여러 구간 작업이 실행 중이라면 다른 GPU에 배정되도록 기존 노드를 제외한다.

```bash
cd /abr/RESEARCH_USER/gdi-cnn-motionbert-fusion-20261030
mkdir -p logs
sbatch --time=01:00:00 --exclude=DIS02,DIS06 submit.slurm pilot
# 파일럿 완료를 확인한 다음에만 본 학습을 제출한다.
sbatch --exclude=DIS02,DIS06 submit.slurm train
```

위 DIS02 제외는 여러 구간 CNN의 현재 노드 기준이다. 제출 직전에 실제 작업 상태를 확인한다. 로그는 `logs/pilot.log`, `logs/train.log`, 특징은 `cache/temporal/`, 결과는 `runs/main/`, 회수 압축은 `runs/main-review.tar.gz`다. 완료 표시는 `FUSION_CNN_PILOT_FINISHED`, `FUSION_CNN_TRAINING_AND_EXPORT_FINISHED`다. 체크포인트와 캐시를 유지한 채 같은 명령으로 재개할 수 있다.

CNN 원 공개 출처는 `sources/`, 기존 MotionBERT 코드와 라이선스는 `lib/`, `MOTIONBERT_LICENSE`에 있다. 신규 패키지를 서버에 설치할 필요 없이 기존 NumPy·PyTorch를 사용하는 구성이다. 실행 가능 여부는 해당 서버 파일럿에서 최종 확인한다.
