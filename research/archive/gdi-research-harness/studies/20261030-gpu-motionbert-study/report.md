# MotionBERT 부분학습 1차 결과

기준일: 2026-10-30. DIS01에서 실제 GDI 학습 15작업·총 3,000회 갱신을 완료했다. 내려받은 예측 파일과 완료 기록을 로컬에서 검산했다. **이번 설정에서는 기존 MotionBERT+Ridge를 교체할 만큼 일관된 개선을 확인하지 못했다.**

## 무엇을 확인하려 했는가

같은 자료에서 점수 계산부만 추가 학습하는 경우보다 MotionBERT의 특징 추출 부분도 조정하는 경우가 더 정확한지 확인했다. 전체 모델을 처음부터 학습한 실험은 아니다.

입력은 Stanford/mobile-gaitlab 유래의 기존 개발 175명·203기록이다. 17관절의 x·y·관측 신뢰도로 구성된 124프레임을 MotionBERT-Lite가 512개 특징으로 요약하고 선형 출력부가 좌우 GDI를 예측한다. 원본 RGB 처리나 3D 관절 정확도 검사는 하지 않았다.

| 조건 | 학습하는 부분 | 학습 매개변수 수 |
|---|---|---:|
| 기존 기준 | 없음. 기존 MotionBERT와 Ridge 유지 | 0 |
| head_only | 기존 Ridge 계수로 시작한 선형 출력부 | 1,026 |
| tail | 마지막 정규화·특징 변환부와 출력부 | 133,122 |
| last_stage | 마지막 공간·시간 Transformer 단계와 특징 변환부·출력부 | 3,293,188 |

출력부는 Ridge 계수에서 시작하지만 추가 학습 후 Ridge 해를 다시 계산한 모델은 아니다. 특징 표준화는 기존 각 fold의 학습 자료에서 구한 값을 유지했다. 모델을 조정한 뒤 새 특징으로 Ridge를 다시 적합하는 실험은 별개이며 아직 실행하지 않았다.

## 어떻게 진행했는가

- 사람 단위 고정 5분할, 매번 140명 학습·35명 평가. 같은 사람이 해당 작업의 학습·평가에 동시에 들어가지 않는다.
- 앞 124프레임으로만 학습하고 제외한 사람의 앞·뒤 124프레임으로 평가했다. 앞·뒤는 촬영 방향이 아니라 같은 영상의 시간 구간이며 일부 겹친다.
- seed 20261028, 배치 32, 작업당 200회 갱신, AdamW, 출력부 학습률 0.0001, 본체 학습률 0.00001, weight decay 0, dropout 비활성화. 세 방법의 초기값·입력 순서·학습 예산을 맞췄다.
- 손실은 기록에 같은 비중을 둔 좌우 GDI 제곱 오차다. 결과 지표는 사람 안에서 좌우·기록을 먼저 평균하고 사람 간 평균했다.
- GPU 환경: DIS01, NVIDIA RTX A6000, Python 3.8.10, PyTorch 2.4.0+cu121. 사전 가상 검사에서 batch 32의 last_stage 최대 PyTorch 할당 메모리는 약 5.55GiB였다. 실제 학습의 최대 메모리를 따로 측정한 값은 아니다.
- 서버 로그 기준 학습·집계 구간은 14:21:54~14:38:49 KST, 16분 55초였다. 환경 진단·전송·후속 분석은 포함하지 않는다.
- DIS06에서는 최소 GPU 메모리 할당이 멈췄고 DIS01에서는 통과했다. 노드 변경으로 실행할 수 있었지만 원인을 하드웨어 고장으로 확정하지 않았다.

## 실제 결과

아래 세 값은 모두 작을수록 좋다. 단위는 GDI점이며 정확도 백분율이 아니다.

| 방법 | 앞 구간 평균 절대 오차 | 뒤 구간 평균 절대 오차 | 앞뒤 예측 차이 |
|---|---:|---:|---:|
| 기존 MotionBERT+Ridge | 8.276 | 9.034 | 3.960 |
| 출력부만 학습 | 8.282 | 9.030 | 3.923 |
| 마지막 특징 변환부도 학습 | 8.319 | 9.070 | 3.922 |
| 마지막 Transformer 단계까지 학습 | 8.294 | 8.926 | 4.041 |

tail은 기존 기준보다 앞·뒤 오차가 모두 조금 커졌다. last_stage는 뒤 구간 오차가 약 0.108점 줄었지만 앞 오차는 약 0.018점, 앞뒤 차이는 약 0.081점 커졌다. 출력부만 학습한 대조와 비교해도 같은 방향이다.

사람을 짝지어 10,000번 재표집한 last_stage의 기존 기준 대비 뒤 오차 감소량 95% 범위는 약 **-0.080~0.302점**으로 0을 포함한다. 출력부만 학습한 대조 대비 감소량도 약 0.104점, 범위 -0.082~0.294점이다. 이번 자료·고정 설정에서 확실한 개선이라고 보기 어렵다. 이는 반복 탐색한 개발 집단의 탐색적 범위이며 여러 비교를 보정한 확증 검정이 아니다.

## 10점 구간 표시와 예측 분포

구간은 기존 분석과 같은 `[10k, 10(k+1))`, 즉 floor(GDI/10)이다. 임상 등급을 만들거나 0~100으로 자르지 않았다. 아래 비율도 사람별 동일 가중 평균이다.

| 방법 | 앞 구간의 정확한 구간 일치 | 뒤 구간의 정확한 구간 일치 |
|---|---:|---:|
| 기존 기준 | 38.57% | 34.38% |
| 출력부만 학습 | 38.14% | 34.38% |
| tail | 38.33% | 33.19% |
| last_stage | 39.67% | 33.71% |

last_stage는 앞의 정확 구간 비율이 약 1.10%p 높아졌으나 뒤에서는 낮아졌다. 앞에서 한 구간 이내인 비율도 기존 80.90%에서 80.33%로 낮아졌다. 정확 구간 일치 한 항목만으로 점수화가 개선됐다고 판단하지 않는다.

앞 구간 예측 범위는 기존 51.21~89.74점에서 last_stage 47.22~91.36점으로 넓어졌다. 사람별 좌우·기록 평균 예측의 표준편차도 5.88에서 6.75로 커졌다. 예측이 더 좁게 몰려 일관성만 좋아진 결과는 아니지만, 범위 확대 자체가 정확도 개선을 뜻하지는 않는다. 점수대별 오차와 편향은 `analysis/dis01-first-run/score_bands.csv`에 남겼다.

## 확인한 것과 남은 한계

- 내려받은 설정을 사전 설정과 대조했다. 실행 코드·manifest는 전송용 사본과 일치했고 그 사본의 14파일 지문도 확인했다.
- 15개 작업의 설정·fold·seed·CUDA 환경 선언·완료 기록과 예측 파일 지문을 검사했다. 각 방법의 203기록이 해당 평가 fold에서 한 번씩 예측됐고 누락·중복·비유한 값이 없었다.
- 서버의 주요 지표를 다른 형태의 사람 가중 합으로 재계산했다. 최대 차이는 약 1.78e-15점이다. 서버의 재표집 범위도 재현했다.
- GPU head_only와 기존 CPU head_only의 개별 예측 최대 차이는 약 3.55e-14점으로 수치 정밀도 수준이었다. 서버 이전으로 대조 결과가 크게 바뀐 문제는 보이지 않았다.
- 체크포인트는 서버에 보존했고 이번 다운로드에는 포함하지 않았다. 따라서 로컬에서 모델을 다시 추론하거나 가중치 변경 범위를 독립 재검사한 것은 아니다. frozen_unchanged는 서버 실행기의 검사 기록으로 확인했다.
- 시드 1개, 고정된 학습률과 200회 갱신, 기존 175명에서의 첫 비교다. 최적 학습 설정을 찾았거나 과적합 원인을 밝혔다는 결과가 아니다. 마지막 미니배치 손실만으로 전체 학습 손실·수렴·일반화 간격을 판단하지 않는다.
- 기존 37/38명, 추가 개발 520명, 최종 평가 예약 223명은 이번 실행에 넣지 않았다. 독립 최종 평가, 고령자 실사용, 재촬영·시점 변화, 임상 유용성 결과가 아니다.

## 현재 판단과 다음 연구

이번 조건에서는 기존 Ridge를 유지한다. 부분학습이 항상 무효라고 결론 내리지는 않는다. 모델을 더 크게 바꿨다는 이유만으로 정확도가 좋아지지는 않았다는 첫 비교 결과로 남긴다.

175명을 후속 연구의 상한으로 두지 않는다. 추가 개발 520명을 포함한 **695명 규모의 확대 개발 후보**에서 학습·검증을 사람 단위로 분리하고 자료 확대 효과를 확인하는 것이 다음 우선순위다. 현재보다 많은 자료가 실제로 도움이 되는지는 아직 실험하지 않았다. 확대 조건의 기준 모델과 부분학습을 같은 평가 사람에게 비교해야 하며 기존 평가자료의 역할은 유지한다.
