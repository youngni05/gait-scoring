# CNN과 STT 예측 결합 — 2026-10-31

같은 사람의 여러 보행 구간을 사용한 CNN과 STT의 예측을 결합해, 단독 모델의 오류를 서로 보완할 수 있는지 비교했다. 기존 신경망은 추가 학습하거나 변경하지 않았다. 692명·1,061기록·11,261구간의 기존 사람 분할을 유지했다.

## 확인한 결과

| 방식 | 사람별 동일 비중 MAE |
|---|---:|
| 여러 구간 CNN | 6.866655 |
| 여러 구간 STT | 6.944988 |
| 고정 50:50 결합 | 6.694609 |
| 학습 사람 내부에서 비율을 정한 결합 | **6.686592** |

내부 선택 결합은 CNN보다 0.180063점, 약 2.62% 낮았고 5개 바깥 분할 모두 개선됐다. 382명에서 오차가 줄고 310명에서 커졌다. 고정 50:50보다 개선된 폭은 0.008016점으로 작다. 현재는 비율을 세밀하게 맞추는 효과보다 두 모델의 오류를 일부 보완하는 효과가 주된 것으로 보인다.

692명을 동일 비중으로 재표집한 10,000회 비교에서, 결합−CNN MAE 차이의 95% 구간은 −0.280960~−0.084321점이었다. 이는 고정된 개발용 예측에 대한 기술적 비교다. 초기값 변화·반복적인 모델 탐색의 불확실성까지 포함한 구간이나 독립 최종 검증이 아니다. 원 연구의 6.5와 같은 대상·평가 조건을 재현했다는 뜻도 아니다.

## 평가 정답이 비율 선택에 들어가지 않도록 한 방법

1. 바깥 평가 집단 하나를 제외한다.
2. 나머지 네 집단에서, 각 내부 검증 사람을 학습하지 않은 CNN·STT의 예측을 모은다. 이 내부 모델은 바깥 평가 사람도 학습하지 않았다.
3. `CNN 비율 × CNN 예측 + (1−CNN 비율) × STT 예측`을 계산한다. CNN 비율 0~1을 0.05 간격으로 비교해 사람별 동일 비중 MAE가 가장 낮은 값을 선택한다. 동점이면 0.5에 가까운 값, 다시 동점이면 작은 값을 고른다.
4. 비율을 저장하고 고정한 뒤에만 해당 바깥 집단의 기존 최종 예측을 결합해 평가한다. 이 과정을 다섯 번 반복한다.

선택된 CNN 비율은 fold0부터 **0.35·0.60·0.50·0.50·0.65**다. 모든 바깥 평가 예측을 한꺼번에 모아 최적 비율을 찾는 방식은 사용하지 않았다. 보정 기울기·절편은 각 기본 모델이 자기 학습 기록으로 계산한 기존 값을 사용하며 결합 뒤 추가 보정은 하지 않는다. 보호된 최종 평가자료는 열지 않았다.

## 중요한 비교 한계

CNN 내부 학습은 마지막 100epoch 모델만 남아 있어 결합 비율 학습에는 CNN 100epoch·STT 200epoch의 고정 마지막 모델을 사용했다. 바깥 평가는 기존처럼 각 모델의 내부 선택 epoch로 재학습한 최종 예측이다. 따라서 내부 모델과 바깥 최종 모델의 학습 길이가 완전히 같지는 않다. 평가 정답이 비율 선택에 들어간 것은 아니지만, 비율이 다른 학습 길이에서도 그대로 잘 맞는다는 보장은 없다.

또한 같은 692명 개발자료에서 여러 실험 결과를 이미 확인하며 이번 결합을 정했다. 사람 분리를 지킨 중첩 비교와 새 독립 자료의 최종 검증을 구분한다. 결과를 보고 비율 후보나 규칙을 바꾸지 않았다.

## 검산과 재현

완료된 CNN 내부 체크포인트 20개를 별도 회수하고 서버·로컬 SHA256과 기존 완료 기록을 대조했다. CPU 재추론으로 학습·내부 검증 예측을 계산했다. STT는 지문이 일치하는 각 마지막 epoch의 저장 원시 예측을 사용했다. 160개 근거 파일, 구간·사람·정답·분할 순서, 내부 20개 학습의 사람 분리, 학습자료만의 보정, 동일인 총 평가 비중을 확인했다.

별도 검산은 점수를 사람·기록별로 다시 합산하고, 평가 정답을 바꿔도 결합 비율이 바뀌지 않는지, 행 순서를 바꿔도 동일한지, 평가 사람을 섞은 잘못된 입력을 거부하는지 확인했다. CNN CPU 보정 예측 검산 차이는 최대 0.000021034점으로 기존 0.0001점 기준 이내였다. 신경망 최적화는 0회다.

- `protocol.json`: 결과 평가 전에 고정한 비교 조건
- `compare.py select`: 내부 예측 검산·결합 비율 저장. 바깥 예측 파일을 열지 않는다.
- `compare.py evaluate`: 저장한 비율을 바깥 예측에 적용
- `verify.py`: 별도 계산·오염 입력·원본 지문 검산
- `analysis/comparison.json`, `analysis/verification.json`: 결과와 검산 근거

기존 GPU 학습과 할당, 자동 감시 설정은 변경하지 않았다.
