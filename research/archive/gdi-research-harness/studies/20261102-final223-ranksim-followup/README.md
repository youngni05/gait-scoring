# 일반 CNN·RankSim 추가의 고정 비율 후속 비교

2026-11-02. **RankSim 추가가 CNN 모델 평균보다 더 낫다는 근거를 확보하지 못했다. 일반 CNN을 추가한 구성보다도 더 낫다고 결론 내릴 수 없다.**

사용자 요청으로 기존 최종 평가 결과를 보존하고 같은 222명·377기록에서 후속 비교했다. 이는 기존 최종 평가 결과를 이미 확인한 뒤의 **사후 보조 분석**이며, 새 미사용 집단의 독립 최종 평가로 부르지 않는다. 모델·결합 비율은 개발자료에서 이미 정했던 값을 그대로 고정했고 재학습·보정 변경·추가 제외는 하지 않았다.

## 동일 평가 집단의 결과

| 구성 | 사람 동일 비중 MAE | MAE 95% 구간 | 상관계수 |
|---|---:|---|---:|
| CNN만 모델 평균 | 6.266755 | 5.832308~6.704704 | 0.766831 |
| 기존 CNN·STT·좌우 보완 결합 | 6.248559 | 5.820594~6.670789 | 0.768134 |
| 기존 결합 + 일반 CNN | **6.223336** | 5.792203~6.651693 | 0.769247 |
| 기존 결합 + RankSim CNN | 6.227104 | 5.795575~6.656157 | 0.768255 |

사람 안의 반복 기록과 좌우 절대오차를 평균한 뒤 222명을 같은 비중으로 평균했다. 아래 차이는 새 구성−비교 기준이며 음수가 새 구성에 유리하다.

| 사전에 고정한 주 비교 | MAE 차이 | 상대 감소 | 사람 짝지은 95% 구간 | 두 주 비교를 함께 고려한 구간 |
|---|---:|---:|---|---|
| 일반 CNN 추가 − CNN 평균 | -0.043419 | 0.693% | -0.139337~+0.054193 | -0.153676~+0.066218 |
| RankSim 추가 − CNN 평균 | -0.039652 | 0.633% | -0.131441~+0.053405 | -0.144106~+0.064822 |

모두 0을 포함해 추가 개선 불확실이다. 일반 CNN 추가는 119명 개선·103명 악화, RankSim 추가는 115명 개선·107명 악화였다. 10,000회 사람 단위 재표집, seed20261103을 고정했다. 마지막 열은 두 비교의 가족 단위 95% 수준을 위한 Bonferroni 보정으로 각각의 양측 97.5% 구간을 쓴 것이다. 이 보정이 이전의 개발 탐색·사후 선택까지 해소하는 것은 아니다.

## 추가 효과를 나눈 보조 비교

- 일반 CNN 추가−기존 결합: -0.025223점, 95% -0.057895~+0.007943점.
- RankSim 추가−기존 결합: -0.021455점, 95% -0.059319~+0.016988점.
- **RankSim 추가−일반 CNN 추가: +0.003768점**, 95% -0.028045~+0.035316점.

보조 비교도 모두 0을 포함했다. 따라서 낮은 점 추정만으로 RankSim의 고유한 추가 가치나 두 방법의 동등함을 주장하지 않는다. 이 보조 구간에는 별도의 다중 비교 보정을 적용하지 않았다.

실제 사람 평균 GDI90 이상 26명의 MAE는 CNN 평균8.731796, 기존 결합8.931501, 일반 CNN 추가8.901215, RankSim 추가8.907913점이다. 두 추가 구성 모두 이 집단에서는 CNN 평균보다 오차가 작지 않았다.

## 고정한 구성과 검증

- 기존 최종 평가의 입력·377개 기록 순서·좌우 정답·CNN 평균·결합 예측을 그대로 재사용했다. 원래223명 중1명 제외 판단을 바꾸거나 다시 제외하지 않았다.
- 일반 CNN은 기존 `scratch_control` MSE 대조군의 refit5개다. 개발 내부에서 정한 추가 비율은 분할별 **0.35/0.20/0.20/0.10/0.20**이다.
- RankSim은 기존 refit5개이며, 추가 비율은 **0.45/0.05/0.15/0.35/0.30**이다.
- 각 분할 안에서 `(1-w)×기존 결합 + w×추가 CNN`을 계산한 뒤 다섯 분할을 같은 비중으로 평균했다. 전체 평균에 평균 비율을 한 번 적용하는 다른 식을 사용하지 않았다.
- 기존10개 체크포인트의 학습·검증 사람과 예약 참가자 중복은0명이다. 개발자료 두 기록씩 재추론한 최대 차이는 모두 기존 허용치0.0001점 미만이다. 추가 CNN은 기존 검산 경로대로 CPU float64로 계산했고, 기존 결합 예측의 float32 결과는 변경하지 않았다.
- 모든 후속 예측을 고정한 뒤 기존 정답을 다시 읽었다. 학습·epoch선택·결합비율 선택은0회다. 새 패키지·GPU작업·기존 학습·예약 변경은 없다.
- 별도 식의 결합 재구성 최대 차이는2.8422e-14점이다. 독립 반복문으로 사람별 MAE와 두 종류의 재표집 구간을 재계산했다. 기존 최종 평가 폴더의 원래 파일들과 입력·예측·정답 배열의 지문이 모두 그대로임을 확인했다.

분할별 MAE와 표준편차는 [fold-diagnostics.json](fold-diagnostics.json)에 보존했다. 이 값은 같은222명에 다섯 출처 모델을 각각 적용한 진단이며, 다섯 번 독립 최종 평가나 반복 촬영 오차가 아니다. 이전 최종 평가와 MAE95 범위가 조금 다른 것은 후속 분석의 재표집 seed가 달라서이며, 기존 점수와 원래 보고서는 변경하지 않았다.

## 해석과 산출물

발표·논문에는 다음처럼 설명할 수 있다.

> 일반 CNN과 RankSim CNN을 기존 시스템에 추가했을 때 평균 오차는 소폭 감소했으나, CNN 모델 평균 대비 차이의 신뢰구간이 0을 포함했다. RankSim의 추가 효과도 일반 CNN 추가와 구분되지 않았다.

[protocol.json](protocol.json)은 후속 비교 전 고정한 기준, [models.json](models.json)은 모델·보정식·비율·파일 지문, [results.json](results.json)은 전체 수치, [verification.json](verification.json)은 독립 검산이다. 작은 코드·기록은 이 C 폴더, 새 예측 배열은 `D:/gait-research-data/D_P/final223-ranksim-followup-20261102`에 저장했다. 기존 최종 평가 파일은 수정하지 않았다.

같은 공개자료의 사후 비교다. 고령자·실제 촬영 서비스의 정확도나 임상 유효성은 검증하지 않았다.
