# Mobilise-D 일어서기 정답 정리와 시간·느림 확률 비교 — 2026-10-31

**보행 패턴을 추가하면 일어서기 예측이 조금 개선되지만, 느린 사람을 구분하는 능력은 여전히 부족하다. 확률을 직접 학습한 모델이 시간 회귀를 확률로 보정한 모델보다 일관되게 낫지는 않았다. TUG는 더 잘 구분했지만 질환별 누락률과 오경보 차이가 컸다.**

정답 정리, CPU 학습, 사람 분리 평가, 질환별 분석, 재검산을 완료했다. 새 모델 360개 조건을 학습했다. 같은 사람을 여러 번 평가한 것이므로 독립 표본 수가 늘어난 것은 아니다. 센서의 **주간 보행 요약**을 입력으로 사용했으며 6초 영상·한 번의 10~30초 보행 실험이 아니다. 기존 OpenCap 및 다른 Mobilise-D 연구 결과는 수정하지 않았다.

## 무엇을 정답으로 사용했는가

원자료는 [Mobilise-D CVS 공개본](https://zenodo.org/records/21060991)이다. 이전 감사에서 같은 사람·같은 방문의 임상 검사와 보행을 연결하고, 제공자 필터를 통과한 유효일 3일 이상, 양수인 보행 속도, 검사·센서 측정 날짜 차이 ±14일 조건을 적용했다. 각 정답의 첫 적격 방문을 고정했다. 이번 정리에서 제외한 사람의 뒤 방문으로 대체하지 않았다.

| 정답 | 기존 연결 후보 | 이번 제외 | 최종 독립 사람 | 실제 20초 이상 |
|---|---:|---:|---:|---:|
| 5회 일어서기 | 1,972 | 2 | **1,970** | **408** |
| TUG | 1,984 | 4 | **1,980** | **277** |

일어서기는 한 번 일어서기를 팔 없이 수행했고, 한 번·다섯 번 수행의 안전 여부가 모두 긍정이며, 기록 시간과 제공자의 의자 점수가 일치해야 포함했다. 0초, 3초 미만, 사전 범위 120초 초과, 수행 상태와 모순된 시간은 별도 상태로 기록했다. 3초 미만은 이번 감사에서 확인이 필요한 기록으로 보류한 것이며 생리적으로 불가능함을 입증한 경계가 아니다.

최초 후보에서 실제 제외된 일어서기 사례는 0.01초 기록 1명과, 다섯 번 수행이 안전하지 않다고 기록됐는데 16초가 있는 1명이다. 전체 방문에는 0.217초도 있었으나 이 방문은 최초 후보가 아니었다. TUG는 3초 미만 4명을 제외했다. 원래 값을 수정하거나 임의로 단위 환산하지 않았다.

일어서기 60초 초과 7명과 TUG 60초 초과 12명은 유지했다. TUG는 자료 사전 상한 60초와 실제 값이 다르므로 미해결 사항으로 남겼고, 평가에서 60초 초과 사람을 뺀 보조 집계도 수행했다. 원본 기록의 진실성을 영상으로 확인한 것은 아니다.

**수행 불가·안전 문제·시간 결측을 빠른 사람으로 처리하지 않았다.** 전체 방문 감사에서는 시간 없이 표준 수행을 못 했거나 안전하지 않았다고 표시된 1,415개 방문, 독립 717명이 있었다. 첫 SPPB 연결 방문 2,232명 중에서도 이 상태가 477명이다. 이 수들은 방문 선택이 다른 1,970명에서 단순히 뺄 수 있는 인원이 아니다. 이번 시간/느림 비교는 표준 수행 완료자의 유효 시간이 있는 집단에 한정된다. 수행 불가까지 포함한 전체 기능 저하 분류 성능을 뜻하지 않는다.

## 같은 조건에서 무엇을 비교했는가

- **속도 입력:** 짧은/긴 보행군의 속도 평균, 상위값, 변동 등 제공자 주간 요약 5개.
- **패턴 추가:** 같은 속도 5개에 보폭, 걸음 빈도, 보행 주기 및 그 변동 관련 주간 요약 10개를 추가했다. 관절 각도나 RGB에서 추출한 패턴은 아니다.
- **결측 대조:** 속도와 추가 패턴의 결측 여부만 사용했다. 실제 패턴값의 효과와 자료가 비어 있는지의 효과를 구분한다.
- 실제 검사 내부의 보행 속도, 의자·균형 점수, TUG, SPPB 총점, 질환명, 나이 등은 보행 모델의 입력에서 제외했다. 질환만 쓰는 별도 기준은 해석용으로 계산했다.

일어서기와 TUG에 공통된 사람 분할표를 만들었다. 질환 구성으로 층화한 5개 묶음을 3가지 난수(17/41/89)로 구성했다. 매번 3묶음은 학습, 1묶음은 확률 보정 및 판정 문턱 설정, 나머지 1묶음은 평가에 사용했다. 두 입력과 모든 모델이 동일한 사람 분할을 사용했다. 사람마다 정답별 기록 하나만 사용했다.

시간 예측은 Ridge와 RF 회귀, 직접 확률 예측은 로지스틱 회귀와 RF 분류를 비교했다. 고정 설정은 Ridge 규제 10, 로지스틱 C=1, RF 200개 나무·최소 잎 10명이다. 평가 결과로 설정을 고르지 않았다. 중앙값 대체와 정규화는 학습 사람에서만 계산했다.

시간 모델에도 공정하게 기회를 주기 위해 예측 시간을 별도 보정 집단에서 느림 확률로 변환했다. 직접 분류 모델도 같은 방식의 시그모이드 보정을 적용했다. 보정 사람 중 실제 20초 미만 집단의 상위 10% 경계 바로 위를 문턱으로 사용했다. **평가 집단에서 오경보율이 정확히 10%가 되도록 문턱을 다시 고르지 않았다.** 아래는 실제 관측한 오경보율이다. 20초는 이전 분석을 잇는 연구용 구분이며 임상 진단 경계가 아니다.

## 시간 예측 결과

단위는 초이며 세 번의 사람 분할 결과를 평균했다. 과소예측은 `max(실제−예측,0)`을 실제 20초 이상인 사람에게서 평균한 값이다. 과대예측과 상쇄하지 않았다.

| 정답·모델 | 속도만 MAE | 패턴 추가 MAE | 느린 사람 과소예측: 속도 → 패턴 |
|---|---:|---:|---:|
| 일어서기·Ridge | 4.877 | **4.702** | 9.966 → **9.321** |
| 일어서기·RF 회귀 | 4.897 | **4.713** | 9.750 → **9.346** |
| TUG·Ridge | 4.672 | **4.275** | 11.595 → **9.950** |
| TUG·RF 회귀 | 3.920 | **3.673** | 10.058 → **9.553** |

일어서기는 모든 사람에게 학습 집단 중앙값만 출력하는 기준의 MAE도 4.855초였다. 패턴 추가 모델은 이를 조금 넘지만, 느린 사람의 과소예측이 약 9초 남는다. 따라서 평균 오차의 작은 개선을 큰 기능 추정 성공으로 해석하지 않는다.

## 느린 구간 확률을 직접 학습한 결과

누락률은 실제 20초 이상인 사람을 느리다고 표시하지 못한 비율이다. 오경보율은 20초 미만인데 느리다고 표시한 비율이다. AUROC는 느린 사람을 더 높은 순서에 놓는 정도이며 개인의 확률이나 정확도가 아니다.

| 정답·모델 | 누락률: 속도 → 패턴 | 오경보율: 속도 → 패턴 | AUROC: 속도 → 패턴 |
|---|---:|---:|---:|
| 일어서기·로지스틱 | 67.6% → **62.1%** | 9.9% → 10.5% | 0.711 → **0.736** |
| 일어서기·RF 분류 | 69.6% → **64.0%** | 10.8% → 10.0% | 0.696 → **0.727** |
| TUG·로지스틱 | 27.0% → **23.2%** | 10.0% → 10.1% | 0.912 → **0.924** |
| TUG·RF 분류 | 27.4% → **26.2%** | 10.0% → 9.8% | 0.912 → **0.920** |

일어서기 로지스틱은 느린 408명 중 분할 반복 평균 276명을 놓치던 상태에서 약 253명으로 줄었다. 약 23명을 더 찾지만 여전히 대부분을 놓친다. 패턴 추가의 개선 방향은 세 분할 모두 같았다. 질환별로 오경보 수준이 같다는 뜻은 아니다.

확률 자체의 오차를 보는 Brier 점수(작을수록 좋음)는 일어서기 로지스틱 0.1476→0.1426, TUG 0.0739→0.0708이었다. 학습 집단의 느림 비율만 출력한 기준은 각각 0.1645, 0.1204였다. 전체 10개 확률 구간의 평균 보정 오차 ECE는 패턴 로지스틱에서 두 정답 모두 약 0.016이었다. 이는 동일 모집단 내부의 전체 평가 결과이며 질환별 보정까지 보장하지 않는다.

확률 50%를 무조건 문턱으로 사용하면 패턴 로지스틱의 누락률은 일어서기 83.4%, TUG 50.4%였다. 결과의 일부는 학습 목표뿐 아니라 **목적에 맞는 판정 문턱 설정**과 관련된다.

## 직접 확률 모델이 시간 모델보다 나은가

같은 패턴 입력, 같은 학습·보정·평가 사람, 같은 오경보 목표에서 비교했다. 아래 시간 모델의 확률은 예측 시간을 보정 자료에서 확률로 변환한 결과다.

| 정답 | Ridge 시간 → 확률 누락률 | 로지스틱 직접 확률 | RF 시간 → 확률 누락률 | RF 직접 확률 |
|---|---:|---:|---:|---:|
| 일어서기 | 62.6% | 62.1% | **60.9%** | 64.0% |
| TUG | 24.5% | 23.2% | **24.4%** | 26.2% |

직접 분류로 바꾸는 것만으로 일관된 개선은 없었다. 일어서기에서 Ridge 확률과 로지스틱의 누락률 차이는 -0.5%p이며 조건부 95% 구간은 -2.3~+1.4%p였다. RF에서는 직접 분류가 회귀 확률보다 3.1%p 더 놓쳤다. TUG 로지스틱은 Ridge보다 Brier 점수가 나았지만, 누락률 차이의 구간에는 0이 포함됐다. 따라서 이번 개선의 중심은 패턴의 추가 정보와 문턱 설정이며 출력 이름 변경 자체로 설명되지 않는다.

COPD의 TUG 2명은 모두 찾았지만 표본이 너무 적어 안정적 성능이라고 해석할 수 없다. 일어서기에서 같은 질환 안의 AUROC는 약 0.636~0.713으로 전체 0.736보다 낮았다. 질환만으로 확률을 주는 기준도 AUROC 약 0.679, MAE 약 4.702초를 보였다. 보행의 순서 구분 정보가 전혀 없는 것은 아니지만 전체 결과에 질환 구성 차이가 섞여 있다.

특히 **MS의 실제 느린 일어서기 비율은 37.1%인데 평균 예측 확률은 26.1%**였다. 전체에서 평균 예측 비율과 실제 비율이 약 20.7%로 잘 맞더라도 특정 질환군에서는 과소평가가 남는다. 사용자 집단이 달라졌을 때 현재 확률을 그대로 쓰면 안 되는 근거다.

## 보조 점검과 남은 범위

- 결측 여부만 더한 대조 조건은 속도 모델과 거의 같았고, 실제 패턴값을 더한 개선은 남았다. 패턴의 효과가 결측 표시만으로 설명되지는 않았다.
- 사람별 반복 평균 오차를 짝지어 2,000회 재추출한 조건부 95% 구간에서 일어서기 Ridge MAE 차이는 -0.176초 [-0.251, -0.099], 로지스틱 누락률 차이는 -5.6%p [-8.7, -2.5]였다. 이미 학습한 모델·현재 사람에 조건부인 구간이며 전체 재학습 변동이나 새 기관의 불확실성을 포함하지 않는다. 여러 탐색 비교에 대한 다중비교 보정은 하지 않았다.
- TUG 60초 초과 12명을 평가 집계에서 빼도 RF 회귀의 MAE는 속도 3.588→패턴 3.347초, 로지스틱 누락률은 27.4%→23.9%였다. 큰 값만으로 개선이 생긴 것은 아니다. 이 점검은 같은 모델의 평가 부분집합이며 해당 사람을 학습에서 제외하고 다시 학습한 실험이 아니다.
- 정답과 기록 상태를 정리했지만 원본 스톱워치·영상으로 검증한 것은 아니다. 검사 수행 불가자의 실제 시간을 생성하지 않았다. 향후 수행 가능 여부와 완료자의 시간을 나누는 별도 질문이 필요하다.
- 다음 개선 후보는 목표 모집단 안에서의 보정과 누락·오경보 조절이다. 질환별 보정을 원인 진단용으로 시험할 수 있지만, 질환 정보 없이 쓰는 보행 제품에 자동으로 적용할 수 있다고 가정하지 않는다. 단일 RGB로의 전환과 예측구간·판단 보류는 이번에 실행하지 않았다.

## 재현과 저장 위치

코드는 C 작업본의 이 폴더에, 새 데이터·분할·예측·표·검증 결과는 `D:/gait-research-data/D_P/gdi-research-harness/studies/20261031-mobilised-function-models`에 저장했다. 기존 Python·scikit-learn 환경을 재사용했으며 GPU와 새 패키지는 사용하지 않았다. 학습은 약 241초였고 모델 가중치는 별도로 저장하지 않았다. 고정 설정·입력·분할·예측과 실행 코드 해시를 보존했다.

핵심 흐름은 `prepare.py`의 원본 기록 상태 분리 → `train.py`의 학습 사람으로 모델 적합·별도 사람으로 확률/문턱 보정 → `analyze.py`의 평가 사람 결과 집계다. 평가 사람의 정답이 보정이나 문턱 선택에 들어가지 않도록 세 집단을 분리한 것이 중요한 설계다.

번들 Python으로 `prepare.py`, `train.py`, `analyze.py`, `verify.py`를 실행했다. 검증은 360조건 모두의 학습·보정·평가 사람 분리, 원본 임상 양식과 정답 연결, 확률 범위, 문턱 계산, 지표 재계산을 확인하고 대표 4조건을 다시 학습해 예측을 재현했다. 상세 결과는 D 폴더의 `verification.json`, `summary.csv`, `paired-comparisons.csv`, `label-audit.json`에 있다. 검증 통과는 계산·분할의 확인이며 임상 사용 적합성의 인증은 아니다.
