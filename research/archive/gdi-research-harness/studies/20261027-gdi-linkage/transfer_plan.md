# 2단계: 기존 124장 모델을 새 개발 520명에 그대로 적용

## 시작 전 질문과 이유

기존 학습 175명에서 만든 124장 모델이 새 개발 520명에서도 단순 평균 예측보다 작은 오차를 내는가? 기존 검증 37명만으로 결론을 내리지 않기 위해 사람 수를 늘린 개발 진단을 한다. 이번 520명은 앞으로 개발에 사용할 수 있는 자료이며 최종 독립 평가로 부르지 않는다.

## 입력·고정 조건

- 정답 연결을 통과한 새 개발 520명·861건 전부. 누락·어려운 사람을 결과를 보고 빼지 않는다.
- 저장된 원시 124장 정규화 입력, 기존과 동일한 고정 MotionBERT-Lite와 전체 시간·관절 평균 512개 특징.
- 기존 length_models.npz의 short124 표준화 평균·크기·계수·절편을 그대로 사용한다. 새 학습, 파인튜닝, alpha 탐색, 보정, 점수 자르기를 하지 않는다.
- 단순 비교는 기존 학습 175명의 203건에서 계산한 좌우 GDI 기록 평균값을 모든 새 기록에 똑같이 예측한다. 새 520명의 평균을 비교 기준에 쓰지 않는다.
- 임상 기준, 정답 값, 사람 분리와 사람별 평균 절대 오차 정의는 유지한다. 최종 예약 223명 및 기존 평가 38명의 정답·특징·예측은 사용하지 않는다.

## 검사와 보고 방법

1. 고정 입력·정답 연결 목록·모델·특징 코드·가중치·본 계획의 지문을 저장한다.
2. 기존 학습 3건의 124장 특징이 저장본과 허용 오차 1e-6 안에서 재현되는지 확인한다. 새 개발 3건의 크기·유한성·연속 프레임·특징 크기도 먼저 확인한다. 실패하면 전체 실행 전에 중단한다.
3. 모든 861건의 특징을 한 번씩 만들고 개별 지문을 남긴다. 중단 후에는 같은 입력·코드·가중치의 완료분만 재사용한다.
4. 기존 검증 37명에서 저장 모델의 7.288263376420894 오차가 재현되는지 확인한 뒤 새 개발 예측을 계산한다.
5. 주 지표는 좌우·기록을 사람 안에서 먼저 평균한 절대 오차다. 좌우 오차·기록 평균 오차·개선/악화 인원도 같이 남긴다. 단순 평균 대비 사람별 차이의 95% 재표집 범위는 기존과 같은 seed=20261026, 10,000회로 계산한다.
6. 내보낸 예측 CSV를 표준 라이브러리로 다시 계산하고, 입력·모델 지문 및 대상 인원 불변을 확인한다.

## 해석 범위와 다음 판단

새 자료는 같은 배포처의 다른 사람이고 기존 243장 규칙을 통과하지 못했던 입력 집단이다. 오차를 기존 37명 수치와 직접 빼서 개선률로 부르지 않는다. 243장 입력이 준비되지 않으므로 이번에는 243장 대 124장의 직접 비교가 아니다. 새 개발 결과로 최종 평가를 대신하지 않는다. 성적에 관계없이 결과를 저장하며, 이후 학습 확대 비교는 별도 계획으로 진행한다. 이번 단계가 끝나면 수집→정답 연결→고정 모델 적용까지 한 단위를 닫고 팀 미팅 요약에 후속 결과를 덧붙인다.
