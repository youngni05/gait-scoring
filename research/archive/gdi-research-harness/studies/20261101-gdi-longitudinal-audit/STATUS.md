## 추가로 필요한 자료

1. **기존 자료 연결 정보:** 검사 ID에 대응하는 실제 날짜 또는 검증된 방문 순서·간격, 나이 필드의 정의, 촬영 조건, 검사와 영상의 시점 관계. 수술 예정 플래그만으로 실제 수술 전후를 확정하지 않는다.
2. **재측정 자료:** 상태가 안정된 대상자가 같은 날 여러 번, 다른 날 다시 걸은 영상. 카메라 재설치·걷기 속도·신발·보조기 등 조건을 기록한다. 임의의 점수 차이를 개선 문턱으로 정하지 않는다.
3. **변화 검증 자료:** 동일인의 초기·추적 RGB와 각 시점의 기준 GDI, 실제 날짜·치료/상태 정보. 실제 기능 개선까지 주장하려면 해당 시점의 기능검사나 독립적인 평가가 추가로 필요하다.
4. **목표 집단 자료:** 실제 사용할 대상과 환경의 자료. 기존 소아 중심 GDI 개발 자료의 결과를 고령자·좁은 실내·단일 RGB에 자동 적용하지 않는다.

## 실행과 검산

- `python -B audit.py`: 기존 ZIP에서 작은 주석 CSV만 메모리로 읽고 현재 개발 묶음과 연결했다. 원본 ZIP의 크기·수정 시각은 유지됐다. 보호 최종 집단의 GDI 숫자를 변환하거나 저장하지 않았다. 주석 CSV 전체가 메모리에 압축 해제된다는 접근 범위는 명시한다.
- `python -B verify.py`: 별도 사람별 재집계, 검사 조합 수, 중복·분할 일관성, 기존 예측 파일 지문 및 식별자·정답 연결을 확인했다. 결과 `passed=true`다. 이 값은 자료 연결 검산 통과이며 임상 성능 검증이 아니다.
- 작은 산출물은 이 C 폴더에 저장했다. 새 다운로드·대량 출력·GPU 실행은 없다. 기본 Python에 NumPy가 없어 초기 확인 명령은 실패했고, 새 설치 없이 표준 라이브러리로 필요한 NPY 메타데이터만 읽도록 작성했다.

## 13:51 KST 후속 확인 — 원 논문의 변화 추적 조건

탐색 실행 질문에 대한 새 사용자 답변은 아직 없다. 새 성능 계산 대신 원 논문과 공개 처리 코드를 확인하고 검사 쌍의 순서 연결을 준비했다.

**원 연구도 새 모델을 학습하지 않고 기존 예측으로 동일인 변화를 분석했다.** Kidziński 등(2020)의 「Predicting longitudinal gait changes and surgical events」에서는 초기 실제 GDI를 알고 있는 조건의 변화 상관이 r=0.59, 실제 초기 GDI를 사용하지 않고 두 예측의 차이를 비교한 조건은 r=0.40이라고 보고한다. 논문에서는 1,026명·1,792영상 중 473명에게 반복 방문이 있었다고 설명한다. 이 인원과 수치는 원 연구의 것이며 현재 229명 후보와 같지 않다. [원문 해당 절](https://pmc.ncbi.nlm.nih.gov/articles/PMC7426855/#Sec5)

우리의 목표가 처음부터 카메라만 쓰는 방식이라면 **초기 예측값과 이후 예측값의 차이**가 직접 대응하는 비교다. 병원에서 측정한 실제 초기 GDI를 쓸 수 있는 조건과 분리해야 한다. 논문 수치는 상관이며 개인별 오차·재촬영 오차·임상적으로 의미 있는 변화의 검증을 대신하지 않는다. 실제 초기 GDI를 사용하는 세부 보정식까지 이번에 코드로 확인한 것은 아니다.

원 논문의 Dataset·Discussion에는 영상과 광학 측정이 같은 방문에서 따로 수집됐고 동시 측정은 아니었다고 명시돼 있다. 따라서 현재의 실제 GDI도 특정 영상의 프레임별 정답이 아니라 방문 수준의 기준값으로 해석한다. 원 논문은 다른 환경에서 사용할 때 카메라 각도·복장 등 수집 조건의 영향과 새 사용자의 촬영 검증이 필요하다고 설명한다. 공개 처리 노트북은 사람·검사·좌우로 GDI를 합치며 별도 날짜를 복원하지 않는다. [원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC7426855/) · [공식 처리 코드](https://github.com/stanfordnmbl/mobile-gaitlab/blob/4167ee6213ac81fb9168f4e20c6538d42a41a5a6/training/process_annotations.ipynb)

`prepare_pairs.py`를 추가해 229명·581쌍을 보고 나이가 작은 검사와 큰 검사로 연결했다. 검사 ID 순서를 시간 순서로 쓰지 않았으며, 정확한 날짜·경과 일수가 있다는 표시는 하지 않았다. 나이 충돌이 있는 단일 검사자는 반복 후보에 포함되지 않아 이 단계의 제외 쌍은 0개다. 결과 `prepared-pairs.json`과 별도 원기록 재대조 `pair-preparation-verification.json`에서 581쌍의 나이 순서·영상·분할·중복 여부를 확인했다. 기존 `verify.py`도 다시 통과했다. 정답 차이·예측 차이 지표 계산과 새 학습은 하지 않았다.

## 14:06 KST 후속 준비 — 변화량 계산 코드

새 사용자 답변과 실제 날짜 정보는 추가되지 않았다. 기존 자료·예측 연결 상태도 동일하다. 다른 채팅의 초기값 학습 상태 파일은 이전 실행 중 기록 그대로여서 현재 서버 상태라고 새로 보고하지 않는다.

`change_metrics.py`에 검토용 변화량 집계 함수를 준비했다. 입력은 사람 ID와 실제·예측 좌우 GDI 차이다. 각 사람 안에서 검사 쌍의 오차를 평균한 뒤 사람 간 같은 비중으로 평균한다. 검사가 많은 사람에게 전체 결과가 치우치는 문제를 줄이려는 제안이다. 좌우 차이는 양쪽 평균을 먼저 내서 상쇄하지 않고 좌우 각각의 오차로 계산한다. 방향 일치는 실제 차이가 정확히 0인 항목을 제외하고 예측 동률은 0.5로 처리한다. 방향 점수의 분모와 변화량 오차의 분모가 다를 수 있어 사람 수와 변경된 좌우·쌍 항목 수를 함께 반환한다. 임상 문턱은 도입하지 않았다. 이 지표 선택과 처리 방법은 아직 실제 자료에 적용하기로 합의한 기준이 아니다.

실제 자료를 읽는 실행 경로는 추가하지 않았다. 직접 만든 가상 2명·3쌍에서 손으로 계산한 사람별 균등 오차 3점, 변화 없음 기준 4.5점과 일치했다. 이 숫자는 가상 코드 검사값이며 현재 모델 성능이 아니다. 실제 차이 0·예측 동률·반대 방향·빈 입력·비정상 숫자·좌우 길이 오류도 검사했다. `python -B change_metrics.py`와 별도 호출의 `synthetic_check()`가 모두 통과했고 `synthetic-metrics-check.json`에 코드 지문과 결과를 저장했다. 새 패키지는 설치하지 않았다.

현재 실자료 성능 계산·새 학습은 계속 미실행이다. 다음 독립 작업은 원 제공처의 나이·날짜 설명 확인이며, 새 근거가 없으면 기존 날짜 미확인 상태를 유지한다. 탐색 승인 답변이 오면 먼저 지표·분모·조건을 확인한 뒤 연결된 고정 예측을 사용하는 실행 경로를 붙인다.

## 14:36 KST 예측 출처의 사람 분리 확인

사용자 답변·측정 날짜·실자료 변화량 결과의 새 정보는 없다. 예정한 독립 작업으로 기존 고정 결합 예측을 구성하는 CNN·STT 모델의 저장된 학습 대상 목록을 확인했다.

`check_prediction_provenance.py`는 기존 50개 모델(내부 모델 40개·최종 재학습 모델 10개)의 `identity.json`과 `fit_complete.json`을 읽는다. 현재 692명의 분할로 학습 대상 목록을 다시 만들고 저장된 목록과 일치하는지, 평가할 사람의 모든 방문이 해당 학습에서 빠졌는지 확인했다. 내부 모델에서는 그 평가 사람이 내부 검증에도 들어가지 않았다. 기존 예측 캐시의 지문, 체크포인트에 대한 저장된 지문, 완료 기록과 원래 집계 보고의 출처 연결도 일치했다. `python -B check_prediction_provenance.py` 실행 결과 `passed=true`이며 `prediction-provenance-check.json`에 범위와 근거를 저장했다.

이는 **저장된 학습·예측 출처의 일관성 검사**다. 이번에 모델 가중치를 다시 읽거나 추론하지 않았으며, 결합에 사용한 양측 STT 별도 모델과 결합 비중 선택 전체는 아직 재감사하지 않았다. 따라서 전체 결합 모델의 모든 누출 가능성을 새로 배제했다고 표현하지 않는다. 원래 `verification.json`의 `training_provenance_reaudited=false`도 전체 재감사 완료로 바꾸지 않았다. 새 성능 지표는 계산하지 않았다.

다음 독립 확인 후보는 양측 STT와 결합 비중 선택의 출처다. 실제 변화량 탐색 실행은 기존 질문의 답변 대기 상태를 유지한다.

## 큰 오차 사례와 다음 실험 — 사용자 후속 요청

요청에 따라 실제 변화 과소예측·방향 오류와 입력 품질 단서를 분리했다. 이 구분은 예측 오차의 형태이며 모델 구조·자료·촬영 중 어느 하나의 인과적 책임을 뜻하지 않는다. 전체 229명·581쌍·좌우 1,162항목을 같은 사람 비중으로 집계하고, 개인별 평균오차가 큰 상위 10명에서 각 사람의 가장 큰 오차 쌍을 골랐다. 큰 사례만으로 전체 빈도를 계산하지 않았다.

### 3. 관절 추출·입력 조건의 확인 범위

반복 방문에 속한 598개 기록에서 원래 124프레임의 필수좌표 최대 결측률·관절 신뢰도, 전체 사용 구간의 대상 선택 모호함, 사용 가능한 창 수를 확인했다. 원본 해시와 기존 준비 증거를 대조했다. 고정된 바깥 분할의 CNN·STT 최종 모델에서 같은 영상의 창별 예측 표준편차도 읽었다. 이는 전체 결합 모델의 불확실성이나 재촬영 오차가 아니라 한 영상 안의 구간 차이에 대한 보조 지표다.

각 사람의 쌍별 최대 품질 지표를 평균해 개인별 오차와 비교한 기술적 상관은 필수좌표 결측 0.0424, 대상 선택 모호함 0.0088, 신뢰도 0 또는 결측 비중 0.0644, CNN 창별 흔들림 -0.0501, STT 창별 흔들림 -0.0206이었다. 실제 변화 크기와의 상관은 0.4349였다. 검정·인과분석을 수행한 것은 아니다. 품질 기준을 통과해 이미 선별된 자료라 범위가 좁고, 대표 124프레임과 실제 여러 창의 범위도 다르다. 고신뢰도 오검출·좌우 바뀜·촬영 방향·원근 영향은 이 지표로 검출하지 못할 수 있다. 원 영상에 겹쳐 정확한 관절 위치를 확인한 분석은 아니다.

### 4. 다음 실험 제안 — 아직 실행하지 않음

**첫 비교는 기존 좌표에서 변화량을 함께 학습하는 효과다.** 같은 사람의 초기·후속 관절 입력과 해당 방문의 실제 GDI를 사용한다. 기존 방문별 GDI 오차만 학습하는 조건과, 방문별 오차에 동일인의 좌우 GDI 차이 오차를 추가하는 조건을 비교한다. 초기 상태 추정과 변화 추적을 함께 유지하려는 목적이다. 같은 구조·사람 분할·입력·학습량을 맞추고, 변화량 손실 비중과 종료 시점은 학습 사람 안에서만 선택한다. 반복쌍 수가 많은 사람이 손실을 지배하지 않게 사람별 비중을 맞춘다. 사용자마다 사용 중 재학습하는 방식은 전제하지 않는다.

비교 기준은 원래 고정 모델과, 학습 사람에서만 정한 양의 변화량 배율 보정이다. 양의 배율은 방향을 바꾸지 못하므로 크기 보정만으로 해결 가능한 부분과 변화 학습의 추가 가치를 나눌 수 있다. 현재 기술적 기울기의 역수를 평가자료에 바로 적용하지 않는다. 바깥 사람에서는 변화량 오차·방향·좌우 결과와 첫 방문 GDI 오차를 함께 보고한다. 보호 최종자료는 열지 않고 기존 개발 반복 탐색임을 유지한다. 학습 실행 전 손실·학습량·평가 조건과 기준을 구체적으로 협의한다.

**원인 분리를 위한 별도 자료 실험은 같은 움직임에서 촬영과 추출을 하나씩 바꾸는 것이다.** 한 영상의 동일 프레임에 기존·대안 관절 추출을 적용하고, 사람이 표시한 일부 관절 또는 동기화된 기준 좌표와 비교한다. 변화 점수가 커졌다는 이유만으로 대안 추출이 더 정확하다고 선택하지 않는다. 촬영 영향은 가능한 한 같은 걸음을 여러 조건의 카메라로 동시에 기록해 움직임 차이와 분리한다. 재촬영 안정성은 상태가 안정된 사람의 같은 날 반복과 다른 날 반복으로 별도 평가한다. 실제 시간·신발·보조기·걷기 지시·FPS를 남긴다. 이 자료가 있어야 촬영·추출·측정 변동을 나누고 최소검출변화량을 추정할 수 있다.

**좌우 학습 비교는 그 다음 후보로 둔다.** 좌우 실제 변화가 반대인 쌍의 표현 실패가 있으므로 공통 움직임과 좌우 차이를 함께 학습하는 조건을 검토할 수 있다. 먼저 기본 변화량 학습과 입력 원인 분리를 하고, 별도 조건으로 추가 가치를 확인한다. 단순 좌우 교환이나 실제 정답을 보고 입력을 골라 성능을 높이지 않는다.

실행 근거: `analyze_causes.py`, 결과 `cause-results.json`·`cause-pairs.json`·`cause-people.json`·`cause-cases.json`. `verify_causes.py`는 오차 분류·사람별 가중치·오차 기여의 합·상위 사례 순위·실제/예측 방문 차이를 독립 재계산했다. 최대 차이 1.78e-15로 기존 1e-10 기준 이내였고, 7.5701점의 합도 기존 결과와 일치했다. 관절 정확도·촬영 인과효과 검증을 통과했다는 뜻은 아니다. 코드·작은 결과는 C 폴더, 원래 대량자료는 D의 기존 위치를 읽기 전용으로 사용했다.

## 15:10 KST 학습 전 계산 준비

새 사용자 지시·실험 승인·원자료·성능 결과는 없다. `pair_loss_reference.py`에 검토용 전체 묶음 손실 계산을 준비했다. 첫 상태 오차는 기존 비교와 비중을 맞추기 위해 기록별 평균으로 두고, 변화량 오차는 같은 사람의 쌍들을 먼저 평균한 뒤 사람별 같은 비중을 준다. 현재 함수는 원래 GDI 단위의 제곱오차 계산 참고이며 기존 GPU 코드에 연결한 학습기가 아니다. 실제 모델의 정답 정규화·배치 학습·자동 미분은 아직 연결하거나 검증하지 않았다. 손실을 합칠 비중도 정하지 않았다.

직접 만든 가상 3명·6방문에서 손계산한 상태 오차 5와 변화량 오차 13/3에 일치했다. 검사 쌍의 순서를 뒤집어도 두 차이의 부호가 같이 바뀌어 손실이 같았고, 쌍이 없는 경우는 0으로 숨기지 않고 변화량 항목을 계산 불가로 반환했다. 학습 대상 외 사람·중복 검사·서로 다른 사람의 쌍·범위 밖 인덱스는 거부했다.

기존 5개 바깥 분할과 각 4개 내부 분할의 25개 학습용 메타데이터 구성을 준비했다. 각 학습 구성의 반복 검사 보유자는 128~188명, 검사 쌍은 306~510쌍이었다. 해당 바깥/내부 제외 사람은 학습 쌍에 포함되지 않았다. 실제 GDI 정답으로 손실을 계산하거나 모델을 학습하지 않았다. `python -B pair_loss_reference.py` 결과와 코드·방문 메타데이터 지문을 `pair-loss-preparation.json`에 저장했다. 가상 계산 통과를 실제 변화량 학습 성능으로 표현하지 않는다.

현재 최소 준비물은 자료 연결·고정 예측 탐색·원인 단서 분석·저장 출처 확인·전체 묶음 손실 참고까지다. 다음 실행에 앞서 확정할 것은 기준 모델과 같은 구조/입력/학습량을 사용하는 비교 범위, 변화량 손실 비중을 내부 자료에서 선택할 방법, 초기 상태 오차 악화의 허용 범위와 변화 지표의 판단 기준이다. 이 선택이나 실제 학습 승인을 대신할 추가 모델·설정 후보를 자동으로 늘리지 않는다. 촬영·추출의 원인 분리에는 여전히 동일 움직임의 원영상·기준 관절과 반복 촬영 자료가 필요하다.

## 15:25 KST 현재 단계 종료와 다음 선택

질문의 근거는 공통 규칙의 중요한 학습·검증 조건 사전 협의다. 새 학습과 데이터 확보 중 사용자의 선택이 필요한 단계이며, 추가 임의 설정이나 반복 계산을 이어가며 합의를 대신하지 않는다. 이후 사용자가 선택하면 해당 작업과 필요한 예약을 이어간다.

## 새 학습 비교 승인과 준비

사용자가 **“기존 CNN으로 새 학습 비교 진행”**을 선택했다. 이전 학습 조건 선택 대기는 종료됐다. 새 실험은 `../20261101-gdi-pairloss-cnn/`에 분리했으며 최신 실행 상태는 그 README와 전용 등록부를 따른다.

같은 CNN·입력·초기값·분할·100epoch 상한·기존 내부 방문 MAE 종료 선택을 유지한 손실0/1 두 조건을 구현했다. 변화 항목은 학습 사람/검사 쌍을 각각 동일 확률로 고르고 두 방문의 모든 창 평균으로 계산한다. 추가 경로는 기울기가 연결된 평가 모드로 두어 기존 BN 통계와 dropout 난수를 보존한다. 기존 방문 손실의 배치·optimizer step 수는 같지만 변화 forward가 추가되므로 시간·연산량 일치 비교는 아니다. 새 GPU 작업을 이미 진행한 것처럼 표현하지 않는다.

두 조건 CPU 가상 검산이 통과했다. 각25개 가상 중첩학습·정확한 중단재개·검증 정답 변경에 대한 학습 불변·변화 손실 기울기·BN/난수 보존·손계산 일치·손실0에서 원래 기준 코드와 모델 상태 완전 일치를 확인했다. 실제 GDI의 CPU 학습은0회다. 가상 모델은 D의 새 실험 폴더, 코드와 작은검산은 C에 있다.
