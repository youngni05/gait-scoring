# OpenCap 확대본: 짧은 보행 시계열로 실제 TUG 예측

2026-10-30 자료 연결·중복 확인·CPU/GPU 학습·독립 재추론 검산을 완료했다. 298명의 3초 보행으로 실제 TUG 시간을 예측한 RF의 평균 절대오차는 2.150초로, 보행 정보를 쓰지 않는 중앙값 기준선 2.472초보다 작았다. 같은 196명에서 비교하면 RF는 1초 3.077초, 3초 2.783초, 6초 2.657초였다. 짧은 보행에 예측 정보가 있다는 초기 결과이며, 3초와 6초의 성능이 같다고 입증한 것은 아니다.

## 자료 연결과 기존 사람 중복

[415명·675방문 공개본](https://zenodo.org/records/22309771)의 임상 CSV와 ZIP 파일 목록을 확보했다. 전체 6.6GB 대신 공식 ZIP의 보행 `.mot` 파일 520개를 선택 다운로드했다. 각 파일은 ZIP CRC와 대조하고 SHA-256을 기록했다. 임상 CSV는 제공처 MD5와 일치했다. 공개된 입력은 RGB 카메라 2–3대에서 OpenCap으로 복원한 관절 각도·골반 위치 시계열이다. 원본 RGB 영상을 새로 추론한 실험은 아니다.

| 단계 | 사람 수 |
|---|---:|
| 공개본 전체 | 415 |
| 10m 보행 시계열 있음 | 330 |
| 실제 TUG와 3초 보행 연결 가능 | 298 |
| 6초 연속 보행까지 가능한 공통 비교 집단 | 196 |

TUG가 연결된 보행 기록은 463개이다. 실제 모델 평가에서는 사람마다 한 방문·한 보행 기록만 선택했다. 196명 공통 비교는 첫 6초 유효 구간이 있는 방문을 선택했다. 298명 추가 실험은 그 196명의 입력·방문·분할을 그대로 두고, 나머지 102명의 첫 3초 유효 방문을 추가했다. 같은 사람의 다른 방문을 학습과 평가에 나눠 넣지 않았다.

기존 129명 공개본과 확대본은 번호가 다르다. 1,390개 움직임 파일의 크기·CRC 일치로 124명의 일대일 번호 대응을 찾았고, 각 사람의 보행 파일을 실제로 받아 SHA-256까지 일치함을 확인했다. 다른 4명은 네 가지 임상 검사 시간·키·몸무게가 유일하게 일치한 유력 중복 후보이다. P098 한 명은 대응을 확인하지 못했다. 이는 공개 파일을 대조한 결과이며 저자가 제공한 공식 번호 대응표는 아니다. 두 공개본의 인원을 더하거나 이전 모델을 그대로 평가에 사용하지 않았다. 근거는 `overlap-summary.json`, `overlap-sha256.json`이다.

공통 196명에는 파일 일치 66명·임상 일치 후보 2명·중복이 확인되지 않은 128명이 포함된다. 확대 298명에는 각각 123명·4명·171명이 포함된다. ‘중복 미확인’을 전부 새 사람으로 확정하지 않는다.

## 무엇을 비교했는가

보행 기록에서 골반의 수평 이동 속도를 0.25초 평균하고, 0.2m/s를 넘는 구간을 찾았다. 0.25초 이하의 짧은 끊김은 연결했다. 공통 비교에서는 첫 6초 연속 구간을 정한 뒤 **같은 시작점의 1초·3초·6초**를 사용했다. 이 규칙과 시간 범위는 모델 성능 확인 전에 정했다. 프레임 간 최대 간격은 전체 520파일에서 약 0.0167초였다.

입력은 몸통·골반·다리의 관절 각도 17개와 골반의 수평 속도·수직 속도, 총 19채널이다. 선택한 구간을 30Hz로 맞춰 1초 31시점, 3초 91시점, 6초 181시점으로 만들었다. 속도는 해당 구간의 위치에서 계산했다. 나이·진단·다른 임상 점수를 회귀 입력에 추가하지 않았다. 정답은 같은 사람·방문의 실제 TUG 초이며 4.22–42.59초이다.

다만 제공된 OpenCap 좌표 자체는 원래의 여러 카메라·신체 보정·전체 촬영 처리로 만들어졌다. 이번 결과는 그 시계열 중 짧은 구간만 점수 모델에 넣은 결과이다. 단일 카메라의 3초 영상만 촬영해 전 과정을 수행한 성능으로 해석할 수 없다. 이동 구간 판별 규칙도 별도의 수동 보행 경계 정답으로 검증한 것은 아니다.

사람 5겹 평가를 사용하고, 설정·학습 종료 시점은 각 학습 집단 안의 사람 3겹 평가에서만 골랐다. 정규화는 학습 사람으로만 계산했다. Ridge·RF는 각 채널의 평균·변동·시간 변화 요약을, CNN·TCN은 시간순 입력 자체를 사용한다. 공통 196명의 조건별 사람·분할·정답은 동일하다. 298명 표는 다른 집단의 추가 분석이므로 길이 효과 비교에 섞지 않는다.

## 결과와 의미

다음 값은 평균 절대오차이며 단위는 초이다. 예를 들어 2.150초는 처음 보는 사람의 실제 TUG 시간과 예측 시간의 차이가 평균 2.150초였다는 뜻이다. 모든 사람의 오차가 이 범위 안이라는 뜻은 아니다. 중앙값 기준선은 학습 사람들의 대표 TUG 시간만으로 예측한다.

| 방법 | 공통 196명·1초 | 공통 196명·3초 | 공통 196명·6초 | 확대 298명·3초 |
|---|---:|---:|---:|---:|
| 평균 기준선 | 3.132 | 3.132 | 3.132 | 2.710 |
| 중앙값 기준선 | 2.902 | 2.902 | 2.902 | 2.472 |
| Ridge | 3.300 | 3.255 | 3.026 | 2.542 |
| RF | 3.077 | 2.783 | 2.657 | 2.150 |
| CNN | 3.158 | 3.095 | 3.075 | 2.524 |
| TCN | 3.162 | 3.171 | 2.988 | 2.513 |

공통 196명에서는 1초 입력의 어떤 모델도 중앙값 기준선을 넘지 못했다. RF의 3초→6초 개선은 평균 0.126초였지만, 사람별 오차를 짝지어 재추출한 95% 구간은 -0.072~0.324초로 0을 포함했다. 따라서 6초의 이점은 이 자료만으로 확정하기 어렵고, 그렇다고 3초와 6초가 동등하다고 결론 낼 수도 없다. 공통 196명 RF의 기준선 대비 개선도 3초·6초 모두 이 구간에 0을 포함했다.

298명에서는 3초 RF가 기준선보다 평균 0.322초 낮았고, 오차 차이의 95% 구간은 -0.589~-0.055초였다. RF의 RMSE는 3.811초로 큰 오차가 있는 사람도 남아 있다. 중복 확인/유력 후보 127명에서는 RF 1.229초·기준선 1.762초, 중복 미확인 171명에서는 RF 2.834초·기준선 3.000초였다. 후자에서 개선이 작아, 확대 집단 전반에 충분히 잘 맞는다고 보기는 어렵다. 이는 같은 사람 분리 예측을 사후 집단별로 요약한 것이며 별도의 외부 검증은 아니다.

위 구간은 저장된 사람별 평가 예측을 10,000회 재추출한 기술적 불확실성 요약이다. 재학습·모델 선택·분할 변경에 따른 변동까지 포함하지 않는다. 작은 CNN·TCN은 한 초기값으로 비교했으며 RF보다 개선되지 않았다. 신경망 전체가 부적합하다는 결론으로 넓히지 않는다. 자세한 지표는 `summary.json`, 사람별 예측은 `comparison-predictions.csv`, 구간과 중복 집단 분석은 `uncertainty-and-overlap.json`에 있다.

## 검산과 실행 기록

`verify.py`에서 원본 파일 CRC·SHA, 실제 TUG 행 연결, 별도 보간·속도 계산으로 모든 입력 재구성, 사람 분리, 조건별 대상 일치, CPU 모델 40개 재추론을 확인했다. GPU 최종 모델 40개도 CPU에서 다시 예측해 저장 결과와 0.0001초 이내로 일치함을 확인했다. 학습 사람으로 계산한 정규화도 재검산했다. `verification.json`의 모든 항목이 통과했다. 기존 패키지를 재사용했다.

학교 GPU DIS03의 RTX A6000에서 파일럿 31781(1분 49초)과 본 학습 31791(6분 16초)이 모두 종료 코드 0으로 완료됐다. 네 조건 각각 CNN·TCN의 사람 5겹 학습을 마쳤다. 전송 묶음의 지문, 서버의 25개 입력·코드 파일, 회수 묶음의 지문과 원래 입력·코드의 동일성을 확인했다. 최초 대기 작업 31770은 자원 배정 전 취소했다. 전송 목록의 Windows 경로 구분자를 정규화했고, Slurm 스크립트의 줄바꿈도 LF로 고친 뒤 실행했다. 상세 내역은 `gpu-run-receipt.json`, 회수 로그는 `gpu-return/logs/`에 있다.

## 해석 범위

이전 129명 결과는 저자가 계산한 보행 특징과 TUG 4.28–14.44초 범위였다. 이번에는 다른 입력 표현과 더 넓은 질환·점수 범위를 사용하므로 오차 수치만 직접 비교하지 않는다. 기존 공개본을 이미 분석한 탐색 연구이며 독립 최종 성능이나 임상 검사 대체를 입증한 결과가 아니다.

핵심 경로는 `prepare.py`의 `active → window`이다. 실제 이동 구간을 정하고, 같은 시작점에서 길이만 바꾼 입력을 만든다. `extend3.py`는 공통 196명을 유지하며 3초 입력이 가능한 나머지 사람을 더한다. `verify.py`는 원본을 다른 방식으로 다시 읽어 입력과 예측을 대조한다.

2026-10-31 후속 갱신: [속도 비교·반복 안정성 실험](../20261030-opencap415-speed-stability/STATUS.md)을 완료했다. 같은 298명·3초 입력에서 사람 분할 5개×학습 난수 3개를 비교했다. 전체 RF 평균 MAE는 2.110초, 평균 속도만 사용하면 2.229초, 속도의 평균·변동·변화량 3개를 사용하면 2.058초였다. 반복에서도 기준선 대비 개선은 유지됐지만 많은 관절 각도의 추가 가치는 확인하지 못했다. 긴 TUG 사례의 큰 과소예측과 10초 미만 집단에서 기준선보다 나쁜 결과도 함께 기록했다.
