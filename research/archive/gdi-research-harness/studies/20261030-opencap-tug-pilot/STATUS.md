# 영상 유래 보행 특징 → 실제 TUG: 129명 예비 실험

2026-10-30: 공식 공개 CSV 확보, 사람 분리 CPU 학습, 모델 재추론 검산을 완료했다. 입력은 보행 영상에서 저자가 계산한 8개 특징이며, 정답은 평가자가 초시계로 측정한 실제 TUG 시간이다. TUG 동작 영상의 소요시간을 입력에 넣어 같은 시간을 맞히는 실험이 아니다.

[공식 공개 자료](https://zenodo.org/records/13788592)는 129명의 OpenCap 기록을 제공한다. FSHD 28명, DM 58명, 대조군 43명이다. [원논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC12416922/)에서는 RGB 카메라 2–3대로 움직임을 기록하고 OpenCap으로 3D 좌표를 추정했다. 평가자는 동시에 임상 검사 시간을 측정했다. 원논문의 동일 검사 시간 재현과 이번의 보행→별도 TUG 예측은 질문이 다르다.

이번에는 원본 RGB 영상이나 관절 시계열을 새로 추론하지 않았다. 제공된 보행 속도, 보행 주기 시간, 보폭, 발목 높이, 몸 중심의 흔들림, 몸통 기울기, 고관절 움직임 범위, 무릎 각도만 사용했다. 10m 보행 검사 중 촬영된 부분의 요약이며, 전체 10m가 카메라에 보이는 것은 아니다. 고정 3초 입력 검증이나 단일 카메라 검증으로 해석할 수 없다. 나이·진단·다른 검사 결과는 모델 입력에서 제외했다.

162개 방문 기록에서 사람별 첫 번째 유효 방문을 선택해 129명을 사용했다. 실제 TUG는 4.28–14.44초이다. 사람을 5개 묶음으로 나눠 하나씩 평가하고 나머지로 학습했다. 설정 선택은 학습 사람 안의 3겹 평가에서만 수행했다. 정규화도 학습 사람으로만 계산했다. 같은 사람의 반복 방문을 양쪽에 넣지 않았다.

| 방법 | 평균 절대오차(초) | RMSE(초) |
|---|---:|---:|
| 평균 기준선 | 1.689 | 2.169 |
| 중앙값 기준선 | 1.592 | 2.254 |
| Ridge | 1.197 | 1.476 |
| RF | 1.116 | 1.495 |

RF는 중앙값 기준선보다 평균오차가 0.475초 작았다. 보행 정보가 별도 TUG 시간 예측에 도움이 될 가능성을 보여준다. 표본이 신경근육질환자와 대조군으로 구성되고 TUG 범위가 제한돼 있어, 일반 고령자나 더 오래 걸리는 사람에게 같은 성능이 나온다고 볼 수 없다. 저자가 이 자료를 보며 설계한 특징을 재사용했고, 외부 독립 검증이나 여러 초기값 비교는 수행하지 않았다. CNN·TCN 및 GPU 시계열 학습은 이번 요약 특징 실험에 포함하지 않았다.

`run.py`는 공식 파일 MD5를 확인하고 ID·방문일로 보행 특징과 실제 시간을 연결한다. 이후 사람 분할 안에서 Ridge·RF를 학습한다. `verify.py`는 원본 CSV 연결, 바깥·안쪽 사람 분리, 129명 평가 포함, 저장 모델 10개 재추론, 지표 재계산을 확인한다. 실행 결과는 `verification.json`, 예측은 `predictions.csv`, 조건은 `protocol.json`이다. 기존 scikit-learn 환경을 재사용했고 새 패키지는 설치하지 않았다.

CSV 1,508개는 cached skeleton 476개, sway metrics 523개, start/end 508개, register 1개였다. register 90행과 대표 sway/start-end 파일, 배포 코드의 지문·내용을 확인했다. 별도의 실제 SPPB 총점·TUG 초 표를 찾지 못했다. TUG의 start/end CSV도 목록에 없었다. 공개 영상은 깊이 자료이며 RGB 파일은 목록에서 확인되지 않았다. 임상에서 점수를 매겼다는 논문 설명과 원점수 공개는 구분한다. 전체 파일 목록은 검사했지만 모든 프레임·모든 CSV 본문을 읽었다는 뜻은 아니다. ## 더 큰 공개본

[2026년 OpenCap 공개본](https://zenodo.org/records/22309771)은 415명·675방문이다. 임상 CSV를 실제 확보했고 TUG 값이 기재된 353명·559방문을 확인했다. 이 수는 보행 시계열까지 연결해 사용할 수 있는 인원과 다르다. 6.6GB 시계열 원본은 이번에 확보·학습하지 않았다. 129명 공개본의 확대 버전이므로 두 자료를 독립 코호트로 더하지 않는다. 다음 확대 실험에는 사람·방문별 보행 파일 연결, 결측과 시간 길이, 기존 공개본과의 중복 확인이 필요하다.

2026-10-30 후속 갱신: 위 문단은 129명 파일럿 시점의 상태이다. 이후 공식 ZIP에서 보행 파일 520개를 선택 확보해 실제 TUG가 연결된 298명과 공통 길이 비교가 가능한 196명의 실험을 완료했다. 기존 129명 중 124명은 파일 SHA-256 일치, 4명은 임상 기록 일치 후보이며 1명은 미확인이다. [확대본 시계열 실험 결과](../20261030-opencap415-tug-timeseries/STATUS.md)에 사람 분리, 1·3·6초 비교와 CPU/GPU 검산을 기록했다.
