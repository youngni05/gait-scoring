# CARE-PD RF와 작은 시간축 모델 비교

사용자 요청: 같은 사람·보행 구간, 사람 단위 평가, 기존 초기값 5개를 유지해 기준선 대비 성능과 높은 보행 점수의 큰 오차를 비교한다. 기존 GDI·Mobilise-D 실험과 별개다.

입력은 110명·2,953개 원본 구간 전체이며, 23개 관절의 국소 회전을 6차원 연속 표현으로 변환해 25Hz 시간 구간별로 평균한다. 원본 프레임을 버리거나 구간 수를 늘리지 않는다. 글로벌 회전·이동·체형·약물·코호트 정보는 입력에서 제외한다. 절대 보행 속도를 직접 쓰는 실험은 아니다. RF는 동일 시계열의 698개 요약값, CNN은 순서를 유지한 시계열을 사용한다. 원본 영상 CNN 학습이나 임상 측정 정확도 검증과 구분한다.

공식 6분할의 사람 배정을 유지한다. 바깥 분할 f의 내부 검증은 (f+1)%6, 내부 학습은 나머지 4개 분할이다. 내부 검증에서 RF 잎 크기와 CNN 종료 epoch를 고른 뒤 바깥 학습 5개 분할 전체에서 새로 학습한다. 초기값은 20261030, 20262030, 20263030, 20264030, 20265030이다. 각 사람은 구간 수와 관계없이 같은 총 학습·평가 비중을 갖는다. 정규화는 각 학습 집합에서만 계산한다.

전체 MAE를 주 지표로 삼고 RMSE, 편향, 2점 이상 오차 비율, 반올림 등급 정확도·등급별 재현율도 계산한다. 실제 2·3점 및 3점만인 사람/구간을 따로 분석한다. 3점 관측자는 7명뿐이므로 일반화 판단은 제한적이다. 평균·중앙값·최빈 등급 기준선은 바깥 학습 자료로만 구한다. 초기값 평균은 결과 요약이며 예측 앙상블이 아니다.

## 실행과 검산

- `prepare.py`: 원본 지문 확인, 입력과 사람/구간 대응표 고정. `protocol.json`에 입력 지문과 조건을 기록한다.
- `run.py pilot`: 실제 학습 자료에서 3epoch, 정규화·사람 분리·패딩 불변성·저장 모델 재추론 및 RF 실행 검사. 바깥 평가 사람은 파일럿 성능에 사용하지 않는다.
- `run.py train`: 총 30개 분할/초기값 조합. RF 내부 후보 60개와 최종 30개, CNN 내부 30개와 최종 30개 학습이다. `complete.json`이 있는 조합은 그대로 유지한다.
- `run.py replay`: Slurm GPU 안에서 최종 CNN 30개와 RF 30개를 재추론하고 저장 예측과 대조한다. CNN 허용 최대 차이 1e-6점, RF 1e-12점이다.
- 완료 표시는 `runs/main/summary.json`, `runs/summary_complete.json`, `CARE_PD_TRAINING_COMPLETE`다. Slurm 종료코드도 함께 확인한다.

GPU 감시 대상은 `/abr/RESEARCH_USER/care-pd-rf-tcn-20261031`이며, 실제 작업 번호는 `submission.json`을 따른다. 감시는 [전용 등록부](watch/registry.json)와 예약 `care-pd`가 담당하며, 요청한 CARE-PD 채팅에서 30분마다 확인하고 완료 결과를 회수·검산·보고한다. 기존 통합 예약 `stt`에서는 이 실험만 제외했다. 비교 기준은 이 README와 protocol을 적용한다. 기존 GPU 유지 작업32844와 다른 실험은 변경하지 않는다.

완료 시 runs 전체의 모델·원시 예측·곡선·분할 선택 기록과 실행 코드를 별도 received 폴더로 회수하고 서버/로컬 SHA256을 맞춘다. `analyze.py`로 지표를 독립 재계산하고 6분할·초기값5개·같은2953구간·사람 중복 없음·외부 평가 미사용을 검사한다. 내부 최저 MAE epoch 및 RF 선택과 최종 학습 epoch도 확인한다. GPU 재추론까지 검산한 뒤 결과/한계를 보고한다. 초기값 평균 및 사람 단위 쌍체 부트스트랩은 별도로 구분한다. 모든 결과를 보고한 뒤 registry의 이 항목만 reported로 갱신한다.

파일럿과 본 학습은 다른 경로에 저장하며, 파일럿 가중치를 본 학습에 재사용하지 않는다. 별도 데이터 재배포나 상업적 활용은 이 실험의 범위가 아니다.

## RF 특징 분석과 입력 축소 — 2026-10-31

같은110명·2,953구간·6분할·초기값5개를 유지해 세 입력 변형을 비교했다. 원래 모델은 보존했다. CPU Slurm32925에서 정상 종료했고90개 최종RF의 재추론을 검산했다. 초기 로컬 계산의 완료 조합은 이어 사용했으며 기존 GPU 작업은 변경하지 않았다.

| 입력 | 특징 수 | 전체 MAE | 실제2·3점 MAE | 실제3점 MAE | 실제3점에서2점 이상 오차 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 전체3D 회전 요약 | 698 | 0.526875 | 0.720409 | 0.912297 | 0% |
| 큰 관절10개 회전 요약 | 308 | 0.543633 | 0.722237 | 0.884468 | 0% |
| 큰 관절의 변동 폭·시간 변화·자기상관 | 128 | 0.535122 | 0.717275 | 0.787709 | 0% |
| 관절 축 방향 변화량을 각도로 단순화 | 58 | 0.562604 | 0.764517 | 0.970619 | 1.948% |

큰 관절은 좌우 고관절·무릎·발목·어깨·팔꿈치다. 128개는 회전행렬60성분의 표준편차60개, 평균 절대 시간차분60개, 자기상관8개다. 58개는3D회전에서 기준 축의 방향 변화 각도를 만든 진단용 입력이다. 해부학적 굽힘각이나 실제2D 영상 검출값으로 부르지 않는다. 세 변형 모두 원래3D자료에서 만든 입력이며 실제 단일카메라 성능 검증은 아니다.

128개 모델은5개 초기값 모두 전체MAE가 증가하고 실제3점MAE는 감소했다. 평균 차이는 전체+0.008247점(사람 부트스트랩95%구간−0.009859~+0.027586), 실제3점−0.124589점(−0.205310~−0.043497)이다. 사전 동등성 허용 범위를 정하지 않았으므로 성능 동등성을 입증했다고 해석하지 않는다. 3점은7명·45구간뿐이며 초기값 반복이 독립 사람 수를 늘리지 않는다.

원래RF의 보지 않은 사람 예측에서 특징군을 함께 섞어 의존도를 확인했다(30모델×3반복, 전체/기관내 섞기). 기관내 섞기의 MAE 증가량은 시간변화량0.115790, 변동폭0.039656, 자기상관0.001895점이다. 부위별로 팔꿈치·손목·손0.050864, 몸통0.040160, 고관절0.039033점이다. 통계별 묶음과 부위별 묶음은 겹치므로 합산하지 않는다. 중요도는 모델 의존도이며 생체역학적 원인이나 필수 특징의 증명이 아니다. 재학습하면 다른 상관 특징으로 대체될 수 있다.

실제3점 예측에서 나무 잎의 가중 학습점수 구성은0점3.92%,1점17.19%,2점45.10%,3점33.79%였다. 이 혼합의 평균은2.087703점으로 실제 예측과 일치했다. 사람 비중을 같게 해도 전체3점 비중은4.14%이고, 분할별 학습에는3점 관측자가5~7명이다. 원래30모델 중29개는 최소 잎 구간수8을 내부 검증에서 선택했다. 학습 사람의3점 MAE는 분할/초기값 평균0.406610점, 평가 사람에서는0.912297점이었다. 이 결과는 평균으로 당기는 구조와 새 사람에서의 오차 증가를 보여주지만 희소성·특징 부족·정규화 설정의 개별 인과 기여를 분리한 실험은 아니다.

원논문은3DGait·PD-GaM·T-SDU-PD가RGB에서WHAM으로 복원된 자료라고 설명한다. 해당87명·2,172구간에서 원래RF의 전체MAE는0.533935점(중앙값 기준선0.645599)이다. 이는 혼합 자료로 학습한 기존 모델의 해당 기관 부분집합 평가이며, RGB자료만 재학습하거나 새 촬영 환경을 검증한 결과가 아니다. 공개 파일에는 영상 프레임이 없으므로 우리 단일카메라의 검출·가림·노이즈·전처리 영향을 직접 검증하지 못했다. 영상→동일한SMPL표현→RF 경로에는 근거가 있지만, 2D 관절점만으로 현재 성능을 유지한다는 결론은 내릴 수 없다.

## 공개 영상에서 RF 점수 안정성 — 2026-10-31

목적은 단일 카메라 영상에서 3D 관절 회전을 복원해 같은 특징과 기존 RF로 연결할 수 있는지, 촬영 방향과 검출 상자 흔들림에 따라 점수가 얼마나 변하는지 확인하는 것이다. 공개 영상에는 CARE-PD 점수 정답이 없으므로 임상 예측 정확도를 검증하는 실험은 아니다.

기존에 확보한 비상업 연구용 MoVi 영상 중 두 카메라에서 주요 12관절이 연속150프레임 동안 화면 안에 있는 첫5명(ID18·27·31·36·40)을 결과 확인 전에 선정했다. 각 사람의 동일5초를 PG1·PG2에서 각각 처리했다. 제공된 보정값의 광축 차이는84.88도다. 사람이 도는 구간도 있어 고정된 정면/측면 비교로 해석하지 않는다. 기준좌표는 구간 선정에만 사용했고 복원·RF 입력에는 쓰지 않았다.

공식 HMR2.0b의 이미지 특징 추출기와 관절 회전 출력부를 사용했다. 별도 SMPL 인체 모델 파일과 표면 생성 단계는 사용하지 않았다. 이는 CARE-PD의 WHAM 복원과 다른 도구이며, 좌표 정의는 같은 국소 SMPL 회전이지만 복원 오차의 분포까지 같다고 볼 수 없다. 기존 MediaPipe Heavy 영상 검출로 사람 상자를 만들었다. 원본 조건과 상자 높이의2%·5%에 해당하는 이동/크기 흔들림을 초기값3개로 생성해 총10영상×7조건=70조건,10,500프레임을 처리했다. 평균 이동 표준편차는약8.7/21.8픽셀이다. 합성 검출 상자 흔들림이며 실제 관절 검출 오차나 가림 전체를 재현하지는 않는다.

GPU 파일럿33002와 본 추론33003이 정상 종료했다. 본 작업은5분32초, 최대 GPU 메모리2.66GiB였다. 첫 실행33000과 CPU 확인33001은 체크포인트의 OmegaConf 의존성 누락으로 실패했고, 전용 폴더에 해당 패키지를 추가한 뒤 같은 모델·입력으로 재실행했다. 대기 작업32991만 대체했고 다른 학습·GPU 확보 작업은 유지했다.

## 영상 점수의1점 집중·촬영 방향 차이 진단 — 2026-10-31

기존 모델30개와 회수한 영상 특징을 고정한 채 CPU에서 분석했다. 입력 분포 차이와 RF 평균화를 모두 확인했지만, HMR2의 단독 인과 기여는 분리하지 못했다. 새로운 학습·GPU 추론·점수 보정은 수행하지 않았다.

**조건 차이를 추가로 확인했다.** CARE-PD 제공처는 KUL-DT-T와 E-LC만 비직선 보행이라고 설명하며, 현재 점수 학습에 사용한3DGait·BMCLab·PD-GaM·T-SDU-PD는 직선 보행 범주다. 반면 이전 MoVi 구간 선정은 주요 관절이 두 영상 안에 있는지만 확인했으며 회전을 제외하지 않았다. 이번에 기준3D 좌표의 좌우 고관절 선으로 몸 방향을 계산하니,5초 안의 방향 변화 범위(5~95백분위)가5명 각각186.8·274.2·163.7·180.1·180.9도였다. 어깨 선으로도 유사한 큰 방향 변화를 확인했다. 이 값은 관절 굽힘각이나 임상 회전 점수가 아니다. 사람 집단·회전·촬영·복원 도구 차이가 함께 존재한다.

**입력 조합 차이는 구간 길이를 맞춰도 남았다.** CARE-PD에서5초 이상인90명·1,722구간의 앞5초를 같은 방법으로 요약했다. 영상 복원 출처3개 자료만 남기면85명·1,657구간이다. 각 바깥 학습 분할의 사람 동일 비중 평균·표준편차로128특징을 표준화하고, 가장 가까운 학습 기록까지 거리를 구했다. MoVi의 거리는 보지 않은 CARE-PD 평가 기록의 거리 분포에서 평균98.94백분위였다. 영상별 분할 평균은97.61~99.96백분위다. 이는 선택한 거리 기준에서 낯선 특징 조합이라는 근거이며,98.94%의 정확도나 임상 위험 확률이 아니다. 개별 특징의 최솟값~최댓값 범위 밖 비율이1.39%로 낮다는 이전 결과만으로 입력이 유사하다고 볼 수 없다. 큰 차이는 무릎·고관절의 일부 회전행렬 성분 변동 폭에서 나타났으며, RGB 기준 일부 무릎 성분의 평균 차이는3.1~4.7표준편차였다. 정상 보행과 PD 보행의 차이 또는 회전의 영향도 포함하므로 HMR2 오류로만 부르지 않는다.

**RF는 서로 다른 점수 기록을 섞어 약1점을 만들었다.** 각 나무의 실제 부트스트랩 중복 횟수와 사람별 학습 가중치를 복원했다. 새 영상에서 도달한 잎에 섞인 정답 비중을 평균하면0점33.98%,1점39.81%,2점24.60%,3점1.60%이며, 가중 평균0.93826점이 실제 예측과 일치했다. 이는 보정된 등급 확률이 아니다. 원래 바깥 학습의 사람 가중 평균은0.92722점이다. 영상에서 나무 간 예측 표준편차는평균0.674점으로, CARE-PD 평가 기록 전체0.548점 및 예측이1점 근처인 기록0.581점보다 컸다. 나무들이 동일하게1점이라고 판단한 결과와 구별해야 한다.

기존 CARE-PD의 실제0·1·2·3점별 평균 예측은0.600·1.010·1.341·2.212점이다. 양끝을 중앙으로 당기는 현상은 원래 평가에서도 존재한다. 다만 예측 전체 범위는약0~2.92점이므로 RF가 입력과 무관하게 상수1점만 내는 것은 아니다. 낯선 입력과 평균화가 함께 관찰됐다는 결론이며 두 원인의 기여율을 추정한 실험은 아니다.

**촬영 방향 차이는 고관절·어깨 요약값과 연결됐다.** 두 번째 카메라의 회전행렬 성분 변동 폭 평균은약7.3%, 시간 변화량 평균은약18.3% 작았다. 시간 변화량은5명 모두 감소했다. 나무의 시작점부터 끝점까지 점수 증감을 실제 분기 특징에 배분하면, 카메라 차이+0.174519점은 변동 폭 분기+0.103507점, 시간 변화 분기+0.072216점, 자기상관 분기−0.001204점으로 재구성됐다. 부위별 별도 묶음에서는 고관절+0.096804점, 어깨+0.049928점이었다. 통계별·부위별 수치를 서로 더하지 않는다. 이 분해는 나무 분기 순서와 상관 특징에 의존하며 인과적 중요도 비율이 아니다. 모델 입력에서 전역 방향은 이미 제외돼 있어 몸 전체 방향만 한 번 회전시키는 보정이 이 문제를 자동으로 해결하지는 않는다.

다음 단계의 우선순위는 제안이며 아직 실행하지 않았다.

1. 직선 구간·길이·몸의 화면 크기·전신 가시성을 맞춘 paired-view 비교부터 한다. 먼저 기존 자료에서 가능한 공통 길이와 사람 수를 확인한다. 회전 구간은 따로 평가한다. 지금 자료로 고정0.175점을 빼거나 MoVi를0점 정답으로 지정하지 않는다.
2. 같은 영상의 HMR2와 WHAM 복원을 대조해 도구 차이를 분리한다. WHAM에는 정식 SMPL 모델 파일이 필요하다. HMR2를 계속 사용할 경우 향후 점수 학습 입력도 같은 복원 방식으로 맞추는 것이 필요하다. 단순 평활화는 시간 변화량을 줄여 점수를 더 높일 수 있으므로 개선으로 가정하지 않는다.
3. 고관절·어깨의 시점 민감도를 먼저 줄이고, 좌표축 성분 의존이 낮은 회전 변화 요약을 후보로 비교한다. 기존58개 단순각도 변형의 MAE0.562604가 악화됐으므로 각도만 남기는 방식을 그대로 채택하지 않는다. 새 특징을 검토할 때는 기존 사람 분리·초기값5개에서 전체 및 높은 점수 오차와 같은 동작의 시점 차이를 함께 확인한다.
4. 입력 조건을 정리한 뒤 RF 잎 크기·서열형 예측·불확실성 출력 등을 비교한다. 점수가 중앙에서 더 퍼지는 것만으로 개선이라 판단하지 않는다. 전체MAE와 높은 점수 오차가 실제로 줄어드는지 내부 검증에서 확인한다.

## CARE-PD 2초 입력 재학습 — 2026-10-31 실행 기록

이전 실험은 전체 구간으로 학습한RF에2초 특징만 넣었다. 이번에는 동일110명·2,914기록으로 전체 구간 대조RF, 앞2초RF, 가운데2초RF를 각각 다시 학습한다. 사람6분할·초기값5개·128특징·나무200개·사람 동일 학습 비중을 유지한다. 바깥 평가 분할f를 제외하고 내부 검증(f+1)%6에서 잎 최소 크기2/8을 고른 뒤 바깥 학습 사람 전체로 다시 학습한다. 최종90모델과 내부180학습을 확인해야 전체 완료다.2초 미만39기록은 모든 새 조건에서 제외한다. 구간을 늘려 독립 사람이 늘었다고 계산하지 않는다.

현재 결과의 해석은 보행 특징에 점수와 관련된 예측 정보가 있다는 연구 근거와, 새 단일카메라 환경에서 개인의 임상 점수를 측정할 수 있다는 근거를 구분하는 것이다. 가운데2초 모델은 중앙값 기준선보다MAE가 약17.4% 작지만, 반올림 등급 일치율은55.05%(기준선38.97%, 기존전체RF54.18%)다. 새 촬영 환경의 점수 정확도는 확인되지 않았다. 동일 평가 사람을 반복적으로 사용한 탐색 결과이며, 최종 설정을 고정한 뒤 독립된 임상 영상·점수 집합에서 확인해야 한다.2초 입력에는 원래 기록의 정답을 부여했으며 별도의2초 임상 판정이 아니다. 또한 현재 정답은UPDRS 보행 항목이므로 SPPB 전체나TUG 예측의 검증으로 확장하지 않는다.

이 해석은 CARE-PD 원논문의 보행 점수 예측 목표와 기관 간 전이 평가에 대응한다. 원논문도 다른 자료로 옮기면 성능이 감소하므로 사람 분리 평가와 촬영 환경을 바꾼 평가를 별도로 수행한다. 우리에게 필요한 다음 근거는 동일한 영상→3D 복원 경로와 전문가 점수가 연결된, 학습에 쓰지 않은 사람·촬영 환경에서의 평가다. 이는 제안이며 이번 실험에서 수행한 임상 검증이 아니다.
