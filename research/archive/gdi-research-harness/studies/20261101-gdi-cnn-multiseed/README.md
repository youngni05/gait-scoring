## 무엇을 비교했나

기존 여러 구간 CNN의 가중치 초기값20261028에20261101·20261102 두 개를 추가했다. 같은692명·1,061기록·11,261구간과 사람5분할,12개 다리 특징·124프레임, RMSprop·기록별 구간 역수 MSE·배치32·최대100epoch를 유지했다. 학습 길이는 바깥 평가 사람을 제외한 내부4분할의 사람 MAE로 선택했다. 정답 변환과 OLS 보정은 각 모델의 학습자료만으로 계산했다. 초기값의 효과를 보도록 원래 배치 순서와 원래 모델 생성 직후의 dropout 난수 상태도 유지했다.

반복별 최종모델1개와 내부모델4개의 보정 후 예측을 같은 비중으로 평균하고, 기존 CNN 평균과 두 새 반복의 평균을 다시1/3씩 합쳤다. 내부모델의 학습 원시 예측 표준편차0.01 미만 제외 규칙을 그대로 적용해 새 반복에서는seed20261102의outer3/inner2 한 개가 제외됐다. 기록이나 평가 사람을 제외한 것이 아니다. 기존 STT 모델 평균·좌우 결합 STT·fold별 CNN 비중과 좌우 차이 비중은 그대로 적용했다. 평가 결과를 보고 좋은 초기값이나 결합 비중을 고르지 않았다. 보호된 최종 평가자료는 열지 않았다.

## 실제 실행과 확인한 범위

작업33618(DIS02)·33619(DIS01)은 서로 다른 물리GPU에서 각각25개 학습·5개 바깥평가를 마치고 종료코드0으로 정상 종료했다. 두 반복 합계50학습·10바깥평가·4,845epoch를 검사했다. CPU/GPU 가상25중첩학습, 중단재개, 검증정답 변경 불변, 실제3epoch 파일럿과 재추론을 통과한 지문으로 본학습을 시작했다. 같은 초기값이면 원 코드와 새 코드의 가상2epoch 가중치·손실·지표·보정계수가 완전히 같았다.

회수 원본의 서버/로컬SHA256, 사람분리·정답/좌우/기록 연결·배치순서·학습자료만의 정규화/보정·내부epoch선택·모든epoch 지표를 검사했다. 최종10모델을 별도CPU64로 재추론했고, 평균 비교에서는50개 구성원 출처와49개 비제외 모델의 재추론을 확인했다. 최대 예측 차이는0.000033051점으로 기존0.0001 기준 이내다. 별도 검산은 사람 비중 합계1, 전체·fold·고득점 지표,3초기값 평균과 좌우 결합을 다른 계산식으로 재구성했다. 지표 최대 차이는4.45e-15, 결합 예측 최대 차이는4.27e-14점이다.

## 보존한 실패와 검산 환경의 구분

최초 CPU 가상검사는 시험자료의 cohort1 누락으로 집계에 실패했다. 가상 집단 구성과 참조파일 포함만 수정했고 실제 자료·학습 설정·기준은 유지했다. 실패 원본은D의 첫 local 검사 폴더에 남겼다.

첫 반복은 로컬 NumPy2.3.5의 원래 엄격 검사를 통과했다. 두 번째 반복은2,428epoch 중2개에서 보정계수 차이가1e-10 기준을 넘었다. 최대 계수 차이는4.7371e-9이고 같은 원시 예측에 두 보정식을 적용한 출력 차이는 최대1.5782e-10점이다. 학습 초기 원시 예측의 표준편차가 작은 두 경우였다. **로컬 엄격 검사 실패는 실패로 보존했다.**

두 번째 반복은 서버의 원래 Python3.8·NumPy1.24.4·PyTorch2.4 환경에서 동결한support.py를 수정하지 않고 동일한1e-10 기준으로25학습·2,428epoch 전체 검사와 최종5모델CPU64 재추론을 통과했다. 별도 로컬5모델CPU64 재추론도 통과했다. 원환경 통과와 로컬 엄격 검사 실패를 구분하며 어느 허용오차도 변경하지 않았다. 원본·학습·보정식·평가 예측도 변경하지 않았다. 회수 실행기는 이 보정계수 예외만 원환경 검사와 로컬 파일 전체 지문·별도 재추론으로 확인하며 다른 실패를 우회하지 않는다.
