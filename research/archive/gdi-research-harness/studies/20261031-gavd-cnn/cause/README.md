# GAVD 낮은 정상 점수의 원인 분리

2026-10-31 · 고정 CNN 진단과 실제 재추출 완료

**모델의 높은 점수 과소예측과 관절 추출에 따른 점수 불안정성이 함께 확인됐다.** 단순한 좌표 크기·위치 차이는 이번 검사에서 영향을 주지 않았다. 촬영 방향·시간 간격에는 민감했지만, 실제 촬영 조건이 낮은 정상 점수의 얼마를 설명하는지는 확정하지 못했다.

이번 작업은 앞선 정상 7·비정상 18구간과 이미 정해 둔 비교 2쌍을 유지했다. 모델을 다시 학습하거나 점수가 더 잘 구분되는 처리 방식을 채택하지 않았다. 개발 자료의 실제 GDI가 있는 예측, 같은 좌표의 통제된 변형, 같은 영상의 실제 BODY25 재추출을 나눠 확인했다.

| 원인 후보 | 직접 확인한 사실 | 현재 판단 |
|---|---|---|
| 학습된 모델의 높은 점수 과소예측 | 개발 자료에서 실제 평균 93.63 → 예측 86.12, 실제 103.93 → 예측 90.14 | GAVD 영상과 관계없이 존재하는 문제다. CNN 구조만의 결함인지, 학습 표본·손실·입력 정보의 한계인지는 추가 분리가 필요하다. |
| 관절 추출 결과의 불안정성 | 같은 4영상·프레임에서 추출 해상도만 바꾸자 점수 변화 절댓값 평균 2.38점·최대 4.35점 | 앞선 비교 차이 약 2점에 비해 무시하기 어려운 영향이다. 어느 추출이 정답인지는 미확인이다. |
| 좌표의 단순 크기·위치 차이 | 25기록 모두 좌표 0.5배·2배, 일정 이동 후 점수 차이 0 | 추출된 좌표에 대한 단순 크기·위치 차이만으로는 현상을 설명하지 못했다. 실제 영상 해상도·원근·가림의 영향까지 배제한 것은 아니다. |
| 좌우 반사·시간 간격 차이 | 반사 평균 절대 변화 1.64점, 시간 간격 ±20% 약 1.35~1.37점 | 입력 조건에 대한 민감성은 있다. 반사는 실제 카메라 각도 변화 전체를 대신하지 못하며, 학습 JSON의 실제 시간 간격도 미확정이다. |

## 1. 모델·학습 자료 쪽 문제

현재 사용하는 동일한 모델 명세 SHA256을 확인하고, 692명·1,061기록의 사람 분리 교차검증 예측을 다시 집계했다. 각 기록은 **그 사람을 학습에 사용하지 않은 모델의 예측**으로 평가했다. 별도로 그 사람을 학습한 나머지 4모델 평균도 살펴봤다. 후자는 일반화 성능이 아닌 학습 자료에 대한 적합 정도다.

| 실제 GDI 범위 | 좌우 점수 수 | 실제 평균 | 미학습 사람 예측 평균 | 학습에 포함된 사람 예측 평균 |
|---|---:|---:|---:|---:|
| 60 미만 | 232 | 55.14 | 62.65 | 59.38 |
| 60~70 미만 | 506 | 65.50 | 69.86 | 68.11 |
| 70~80 미만 | 674 | 75.05 | 75.37 | 75.51 |
| 80~90 미만 | 455 | 84.50 | 80.73 | 82.08 |
| 90~100 미만 | 211 | 93.63 | 86.12 | 88.68 |
| 100~120 미만 | 44 | 103.93 | 90.14 | 93.19 |

낮은 점수는 높이고 높은 점수는 낮추는 **중간값 쪽으로 몰리는 경향**이 있다. 100점 이상 사례는 좌우 총 2,122점 중 44점이며 36명에 해당한다. 같은 사람의 여러 기록·좌우가 포함되므로 각 점수를 독립 참가자로 세면 안 된다. 높은 점수의 표본 비중이 작다는 사실은 확인했지만, 이것이 압축의 단독 원인이라고 입증하지는 않았다.

이 분석은 GDI 회귀의 문제를 보여준다. 개발 자료의 높은 GDI 사례를 임상적으로 건강한 사람이라고 다시 라벨링하거나, 정상·비정상 분류 성능으로 바꾸어 해석하지 않는다. GAVD에 실제 GDI 정답이 없으므로 ‘정상 점수 부족분 중 13.79점은 모델 탓’처럼 원인별 점수를 분배할 수도 없다.

## 2. 같은 영상에서 관절 추출만 바꾼 결과

앞선 두 비교 쌍의 **같은 4영상·같은 프레임**을 사용했다. 공식 BODY25 가중치·원영상·대상자 선택 규칙·CNN·보정식을 유지하고 OpenPose 입력 높이만 368에서 544로 바꿨다. 높은 해상도가 정답이라고 가정하지 않았다. 출력은 모두 원영상 픽셀 좌표이며, 겹치는 원래 창 11개로 비교했다.

| 구분·영상 | 368 추출 점수 | 544 추출 점수 | 변화 |
|---|---:|---:|---:|
| 정상·EHx08gSNfxQ | 72.35 | 73.12 | +0.77 |
| 정상·WpARylM4UYU | 70.99 | 73.62 | +2.63 |
| 비정상·kA40kglSmYw | 70.19 | 68.40 | −1.79 |
| 비정상·05oyBOE_0UE | 69.04 | 64.69 | −4.35 |

후면 쌍의 정상−비정상 차이는 **2.16 → 4.72점**, 정면 쌍은 **1.95 → 8.93점**으로 변했다. 그러나 두 정상 점수는 여전히 73점대다. 관절 추출을 바꿔도 정상의 낮은 점수가 사라지지는 않았다.

**차이가 커졌다고 관절 정확도나 분류 성능이 좋아졌다고 결론 내릴 수 없다.** 544 추출에서는 4기록 모두 평균 발끝 신뢰도가 낮아졌고, 3기록의 최대 필수좌표 결측률이 높아졌다. 예를 들어 `05oyBOE_0UE`의 발끝 신뢰도는 0.506 → 0.307, 최대 결측률은 13.66% → 19.13%였다. 기존 결측 25% 제한은 두 조건 모두 통과했다. 신뢰도 자체도 두 설정 간 정확도의 보증은 아니다.

원영상에 두 좌표를 겹쳐 가장 차이가 큰 프레임을 확인했다. `WpARylM4UYU` 148번 프레임에서 오른발 끝 위치가 발목 쪽으로 이동했고, 가림이 있는 `EHx08gSNfxQ`에서도 발목 위치가 크게 달랐다. 전체 고신뢰도 필수 관절의 두 추출 간 거리 중앙값은 영상별 약 1.34~3.25픽셀이지만, 일부는 24~48픽셀 차이가 있었다. 이는 두 추출의 **불일치**이며, 실제 관절 정답에 대한 오차값이 아니다. 새 그림 확인을 이유로 기존 표본이나 점수를 바꾸지 않았다.

![원영상과 두 BODY25 추출의 최대 불일치 프레임](pose_disagreements.jpg)

각 행에서 원영상 → 368 → 544 순서다. 관절 번호 11은 오른쪽 발목, 22는 오른쪽 엄지발가락 끝이다. 사람이 확인한 것은 그림에 표시된 프레임과 앞선 표본 시점이며, 모든 프레임의 관절 정답을 수작업으로 작성한 것은 아니다.

## 3. 촬영 조건·검출 오류를 흉내 낸 민감도 검사

실제 GAVD 좌표의 한 조건만 바꿔 기존 전처리와 CNN을 다시 적용했다. 변형 전후 같은 기록·같은 창끼리 비교했다. 이 결과는 조건 변화에 모델이 얼마나 반응하는지를 보여주며, 실제 원영상에 해당 오류가 있었다는 증거는 아니다.

| 변경 | 기록 수 | 점수 변화 절댓값 평균 / 최대 | 해석 |
|---|---:|---:|---|
| 좌표 0.5배 또는 2배 | 25 | 0 / 0 | 허벅지 길이로 나누는 기존 정규화가 단순 배율을 제거했다. |
| 화면 내 좌표에 일정값 더하기 | 25 | 0 / 0 | 엉덩이 중심을 빼는 기존 처리로 위치 이동이 제거됐다. |
| 좌표를 수평 반사 | 25 | 1.64 / 4.79 | 좌우 화면 방향에 완전히 불변인 모델은 아니다. 실제 전후방·원근 변경과는 다른 검사다. |
| 표본 간 시간 간격 ×0.8 | 13 | 1.35 / 3.51 | 관측 범위 안에서 동일 중심의 124시점을 보간했다. |
| 표본 간 시간 간격 ×1.2 | 13 | 1.37 / 5.53 | 바깥 구간을 지어내지 않아 정상 1·비정상 12기록만 가능했다. 전체 정상의 FPS 원인 진단으로 일반화할 수 없다. |
| 신뢰도 0.1 미만 좌표를 결측 처리 | 25 | 0.09 / 1.00 | 기존 보간·결측 제한을 유지했다. 고신뢰도 오검출은 이 방법으로 걸러지지 않는다. |
| 대상자 bbox 높이의 1% 표준편차로 좌표 흔들기 | 25 | 2.93 / 7.26 | 정상 평균 변화는 −3.95점. 정해 둔 난수 한 번의 민감도이며 실제 오류량의 측정은 아니다. |

추가로 가운데의 완전히 관측된 자세를 반복한 정지 입력에서는 점수가 절댓값 평균 5.34점 변했다. 모든 입력을 같은 상수로 내보내는 모델은 아니지만, 정지 자세는 정상 보행 대조군이 아니므로 보행 정보를 올바르게 학습했다는 증거로 쓰지 않는다.

## 검산과 남은 한계

- 개발 자료 재집계는 원예측 CSV와 대조했다. 구간별 평균 차이 최대 약 5.88×10⁻⁷점. 기존 저장 모델 재추론 예측과 OOF 대조는 최대 3.05×10⁻⁵점으로 기존 10⁻⁴ 기준 안이었다.
- GAVD 진단의 원본 특징은 기존 특징과 비트 단위 동일했고, 원본 창별 점수 재현 오차는 0이었다. 변형별 차이를 저장된 5모델×좌우 배열에서 독립 재계산한 오차는 최대 약 3.08×10⁻¹⁴점이었다.
- Slurm 33490은 0:0으로 완료됐다. 실제 3이미지의 544 입력 blob이 공식 CPU와 일치하고 열지도 오차 최대 1.79×10⁻⁶로 기존 10⁻⁴ 기준을 통과했다. 4기록·772프레임·33청크 회수 후 JSON 지문을 재검산했다. 여유 프레임을 제외한 점수 입력은 원래 범위 769프레임이다.
- 최종 4기록은 원래 11창·5모델을 사용했고 제외가 없었다. 544 출력은 신뢰도 상한 예외도 실제로 필요하지 않았다. 원래 두 기록의 예외 승인·원래 결과는 보존했다.
- 표본·매칭 목록과 기존 bundle 684파일 지문이 유지됐다. 학습·보정 변경·점수에 따른 입력 선택은 없다. 이전 별도 4-ULP 좌표 동일성 검사 실패를 이번 열지도 검산으로 덮어쓰지 않았다.

**이번 결과로 원인을 하나만 지목하거나 기여율을 계산할 수는 없다.** 확인된 것은 (1) 학습된 예측 체계의 고점 압축, (2) 관절 추출 설정에 따른 수 점 수준의 불안정성, (3) 단순 크기·위치 변환에 대한 불변성이다. 실제 카메라 각도·FPS·대상자 특성의 영향과 실제 관절 오류를 더 분리하려면, 같은 사람·보행의 촬영 조건을 통제한 자료 또는 독립적으로 검토한 관절 기준 좌표가 필요하다. 높은 해상도 결과나 단순 신뢰도 필터를 정답으로 채택할 근거는 아직 없다.

코드는 `diagnose.py`가 저장된 모델을 그대로 호출해 개발 자료와 변형 입력을 분석하고, `prepare_highres.py`가 같은 프레임·대상자 규칙을 유지하며, `analyze_highres.py`가 공통 창 점수를 비교한다. `verify.py`는 별도 원 CSV·예측 배열·파일 지문으로 이를 다시 검사한다. 작은 수치·그림·검산은 이 C 폴더, 원영상·JSON·진단 배열은 `D:/gait-research-data/D_P/datasets/GAVD/cause` 및 `cause_highres_body25`에 있다.
