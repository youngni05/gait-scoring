# GPU 부분학습 사전 준비

사용자 직접 요청: 필요한 실험과 GPU 연결 전 준비. DESKTOP_AUTORUN은 시작 신호/예약에 적용되며 이번은 수동 기술 준비다. 자동 claim은 cooldown_wait였고 자동 제한/설정/완료기록을 수정하거나 실험 학습으로 우회하지 않는다. 이 폴더에 준비 증거를 별도로 보존한다. 실제 GDI 학습과 외부 GPU 전송은 수행하지 않는다.

1. 기존 모델과 데이터 계약 읽기: 기존175명/203기록/5묶음, 124프레임 앞/중간/뒤, 좌우GDI, baseline alpha1 보존. 보호37/38/223과 새520명 미사용.
2. 실험 묶음: 기존baseline 재사용; 출력부만 학습 대조; norm/pre_logits+출력부; 마지막Transformer단계+norm/pre_logits+출력부. 동일입력/초기값/손실/시드/업데이트예산을 제안한다. 새 임상 기준 없음. 학습률/반복/배치는 GPU 확인 후 확정할 미정값으로 두고 실제학습 실행을 차단한다.
3. 로컬 실행묶음 준비: 기존학습자료만 추출, 코드/가중치/라이선스/지문, 학습범위제어, fold보호, 저장재개, 완료후지표계산. 실제자료는 초기값재현만 검사하며 학습하지 않는다.
4. CPU 가상입력 검사: 선택부분만 변함, 연속2step과1step저장재개+1step 일치, 잘못된데이터/설정/재개혼합 거부. 이는 임상학습이나 성능검증이 아니다.
5. 실행안내와 준비상태를 저장하고 압축본 내용/지문검사. 외부전송/자동예약변경 없음. 시간한도30분/사용률80%보존. 연결후 CUDA/메모리/속도/버전검사 필요.
