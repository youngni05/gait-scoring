# 앱 개발 진행 상태

2026-10-28 사용자 직접 실행으로 첫 코드 점검을 마쳤다.

**재사용 가능한 화면과 측정 모듈은 있지만 아직 연결되지 않았다.** 관리 앱의 로그인·대상자·기록 조회·비교 틀, 실험 앱의 실제 카메라·관절 추정·영상 분석 코드를 확인했다. 관리 앱의 측정은 시뮬레이션이고 저장·변화 판정은 SPPB 전용이다. 조사한 코드에서 원본 영상 녹화·보관 경로는 확인하지 못했다. 좌표 JSON 보관과 영상 저장은 다르다.

현재 두 작업본에 로컬 변경이 있어 원본을 수정하지 않았다. 검사 사본에서 앱 관련57개가 통과했다. 실제 서버·카메라·휴대폰·전체 빌드는 미검증이다.

다음 목표: 관리 앱의 현재 로컬 변경을 보존할 별도 작업본 준비 범위를 정리하고, 실험 앱의 카메라·관절 추정 모듈을 붙일 지점과 필요한 의존성을 확인한다. SPPB와 분리된 보행 기록의 입력·결과 및 원본 영상 보관 방식 선택지를 제시한다. 원본 앱·서버·저장 계약은 임의 변경하지 않는다.

결정 필요: 새 보행 기록·원본 영상의 저장 정책, 분석 결과 연결 형식. 선택과 무관한 의존성·연결 위치 확인은 계속할 수 있다.
