# 두 작업 첫 점검 결과 — 2026-10-28

**앱은 기존 화면과 실제 카메라 모듈을 연결할 기반이 있고, 연구는 시간 정보부터 검증할 가치가 있다.** 이번은 사용자가 요청한 코드·자료 점검이다. 새 앱 기능이나 새 모델 성능을 완성한 것이 아니다.

| 작업 | 확인한 것 | 다음에 할 일 |
|---|---|---|
| 앱 개발 | 관리 앱은 대상자·기록 기능이 있지만 측정은 모의 동작이다. 실제 카메라·관절 추정은 별도 실험 앱에 있다. 저장·비교는 SPPB에 묶여 있다. | 원본을 보존하는 개발 작업본 준비 범위, 카메라 모듈 연결 위치, 보행 기록·영상 보관 선택지 정리 |
| AI 연구 | 바닥선 통과 시간 코드는 있다. 걸음 수·간격 검출은 새 검증이 필요하며 속도에는 실제 거리 기준이 필요하다. | 짧은 영상의 걸음 사건을 확인할 공개 원본·시각·정답 준비 여부를 점검하고 비교 절차 제안 |

검사 사본에서 기존 앱57개·측정23개, 합계80개가 통과했다. 측정 한 파일은 처음 의존성 경로를 찾지 못했고 이미 설치된 경로를 연결해 통과했다. 원본 소스·테스트 기준은 바꾸지 않았다. 실제 서버·휴대폰·MediaPipe 추론·영상 측정 정확도는 이번 검사에 포함되지 않는다.

보행 영상 자체를 녹화·보관하는 기능과 관절 좌표 JSON 보관은 다르다. 조사한 코드에서 전자의 완성 경로는 확인하지 못했다. 두 앱의 로컬 변경을 보존했고, 현재 소스150개가 검사 전후 같음을 확인했다.
