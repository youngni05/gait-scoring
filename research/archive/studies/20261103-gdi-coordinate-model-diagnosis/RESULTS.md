# 원 GDI 예측에서 좌표 처리와 모델 영향을 구분한 실험

**좌표 처리 방식과 학습 방식의 조합이 GDI 오차에 영향을 준다는 것을 확인했다.** 기존 모델에 입력 처리만 바꾸면 악화될 수 있지만, 같은 회귀 모델을 바뀐 입력에 맞춰 학습하면 오차가 줄었다. 다만 현재 최선 결합 모델의 6.52점보다 좋은 새 모델을 만든 결과는 아니다. 실제 좌표 정답이 없어 전체 오차 중 좌표 오류가 차지하는 비율이나 이론적 최저 오차는 계산할 수 없다.

| 핵심 비교 | 평균 GDI 오차 | 해석 |
|---|---:|---|
| 기존 회귀 모델 · 기존 입력 | 7.53점 | 같은 모델 안에서 비교할 기준 |
| 기존 회귀 모델 · 크기 보정만 안정화한 입력 | 8.89점 | 학습 때와 다른 입력 처리만 적용하면 악화 |
| 안정화한 입력으로 다시 학습한 같은 회귀 모델 | 7.32점 | 학습·평가 입력을 맞추면 기준보다 0.21점 개선 |
| 기존 CNN · 기존 입력 | 6.87점 | 원 좌표의 신경망 기준 |
| 기존 최선 결합 모델 · 같은 기존 입력 | 6.52점 | 동일 좌표에서도 모델 방법에 따른 차이가 남음 |

회귀 모델의 크기 보정 안정화 결과는 기준 대비 −0.21점, 조건부 95% 구간 −0.35~−0.08점이었다. 세 전처리 후보를 고려한 98.33% 구간도 −0.38~−0.05점이었다. 새 독립 집단의 성능 확인은 아니며, 이 결과를 CNN이나 최선 결합 모델에서도 같은 개선이 날 것이라는 보장으로 확장하지 않는다.

## 실험의 목적과 정답

이번 모델이 답하는 질문은 “이 보행 기록의 왼쪽·오른쪽 GDI는 얼마인가”다. 정답은 기존 뇌성마비 공개 자료에 연결된 원 GDI 값이다. 앞선 고령자 POMA 예측이나 자체 보행 편차 점수 학습과 구분한다.

반복해서 살펴본 개발 집단 692명·1,061개 기록·11,261개 보행 구간을 사용했다. 기존 사람별 다섯 분할과 124프레임 구간을 유지했다. 원 GDI 정답, 대상자, 구간은 모든 조건에서 같으며 보호된 최종 평가 집단의 입력·정답은 열지 않았다.

원 연구의 영상과 Vicon 측정은 같은 방문의 서로 다른 보행이었다. 따라서 남은 GDI 오차에는 좌표 추정, 2D 정보 손실, 모델의 학습, 서로 다른 보행을 비교하는 변동이 함께 들어갈 수 있다. [원 연구의 자료 수집 방법](https://www.nature.com/articles/s41467-020-17807-z)

## 원본 입력과 실행 순서

1. 공개 OpenPose 자료에서 해당 개발 대상자의 원래 좌표와 신뢰도를 복원했다. 원본 내용 지문을 기존 기록과 대조했고, 기존 전처리로 만든 11,261개 입력 구간은 저장된 원 입력과 완전히 일치했다.
2. 원 좌표를 그대로 둔 기준과 세 전처리 후보, 여섯 무작위 흔들림 조건, 한 가지 지속적 위치 편향 조건을 만들었다. 총 11개 조건이며, 겹치는 구간에는 동일한 프레임의 동일한 변화를 적용했다.
3. CNN과 Transformer 각각 기존 다섯 저장 모델을 사용했다. 각 사람은 그 사람을 학습하지 않은 모델로만 예측했다. 원래 학습 집단에서 구한 출력 보정 계수도 유지했다.
4. 기존 처리와 세 전처리 후보에 대해서는 같은 작은 회귀 모델을 각각 학습했다. 좌표와 파생 특징의 분포·변화량을 요약한 96개 특징을 다리별로 사용했다. 설정 선택은 바깥 평가 사람을 제외한 네 내부 분할에서만 했다.
5. 구간 예측을 기록 안에서 평균하고, 좌우와 여러 기록의 절대오차를 사람 안에서 평균했다. 최종 평균은 692명이 같은 비중을 갖는다. 좌표를 바꾼 뒤 좋은 사람이나 좋은 구간만 골라내지 않았다.
6. 회귀 모델 네 조건의 평균 오차를 본 뒤, 같은 모델의 학습·평가 입력을 교차 적용하는 추가 진단을 기록하고 실행했다. 기존에 저장한 모델만 사용하고 설정이나 계수를 다시 맞추지 않았다. 이 행렬은 추가 탐색 진단이며 사전 고정된 주비교와 구분한다.

주계획은 [protocol.json](D:/Projects/D_P/studies/20261103-gdi-coordinate-model-diagnosis/protocol.json), 추가 진단의 시점과 조건은 [cross-input-addendum.json](D:/Projects/D_P/studies/20261103-gdi-coordinate-model-diagnosis/cross-input-addendum.json)에 보존했다. 입력 준비 중 허벅지 길이 변동 지표 하나가 전체 기록을 참조하는 것을 발견해, 예측 전에 계획대로 공통 구간만 사용하도록 수정했다. 모델 입력과 비교 조건은 바뀌지 않았다.

## 좌표 처리만 바꾸었을 때와 다시 학습했을 때

| 입력 처리 | 고정 CNN | 고정 Transformer | 해당 입력으로 학습한 회귀 모델 |
|---|---:|---:|---:|
| 기존 처리 | 6.87 | 6.94 | 7.53 |
| 추가 평활화 | 7.02 | 7.18 | 7.41 |
| 단발성 튀는 점 보간 | 6.86 | 6.95 | 7.46 |
| 신체 크기 보정 안정화 | 8.93 | 8.47 | 7.32 |

추가 평활화는 원래의 시간 방향 가우시안 필터 폭을 1프레임에서 2프레임으로 늘렸다. 단발성 보간은 앞뒤 점은 가까운데 가운데 한 프레임만 크게 튄 경우에만 앞뒤 중간 위치로 바꿨다. 두 방법 모두 실제 빠른 움직임을 지울 가능성이 있어, 매끄러워진 것을 정확해졌다고 간주하지 않았다.

신체 크기 보정 안정화는 관절 위치 자체를 다른 해부학적 위치로 바꾸는 작업이 아니다. 기존 처리는 매 프레임의 허벅지 길이로 좌표 크기를 나눈다. 이를 기록 전체의 중앙값 길이로 나누도록 변경했다. 크기 분모의 순간 변동을 줄이는 목적이지만, 실제 원근 변화까지 보정하는 완전한 해법은 아니다.

고정 신경망에서는 추가 평활화가 CNN +0.15점·Transformer +0.24점, 크기 보정 안정화가 각각 +2.06점·+1.53점의 오차 증가를 보였다. 단발성 보간의 변화는 약 −0.003점·+0.008점으로 뚜렷하지 않았다.

반면 입력에 맞춰 다시 학습한 회귀 모델에서는 추가 평활화 −0.12점, 단발성 보간 −0.07점, 크기 보정 안정화 −0.21점이었다. 이 차이는 “고정 모델에 새로운 입력 처리를 적용해서 나빠졌다”는 결과만으로 그 입력 처리의 학습 가치를 판단하면 안 된다는 근거다. 다만 같은 신경망을 다시 학습한 비교는 아직 아니다.

| 회귀 모델의 학습 입력 ↓ / 평가 입력 → | 기존 처리 | 평활화 | 단발성 보간 | 크기 보정 안정화 |
|---|---:|---:|---:|---:|
| 기존 처리 | 7.53 | 7.66 | 7.52 | 8.89 |
| 추가 평활화 | 7.79 | 7.41 | 7.78 | 9.24 |
| 단발성 튀는 점 보간 | 7.46 | 7.61 | 7.46 | 8.85 |
| 신체 크기 보정 안정화 | 7.76 | 7.90 | 7.76 | 7.32 |

행렬의 대각선은 학습과 평가의 입력 처리를 맞춘 결과다. 예를 들어 기존 입력으로 학습한 회귀 모델은 크기 보정 안정화 입력에서 8.89점이지만, 그 입력으로 학습하면 7.32점이다. 이 추가 진단은 입력 분포 변화의 영향을 보여주며, 보정 좌표가 실제 관절 위치에 더 가까워졌다는 검증은 아니다.

## 크기를 아는 좌표 오류를 추가한 결과

허벅지의 화면상 길이를 기준으로 각 좌표축에 표준편차 1%·3%·5%인 무작위 흔들림을 추가했다. 결측 좌표와 신뢰도는 유지했다. 두 난수 반복에서 동일한 흔들림 형태를 크기만 바꾸었고, 아래 값은 두 반복의 오차를 평균한 것이다. 밀리미터 단위의 실제 측정 오차를 추정한 것이 아니다.

| 추가한 흔들림 | CNN 평균 오차 | CNN 기준 대비 변화 | Transformer 평균 오차 | Transformer 기준 대비 변화 |
|---|---:|---:|---:|---:|
| 1% | 6.85 | -0.01 | 6.95 | +0.00 |
| 3% | 6.90 | +0.03 | 6.96 | +0.01 |
| 5% | 7.21 | +0.34 | 7.00 | +0.06 |

5% 흔들림은 CNN 오차를 약 0.34점 늘렸고 변화 구간은 +0.18~+0.51점이었다. Transformer는 약 0.06점 증가했으나 구간 −0.01~+0.12점으로 불확실했다. 따라서 같은 좌표 흔들림에도 모델별 민감도가 다르다. 작은 무작위 흔들림의 영향이 작다는 결과를 지속적 위치 편향·좌우 오인식·가림·깊이 정보 손실 전체가 작다는 결론으로 확대하면 안 된다.

두 무릎을 지속적으로 가로 방향 3%만큼 어긋나게 만든 조건에서는 CNN +0.08점, Transformer +0.10점의 평균 오차 증가가 나왔다. 예측값 자체는 사람당 평균 약 0.94점·1.09점 움직였다. 예측값의 변화와 정답 대비 평균 오차의 변화는 같은 값이 아니다.

## 같은 입력에서 모델 방법의 차이

기존 입력을 유지했을 때 CNN 6.87점, Transformer 6.94점, 기존 최선 결합 모델 6.52점이었다. 결합 모델과 CNN의 차이는 −0.35점, 조건부 95% 구간 −0.48~−0.23점이었다. 결합 모델의 수치는 새로 만든 최고 기록이 아니라 기존 저장 예측을 재구성하고 검산한 값이다.

이는 동일한 관측 좌표에서도 학습·모델 결합 방법에 따라 얻는 결과가 달라짐을 보여준다. 그러나 결합 모델의 6.52점이 더는 줄일 수 없는 한계라는 뜻은 아니다. 새로 학습한 회귀 모델의 최선 7.32점 역시 기존 결합 모델을 넘지 못했다.

## 품질 지표와 어려운 점수대

결측률, 낮은 신뢰도 비율, 단발성 튐 비율, 좌표의 빠른 변화, 허벅지 길이 변동과 기존 결합 모델 오차의 순위 상관은 각각 −0.018, −0.045, +0.009, +0.051, +0.036이었다. 실제 GDI 수준과 구간 수를 함께 고려한 순위 관계도 모두 절댓값 0.04 미만이었다. 이 단순 지표만으로 오차 큰 사람을 골라내기는 어려웠다. 이것이 좌표가 정확하다는 증거는 아니다.

사람의 평균 원 GDI로 아래 구간을 정했다. 평균 오차만으로 모델을 평가하지 않기 위해 낮은 점수와 높은 점수 모두 남긴다.

| 모델 | GDI 60 미만 · 62명 | 60~75 미만 · 310명 | 75~90 미만 · 252명 | 90 이상 · 68명 | 사람 평균 오차 10점 초과 |
|---|---:|---:|---:|---:|---:|
| 기존 CNN | 8.53 | 6.34 | 6.71 | 8.29 | 125/692명 |
| 기존 최선 결합 | 7.88 | 5.88 | 6.35 | 8.78 | 112/692명 |
| 기존 처리 회귀 | 9.32 | 7.07 | 6.72 | 10.99 | 154/692명 |
| 크기 보정 안정화로 학습한 회귀 | 8.71 | 6.97 | 6.59 | 10.35 | 141/692명 |

기존 최선 결합 모델도 GDI 90 이상에서는 8.78점 오차이고, 692명 중 112명은 사람 평균 오차가 10점을 넘었다. 전체 평균은 CNN보다 좋지만 90 이상 집단에서는 CNN 8.29점보다 나빴다. 낮은 실제 점수는 높게, 높은 실제 점수는 낮게 예측하는 경향도 남았다. 이는 관찰된 오차 모양이며 그 원인을 좌표나 모델 중 하나로 확정한 것은 아니다.

## 판단과 다음 학습의 우선순위

현재 확인한 범위는 세 가지다. 첫째, 지정한 인위적 좌표 오류에 대한 민감도는 모델마다 다르다. 둘째, 입력 처리와 학습 방식을 맞추는 것이 중요하며 같은 회귀 모델에서는 전처리 변경의 작은 개선을 확인했다. 셋째, 같은 좌표에서도 모델 방법에 따른 차이가 남는다.

현재 자료에는 원 영상의 같은 프레임과 짝지어진 정확한 관절 좌표 정답이 없으므로 실제 좌표 오차, 2D에서 사라진 정보, 모델의 미활용 정보, 방문 안의 보행 차이를 비율로 분해할 수 없다. 원 GDI 연구가 비공개 원 영상을 사용했다는 접근 제약도 남는다. 188명 자료의 불확실한 GDI를 대신 정답으로 쓰지 않았다.

다음 신경망 학습에서 우선 비교할 후보는 기존 처리와 신체 크기 보정 안정화다. 같은 사람 분할·구간·학습 예산에서 CNN을 각각 학습하고, 내부 사람만으로 설정을 선택한 뒤 평균뿐 아니라 60 미만·90 이상 구간과 큰 오차도 비교하는 방식이다. 현재 결과는 이 후속 학습의 근거이며 신경망 개선의 완료 보고는 아니다. 추가 평활화도 후보로 남지만, 여러 설정을 결과에 맞춰 계속 고르는 것은 피한다.

## 검산과 해석 한계

CPU에서 입력 준비·10개 신경망 체크포인트의 재추론·20개 회귀 모델 학습을 완료했다. 기존 최선 결합 모델의 출력은 구성원별 저장 평가 예측으로 다시 조합했다. 원본 좌표 지문, 기존 입력의 완전 일치, 사람 분리, 신경망 110개 모델·조건 조합의 표본 재추론, 회귀 모델의 내부 후보 학습 480회와 저장 모델 20개, 추가 입력 교차 16개 조건을 검산했다.

회귀 학습의 고유값 분해 계산은 독립된 선형방정식 풀이로 대조했고, 최대 예측 차이는 약 3.85×10⁻¹²점이었다. 신경망은 다른 배치 크기로 다시 계산했으며 최대 차이는 약 1.83×10⁻⁵점이었다. 평균·점수대별 오차와 잡음 반복·짝지은 구간도 다시 계산했다.

불확실성 구간은 저장된 예측의 사람 단위 10,000회 재표집 결과다. 모델 학습을 매번 다시 한 구간이 아니며 반복해서 살펴본 개발 집단의 탐색이라는 한계가 있다. 세 전처리 후보에 대한 보정 구간은 모델별로 계산했으며 여러 모델 전체를 아우르는 확증 검정으로 해석하지 않는다.
