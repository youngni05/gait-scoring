# 정상 자료 추가 효과의 출처 구분·외부 전이 검사

2026-11-05 사용자 승인으로 실행했다. 목적은 성인 LJMU를100점으로 추가했을 때의 출력 변화가 단순한 자료 출처 구분으로도 나타나는지, 학습하지 않은 LIVE 아동에게도 이어지는지 확인하는 것이다. 새 정상 GDI 정답을 만든 실험은 아니다.

## 완료한 두 검사

원래 LJMU64명·881편 혼합 실험의 일반 CNN·STT를 사용했다. 새 A~D 사전학습 모델과 섞지 않는다. 출처 비교는 기존 Stanford692명·LJMU64명의 같은 사람 단위5분할, 외부 적용은 LIVE9명·12편이다. LIVE는 이 모델의 학습에서 전부 제외됐지만 프로젝트에서 이전에 탐색한 자료이므로 처음 개봉한 독립 최종 평가자료로 부르지 않는다.

출처 비교 모델은 관절 특징48개로 LJMU일 확률만 학습한다. 나이·GDI·사람 번호는 입력하지 않는다. 학습 사람만으로 특징 크기를 조정하고, 분류 손실은 사람과 자료 출처별 비중을 맞춘다. 확률0.5 이상이면100점, 나머지는 원래 GDI 예측을 사용하는 조건과 확률로 두 출력을 평균하는 보조 조건을 결과 확인 전에 고정했다. 보정·임계값을 평가 결과에 맞춰 조정하지 않았다.

| 일반 모델 | Stanford 전체 MAE: 추가 전 | 실제 LJMU100 추가 | 출처 구분만 사용 | 출처 구분의 LJMU 평균 예측 |
|---|---:|---:|---:|---:|
| CNN | 6.867 | 6.873 | 6.909 | 99.82 |
| STT | 6.945 | 7.115 | 6.977 | 99.84 |

출처 분류의 사람 단위 AUC는1.0이다. 출처 구분만으로도 LJMU가 거의100점이고 Stanford 평균오차 변화는 작은 양상이 만들어졌다. 이것은 가정100과의 오차만으로 정상 움직임을 학습했다고 결론낼 수 없다는 반례다. 원래 신경망이 실제로 같은 규칙을 사용했다는 증명은 아니다. 실제 GDI≥90·≥100·<70의 MAE·과소예측량·편향·과소예측 비율·과대예측량과 대응 재표집 구간은 `source-gate-results.json`에 있다.

LIVE는 원래 학습과 분리된 측면124프레임 구간12개를 그대로 사용했다. 각 모델의5개 바깥 분할 refit 예측을 먼저 평균하고 사람별로 동일 비중을 줬다. 이는 기존 OOF 한 모델씩의 집계와 다르므로 Stanford MAE와 직접 합산하지 않는다.

| LIVE9명 평균 출력 | 추가 전 | 성인 LJMU 추가: 원래 보정 | 같은 추가 모델: Stanford 학습자료만 보정 | 출처 구분만 사용 |
|---|---:|---:|---:|---:|
| CNN | 84.63 | 95.05 | 100.52 | 97.91 |
| STT | 77.02 | 96.17 | 98.87 | 98.04 |

원래 보정의 사람별 평균 변화는 CNN+10.41점(대응 사람 재표집95%7.27~13.27), STT+19.15점(13.52~25.24)이다. 추정 구간은 고정 모델과9명 표본에 한정되며 초기값·다른 표본의 불확실성이나 여러 비교 보정을 포함하지 않는다. 실제 GDI가 없으므로 MAE·정확도 향상을 계산하지 않는다.

성인 자료 추가의 높은 출력이 다른 출처의 아동에게도 이어졌다. 동시에 출처 구분 모델도 LIVE에 높은 출력을 줬다. 따라서 이번 전이만으로 움직임의 정상성 때문인지, Stanford와 외부 자료의 공통 차이 때문인지 분리되지 않는다. 환자까지 일괄 높이는지 확인할 외부 음성 대조군은 이번에 평가하지 않았다.

## 검산과 제약

원래20개 refit 체크포인트의 지문과 학습 사람을 확인하고, 각 모델의 기존 미학습 기록3개를 CPU에서 재추론했다. 최대 차이는0.00002099점으로 기존 허용오차0.001점 이내다. 이전 전수 감사 기록도 유지한다. 출처 분류기의 저장 계수를 직접 계산한 확률이 일치했고, 두 검사의50개 집계 행을 관측별 역수 가중치로 독립 재계산했다. `verification.json`에 결과 지문과 검증 범위를 남겼다.

MoVi 성인28명의 기존 적격 측면 구간은 연속124프레임 조건을 충족하는 구간이0개다. 늘이기·반복·방향 전환 구간 연결로 이 조건을 통과시키지 않았다. 동일 조건의 추가 성인 외부 검증은 미실행이다. LIVE는 연령·촬영·추출 차이가 함께 있으므로 나이 효과 검증도 아니다.

## 진행 중인 후속 학습

- 기존 A~D: `../20261105-gdi-masked-pretrain-v3/`의60개 GDI 모델. 신규 연구와 같은 사람 분할을 사용한다.
- 가정 점수·비중 민감도: `../20261105-normal-label-sensitivity/`. 성인9명·12편 고정, 점수90/100/110 또는 외부 손실¼/1/4배를 한 요소씩 바꾼다.100점·1배는 기존 A~D의 B성인으로 재사용하고40개를 새로 학습한다. 조건별 최적화를 하지 않고 같은 초기값·예제 순서·학습량·Stanford 전용 보정을 유지한다.

기존 모델과 자료를 재사용해 로컬 CPU에서 두 검사를 실행했다. 새 GPU 실험에는 약52KB 코드만 전송했고 이미 승인된 서버 자료를 그대로 참조한다. 새 사람 자료를 서버로 보내거나 기존 실행을 중단하지 않았다.
