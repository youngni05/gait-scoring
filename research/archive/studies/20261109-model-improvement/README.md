# 모델 개선 실험

모델이 출처 지름길을 배운다는 진단에서 나온 세 가지 개선안을 시험한다. 조건과 성공 기준은 [protocol.json](protocol.json)에 결과 전 고정했다. 입력 준비 기록은 [preparation.json](preparation.json)에 있다.

| 조건 | 내용 |
| --- | --- |
| R_rank | 뇌성마비 자료 + LIVE 안 순위 학습(정상 아동 ≥ 뇌성마비 아동 + 20점), LJMU 없음 |
| D_adversarial | 뇌성마비 자료 + LJMU 100점 + 출처 구분 방지(기울기 반전) |
| C0_cycle | 뇌성마비 자료, 보폭 두 번 길이로 맞춘 입력 |
| C1_cycle | 뇌성마비 자료 + LJMU 100점, 같은 입력 |

## 진행 기록

- 보폭 주기는 뇌성마비 자료 27프레임, LJMU 33프레임이었다. 주기를 찾지 못한 구간 8.7%는 원래 입력을 유지했다.
- CPU 점검에서 순위 간격 10점이면 순위 벌칙이 거의 0이라, 성능 결과를 보기 전에 20점으로 올렸다. 순위 벌칙은 보정 전 출력에 걸린다. GPU 파일럿에서도 훈련 쌍의 93%가 이미 20점 이상 벌어져 있어, 순위 벌칙의 영향은 제한적일 수 있다.
- GPU 파일럿: 작업 47966(R), 47969(D), 47970(C0), 47972(C1) 모두 정상 종료, 재추론 오차 0. 에폭당 R 14.7초, D 13.5초, C0 6.3초, C1 8.4초.
- 본 학습: C0 작업 48155, C1 작업 48156. R과 D는 한 작업으로는 시간 상한을 넘을 수 있어 분할 0~2와 3~4로 나눠 다시 제출했다(R 48159·48160, D 48161·48162). 원래 작업 48153·48154는 대기 중에 취소하려 했으나 이미 시작되어 있었고, 같은 분할을 두 작업이 동시에 쓰지 않도록 약 1분 만에 취소했다. 시작된 첫 내부 학습은 같은 설정의 체크포인트에서 이어진다. 모든 본 학습은 DIS04~06을 제외한다. 서버 경로는 `/abr/RESEARCH_USER/gdi-model-improvement-20261109`이다.
- 회수: 여섯 작업 모두 정상 종료(COMPLETED, 종료 코드 0), 20개 분할 완료. 서버 압축본과 받은 파일의 SHA-256이 일치했다(`4d883fc6…9672`). 결과는 `D:/gait-research-data/D_P/model-improvement-20261109/received/runs`에 있다. 재학습 모델 재추론 최대 오차는 0.0004점 이하였다.

## 해석

- **고득점 과소 예측은 어느 조건에서도 줄지 않았다.** 네 조건 모두 실측 90점 이상 다리의 편향이 기존 모델보다 0에서 더 멀어졌다. 정확도 기준도 모두 넘지 못했다. C0만 오차 변화가 0에 가까웠으나 상한 0.16점이 기준 0.10점을 넘었다.
- **외부 정상 반응은 커졌지만 새로운 이득은 아니다.** R·D·C1은 LIVE 정상과 뇌성마비의 차이를 키웠다. 그러나 가장 큰 C1(20.8점)은 기존 정상 추가 모델(20.8점)과 같다. 주기 입력이 더한 효과는 확인되지 않았다.
- **도메인 적대는 출처를 지우지 못했다.** 반전 가중치 0.3에서 표현으로 출처를 98.5% 맞혔다. 그 대가로 정확도만 0.72점 나빠졌다.
- **순위 학습은 LIVE 구분을 늘린 대신 개발 자료 정확도를 크게 잃었다.** 직접 촬영 영상에서는 정상과 이상의 차이가 0.5점으로 줄어, LIVE 밖으로는 일반화되지 않았다.
- C1의 기울기가 양수로 바뀌어 사전 기준은 형식상 통과했지만, 순위 상관 0.10과 LJMU 이웃 5%는 작은 변화다. 고득점 편향도 오히려 커졌으므로 지름길이 실질적으로 줄었다고 보기 어렵다.
- 종합하면 외부 정상 영상을 더 잘 올리는 방향의 수정은 Kidziński 고득점 다리의 과소 예측으로 이어지지 않았다. 이 과소 예측은 출처 지름길만으로 설명되지 않으며, 개발 자료 안의 입력과 실측 GDI 관계에서 비롯되었을 가능성이 남는다. 이는 결과에서 나온 해석이며 직접 검증하지는 않았다.
