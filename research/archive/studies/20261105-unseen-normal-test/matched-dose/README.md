## 최종 실행

학습이 끝나면 다음 순서로 실행한다.

1. `collect_once.py --scope complete`로 회수한다.
2. `audit_results.py --arm <adult|child> --family <STT|bilateral>`로 검산한다.
3. `infer.py <arm> <STT|bilateral>`을 baseline·adult·child에 실행한다.
4. `analyze.py final`로 판정한다.

수치는 [results-interim.json](results-interim.json)에 있다.
