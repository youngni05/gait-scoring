# 혼합 모델의 스탠퍼드 전용 보정 시험

2026-11-05. 사용자 승인 후 수행했다. 혼합 학습의 신경망은 그대로 두고 마지막 기울기·절편만 각 모델의 스탠퍼드 학습 행으로 다시 계산했다. 새 학습은 없고 CPU 추론만 했다. 판단 기준은 [protocol.json](protocol.json)에 결과를 보기 전 고정했다.

## 결론

**사전 기준 세 가지를 모두 통과했다.** 외부 정상 보행의 높은 점수를 유지하면서, 혼합 학습이 만든 스탠퍼드 고득점 악화를 추가 전 수준으로 되돌렸다. 다만 고득점 과소예측 자체가 해결된 것은 아니고, 전체 MAE와 저득점 구간의 악화는 남았다.

| 사전 기준 | 결과 | 판정 |
|---|---|---|
| 스탠퍼드 90 이상 MAE 변화의 95% 상한 ≤ +0.5 | +0.219 | 통과 |
| LIVE 평균 ≥ 90, 직접 촬영 정상 평균 ≥ 90 | 98.83, 94.23 | 통과 |
| 정상−이상 차이 ≥ 12.67, 범위 겹침 없음 | 24.77, 겹침 없음 | 통과 |

## 스탠퍼드 결과

사람별 평균을 다시 사람 수로 평균했다. 괄호는 추가 전 대비 변화량의 사람 재표집 95% 구간이다. 낮을수록 좋다.

| 실제 GDI 구간 | 추가 전 MAE | 혼합 보정 | 스탠퍼드 전용 보정 |
|---|---:|---:|---:|
| 전체 692명 | 6.516 | 6.681 (+0.061~+0.269) | **6.655** (+0.053~+0.224) |
| 90 이상 162명 | 9.757 | 11.169 (+1.133~+1.678) | **9.753** (−0.246~+0.219) |
| 100 이상 36명 | 15.079 | 16.888 (+1.254~+2.302) | **14.714** (−0.962~+0.142) |
| 70 미만 383명 | 7.178 | 7.449 (+0.120~+0.429) | **7.518** (+0.201~+0.489) |

| 전체 지표 | 추가 전 | 혼합 보정 | 스탠퍼드 전용 보정 |
|---|---:|---:|---:|
| 예측 기울기 | 0.566 | 0.490 | **0.557** |
| 상관계수 | 0.744 | 0.730 | **0.731** |
| 예측 표준편차 | 9.17 | 8.09 | **9.18** |

보정은 점수의 눈금만 바꾼다. 그래서 기울기와 표준편차는 회복됐지만 상관계수는 그대로다. 기록 평균 기준 전체 MAE 악화의 95% 구간도 여전히 0보다 크다.

## 외부 자료 결과

| 대상 | 추가 전 | 혼합 보정 | 스탠퍼드 전용 보정 |

| LIVE 정상 아동 9명 | 81.76 | 95.49 | **98.83** (96.33~101.31) |
| 직접 촬영 정상 6편 | 79.35 | 91.52 | **94.23** (86.60~98.23) |
| 직접 촬영 이상 모사 7편 | 66.68 | 69.79 | **69.46** (67.59~72.48) |

| LJMU 64명 | 80.47 | 99.88 | **103.87** |

LJMU는 가정한 100을 넘었다. 건강한 성인의 실제 GDI 계산값 약 93~97과 비교하면 외부 점수가 높은 쪽으로 치우쳤을 가능성이 있다. 외부 자료에 측정 GDI가 없어 정확도는 말할 수 없다.

## 남은 문제

- **고득점 과소예측은 그대로다.** 스탠퍼드 90 이상의 편향은 −9.44점으로 추가 전 −9.50점과 비슷하다. 악화를 되돌렸을 뿐 해결하지 못했다.
- **스탠퍼드와 외부의 차이는 커졌다.** 결과를 본 뒤 추가한 [사후 분석](posthoc-gap.json)에서, LIVE와 같은 나이대의 스탠퍼드 GDI 95 이상 20명(실제 98.79)은 89.27점(86.98~91.36)이었다. LIVE는 98.83점이다.
- **저득점 구간은 나빠졌다.** 70 미만 MAE가 추가 전보다 0.340점 높고, 구간이 0을 포함하지 않는다.

## 한계

- 앞선 진단에서 이 보정의 효과를 이미 봤다. 같은 개발자료의 확인이며 독립 시험이 아니다.
- LIVE와 직접 촬영 영상은 앞선 시험에서 이미 본 자료다.
- 앙상블 비중은 혼합 전 값을 유지했다. 이 조건의 최적값을 찾은 결과가 아니다.
- 입력 변형 시험과 RF는 이 조건에서 다시 하지 않았다.
