# 처음 보는 출처의 정상 보행 시험

2026-11-05. LJMU 정상 보행을 100점으로 넣어 학습한 모델이 **정상 보행 자체를 높게 보는지**, 아니면 **LJMU처럼 보이는 입력만 높게 보는지** 확인한 시험이다. 사용자 승인 후 저장 모델로 CPU 추론만 했다. 새 학습·재보정·가중치 탐색은 없었다.

## 결론

**사전에 정한 기준에서 "정상 보행을 배웠다" 쪽을 지지했다.** 학습에 없던 두 자료의 정상 보행이 모두 90점을 넘었고, 같은 촬영 묶음의 이상 보행 모사는 약 70점에 머물렀다. 시험 전의 주된 해석이던 "LJMU처럼 보이면 100점"은 지지되지 않았다.

다만 스탠퍼드의 실제 고득점자는 여전히 낮다. 이 차이의 원인은 아직 모른다.

후속으로 혼합 보정을 스탠퍼드 전용으로 바꾼 조건은 [별도 기록](stanford-calibration/README.md)에 있다.

## 시험 자료

| 자료 | 규모 | 시험 방식 |
|---|---|---|
| LIVE 정상 아동 | 9명·12기록, 5~10세 | 두 모델 모두 학습에 쓰지 않음. 5개 분할 평균 |
| 직접 촬영 Test01 | 성인 3명·영상 13편 (정상 6, 이상 모사 7) | 두 모델 모두 학습에 쓰지 않음. 5개 분할 평균 |
| LJMU 입력 변형 | 64명·881기록·3,305구간 | 그 사람을 학습에서 뺀 분할 모델로만 평가 |

Kuopio는 시행이 약 1초(100Hz)라 124프레임 입력을 만들 수 없어 제외했다. MoVi는 BODY25 관절이 없고 엄격한 측면 124프레임 구간이 0개라 제외했다.

기준은 [protocol.json](protocol.json)에 결과를 보기 전 고정했다. 모델은 고정 앙상블이다.

LIVE의 사람 간 표준편차는 3.54다. LJMU의 1.18과 달리 개인차가 남았다.

### LJMU 입력을 망가뜨렸을 때

평균은 사람별 평균이고, 변화량의 괄호는 사람 재표집 95% 구간이다.

| 변형 | 추가 전 평균 | 추가 후 평균 | 추가 후 변화량 | 판정 |
|---|---:|---:|---:|---|
| 원본 | 80.47 | 99.88 | - | - |
| 프레임 순서 섞기 | 71.77 | **93.74** | −6.13 (−6.63~−5.67) | 부분 |
| 움직임 제거 (구간 평균 고정) | 67.62 | **71.46** | −28.41 (−28.96~−27.87) | 움직임에 반응 |
| 왼다리 움직임 제거 | 72.40 | **82.96** | −16.91 (−17.25~−16.57) | 움직임에 반응 |
| 양다리 움직임 50% | 73.57 | **79.86** | −20.02 (−20.74~−19.30) | 움직임에 반응 |

왼다리만 고정했을 때 왼쪽 74.82, 오른쪽 91.10으로 고정한 쪽 점수가 더 떨어졌다. 프레임 순서를 섞어도 93.74가 남았으므로, 시간 순서보다 **어떤 자세들이 얼마나 넓게 나타나는지**에 크게 의존하는 것으로 보인다.

변형 입력은 실제 질환이 아니고 학습 범위를 벗어난 입력일 수 있다. 점수 하락만으로 보행의 질을 측정한다는 증거가 되지는 않는다.

## 남은 문제 (결과를 본 뒤 추가한 사후 분석)

[posthoc-gap.json](posthoc-gap.json)에서 LIVE와 나이가 겹치는 스탠퍼드 고득점자를 비교했다.

| 집단 | 실제 평균 GDI | 추가 전 예측 | 추가 후 예측 |
|---|---:|---:|---:|
| 스탠퍼드 같은 나이대, 기록 평균 GDI ≥ 95 (20명) | 98.79 | 88.51 | **87.05** |
| LIVE 정상 아동 (9명, 실제 GDI 없음) | 미측정 | 81.76 | **95.49** |
| 스탠퍼드 성인, 기록 평균 GDI ≥ 90 (7명) | 94.94 | 85.57 | **83.43** |
| 직접 촬영 정상 (영상 6편, 실제 GDI 없음) | 미측정 | 79.35 | **91.52** |

실제 점수가 높은 스탠퍼드 대상보다 외부 정상 보행이 더 높게 나온다. 가능한 설명은 임상 환자의 움직임 특성, 스탠퍼드 촬영·처리 특성, 혼합 점수 보정이다. 이번 시험으로는 구분하지 못했다. 직접 촬영 영상에도 카메라 회전이 있어 "고정 카메라 대 회전 카메라"만으로는 설명하기 어렵다.

## 한계

- 어느 시험 자료에도 측정 GDI가 없다. 정확도가 아니라 **점수의 방향**을 본 시험이다.
- LIVE는 9명, 직접 촬영은 3명이다. 직접 촬영의 영상은 독립 표본이 아니므로 구간을 계산하지 않았다.
- 직접 촬영 라벨 6·8·9번은 이전 점수를 본 뒤 사용자가 정정한 값이다. 이상 모사도 임상 진단이 아니다.
- LIVE와 직접 촬영을 앞으로 모델 선택에 쓰면 더는 "처음 보는 자료"가 아니다.
- RF는 시험하지 않았다.

## 검산

- 체크포인트 지문: CNN 49개, STT 50개, 좌우 결합 STT 30개를 저장 기록과 대조했다. 기록은 `infer-*.json`에 있다.
- 기존 예측 재현 최대 차이(사전 허용 0.005점): LJMU 추가 전 0.000414, LJMU 추가 후 0.0000128, 직접 촬영 추가 전 0.000000376.
- LIVE·직접 촬영의 주요 평균은 별도 계산 경로로 1e-9 이내로 일치했다.
