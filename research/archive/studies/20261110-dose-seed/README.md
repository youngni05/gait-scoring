# 정상 자료 양과 초기값에 따른 정상 추가 모델 변화

논문의 주 모델(CNN·STT 앙상블)을 같은 설계로 다시 학습해 두 가지를 확인한다. 2026-11-10 사용자 요청으로 시작했다.

- **용량-반응:** 정상 성인(LJMU)을 0·4·8·16·32·64명 넣었을 때 정상 보행 점수와 평가자료 오차가 어떻게 변하는가. 논문 표 2의 소량 추가 모델(영상 12개, 영상당 1구간, 학습에만 사용)은 설계가 달라, 같은 설계의 곡선으로 대체하려는 목적이다.
- **초기값 반복:** 기존 모델과 정상 추가 모델을 다른 초기값 2개로 다시 학습해도 같은 방향의 결과가 나오는가.

조건과 판정 기준은 결과 전에 [bundle/study-protocol.json](bundle/study-protocol.json)에 고정했다. 0명·초기값 0과 64명·초기값 0은 이미 있는 논문 모델을 그대로 쓴다.

| 조건 | 정상 성인 | 초기값 |
| --- | --- | --- |
| n4_s0, n8_s0, n16_s0, n32_s0 | 4·8·16·32명 | 기존과 같음 |
| n0_s1, n0_s2 | 0명 | +1000, +2000 |
| n64_s1, n64_s2 | 64명 | +1000, +2000 |

**설계:** 학습 함수·분할·학습 종료 규칙·앙상블 비율은 [논문 모델 학습](../20261104-ljmu100-mixed/README.md)과 같다. 정상 성인은 원래 분할을 유지하고, 분할마다 고정 해시 순서로 돌아가며 뽑는다. 그래서 적은 인원은 많은 인원에 포함된다. 각 학습이 끝나면 평가자료 222명, LIVE 정상 아동·환자, 직접 촬영, 고령자 입력의 출력을 함께 저장한다. 점수 척도는 논문과 같이 뇌성마비 자료 학습자료의 측정 GDI만으로 보정한다.

**GPU 운영:** 작업당 GPU 1개 제한이 있어, 조건·모델 종류·분할마다 작업 하나씩(120개) Slurm 배열로 나누고 동시 실행을 최대 10개로 제한한다. DIS04~06은 제외한다.

## 진행 기록

- CPU 점검: 64명 조건이 논문 학습 자료(1,942기록, 14,566구간)와 일치했다. 4명 조건은 분할 0~3에 1명씩 들어간다.
- 서버 `/abr/RESEARCH_USER/dose-seed-20261110`. 학습 자료는 서버의 논문 학습 자료를 복사했고, 묶음·외부 입력과 함께 지문이 일치했다([preparation.json](preparation.json)).
- GPU 파일럿 51474(DIS02, 2분 37초): CNN·STT·좌우 결합 STT 모두 통과. 저장 모델 재추론 오차 0, 외부 입력 5종 출력 정상. 에폭당 CNN 6.6초, STT 5.8초, 좌우 결합 STT 5.7초(4명 조건).
- 본 학습: 작업 배열 51477(120개, 동시 최대 10개, 작업당 시간 상한 3시간). 예상 작업당 1~2시간, 전체 GPU 약 170시간. 제출 직후 6개가 DIS01·DIS02에서 시작했다. 감시는 이 세션에서 40분 간격으로 한다.
- 본 학습 종료: 120개 작업 모두 COMPLETED(실패 0). 이 세션의 감시는 2026-11-11 02:01(57개 완료) 이후 PC 연결이 끊겨 멈췄지만 학습에는 영향이 없었다. 09:07 조회에서 8개 조건 × 15개 모두 완료를 확인했다.
- 회수: 압축본 1.06GB, 서버와 받은 파일의 SHA-256 일치(`7e9bb284…c4404`). 결과는 `D:/gait-research-data/D_P/dose-seed-20261110/received/runs`.
- 검산([audit.py](audit.py), [audit.json](audit.json)): 체크포인트 600개 모두 완료 기록의 지문과 일치했다. 조건·모델 종류마다 분할 0 최종 모델을 CPU에서 다시 예측한 결과, 저장된 평가용 출력과의 최대 차이는 0.00004점이었다.

## 결과

분석 코드는 [analyze_arms.py](analyze_arms.py), 판정은 [summarise.py](summarise.py), 수치는 [results.json](results.json)에 있다. 점수 척도는 논문과 같이 학습용 환자 자료의 실측 GDI만으로 보정했다. 0명·64명의 원래 초기값(s0)은 논문 모델 값을 그대로 썼다.

**분석 코드 확인:** 초기값만 바꾼 0명 조건은 평가용 MAE 6.233·6.266점, 정상 아동 80.7·82.6점이었다(논문 6.249점, 81.8점). 64명 조건은 6.340·6.345점, 98.9·99.3점이었다(논문 6.375점, 98.8점). 분석 경로가 논문 결과를 재현한다.
