# 뇌졸중 환자의 마비 쪽 다리 구분

**질문:** 학습하지 않은 고령 뇌졸중 환자에서, 모델이 마비 쪽 다리를 다른 쪽보다 낮게 평가하는가? 2026-11-10 사용자 요청으로 실행했다(실험 B). 조건은 계산 전에 [protocol.json](protocol.json)에 고정했고, 수치는 [results.json](results.json), 사람별 값은 [people.json](people.json)에 있다. 새 추론은 없다.

**자료:** Van Criekinge 등(2023)의 뇌졸중 환자 중 모델 점수와 양쪽 다리 재계산 GDI가 모두 있는 41명(오른쪽 마비 13명). 마비 쪽은 병변 위치(왼쪽 병변 → 오른쪽 마비)로 정했다. 모델 입력은 3차원 표지점을 측면 2D로 바꾼 좌표다.

| | 마비 쪽이 더 낮은 사람 비율 (95% 구간) | 마비 쪽 − 반대쪽 평균 (95% 구간) | 재계산 GDI 좌우 차이와의 상관 |
| --- | --- | --- | --- |
| 재계산 GDI (3차원) | 56.1% (41.5~70.7) | −1.60 (−5.10~+1.94) | — |
| 기존 모델 | 65.9% (51.2~80.5) | −1.64 (−2.98~−0.30) | 0.42 (0.12~0.65) |
| **정상 추가 모델** | **80.5% (68.3~92.7)** | **−2.77 (−4.26~−1.24)** | 0.44 (0.14~0.65) |

- 정상 추가 모델은 41명 중 33명에서 마비 쪽 다리를 더 낮게 평가했다. 우연(50%)이라면 이렇게 나올 확률은 약 0.006%다(이항 검정, 사후 계산).
- **사후 비교:** 정상 추가 모델과 기존 모델의 차이는 비율 +14.6%p(95% 구간 +2.4~+26.8), 좌우 차이 −1.14점(−1.87~−0.41)이다. 사전에 정한 비교가 아니므로 사후 결과로 표시한다.
- 3차원으로 재계산한 GDI는 마비 쪽을 56%만 낮게 잡았다. 다리마다 걸음 주기가 몇 개뿐이라 잡음이 크다. 건강 성인의 좌우 차이가 평균 7.0점으로, 모델(2.4~2.5점)보다 훨씬 크다. 따라서 이 비교의 기준은 재계산 GDI가 아니라 임상 정보인 마비 쪽이다.
- 모델 입력은 실제 영상이 아니라 3차원 표지점을 변환한 좌표다.
