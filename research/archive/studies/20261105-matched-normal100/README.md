# 성인·아동 인원과 학습 비중을 맞춘 정상100점 추가 비교

사용자가 요청한 후속 실험이다. 기존에 성인 자료를 많이 넣었을 때 고득점 과소예측이 커진 현상이, 자료량을 통제하고 스탠퍼드 학습자료로만 점수를 보정하면 어떻게 달라지는지 비교한다. 추가한 정상 자료의100점은 실제 측정 GDI가 아닌 가정이다.

## 자료 재검토와 고정한 비교 조건

LIVE 원본 측면46편·23명을 저장된 관절자료로 다시 검색했다. 기존7명10편을 유지하고, 배경 사람 선택을 수정한8세 아동의 보행1편과 영상 후반의 연속 보행을 찾은5세 아동1편을 추가해 **9명12편**을 확보했다. 모두5~10세다. 새 두 구간의 필수 좌표 결측은7.26%,5.65%이며, 기존25% 이하 기준을 통과했다. 움직임 비율은89.52%,95.16%로 기존80% 기준을 통과했다.

새 구간은 실제 시간 순서대로17개 프레임을 뽑아 대상 아동·연속 측면 보행을 눈으로 확인했다. 이는 모든 프레임의 관절 정답을 확인한 검사가 아니다. S03은 화면을 떠난 뒤 배경 사람으로 바뀌는 끝부분을 제외하고 실제726~849프레임을 사용했다. S20은 앞쪽의 불연속 구간 대신577~700프레임을 사용했다. 유사한 다른 S20 영상은 중복 가능성을 보수적으로 취급해 추가하지 않았다. 점프가 섞이거나 보행이 짧은 나머지 영상의 기준을 낮추지 않았다.

성인은64명 중 고정된 문자 해시 순서로9명을 골랐다(seed문자20261105). 예측 결과를 보고 고르지 않았다. 각 아동의 영상 수에 맞춰 대응 성인의 영상 수를 고르고, 성인 영상의 기존 적격 구간 중 가운데124프레임 구간 하나를 사용했다. 두 조건의 추가 사람 수·기록 수·구간 수와 사람별 총 가중치가 같다. 사람을 새로 뽑는 반복 실험까지 한 것은 아니다.

스탠퍼드는 기존 기록별 동일 비중을 유지한다. 추가 사람은 각각 기존 기록1개와 같은 총 비중을 주며, 영상이2편이면 각0.5,1편이면1을 준다. 따라서 두 조건 모두 추가 총 비중은9기록 상당이다. 실제 학습 부분에서 추가 자료의 비중은 안쪽/바깥 분할에 따라1.03~1.44%이며 두 조건에서 정확히 같다. 이는 관측된 경사 크기나 예측 영향의 비율을 뜻하지 않는다.

추가 사람은 모든 학습에 들어가지만 검증·평가에는 들어가지 않는다. 신경망은 매 학습시점과 최종 재학습에서 **스탠퍼드 학습 부분만으로 정답 크기 조정과 공통 선형 보정**을 계산한다. 학습 길이와 RF 설정은 스탠퍼드 내부검증의 전체 사람 평균 MAE로 선택한다. 묶음에서 붕괴한 모델을 제외하는 기존 기준도 스탠퍼드 학습 출력에 적용한다. RF는 기존처럼 별도 선형 보정을 하지 않는다.

일반 다구간 CNN·RF·STT, 주력 CNN 묶음·STT 묶음, 좌우 결합 STT와 기존 고정 앙상블을 비교한다. 기존5개 사람 분할·신경망 구조·초기값 규칙·최대 학습 길이·앙상블 비중은 유지한다. 신경망 본 학습은 조건별75회, 합계150회다. 이전 성인·아동 실험은 수정하거나 중단하지 않는다.
