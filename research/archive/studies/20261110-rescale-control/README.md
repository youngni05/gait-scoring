# 점수 눈금만 늘린 대조군

**질문:** 다시 학습하지 않고 기존 모델 점수의 눈금만 바꿔도 정상 보행을 100점 가까이 올릴 수 있는가? 그렇다면 대가는 무엇인가? 2026-11-10 사용자 요청으로 실행했다. 조건은 계산 전에 [protocol.json](protocol.json)에 고정했고, 수치는 [results.json](results.json)에 있다. 새 학습은 없고, 저장된 기존 모델 예측값만 사용했다.

**결론:** 눈금만 늘려도 정상 아동 점수와 정상·이상 점수 차이는 정상 추가 모델과 비슷하게 맞출 수 있다. 그러나 평가자료 오차가 6.25점에서 13.71점으로 2배 이상 커진다. 정상 추가 모델은 같은 정상 점수에서 오차 증가가 0.13점이다. 따라서 정상 점수의 회복은 다시 학습해야 정확도를 지키며 얻을 수 있다.

- C의 정상−이상 차이는 LIVE 17.5점, 직접 촬영 23.7점, 고령자 20.3점이다. 정상 추가 모델(19.5, 24.8, 19.2점)과 비슷하다. 다만 뇌졸중 고령자는 C에서 80.4점으로 오르고 정상 추가 모델에서는 73.4점에 머물렀다.
