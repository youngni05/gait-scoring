# 기준점 하나로 정상·이상 보행 구분

**질문:** 미리 정한 기준점 하나(90점)로 세 외부 자료의 정상과 이상 보행을 모두 구분할 수 있는가? 2026-11-10 사용자 동의로 실행했다(실험 9). 조건은 계산 전에 [protocol.json](protocol.json)에 고정했고, 수치는 [results.json](results.json)에 있다. 저장된 점수만 사용했다.

**기준점 90점의 의미:** GDI에서 10점은 정상 기준 집단의 표준편차 1배다. 따라서 90점 이상을 "정상 범위"로 본다. 자료마다 기준점을 다시 맞추지 않는다.

| 자료 | 단위 | 기존 모델: 정상을 정상으로 / 이상을 이상으로 | 정상 추가 모델: 정상을 정상으로 / 이상을 이상으로 | 균형 정확도: 기존 → 정상 추가 |
| --- | --- | --- | --- | --- |
| LIVE 아동 | 9·14명 | 0% / 100% | 100% / 85.7% | 0.50 → 0.93 |
| 직접 촬영 | 6·7개 영상 | 0% / 100% | 83.3% / 100% | 0.50 → 0.92 |
| 고령자 | 11·25명 | 9.1% / 100% | 81.8% / 96.0% | 0.55 → 0.89 |
| 합계 | 26·46 | 3.8% / 100% | **88.5% / 93.5%** | **0.52 → 0.91** (0.83~0.97) |

- 기존 모델은 정상 보행 26개 중 1개만 90점을 넘었다. 사실상 모두를 이상으로 판정했다.
- 정상 추가 모델은 같은 기준점으로 정상 23/26, 이상 43/46을 맞혔다. 균형 정확도 차이의 95% 구간은 +0.31~+0.46이다.
- 보조 기준점에서도 같은 방향이다. 85점에서는 0.61 → 0.89, 95점에서는 0.50 → 0.75였다.
- **해석의 범위:** 기존 모델도 자료마다 더 낮은 기준점을 따로 고르면 정상과 이상을 꽤 구분한다(AUC 약 0.9). 이 결과의 의미는 정상 추가 모델에서 "100점 = 정상, 90점 = 표준편차 1배"라는 GDI 눈금의 뜻이 자료가 바뀌어도 그대로 통한다는 점이다.

## 추가 분석: 한 자료에서 정한 기준점을 다른 자료에 옮겨 쓰기

"기존 모델도 기준점만 낮추면 된다"는 반론을 확인하려고 실행했다. 조건은 계산 전에 [protocol-transfer.json](protocol-transfer.json)에 고정했고, 수치는 [results-transfer.json](results-transfer.json)에 있다. 각 모델에 대해 한 자료에서 균형 정확도가 가장 높은 기준점을 고르고, 나머지 두 자료에 그대로 적용했다.

| 모델 | 자료별 최적 기준점 (LIVE / 직접 촬영 / 고령자) | 옮겨 쓴 6가지 경우의 평균 균형 정확도 |
| --- | --- | --- |
| 기존 모델 | 76.6 / 72.6 / 75.0 (폭 4.0) | 0.869 |
| 정상 추가 모델 | 91.1 / 79.5 / 78.7 (폭 12.4) | 0.860 |

- **반론은 막지 못했다.** 기존 모델은 약 75점을 기준으로 쓰면 자료가 바뀌어도 잘 통했다. 두 모델의 차이는 −0.009(95% 구간 −0.080~+0.116)로 구분되지 않는다.
- 정상 추가 모델의 최적 기준점 폭이 더 넓은 것은 직접 촬영 자료처럼 정상과 이상이 완전히 갈리는 자료에서 최적 구간이 넓어, 그 가운데를 고르는 규칙 때문이기도 하다.
- **사용할 수 있는 해석:** 차이는 구분 능력이 아니라 기준점을 어디서 얻느냐에 있다. 기존 모델의 75점은 정상·이상 정답이 있는 자료로 찾아야 하는 값이다. 정상 추가 모델의 90점은 GDI 정의(표준편차 1배)에서 바로 나온다. 따라서 "정상 추가 모델은 기준점 하나로만 구분된다"거나 "기존 모델은 여러 자료에 쓸 수 없다"고 주장하면 안 된다.
