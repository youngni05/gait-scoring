# 보행 정보 추가에 따른 POMA 예측 비교 결과

65세 이상 뇌졸중 대상자 25명에서 **기존 GDI·자체 편차·2D 관절 정보가 속도만 쓴 모델보다 POMA 검사 점수를 더 잘 예측한다는 근거를 확보하지 못했다.** 3D 관절 정보를 추가하면 평균 오차가 3.99점에서 3.77점으로 줄었지만, 개선 폭의 불확실성이 크고 낮은 점수대 오차도 줄지 않았다.

이번 비교는 이전에 관련성을 살펴본 대상자를 다시 사용한 탐색 실험이다. 새 예측을 계산하기 전에 대상자·모델·구간·판정 기준을 고정했다. 임상적으로 검증된 모델이나 독립된 외부 검증으로 해석하지 않는다.

| 입력 | POMA 평균 절대오차 | 속도만 대비 오차 변화 | 변화의 95% 구간 |
|---|---:|---:|---|
| 속도만 | 3.99점 | +0.00점 | +0.00 ~ +0.00 |
| 속도 + 기존 GDI 예측값 | 4.13점 | +0.14점 | -0.04 ~ +0.35 |
| 속도 + 자체 편차 예측값 | 4.30점 | +0.32점 | -0.01 ~ +0.69 |
| 속도 + 2D 관절 정보 | 4.44점 | +0.45점 | -0.49 ~ +1.63 |
| 속도 + 3D 관절 정보 | 3.77점 | -0.22점 | -1.10 ~ +0.71 |
| 속도 + 실제 3D 각도로 계산한 편차 | 4.14점 | +0.15점 | -0.31 ~ +0.62 |
| 속도 + 자체 편차 예측값 · 전체 정상 기준 | 4.37점 | +0.38점 | +0.08 ~ +0.72 |

평균 절대오차는 실제 점수와 예측 점수의 차이를 절댓값으로 평균한 값이다. 변화가 음수이면 속도만 쓴 경우보다 개선된 것이다. 모두 0~28 범위의 POMA 총점을 예측했다. 학습 사람들의 점수 중앙값을 그대로 내는 단순 기준은 5.30점이었다.

표의 구간은 이미 계산된 개인별 예측을 10,000번 다시 뽑아 계산했다. 매번 모델 전체를 다시 학습한 구간이 아니며, 학습 대상자가 겹치는 교차검증의 불확실성을 모두 반영하지 못한다. 주요 추가 조건 세 가지는 다중 비교를 고려한 98.33% 구간도 계산했다. 기존 GDI −0.08~+0.40점, 자체 편차 −0.06~+0.80점, 2D 관절 −0.67~+1.96점으로, 어느 조건도 오차 감소를 뒷받침하지 않았다.

## 실험의 질문과 자료

모델이 답하는 질문은 “이 사람의 보행을 보고 실제 POMA 검사 점수를 얼마나 가깝게 예측하는가”다. 정답은 자료에 기록된 POMA이며, 뇌성마비 GDI나 자체 각도 편차가 정답인 실험과 구분한다. 이 자료에는 이번 비교에 쓸 TUG·SPPB 점수가 없어 두 검사는 예측하지 않았다.


기존 GDI·자체 편차 예측·2D 및 3D 관절 특징은 동일한 124프레임 구간을 사용했다. 30fps 기준 약 4.1초이며, 이전 측면 추적 카메라 투영과 발가락 대체 조건을 유지했다. 구간별 특징을 기록 안에서 평균하고, 기록별 값을 같은 비중으로 평균하여 사람당 한 입력을 만들었다. **속도는 같은 사람의 원자료 세션 평균 속도**이며 이번 영상 구간에서 새로 추정한 속도가 아니다. 실제 각도로 계산한 편차 조건도 세션의 완전한 보행 주기 평균을 사용한 별도 진단 조건이다.

## 학습과 평가 절차

1. 기존 뇌성마비 GDI 모델은 그대로 고정했다. 저장된 구간별 예측을 다시 합쳐 이전 사람별 결과와 일치하는지 확인했다.
2. 자체 편차 모델은 주평가 대상 25명을 전부 제외한 33명으로 새로 학습했다. 33명은 정상 16명·뇌졸중 17명이다. 2D 관절 특징에서 정상 기준과의 각도 차이를 예측하는 작은 회귀 모델이다. 이전 134명 모델의 예측을 그대로 가져오지 않았다.
3. 자체 편차의 정상 기준은 65세 이상 정상 40명의 3D 각도 곡선이다. 전체 정상 138명은 보조 비교로만 사용했다. 정상 학습자의 정답을 만들 때 자기 자신은 기준에서 제외했고, 내부 검증 대상 정상인도 해당 학습 기준에서 제외했다. 정상 40명과 POMA 평가 대상 25명은 겹치지 않는다.
4. POMA 모델은 25명 중 한 사람을 빼고 나머지 24명으로 학습한 뒤, 뺀 사람을 예측했다. 이를 25번 반복했다. 여러 보행 기록이 있는 사람도 항상 한 묶음으로 처리했다. 정상인의 POMA 점수를 임의로 만들어 넣지 않았다.
5. 모델 설정은 매번 학습 대상 24명 안에서 다시 네 묶음으로 나누어 선택했다. 속도는 직선·2차·3차 곡선 관계를 모두 후보로 두었다. 추가 특징이 많아 과도하게 영향을 주지 않도록 입력 묶음의 크기를 보정하고, 계수 크기를 제한하는 회귀를 사용했다.
6. 평균 오차·개인별 오차 변화·점수대별 오차·5점 넘는 큰 오차를 비교했다. 2D 관절 정보를 사람끼리 뒤섞는 대조 조건도 다섯 번 실행했다. 결과를 본 뒤 특징이나 모델 후보를 추가 탐색하지 않았다.

자체 편차 모델의 보조 학습 인원이 이전보다 줄었으므로, 이번 결과를 이전 모델 자체가 열등하다는 판정으로 바꾸면 안 된다. 이번 재학습의 목적은 평가 대상자가 앞단 학습에 포함되지 않는 비교를 만드는 데 있다.

## 관절 정보와 3D 비교의 의미

2D·3D 모두 같은 고관절·무릎·발목 위치를 사용했다. 골반 중앙을 기준으로 맞추고 허벅지 길이로 크기를 보정한 뒤, 관절 위치·무릎 각도·양 발목 간격의 분포와 변화량, 좌우 차이, 무릎 움직임의 반복성을 계산했다. 2D 특징은 133개, 3D 특징은 181개다. 2D에는 발가락 대체 지점을 넣지 않았다. 기존 GDI 예측에는 이전 발가락 대체 조건이 그대로 남아 있다.

약 4초의 짧은 입력에서 계산한 반복성은 발뒤꿈치 접지 시점이나 임상 보행 주기를 확정한 값이 아니다. 접지 단계별 곡선과 여러 주기에 걸친 불규칙성은 이번에 검증한 특징에 포함하지 않았다. 더 긴 보행과 접지 시점 확인이 필요한 후속 항목이다.

3D 조건의 오차는 2D보다 0.67점 작았지만, 차이 구간은 −1.49~+0.09점이었다. 따라서 “2D 투영 때문에 성능이 떨어졌다”는 결론도 아직 확정할 수 없다. 두 조건은 좌표 차원과 특징 수가 다르며 모델도 작은 표본으로 학습했다.

실제 3D 각도로 편차를 직접 계산해 넣어도 오차는 4.14점이었다. 따라서 편차 점수의 예측 오차만 고치면 POMA 예측이 해결된다는 근거도 없다. POMA와 다른 목적의 정상 이탈 정도를 하나의 수치로 압축한 데서 한계가 생겼을 가능성은 후속 검토 대상이다.

2D 정보를 사람끼리 뒤섞은 대조 실험의 평균 오차는 4.08~4.50점이었다. 원래 연결의 4.44점이 뚜렷한 우위를 보이지 않았다. 이 검사는 속도와 관절 정보의 원래 관계도 깨뜨리므로, 속도를 통제한 정식 유의확률로 해석하지 않는다.

## 낮은 점수대와 큰 오차

아래 점수대는 오류를 보기 위한 구분이며 검증된 낙상 위험 등급이 아니다.

| 조건 | POMA 0~18 · 13명 오차 | POMA 19~24 · 9명 오차 | POMA 25~28 · 3명 오차 | 전체 5점 초과 오차 | 전체 최대 오차 |
|---|---:|---:|---:|---:|---:|
| 속도만 | 4.10 | 3.49 | 5.02 | 7/25명 | 13.92 |
| 속도 + 기존 GDI 예측값 | 4.15 | 3.69 | 5.37 | 8/25명 | 14.97 |
| 속도 + 자체 편차 예측값 | 4.34 | 3.59 | 6.32 | 7/25명 | 14.27 |
| 속도 + 2D 관절 정보 | 5.17 | 2.86 | 6.03 | 8/25명 | 13.53 |
| 속도 + 3D 관절 정보 | 4.28 | 2.70 | 4.77 | 7/25명 | 12.46 |

3D 조건은 전체 평균이 조금 좋아졌지만 POMA 0~18 집단에서는 오차가 4.10→4.28점으로 늘었다. 이 집단 13명 중 2명을 18점 초과로 예측했고, 18점 초과인 12명 중 3명을 18점 이하로 예측했다. 속도만 쓴 조건의 해당 수는 각각 0명·4명이었다. 높은 점수대는 3명뿐이므로 평균을 안정적인 성능으로 해석하기 어렵다.

개인별 차이를 놓치는 사례도 남았다. TVC38은 속도 0.225m/s·실제 POMA 8점, TVC47은 0.239m/s·실제 28점이었다. 속도만 쓴 예측은 각각 15.27점·14.08점이고, 3D를 추가한 예측도 20.46점·16.67점이었다. 비슷한 속도에서 크게 다른 기능 상태를 이번 모델이 충분히 구별하지 못했다. 이 사례는 결과 확인 후 설명용으로 고른 것이며 모델 조정에 쓰지 않았다.

## 확인 범위와 다음 실험

현재 확인한 것은 선택된 고령 뇌졸중 대상자 25명에 대한 모의 카메라 입력 비교다. 실제 RGB 영상에서 관절을 찾는 오차·가림·촬영 환경 변화는 반영하지 않았고, 일반 고령자 전체에 대한 성능을 입증하지 않았다. C3D의 가상 관절점과 RGB에서 찾는 관절점의 완전한 해부학적 동일성은 이번 실험으로 검증하지 않았다. 기존 GDI 입력의 발가락 위치 대응과 원 학습자료 시간축 문제도 해소된 것이 아니다. 불확실한 원자료 GDI를 정확도 정답으로 사용하지 않았다.

다음 우선순위는 같은 기능 점수에 연결된 사람 수를 늘리고, 속도가 비슷해도 점수가 다른 사람들을 충분히 포함하는 것이다. 3D 관절의 작은 평균 개선은 후보로 남기되 낮은 점수대 오류와 함께 재검증해야 한다. TUG·SPPB 예측으로 확장하려면 해당 검사 점수와 연결된 자료를 별도로 사용해야 한다. 장시간 반복성·회전·일어서기 정보는 실제 관측 자료와 정답이 있을 때 새 계획으로 검토한다.

## 실행과 검산 기록

CPU에서 비교를 완료했다. 기존 GDI 모델 가중치는 바꾸지 않았으며, 취소된 GPU 학습이나 감시 예약을 재시작하지 않았다. POMA용 저장 모델 175개와 자체 편차 모델 2개의 예측을 다시 실행했다. 원래 특이값 분해 계산과 독립된 선형방정식 계산을 대조했고, 내부 설정 선택 18,000회 및 편차 모델 내부 선택 30회, 사람 분리, 정상 기준, 해시, 점수대별 오차와 불확실성을 검산했다. 최대 재추론 차이는 약 2.15×10⁻¹²점이었다.
