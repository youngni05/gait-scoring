# 정상 아동 100점 가정 — 학습에만 추가

실제 GDI가 높은 스탠퍼드 평가 대상의 과소예측이 줄어드는지 확인하는 탐색 실험이다. 정상 아동의 100점은 측정값이 아니라 실험용 가정이다.

## 현재 결과

## 자료와 비교 방법

- 스탠퍼드 692명·1,061기록·11,261구간의 입력, 정답, 기존 5개 사람 분할을 그대로 유지했다.
- LIVE-GaitNeuroKids에서 이전에 대상 아동 추적을 검토한 16명·31편을 출발점으로 삼았다. 전체 원본의 모든 구간을 복구한 결과는 아니다.
- 전체 영상에서 움직임이 많은 124프레임 후보를 찾고, 영상으로 직선 측면 보행을 확인했다. 점프나 불연속 장면이 포함된 후보를 제외하고 기존 전처리를 통과한 **5~10세 7명·10편·10구간**을 이번 실험에 넣었다.
- 일부 구간에는 화면 진입·퇴장 때 가림이 남는다. 필수 좌표의 결측 비율은 약 2~22%이며, 기존의 25% 이하 허용 기준과 보간을 그대로 적용했다. 시간을 늘리거나 다른 보행을 이어 붙이지 않았다.
- 아동은 각 바깥 분할의 재학습과 네 개 안쪽 학습에 모두 포함한다. **모든 검증·평가는 스탠퍼드만 사용한다.** 아동의 100점 오차로 학습 길이나 설정을 고르지 않는다.
- 자료를 복제하거나 가중치를 올리지 않았다. RF는 기록·좌우 다리를 같은 비중으로 학습하며, 신경망은 기존 기록별 동일 비중 손실을 유지한다.
- 일반 다구간 CNN, RF, STT, 주력 CNN 묶음·STT 묶음, 좌우 결합 STT, 기존 고정 앙상블을 비교한다. 신경망의 설정·초기값 규칙·학습 길이 선택 방식과 앙상블 비중을 유지한다.

높은 구간은 사람 평균이 아니라 **실제 기록별·다리별 GDI가 90점 또는 100점 이상인지**로 고른다. 해당 오차를 사람 안에서 평균한 뒤 사람을 같은 비중으로 평균한다. 90점 이상은 162명·194기록·255개 다리 관측, 100점 이상은 36명·39기록·44개 다리 관측이다. 두 구간은 중첩된다. 같은 사람의 전후 차이를 10,000번 다시 뽑아 불확실성을 계산했다.

아동은 7명뿐이고 13세 전후보다 어리다. 카메라도 고정식이다. 결과가 좋아지더라도 100점 가정의 진실성이나 정확한 연령 일치 효과를 입증하지 않는다. 성인 LJMU 실험과는 추가 자료량과 검증 포함 방식도 다르다.

## 검증과 보관

실제 학습 코드의 모든 25개 분할에서 아동이 학습에만 포함되는지 검사했다. 스탠퍼드 배열은 원본과 일치했다. RF는 저장된 후보 점수로 선택을 재구성하고, 저장 모델을 다시 불러와 예측했다. 최대 차이는 2.85×10⁻¹⁴점 이하였다.

초기 `rf-protocol.json`의 설명 일부에 신경망 OLS 보정과 이전 LJMU 평가 문장이 잘못 남았다. 실제 RF 코드는 보정 없이 숲의 출력값을 사용했고, 평가는 스탠퍼드에만 했다. 실행 설정·모델·예측은 변경하지 않고 초기 지문을 보존했으며, 설명 정정은 `rf-audit.json`에 기록했다.

작은 기록은 이 폴더, 특징·모델·전송 묶음은 `D:/gait-research-data/D_P/child100-train-only-20261105`에 있다. `child-membership.json`은 선정 구간과 원본 지문, `comparison.json`은 전후 수치, `rf-audit.json`은 검산 결과, `bundle/study-protocol.json`은 비교 조건을 담는다. 실행 묶음은 약 39MB이며 관절 특징·나이·익명 번호·라벨·코드만 포함한다. 원본 영상은 포함하지 않는다.
