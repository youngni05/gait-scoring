# 직접 촬영·고령자 비교의 통계 보강

**질문:** LIVE 아동에서 확인한 "정상 보행이 이상 보행보다 더 많이 오른다"는 결과가 직접 촬영 영상과 고령자 자료에서도 우연을 넘어서는가? 2026-11-10 사용자 요청으로 실행했다. 조건은 [protocol.json](protocol.json), 수치는 [results.json](results.json)에 있다. 저장된 점수만 사용했고 새 추론은 없다.

| 자료 | 단위 | 정상 상승 | 이상 상승 | 상승 차이 (95% 구간) | 정상−이상 차이: 기존 → 정상 추가 | AUC: 기존 → 정상 추가 |
| --- | --- | --- | --- | --- | --- | --- |
| 직접 촬영 | 영상 6·7개 | +14.87 | +2.77 | 12.10 (9.13~14.83) | 12.67 → 24.77 | 1.000 → 1.000 |
| 고령자 | 사람 11·25명 | +9.89 | +1.48 | 8.41 (4.54~12.25) | 10.81 → 19.22 | 0.909 (0.80~0.98) → 0.949 (0.87~1.00) |

- 두 자료 모두 상승 차이의 95% 구간이 0을 포함하지 않는다. LIVE 아동의 결과(−10.20점, 95% 구간 −14.50~−5.93점, 이상 상승−정상 상승 방향)와 같은 방향이다.
- 직접 촬영 영상은 성인 3명에게서 나왔다. 그래서 구간은 영상 단위 재표집이며, 사람 단위의 불확실성은 반영하지 못한다.
- 직접 촬영 자료의 AUC는 기존 모델에서도 이미 1.0이었다. 정상 추가 모델의 효과는 구분 여부가 아니라 점수 수준과 차이 크기로 나타난다.
