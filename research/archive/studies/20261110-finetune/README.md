# 기존 모델에서 출발하는 짧은 추가 학습

**질문:** 처음부터 다시 학습하는 대신, 이미 있는 기존 모델에 정상 성인 영상을 섞어 짧게 더 학습하면 환자 정확도를 덜 잃으면서 정상 보행 점수를 회복할 수 있는가? 2026-11-10 사용자 요청으로 시작했다(실험 C). 조건과 판정 기준은 결과 전에 [bundle/study-protocol.json](bundle/study-protocol.json)에 고정했다.

**설계**
- 학습 자료, 분할, 초기값, 앙상블 비율은 논문의 정상 추가 모델과 같다.
- 각 모델은 같은 분할의 기존 모델 가중치에서 출발한다. 그래서 학습에 쓰인 뇌성마비 자료의 사람이 같고, 검증·평가 대상자는 한 번도 학습되지 않는다.
- 학습률은 원래의 0.1배다. 최대 학습 길이는 CNN 30에폭, STT 40에폭이다.
- 학습 종료 시점은 남아 있는 기존 내부 모델의 검증 곡선으로 고른다. CNN 분할 0은 내부 모델이 3개뿐이다. 좌우 결합 STT는 기존 내부 모델이 없어, 같은 분할 STT가 고른 시점을 따른다.
- 점수 척도는 논문과 같이 뇌성마비 자료의 측정 GDI만으로 보정한다.

**판정 기준(사전 고정)**
- 평가자료 오차 증가가 논문의 정상 추가 모델(+0.126점)보다 작은가.
- LIVE 정상 아동과 직접 촬영 정상 보행의 평균이 90점 이상인가.
- 세 외부 자료에서 정상−이상 차이가 기존 모델보다 큰가.

## 진행 기록

- 이 PC 점검: 정상 성인을 더해도 목표값 눈금(최소·최대)이 세 모델 종류 모두 기존 모델과 같았다. 기존 체크포인트는 54개다(CNN 24, STT 25, 좌우 결합 STT 5).
- 서버 `/abr/RESEARCH_USER/finetune-20261110`. 학습 자료·외부 입력은 용량-반응 실험과 같은 파일이며, 지문이 일치했다([preparation.json](preparation.json)).
- GPU 파일럿 51574: 세 모델 모두 통과. 학습 시작 시점의 모델 출력이 기존 모델과 같았다(최대 오차 0). 에폭당 CNN 6.4초, STT 5.7초, 좌우 결합 STT 8.5초.
- 본 학습: 작업 배열 51607(10개, 작업당 시간 상한 1시간 30분). CNN은 분할마다 1개, STT와 좌우 결합 STT는 분할마다 1개 작업에서 차례로 학습한다.
- 회수: 10개 작업 모두 정상 종료(작업당 13~25분). 15개 분할·모델 조합 완료. 서버 압축본과 받은 파일의 SHA-256 일치(`1d9d976e…423e9c`). 결과는 `D:/gait-research-data/D_P/finetune-20261110/received/runs`.
- 고른 학습 길이: CNN 14~26에폭(최대 30). STT와 좌우 결합 STT는 4개 분할이 최대 40에폭, 1개 분할이 39에폭으로, 거의 최대 길이에서 멈췄다. 더 길게 학습했다면 결과가 달라졌을 수 있다.

## 결과

분석 코드는 [../20261110-dose-seed/analyze_arms.py](../20261110-dose-seed/analyze_arms.py)이며, 점수 척도는 논문과 같이 뇌성마비 자료의 실측 GDI로만 보정했다.

**사전 기준 판정**
- 정확도(오차 증가가 +0.126보다 작음): **실패.** 짧은 추가 학습의 오차 증가가 더 컸다.
- 정상 점수 90 이상: 통과(정상 아동 95.8, 성인 촬영 정상 92.0).
- 세 자료의 정상−이상 차이가 기존 모델보다 큼: 통과(16.7, 21.9, 18.2. 기존은 9.4, 12.7, 10.8).

**해석:** 기존 모델에서 출발해 짧게 더 학습해도 정상 보행 점수는 회복되었지만, 환자 정확도 손실은 처음부터 다시 학습할 때보다 줄지 않았다. 정상 점수의 상승도 조금 작았다.

**확인 범위:** 이 분석 코드는 아직 논문 모델의 수치를 그대로 재현하는지 대조하지 못했다. 같은 설계의 초기값 반복 결과(n64_s1·s2)가 나오면 논문 값과 가까운지 함께 확인한다.
