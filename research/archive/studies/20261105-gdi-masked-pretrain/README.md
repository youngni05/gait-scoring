# 일반 CNN·STT의 정상100 추가와 가려진 좌표 복원 사전학습 비교

사용자가 승인한 A~D 비교다. 성인 LJMU9명12편과 아동 LIVE9명12편은 기존 비중 통제 실험에서 정한 동일 표본을 사용한다. 스탠퍼드692명1061기록의 사람 분할과 입력은 그대로 유지한다. 외부 정상자료는 평가에 들어가지 않는다. 보호된 최종223명 자료는 열지 않는다.

## 현재 상태

이 실행본은 파일럿 실패 원본으로 보존한다. CNN35917은 사전학습의 CUDA 선형 보간 역전파가 결정적 실행을 지원하지 않아 종료코드1로 중단됐다. STT35918은 정상 종료했지만 이 실행본으로 본 학습은 제출하지 않았다. 후속 실행은 [수정 실행본](../20261105-gdi-masked-pretrain-v2/README.md)에서 진행한다. 데이터·모델 구조·학습 조건을 유지하고 선형 보간을 고정 행렬곱으로 계산하도록 수정했다. 재현성 옵션을 해제하거나 허용오차를 완화하지 않았다.

2026-11-05 15:50 KST: 약39.5MB 실행 묶음의 전송·파일럿·본 학습을 사용자가 명시적으로 승인했다. 서버/로컬 묶음 지문 일치 후 CNN파일럿35917·STT파일럿35918을 제출했다. 본 학습은 파일럿 회수·CPU 재추론 검산 이후에만 제출한다. 현재 최종 MAE 결과는 없다.

관측 마스크 준비와 로컬 사전 검사는 완료됐다. 원본 Stanford JSON을 다시 읽어 기존 선택 규칙과 프레임 연결대로 실제 검출 좌표를 표시했다. 전체 좌표의94.84%가 복원 정답에 사용할 관측 좌표다. 보간·누락 좌표는 복원 오차에서 제외하지만 원래 GDI 입력은 바꾸지 않는다. 유효한 관측 표시가 해부학적 좌표 정확도를 보증하는 것은 아니다.

자동 승인 검토가 최초 전송을 새 민감자료 묶음의 명시적 승인 부족으로 거절했고, 이후 사용자가 해당 묶음의 학교 GPU 전송·학습을 명시적으로 승인했다. 미승인 우회 전송은 하지 않았다. 묶음에는 기존 관절 특징·스탠퍼드 GDI·익명 번호·관측 여부 마스크·코드만 있고 RGB영상은 없다.

## 고정 조건

| 조건 | 사전학습 | GDI 학습 |
| --- | --- | --- |
| A | 없음 | Stanford만 |
| B 성인 / B 아동 | 없음 | Stanford + 해당 정상자료의 가정100 |
| C | 해당 외부 분할의 Stanford 학습 사람만, 점수 없이 좌표 복원 | Stanford만 |
| D 성인 / D 아동 | C의 자료 + 해당 정상자료, 점수 없이 좌표 복원 | Stanford만 |

A·C는 성인/아동 비교의 공통 모델이므로 중복 학습하지 않는다. 모델2종×조건6개×바깥5분할로 GDI학습60회다. 이 중 C·D의30회에는 각각2000업데이트 사전학습이 붙는다. 주력 묶음·좌우 결합 STT·RF·앙상블은 이번 범위에 포함하지 않는다.

기존 A의 Stanford 내부검증에서 선택한 학습 길이를 모든 조건에 공통 적용한다. CNN은 분할0~4에78·90·95·76·76회, STT는115·108·157·139·183회다. 이번 조건별 내부 탐색은 추가하지 않는다. 과거 저장 모델을 그대로 A로 쓰지 않고 모두 새로 초기화하여 학습한다. 동일 모델/분할 내 GDI업데이트 수·예제 수·배치 크기·초기값·학습률 일정은 같다. CNN과 STT 사이의 업데이트 수까지 같다는 뜻은 아니다.

A/C/D는 같은 Stanford 예제 순서와 기존 기록별 동일 비중 손실을 쓴다. B는 Stanford+정상 구간을 섞고, 매 학습시점에 Stanford만의 예제 수만큼 비복원 추출해 총 학습량을 맞춘다. 정상 사람마다 기록1개와 같은 총 비중을 주며 반복 영상은 그 비중을 나눈다. 따라서 B는 과거의 모든 혼합 구간을 매번 사용하는 실험과 완전히 같은 조건은 아니고, 이번의 학습량 통제 조건이다.

C/D의 사전학습은2000업데이트×32개 좌우 구간쌍으로 고정한다. 사람→기록→구간 순서로 균등 추출한다. D는 같은 Stanford 추출 위치 일부를 정상 사람으로 대체하며 확률은9/(해당 Stanford 학습 사람 수+9)다. 성인·아동의 대체 위치와 횟수는 같다. C/D의 전체 사전학습 예제 수는 같지만, A/B에는 사전학습이 없으므로 두 단계 전체 연산량까지 같지는 않다.

각124프레임을31프레임씩 네 구역으로 나눠 구역마다 연속8프레임을 가린다. 총32/124프레임이며 양쪽 다리의 같은 시점을 가린다. CNN의 좌표·파생 각도·거리도 모두 함께 가린다. 좌표 복원 부분은 사전학습 후 버리고 기존 특징 추출 부분만 이전한다. GDI 출력 부분은 모든 조건에서 같은 초기 가중치를 갖는다. 전체 특징 추출 부분도 GDI 학습에서 함께 갱신한다.

복원 정답은 기존 전처리된2D좌표 중 원본이 관측된 부분이다. 원래부터 누락·보간한 좌표는 손실에서 제외한다. 복원 오차의 좌표별 크기 조정도 Stanford 학습 좌표만 사용한다. 사전학습 함수에는 GDI 배열 자체를 전달하지 않으며, 저장 데이터에서 외부 점수는 NaN이다. B 학습 단계에서만 명시적으로100을 생성한다.

## 평가와 검산

모든 평가는 동일한 Stanford 실제 GDI에 대해 수행한다. 전체·실제 기록/다리GDI≥90·≥100·<70에서 한 사람의 해당 관측 오차를 먼저 평균하고 사람을 같은 비중으로 평균한다. MAE,과소예측량mean(max(정답−예측,0)),평균 편향,과소예측 비율을 보고한다.90점 이상162명,100점 이상36명이며 두 집단은 중첩된다.

주 비교는 C−A(사전학습 전략),D−C(외부 정상자료의 추가 효과),D−B(활용 방식),D아동−D성인이다. 사람별 대응 재표집10000회로95% 구간을 계산한다. 보정 전 예측도 보조 결과로 보존하며, 주 결과는 Stanford 학습자료만의 공통 선형 보정 후 값이다. 결과를 보고 점수 자르기·구간 제외·가중치 변경을 하지 않는다.

사전검사는60개 조건/분할의 사람 분리·동일 업데이트 수·동일 예제 수, 가린 값을 바꿔도 복원 출력이 같다는 검사, 유한 기울기, 특징 이전 시 GDI 출력층 불변을 통과했다. GPU파일럿에서는 실제 두 단계 학습과 저장을 확인하고 별도 CPU 재추론으로 검산한다. 본 학습도60개 모델을 모두 회수·파일 지문 대조·재추론·보정 재계산한 뒤 비교표에 포함한다.

고정한 단일 초기값 일정과 정상 표본1개를 사용하는 개발 비교다. 반복 초기값·정상 표본 재추출의 불확실성은 포함하지 않는다. 촬영·연령·질환 분포 차이가 남으며, 순수 나이 효과나 임상 정확도 검증으로 해석하지 않는다.

작은 코드·기록은 이 폴더, 특징·전송 묶음·수신 모델은 `D:/gait-research-data/D_P/gdi-masked-pretrain-20261105`에 보존한다. `bundle/protocol.json`과 `epoch-provenance.json`이 비교 조건·학습 길이의 근거다. `ops.py`는 한 번의 제출/조회/회수 후 종료하며 반복 감시나 새 예약을 만들지 않는다. 기존 실험과 GPU확보 대기는 변경하지 않는다.
