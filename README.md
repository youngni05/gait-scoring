# gait-scoring

# 어르신 보행 분석 및 기록 관리 시스템

## 서비스 개요

어르신의 보행 영상에서 관절 좌표를 추출하고, AI 기반 보행 분석과
측정 기록 관리를 지원하는 시스템입니다.

복지사가 어르신의 정보를 관리하고 보행 측정 결과를 확인하며,
이전 기록과 비교해 보행 상태의 변화를 살펴볼 수 있도록 돕는 것을 목표로 합니다.

원본 영상은 서버로 전송하지 않고 앱에서 추출한 관절 좌표를 활용하도록 설계합니다.
현재 보행 편차 지수(GDI) 예측을 중심으로 AI 모델을 연구하고,
모바일 영상 처리와 백엔드 기능을 개발하고 있습니다.

## 프로젝트 배경

어르신의 보행 상태를 지속적으로 살펴보기 위해서는 한 번의 평가뿐 아니라
측정 결과를 기록하고 이전 상태와 비교할 수 있는 환경이 필요합니다.
그러나 정해진 검사를 준비하고 반복 수행하는 과정은
측정 대상자와 담당자 모두에게 부담이 될 수 있습니다.

본 프로젝트는 이러한 부담을 줄일 수 있는 방법으로
카메라로 촬영한 보행 영상의 활용 가능성에 주목했습니다.
영상에서 추출한 관절 움직임으로 보행 상태와 관련된 평가값을 추정하고,
측정 기록을 관리하는 시스템을 구현하고자 합니다.

이를 통해 복지 현장에서 어르신의 보행 상태를 살펴보고
변화를 추적하는 업무를 지원하는 것을 목표로 합니다.

## 백엔드 실행과 API 연동

FastAPI·PostgreSQL 백엔드의 Docker 실행, 환경변수, 마이그레이션 및 최초 복지사 계정 생성은
[백엔드 README](backend/README.md)를 참고하세요. 요청·응답 예시는 [API 명세](docs/API_SPEC.md)에 있습니다.

현재 로그인, 어르신 등록·조회·수정, 관절 좌표 저장, 촬영 목록·저장된 분석 결과 조회를 제공합니다.
앱에서 좌표를 추출하며 원본 영상은 서버로 보내지 않습니다. AI 실행·분석 결과 자동 저장은 아직 연결되지 않았습니다.

신규 앱은 `processing_metadata`와 `Idempotency-Key`를 함께 보내는 `processing-2` 계약을 사용합니다.
분석 시작 시각을 저장하며 한국 시간 기준 분석 시작일의 만 나이를 계산합니다.
디자인 화면의 실제 API 연결과 실행 방법은 [프론트 연동 안내](docs/integration/design-ui-api.md)를 참고하세요.
기존 4필드 요청은 호환용으로 유지되며 중복 제출 방지가 없습니다. 두 요청의 검증·오류·재시도 차이는
[API 명세의 측정 저장](docs/API_SPEC.md#7-촬영관절-좌표-기록-저장)과 [신규 계약](docs/API_SPEC.md#12-processing-1-측정-저장-계약)에 정리했습니다.

AI 모듈 연동에서 확정된 요구사항과 남은 논의는 [AI–백엔드 협의 문서](docs/AI_BACKEND_INTEGRATION_DISCUSSION.md)를 참고하세요.

원본 영상·개인별 좌표·정답·예측·학습 중간 파일은 공개 대상에서 제외했다. 선별 목록은 기존 고정 모델과 비교 후보를 구분한 것이며, 임상 사용을 확정한 최종 모델의 선언은 아니다. 보관한 각 실험의 상태는 해당 문서의 마지막 확인 시점을 따른다. 아래 과거 안내의 연구 중단·공개 범위 표시는 당시 기록이다.

**대학 과목 제출을 위한 비상업적 연구 결과를 공유하는 저장소다.** 원자료·기존 코드·모델의 출처별 이용 조건은 [출처·라이선스·수정 안내](research/licenses/README.md)를 따른다. 같은 안내와 관련 라이선스 원문을 각 모델 압축에도 동봉했다.

카메라로 촬영한 보행 정보에서 상태 관련 평가값을 추정할 수 있는지 연구하는 프로젝트다. 정해진 검사를 준비하고 반복 수행하는 부담을 줄이고, 장기적으로 결과 기록과 이전 상태 비교를 지원하는 시스템을 목표로 한다.

현재 연구의 중심은 **GDI(보행 편차 지수) 예측**이다. SPPB·TUG 예측은 이전에 진행한 탐색 연구이며, GDI 중심으로 방향을 전환해 **현재 후속 실험을 중단한 상태**다. 완료한 실험의 코드·결과·모델은 연구 이력으로 보존한다. 일상 촬영·고령자 현장 적용·개인의 시간에 따른 변화 감지까지 검증한 상태는 아니다.
